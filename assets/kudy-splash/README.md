# Вектарны цмок для экрана ўваходу

`dragon-paths.json` захоўвае SVG-контуры, атрыманыя з прынятай іконкі
`assets/kudy-icon/icon.png`. Гэта часткі твару, рогаў, вачэй, мордачкі,
дзвюх лап і рамкі. Кожная частка мае свой колер, шлях `d` і пры патрэбе
трансфармацыю. Частка контураў выкарыстоўвае зыходныя каардынаты 5120 × 5120,
а дапрацаваныя дэталі — каардынаты 1024 × 1024. Абводка вачэй, рогі і лапы
застаюцца вектарнымі.

Рух і парадак з'яўлення частак задае `components/animated-splash.tsx`.
Контуры застаюцца вектарнымі для наступных анімацый. Яны паходзяць з
растравай іконкі, таму павелічэнне не дадае дэталяў, якіх няма ў крыніцы.
Сістэмная застава Expo па-ранейшаму выкарыстоўвае прынятую іконку з
`app.json`.
