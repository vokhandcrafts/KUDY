# DQ-13 — Storybook React Native on the device

## Epic

Epic: #908

## Goal

The owner can browse and tweak component states on the phone from the same stories the specimen screen uses (spec §4.4).

## Sources

Spec: `docs/specifications/design-qa/2026-10-30-design-qa-system.md` (sections cited per criterion). Canon: `docs/design/visual-language.md`; decision register: `docs/design/brand/decisions.md` (only rows marked accepted are rules). Record the git commit the sources were read at.

## Acceptance criteria

1. [ ] Install `@storybook/react-native` 10.7.0 and the matching `storybook` core at exact versions at least two weeks old; first verify compatibility with `metro.config.js`, `npm run arch:check` and the Expo 54 dev client; on a conflict stop and report.
2. [ ] Storybook is enabled only in dev builds through an environment variable; a test proves the production bundle contains no Storybook module.
3. [ ] Telemetry is disabled; websockets remote control and the Storybook MCP server are not enabled.
4. [ ] The guide-card stories from DQ-02 appear in Storybook on the emulator without a second definition of states.

## Out of scope

Web Storybook and external visual services (rejected in spec §4.4); stories for other components.

## Dependencies

Blocked-by: #911

## Proof

The production-bundle test; Showboat demo with a screenshot of Storybook on the emulator.
