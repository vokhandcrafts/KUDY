# DQ-12 — Preflight HTML mockups against the canon

## Epic

Epic: #908

## Goal

A mockup is checked against the canon before development, the way `test/map-05-specimen.test.mjs` checks MAP-05 (spec §2, §7).

## Sources

Spec: `docs/specifications/design-qa/2026-10-30-design-qa-system.md` (sections cited per criterion). Canon: `docs/design/visual-language.md`; decision register: `docs/design/brand/decisions.md` (only rows marked accepted are rules). Record the git commit the sources were read at.

## Acceptance criteria

1. [ ] One reusable check: colors in a mockup come from canon tokens of the matching theme; contrast pairs hold; state names come from the canon; interface text references existing localization keys.
2. [ ] MAP-05's test uses the shared check without losing any of its current assertions.
3. [ ] A seeded mockup with an off-canon color and an unknown state fails with a readable message.

## Out of scope

Judging mockup aesthetics.

## Dependencies

Blocked-by: #912

## Proof

The seeded-mockup test fails when the shared check is reverted.
