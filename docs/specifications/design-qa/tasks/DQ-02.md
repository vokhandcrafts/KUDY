# DQ-02 — Guide-card stories and the dev-only specimen screen

## Epic

Epic: #908

## Goal

Component states are written once, as Storybook CSF stories, and a dev-only screen renders them for stable screenshots (spec §4.4, §8.1).

## Sources

Spec: `docs/specifications/design-qa/2026-10-30-design-qa-system.md` (sections cited per criterion). Canon: `docs/design/visual-language.md`; decision register: `docs/design/brand/decisions.md` (only rows marked accepted are rules). Record the git commit the sources were read at.

## Acceptance criteria

1. [ ] `components/guide-card.stories.tsx` defines CSF stories for the guide card with access badges `free`, `paid`, `mixed` and one long synthetic title; args use synthetic fixtures only. The file has no runtime dependency on Storybook packages (types may be declared locally).
2. [ ] A dev-only route renders one component's stories by deep link (for example `kudy:///dev-specimen?component=guide-card`), each story labelled by its name; it renders nothing outside `__DEV__`, following `app/han-probe.tsx:143`.
3. [ ] A test fails if the `__DEV__` gate is removed; a test renders every story of `guide-card.stories.tsx` through the specimen screen.
4. [ ] `npm test`, `npm run arch:check` and jscpd pass; the route classifier/purity tests accept the new route.

## Out of scope

Installing Storybook (DQ-13); stories for other components (G26.11, #775); visual comparison.

Blocked-by: #909

## Proof

The `__DEV__` test and the story-render test; Showboat demo per `docs/agent-rules/showboat.md`.
