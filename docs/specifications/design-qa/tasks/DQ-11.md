# DQ-11 — Check generated images against the brand brief

## Epic

Epic: #908

## Goal

Generated illustrations, icons and dragon images get the same checks every time, and drafts are never mistaken for accepted assets (spec §5, §6.2).

## Sources

Spec: `docs/specifications/design-qa/2026-10-30-design-qa-system.md` (sections cited per criterion). Canon: `docs/design/visual-language.md`; decision register: `docs/design/brand/decisions.md` (only rows marked accepted are rules). Record the git commit the sources were read at.

## Acceptance criteria

1. [ ] `docs/design-qa/image-checklist.md`: dragon anatomy (exactly two legs and two wings, no arms, hands or separate forelegs), no text baked into the image, palette roles only from accepted canon values, status draft/accepted with a decision link, provenance and rights record.
2. [ ] A script reports dimensions, alpha channel, file size and SHA-256, and fails when the provenance file lacks the checksum.
3. [ ] Run on the accepted icon package (#429) — passes; run on one draft — reported as draft, not as accepted.
4. [ ] Likeness to the figurine is always NOT-VERIFIED for the agent; the owner decides.

## Out of scope

Generating new images; changing accepted assets.

## Dependencies

Blocked-by: #912

## Proof

Script tests fail when the checksum or status check is reverted.
