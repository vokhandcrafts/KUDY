# Documentation language policy

This file is the single source of truth for Codex, Claude Code, and Cursor.

## Rule

- Documentation written for humans (READMEs, product docs, user-facing guides, changelogs meant for people) must be written in Belarusian.
- Documentation written for agents (CLAUDE.md, AGENTS.md, agent-rules files, skill files, prompts, machine-oriented specs) must be written in English.
- Code, comments, commit messages, and identifiers are unaffected by this rule; follow existing project conventions for those.
