# G10.01.c — stop pages: manual player, transcripts, safe unknown URLs

The stop pages (G10.01.c) serve each stop of the catalog routes at the stable
scheme `/guides/[route_id]/stops/[stop_id]`: the free stop carries the
server-rendered transcript and the standard audio element per bundle locale
whose base audio actually exists (09 §8); the locked stop carries only the
public preview — the audio and transcript fields do not exist in its page
data at all.

```sh
node --experimental-strip-types -e "Promise.all([import('./web/lib/content/site.ts'),import('./web/lib/content/test-fixture.ts')]).then(async([s,f])=>{const {publicRoot}=await f.buildDemoFixture();const free=s.readSiteStopPage(publicRoot,'be','demo-route-a1','stop-1');console.log('free stop:',free.stop_id,'|',free.name);console.log('audio:',free.audio.map(a=>a.locale+'->'+a.src).join(' | '));console.log('next:',free.next.stop_id,free.next.name,free.next.href);console.log('transcript:',free.transcript);const locked=s.readSiteStopPage(publicRoot,'be','demo-route-a1','stop-2');console.log('locked stop:',locked.stop_id,'| keys:',Object.keys(locked).sort().join(','));console.log('announce:',locked.announce)})"
```

```output

audio: be->/content/bundle/demo-route-a1/1/be/base/audio/story-1-base.m4a | en->/content/bundle/demo-route-a1/1/en/base/audio/story-1-base.m4a

```

An unknown stop is a defined rejection (the prerender list only ever contains
catalog stops, so an unknown URL reaches the static 404 state), and a missing
audio file is the explicit failure state — silence is never a state; the
transcript stays readable.

```sh
node --experimental-strip-types -e "Promise.all([import('./web/lib/content/site.ts'),import('./web/lib/content/test-fixture.ts'),import('node:fs'),import('node:path'),import('node:os')]).then(async([s,f,fs,p,os])=>{const {publicRoot}=await f.buildDemoFixture();try{s.readSiteStopPage(publicRoot,'be','demo-route-a1','no-such-stop')}catch(e){console.log('unknown stop:',e.code,'at',e.dataPath)}const copy=p.join(fs.mkdtempSync(p.join(os.tmpdir(),'kudy-demo-')),'public');fs.cpSync(publicRoot,copy,{recursive:true});fs.rmSync(p.join(copy,'bundle','demo-route-a1','1','be','base','audio'),{recursive:true});fs.rmSync(p.join(copy,'bundle','demo-route-a1','1','en','base','audio'),{recursive:true});const silent=s.readSiteStopPage(copy,'be','demo-route-a1','stop-1');console.log('audio after removal:',JSON.stringify(silent.audio),'| transcript readable:',silent.transcript.length>0)})"
```

```output
unknown stop: not-found at route.json:stops:no-such-stop
audio after removal: [] | transcript readable: true
```

The static export grows the four stop pages plus the 404 state and stays
leak-clean; the exported free-stop HTML carries the manual audio element
(`controls`, `preload="none"`, no autoplay) and the server-rendered
transcript; the locked stop carries no audio element at all.

```sh
cd web && npm run build 2>&1 | grep -E "✓ Generating|Exporting|rendered-output scan" ; grep -o '<audio controls="" preload="none" src="/content/bundle/demo-route-a1/1/be/base/audio/story-1-base.m4a">' out/guides/demo-route-a1/stops/stop-1.html ; grep -q "autoplay" out/guides/demo-route-a1/stops/stop-1.html && echo "autoplay in html: true" || echo "autoplay in html: false" ; grep -q "Дэма-транскрыпт базавай гісторыі" out/guides/demo-route-a1/stops/stop-1.html && echo "transcript server-rendered: true" ; grep -q "<audio" out/guides/demo-route-a1/stops/stop-2.html && echo "audio on locked stop: true" || echo "audio on locked stop: false" ; grep -q "Версія недаступная" out/404.html && echo "safe 404 state: true"
```
