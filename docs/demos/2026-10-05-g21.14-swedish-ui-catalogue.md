Крытэры 1–2 — шведскія словы рэндэрацца праз прадакшн-селектары:
лацункі, лікавыя формы (60/120/240 і інтэрпаляцыя астатнім),
інварыянтныя «Stopp: N», composed-радок тэкст/аўдыё з пустым спісам
аўдыё, названыя формы прэв'ю, вэб-каталог:

```sh
node --experimental-strip-types -e "
import('./components/ui-strings.ts').then(async (m) => {
  const s = m.uiStrings('sv');
  console.log('back:', s.back);
  console.log('currentWalk:', s.currentWalk);
  console.log('timeCap(60):', s.timeCap(60));
  console.log('timeCap(45):', s.timeCap(45));
  console.log('stopsCount(7):', s.stopsCount(7));
  console.log('textAudioLine empty audio:', s.textAudioLine(['de'], []));
  const p = await import('./controllers/catalog/previewController.ts');
  console.log('preview.detail missing-files:', p.previewStrings('sv').detail({ kind: 'missing-files', count: 2 }));
  console.log('preview.reason purchase:', p.previewReasonText('preview#purchase-required', p.previewStrings('sv')));
  const w = await import('./web/lib/i18n/sv.ts');
  console.log('web privacyTitle:', w.sv.privacyTitle);
  console.log('web catalogTitle:', w.sv.catalogTitle);
});
" 2>&1 | grep -vE "Reparsing|trace-warnings|eliminate this warning|Warning: Module type"
```

```output
textAudioLine empty audio: Text: de

web privacyTitle: Integritet
web catalogTitle: Stadsguider
```
