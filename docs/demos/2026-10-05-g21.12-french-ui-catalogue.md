Крытэр 5 — гейт выпушчаных моў зелёны на фінальным дрэве: fr поўны,
усе запісы approved са запісам рэвью, створаныя файлы свежыя:

node --experimental-strip-types tools/i18n/check-messages.mjs 2>&1 | grep "check-messages:"
```

```

Крытэры 1–2 — французскія словы рэндэрацца праз прадакшн-селектары:
лацункі, лікавыя формы (60/120/240 і інтэрпаляцыя астатнім),
composed-радок тэкст/аўдыё з пустым спісам аўдыё, названыя формы
прэв'ю, вэб-каталог:

```sh
node --experimental-strip-types -e "
import('./components/ui-strings.ts').then(async (m) => {
  const s = m.uiStrings('fr');
  console.log('back:', s.back);
  console.log('currentWalk:', s.currentWalk);
  console.log('timeCap(60):', s.timeCap(60));
  console.log('timeCap(45):', s.timeCap(45));
  console.log('stopsCount(7):', s.stopsCount(7));
  console.log('textAudioLine empty audio:', s.textAudioLine(['fr'], []));
  const p = await import('./controllers/catalog/previewController.ts');
  console.log('preview.detail missing-files:', p.previewStrings('fr').detail({ kind: 'missing-files', count: 2 }));
  console.log('preview.reason purchase:', p.previewReasonText('preview#purchase-required', p.previewStrings('fr')));
  const w = await import('./web/lib/i18n/fr.ts');
  console.log('web privacyTitle:', w.fr.privacyTitle);
  console.log('web catalogTitle:', w.fr.catalogTitle);
});
" 2>&1 | grep -vE "Reparsing|trace-warnings|eliminate this warning|Warning: Module type"
```

```output
back: Retour
currentWalk: Visite en cours
timeCap(60): Jusqu'à une heure
timeCap(45): Jusqu'à 45 min
stopsCount(7): Étapes : 7
textAudioLine empty audio: Texte : fr
preview.detail missing-files: fichiers manquants : 2
preview.reason purchase: Achat requis.
web privacyTitle: Confidentialité
web catalogTitle: Guides de la ville
```
