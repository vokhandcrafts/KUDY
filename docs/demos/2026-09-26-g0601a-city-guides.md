# G06.01.a — Горад і Гіды на апублікаваным каталогу

*Showboat demo for issue #313 (G06.01.a), created 2026-09-26.*

<!-- showboat-id: g0601a-city-guides -->

Паверхні Горад і Гіды рэндэруюць тое, што вытварае каталожны сэрвіс
(`services/catalog`): конверт каталога (09 §4) плюс неабавязковы discovery-індэкс
(21 §3.3), спраецыяваны ў карткі гідаў. Дэма ганяе вытворчы сэрвіс па
апублікаваных фікстурах `fixtures/discovery-contract` — пара, дзе pointer
каталога пінуе індэкс па bytes і sha256, таму цэласнасць правяраецца сапраўдным
шляхам. Вывад дэтэрмінаваны: фіксаваныя ўваходы, без гадзіннікаў і выпадковасці.

Адна праглоўка паказвае ўсе сумленныя станы (табліца пакрыцця станаў
`screens-and-transitions.md`): ready з offer-карткай і route-only-хвастом,
дэградацыю без індэкса (звычайныя гіды застаюцца — NAV2), offline над апошнім
валідным кэшам (09 §4) і памылку без кэша.

```sh
node --experimental-strip-types --disable-warning=MODULE_TYPELESS_PACKAGE_JSON services/catalog/demo-g0601a.mjs
```

```output
card guide-route-a1 v1 access=paid order=1 text=be,en,uk audio=be,en title="Гісторыі сукнараў: ад мытні да порта"
card guide-route-b1 v3 access=free order=- layers=be title="guide-route-b1"
state=ready degraded=null
state=ready degraded=index-unavailable guides=2
state=offline reason="network down" guides=2
state=error reason="network down"
```

Рэндэр-тэст экранаў (`app/navigation.test.tsx`, jest) праходзіць той самы
вытворчы шлях праз мок fetch з тымі фікстурамі: карткі, пазнака тарыфу,
мовы, ланцуг Горад → Гіды → прэв'ю → Run і вяртанні NAV9 — 12/12.
