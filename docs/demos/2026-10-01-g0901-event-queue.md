# G09.01 — лакальны лог падзей і ідэмпатэнтная чарга

*Showboat demo for issue #285 (G09.01 — services/eventLog.ts над durable-табліцай event_queue), created 2026-10-01.*

Сцэнар на рэальным прадакшн-кодзе (`services/eventLog.ts` + `services/db`):
тры падзеі запісваюцца ў durable-чаргу; першы flush адпраўляе дзве і адзначае
іх; трэцяя (ручны Play) трапляе ў чаргу перад «забойствам» — store закрываецца
пасярэдзіне чаргі; пасля паўторнага адкрыцця таго ж файла чарга аддае роўна
нядасланую падзею з тым самым event_id, а наступны flush ужо будзіць — чарга
пустая. (`export LD_LIBRARY_PATH` — хоставае патрабаванне node, не частка
змены.)

```sh
export LD_LIBRARY_PATH=$HOME/.local/lib
rm -rf /tmp/kudy-g0901-demo
mkdir -p /tmp/kudy-g0901-demo
node --experimental-strip-types --input-type=module -e '
import { pathToFileURL } from "node:url";
const { openDatabase } = await import(pathToFileURL("services/db/db.ts"));
const { nodeSqliteFileDriver } = await import(pathToFileURL("services/db/test-fixture.ts"));
const { emitEvent, flushEvents } = await import(pathToFileURL("services/eventLog.ts"));

const sender = (events) => {
  console.log(`SEND ${events.length}: ${events.map((e) => e.event_id).join(",")}`);
  return Promise.resolve();
};
const store = nodeSqliteFileDriver("/tmp/kudy-g0901-demo/events.db");
openDatabase(store.driver);
emitEvent(store.driver, { eventId: "evt-a", type: "app_open", at: 1, schemaVersion: 1, payload: "{}" });
emitEvent(store.driver, { eventId: "evt-b", type: "session_started", at: 2, schemaVersion: 1, payload: JSON.stringify({ session_id: "s1", route_id: "r1", version: "1" }) });
console.log("flush-1 marked", await flushEvents(store.driver, sender));
emitEvent(store.driver, { eventId: "evt-c", type: "story_play_started", at: 3, schemaVersion: 1, payload: JSON.stringify({ stop_id: "stop-1", story_id: "story-1", play_id: 1, trigger: "manual" }) });
store.close();

const reopened = nodeSqliteFileDriver("/tmp/kudy-g0901-demo/events.db");
openDatabase(reopened.driver);
console.log("flush-2 marked", await flushEvents(reopened.driver, sender));
console.log("flush-3 marked", await flushEvents(reopened.driver, sender));
reopened.close();
' 2>/dev/null
rm -rf /tmp/kudy-g0901-demo
```

```output
SEND 2: evt-a,evt-b
flush-1 marked 2
SEND 1: evt-c
flush-2 marked 1
flush-3 marked 0
```

Ідэнтыфікатар падзеі стабільны на retry: пасля збою адпраўкі чарга кладзе
тыя жа id, сервер дэдупіруе па event_id (`09` §15); адзначаны батч не ідзе
паўторна, а батч адпраўкі абмежаваны 256 падзеямі — ліміт bind-параметраў
драйвера не можа заклінаваць чаргу. Прыёмачная сюіта крытэрыяў 1–5 з issue
#285 зялёная (grep пакідае толькі дэтэрмінаваныя радкі зводкі, без
таймінгаў):

```sh
export LD_LIBRARY_PATH=$HOME/.local/lib
node --test --experimental-strip-types services/eventLog.test.ts 2>&1 | grep -E '^ℹ (tests|pass|fail)'
```

```output
ℹ tests 9
ℹ pass 9
ℹ fail 0
```
