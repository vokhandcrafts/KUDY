# G06.07 — visual canon: prototype tokens resolve to the approved source

*Showboat demo for issue #180 (`docs/design/visual-language.md`), created 2026-09-25.*

<!-- showboat-id: g0607-visual-canon -->

The visual canon is now the single source of visual values; the prototype's
draft `:root` tokens resolve to it through the supersession map. Three marker
colors and the hint-card background were overridden to meet the street-readability
contrast floors (WCAG 1.4.3 text 4.5:1, 1.4.11 objects 3:1), and big-text grew
from 19px to 20px to reach the ≥ 1.2× a11y floor. The guard proves the
canon ↔ prototype ↔ contrast contract; reverting any value fails it (verified
in-session).

The values the prototype now renders with:

```sh
node -e '
const fs = require("node:fs");
const doc = fs.readFileSync("docs/design/visual-language.md", "utf8");
const canon = JSON.parse(doc.split("```json")[1].split("```")[0]);
const t = canon.tokens;
const lum = (hex) => { const c = hex.replace("#",""); const [r,g,b] = [0,2,4].map(i => parseInt(c.slice(i,i+2),16)/255).map(v => v <= 0.03928 ? v/12.92 : Math.pow((v+0.055)/1.055, 2.4)); return 0.2126*r + 0.7152*g + 0.0722*b; };
const ratio = (a,b) => { const [l1,l2] = [lum(a),lum(b)].sort((x,y)=>y-x); return (l1+0.05)/(l2+0.05); };
const m = (n) => t["color.marker." + n].value;
console.log(`markers: ${canon.markers.map((n) => n + " " + m(n)).join(" · ")}`);
const base = parseFloat(t["font.base-size"].value), f = parseFloat(t["font.big-text-factor"].value);
console.log(`big-text: ${base*f}px (${f}× of ${base}px; draft was 19px = 1.1875×)`);
const locked = m("locked"), draft = canon.supersession["--kudy-locked"].draftValue;
console.log(`contrast white/locked: ${ratio("#ffffff", locked).toFixed(2)}:1 (draft ${draft} was ${ratio("#ffffff", draft).toFixed(2)}:1); locked/street: ${ratio(locked, t["color.street"].value).toFixed(2)}:1 (draft was ${ratio(draft, t["color.street"].value).toFixed(2)}:1)`);
'
```

```output
markers: locked #67707a · playing #b3331f · played #1d6b4f · available #8a610e · pending #646c77
big-text: 20px (1.25× of 16px; draft was 19px = 1.1875×)
contrast white/locked: 5.03:1 (draft #9aa2ab was 2.58:1); locked/street: 3.98:1 (draft was 2.05:1)
```
