# #366 — голыя URL у тэксце абзацаў — гэта спасылкі

*Showboat-дэма для issue #366 (`tools/collector`), створана 2026-09-29.*

G17.09 абяцае, што адрас, напісаны простым тэкстам у абзацы артыкула
(«Гл. https://example.org/museum»), — гэта спасылка нараўне з анкарнай:
адрас трапляе ў табліцу спасылкаў запіса (анкер = сам адрас, кантэкст = абзац)
і адтуль — у чаргу паўзука, а тэкст трымае адрас бачным як маркдаўн-спасылка.
Словы без схемы («www.…») ніколі не становяцца спасылкамі. Дэма ганяе
прадакшн CLI праз file: -фікстуру — афлайнавая мяжа, без сервера і сеткі.
Ідэнтыфікатар запіса выпадковы на кожны прагон, таму `sed` дэмы маскіруе яго
(`<record-id>`); усё астатняе — хэш кампаніі, лічбы, байты тэксту —
вызначанае.

Падрыхтоўка: фікстуры і кампанія ў фіксаванай тэчцы, потым `init`, `run`,
`clean`:

```sh
rm -rf /tmp/kudy-g1709-demo && mkdir -p /tmp/kudy-g1709-demo && node -e '
const fs = require("node:fs");
const { pathToFileURL } = require("node:url");
const article = [
  "<!DOCTYPE html>", "<html lang=\"en\">", "<head>", "  <title>Gdansk shipyard turns into a museum</title>",
  "  <meta name=\"date\" content=\"2026-09-20\">", "</head>", "<body>",
  "  <p>The <a href=\"https://gdansk.example/history\">shipyard history</a> began in 1844.</p>",
  "  <p>Details at https://gdansk.example/museum.</p>",
  "  <p>The site www.gdansk.example is scheme-less text.</p>",
  "</body>", "</html>", "",
].join("\n");
fs.writeFileSync("/tmp/kudy-g1709-demo/seed.html", article);
fs.writeFileSync("/tmp/kudy-g1709-demo/campaign.yaml", [
  "city: gdansk",
  "seeds:",
  "  - " + pathToFileURL("/tmp/kudy-g1709-demo/seed.html").href,
  "topics: [history]",
  "fence:",
  "  depth: 3",
  "  extra_domains: []",
  "  delay_s: [2, 5]",
  "youtube: []",
].join("\n") + "\n");
console.log("fixtures ready");
' && node tools/collector/collector.mjs init --db /tmp/kudy-g1709-demo/db.sqlite && node tools/collector/collector.mjs run --campaign /tmp/kudy-g1709-demo/campaign.yaml --db /tmp/kudy-g1709-demo/db.sqlite && node tools/collector/collector.mjs clean --campaign /tmp/kudy-g1709-demo/campaign.yaml --db /tmp/kudy-g1709-demo/db.sqlite
```

Сыры снапшот трымае адрас бачным як маркдаўн-спасылка на сваёй пазіцыі,
слова без схемы засталося простым тэкстам; у табліцы спасылак голы адрас
з самім сабой як анкерам — побач з анкарным радком:

```sh
cat /tmp/kudy-g1709-demo/snapshots/*/*/text.md && echo '---' && node -e 'const { DatabaseSync } = require("node:sqlite"); for (const row of new DatabaseSync("/tmp/kudy-g1709-demo/db.sqlite").prepare("SELECT anchor_text, url FROM links ORDER BY rowid").all()) console.log(row.anchor_text, "->", row.url)'
```

```output
The [shipyard history](https://gdansk.example/history) began in 1844.

Details at [https://gdansk.example/museum](https://gdansk.example/museum).

The site www.gdansk.example is scheme-less text.
---
shipyard history -> https://gdansk.example/history
https://gdansk.example/museum -> https://gdansk.example/museum
```

Ачышчаны дакумент нясе той самы тэкст — рэдактар бачыць спасылку, а шапка
застаецца метаданымі запіса:

```sh
sed -E 's/[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}/<record-id>/' /tmp/kudy-g1709-demo/snapshots/*/*/cleaned/v1.md
```
