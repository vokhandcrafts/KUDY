# G07.02 — ручны Play Moment: адзіны ўладальнік плэера і перахоп адным пераходам

*Showboat demo для issue #282 (`controllers/moment`, `services/contentRepo`), створана 2026-09-27.*

<!-- showboat-id: g0702-moment-play -->

Кантракт уладальніка гуку (ADR G01.02 §3.4/§3.8) на жывым кодзе: ручны Play Moment па-за сесіяй ідзе праз кантролер адзінага плэера (`controllers/moment/momentPlayController.ts`), а пры гучачым Run-аўдыё — праз жывую сесію (рухавік робіць увесь перахоп: гід спынены камандай — не finished, не `heard`; чарга ў `auto_fired`; `autoplay_suspended = true`; `playing` → moment-варыянт). Сцэнарыі гоняць рэальныя аркестратар, рухавік і аудыё-сэрвіс з фейк-портам (ідыёма suite G05.04); фізічны здымак порта скрыптаваны — плэер «грае».

Доказ крытэрыя 1 — перахоп адным пераходам; пры адкатзе праводкі (`reverted`) той самы Play — іменаваная адмова без другога плэера:

```sh
node --experimental-strip-types --disable-warning=MODULE_TYPELESS_PACKAGE_JSON --input-type=module -e "
import { RunOrchestrator } from './controllers/run/runOrchestrator.ts';
import { defaultEngineConfig } from './core/engine/reducer.ts';
import { AudioService } from './services/audio/service.ts';
import { FakeAudioPlayerPort } from './services/audio/fake-port.ts';
import { FakeLocationOsPort } from './services/location/fake-port.ts';
import { LocationService } from './services/location/service.ts';
import { createMomentPlayController } from './controllers/moment/momentPlayController.ts';
const withRouting = process.argv[2] !== 'reverted';
const clock = { now: () => 0, schedule: () => () => {} };
const port = new FakeAudioPlayerPort();
const audio = new AudioService({ createPort: () => port });
let seq = 0;
const nextSeq = () => ++seq;
let orchestrator;
const controller = createMomentPlayController({
  audio, nextSeq, now: () => clock.now(),
  sessionMoment: withRouting
    ? { playMoment: (m, s) => { orchestrator.playMoment(m, s); return true; } }
    : undefined,
});
orchestrator = new RunOrchestrator({
  location: new LocationService({ port: new FakeLocationOsPort(), clock, permissions: { foreground: 'fg', background: 'bg' } }),
  audio, clock, engineConfig: defaultEngineConfig, pipelineConfig: { dwellMs: 0 },
  route: { routeId: 'route-1', version: 'v1', locale: 'be', tier: ['base'] },
  stops: [{ stopId: 'a', lat: 0, lng: 0, radius: 20, storyBaseId: 'a' }],
  nextMomentSeq: nextSeq,
});
orchestrator.start('walk-1');
orchestrator.selectStop('a');
port.snapshotValue = { state: 'playing', positionMs: 0, durationMs: 9000 };
const outcome = controller.play({ momentId: 'm-1', storyId: 's-1', path: 'bundles/route-1/1/be/base/audio/s-1.m4a' });
const state = orchestrator.state;
console.log(JSON.stringify({ outcome, port: port.commands, violations: port.violations, playing: state.playing, heard: state.heard, suspended: state.autoplaySuspended, queued: state.queued }));
"
```

```output
{"outcome":{"outcome":"routed"},"port":["play 1:be/base/audio/a.m4a","stop","play 2:"],"violations":[],"playing":{"owner":"moment","momentId":"m-1","storyId":"s-1","seq":1,"paused":false},"heard":[],"suspended":true,"queued":null}
```

Адкат праводкі — той самы тап без порта да жывой сесіі: іменаваная адмова, фізічны плэер адзін, гід працягвае гучаць (`playing` = guide-варыянт, `suspended = false`):

```sh
node --experimental-strip-types --disable-warning=MODULE_TYPELESS_PACKAGE_JSON --input-type=module -e "
import { RunOrchestrator } from './controllers/run/runOrchestrator.ts';
import { defaultEngineConfig } from './core/engine/reducer.ts';
import { AudioService } from './services/audio/service.ts';
import { FakeAudioPlayerPort } from './services/audio/fake-port.ts';
import { FakeLocationOsPort } from './services/location/fake-port.ts';
import { LocationService } from './services/location/service.ts';
import { createMomentPlayController } from './controllers/moment/momentPlayController.ts';
const clock = { now: () => 0, schedule: () => () => {} };
const port = new FakeAudioPlayerPort();
const audio = new AudioService({ createPort: () => port });
let seq = 0;
const nextSeq = () => ++seq;
const controller = createMomentPlayController({ audio, nextSeq, now: () => clock.now() });
const orchestrator = new RunOrchestrator({
  location: new LocationService({ port: new FakeLocationOsPort(), clock, permissions: { foreground: 'fg', background: 'bg' } }),
  audio, clock, engineConfig: defaultEngineConfig, pipelineConfig: { dwellMs: 0 },
  route: { routeId: 'route-1', version: 'v1', locale: 'be', tier: ['base'] },
  stops: [{ stopId: 'a', lat: 0, lng: 0, radius: 20, storyBaseId: 'a' }],

"
```

```output
{"outcome":{"refused":"moment#session-unroutable"},"port":["play 1:be/base/audio/a.m4a"],"violations":[],"playing":{"owner":"guide","stopId":"a","storyId":"a","playId":1,"paused":false},"heard":[],"suspended":false,"queued":null}
```
