# G10.01.b — the static city map: data, provider guard, loud failures

The map step (G10.01.b step 3) joins catalog routes, ordered stop rows and the bundle `places.json` geo facts into GeoJSON markers — `[lng, lat]` order, public names only. The founder's provider decision (2026-09-21): **OpenFreeMap**; the config is the single tile-source home.

```sh
node --experimental-strip-types -e "Promise.all([import('./web/lib/content/site.ts'),import('./web/lib/content/test-fixture.ts'),import('./web/lib/map-config.ts')]).then(async([s,f,m])=>{const {publicRoot}=await f.buildDemoFixture();const map=s.readSiteMapPage(publicRoot,'be');console.log('routes:',map.routes.length,'title:',map.routes[0].title);console.log('markers:',map.markers.features.map(x=>x.properties.stop_id+'@'+x.geometry.coordinates.join(',')).join(' | '));console.log('locked flags:',map.markers.features.map(x=>x.properties.locked).join(','));console.log('provider:',m.mapProvider.providerName,m.mapProvider.styleUrl)})"
```

```output
routes: 1 title: Дэма-гід: сукнаны двор
markers: stop-1@18.6534,54.3487 | stop-2@18.652,54.3512
locked flags: false,true
provider: OpenFreeMap https://tiles.openfreemap.org/styles/liberty
```

Corrupt or missing geo facts fail loudly with named diagnostics (implementation-rules 14): a malformed entry names the rule and the per-entry path; a stop without a geo entry names the place — the build dies, no silent missing dot.

```sh
node --experimental-strip-types -e "Promise.all([import('./web/lib/content/readers.ts'),import('./web/lib/content/site.ts'),import('./web/lib/content/test-fixture.ts'),import('node:fs'),import('node:path')]).then(async([r,s,f,fs,p])=>{const bad=r.readPlacesGeo([{id:'place-1',content_version:'1',lat:'high',lng:18.65,trigger_radius_m:30,kind:'sight'}]);console.log('corrupt entry:',bad.ok===false?bad.errors.map(e=>e.rule+' at '+e.path).join('; '):'ok');const {publicRoot:root2}=await f.buildDemoFixture();const pp=p.join(root2,'bundle','demo-route-a1','1','places.json');const arr=JSON.parse(fs.readFileSync(pp,'utf8'));fs.writeFileSync(pp,JSON.stringify(arr.filter(x=>x.id!=='place-2')));try{s.readSiteMapPage(root2,'be')}catch(e){console.log('missing geo:',e.code,'at',e.dataPath)}})"
```

```output
corrupt entry: $.lat at places[0].$.lat
missing geo: not-found at bundle/demo-route-a1/1/places.json:place-2
```
