# G06.02 — Карта Run: маркеры пяці станаў, POI і честная схема без тайлаў

*Showboat demo for issue #278 (G06.02), created 2026-09-27.*

<!-- showboat-id: g0602-run-map -->

Дэма ганяе чысты драйвер мадэлі маркераў (`runMapView`) над сцэнарызаванымі
станамі engine: пяць станаў маркераў ADR G01.01 §4.5 (`stopStatus` бярэцца
з `core/engine/state.ts` — адзінае правапісанне, без другога кантракту),
POI-кропка (месца, на якое не спасылаецца ніводны stop маршруту — 11 §6) і
радкі BE/EN па лякалі прагулкі. Поўны прагноз праз кампазіцыйны корань —
стек сэрвісаў над фэйкавымі портамі і рэальная база — ёсць у сюітах
(`controllers/run/runSurfaceController.test.ts`, node --test; `app/run.test.tsx`,
jest): старт прагулкі, жывыя пераходы станаў, тап-прэвʼю без гуку і аднаўленне
з жывога радка. Вывад дэтэрмінаваны: фіксаваныя ўваходы, без гадзіннікаў.

```sh
node --experimental-strip-types --disable-warning=MODULE_TYPELESS_PACKAGE_JSON controllers/run/demo-g0602-map.mjs
```

```output
fresh: stop-1=pending stop-2=pending stop-3=locked stop-4=pending poi=place-9:cafe
after AudioFinished: stop-1=played stop-2=pending stop-3=locked stop-4=pending poi=place-9:cafe
autoplay: stop-1=played stop-2=playing stop-3=locked stop-4=pending poi=place-9:cafe
focus loss: stop-1=played stop-2=available stop-3=locked stop-4=pending poi=place-9:cafe
be: playing=гучыць played=праслухана available=даступна pending=чакае locked=зачынена
en: playing=playing played=played available=available pending=pending locked=locked
```

Чатыры фазы закрываюць усе пяць станаў: свежы прагон (pending ×3, платная
кропка `locked`), прыняты `AudioFinished` (`played` — назаўсёды ў сесіі),
аўтазапуск (`playing`), страта фокусу (запуск жывы, маркер ідзе за чутным
станом — `available`, ADR G01.02 §3.4). Адкат праверкі: замена
`stopStatus(run, …)` на канстанту ў `runMapView` валіць node-сюіту
(«AC1: a fresh walk…» і аднаўленне) і jest-сюіту экрана («AC1: the map…»,
«AC5»), што і ёсць Proof задачы.
