# G06.03 — Peek/Half/Full: панэль гісторыі і незалежны inspected

*Showboat demo for issue #279 (G06.03), created 2026-09-27.*

<!-- showboat-id: g0603-run-panel -->

Дэма ганяе чыстыя адзінкі панэлі: лесвіцу пазіцый Peek → Half → Full з
адзіным крокам закрыцця (✕ і Back — адно і тое ж, 11 §6 — крытэрый 1),
захаванне «што апошняе адкрывалі» (`inspected` перажывае закрыццё —
11 §3.2) і чытанне транскрыптаў пінаванага слоя (`stops.json` → карта
карткі; крытэрый 2: транскрыпт належыць inspected, паласа — гуку, які
гучыць). Поўны стэк — стрып з прагрэсам гучнага аўдыё, радок «Зараз грае»,
нулявыя аўдыё-каманды пры кожным пераходзе панэлі (крытэрый 3), захаванне
сесіі пры выхадзе з Run з адкрытай карткай (крытэрый 4) і незалежнасць
`inspected` ад `heard` (крытэрый 5) — у сюітах экрана і чыстых адзінак
(`app/run.test.tsx` пад jest; `controllers/run/runPanel.test.ts` і
`services/contentRepo/runStoryFacts.test.ts` пад node --test). Вывад
дэтэрмінаваны: фіксаваныя ўваходы, без гадзіннікаў.

```sh
node --experimental-strip-types --disable-warning=MODULE_TYPELESS_PACKAGE_JSON controllers/run/demo-g0603-panel.mjs
```

```output
peek: position=peek inspected=—
tap stop-1 (Half): position=half inspected=stop-1
expand (Full): position=full inspected=stop-1
card transcript (inspected stop-1): Транскрыпт мытні
✕ (Half, inspected kept): position=half inspected=stop-1
Back (Peek, inspected kept): position=peek inspected=stop-1
tap stop-2 (Half): position=half inspected=stop-2
card transcript (inspected stop-2): Транскрыпт порта
```

Лесвіца зачыняе крытэрый 1 (адзіны крок закрыцця: Full → Half → Peek,
`inspected` нікуды не знікае) і крытэрый 2 з боку карткі: транскрыпт чытаецца
з пінаванага слоя па story-ідэнтычнасці кропкі, якую прагледзелі. Адкат
праверкі: замена `panelClosed` на no-op валіць чатыры тэсты jest-сюіту экрана
(«G06.03 AC1», «AC2», «AC3», кнобу «Граць/Паўза») — праверана адкатам
перад push; выдаленне чытання `stops.json` з кампазіцыйнага кораня валіць
node-сюіты чытальніка і карткі. Proof задачы — тэст «адкрыццё Peek не змяняе
аўдыё-стан»: у сюіце экрана кожны пераход панэлі правярае
`audioPort.commands === []`.
