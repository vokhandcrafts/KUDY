# G05.06.a — the deterministic simulator on production functions

*Showboat demo for issue #218 (`tools/simulate`), created 2026-09-26.*

<!-- showboat-id: g0506a-simulator -->

The simulator replays a JSON trace through the same stack the app runs: the
real `LocationService` and `AudioService` over deterministic OS ports, the
real `RunOrchestrator` — which itself runs `acceptFix` and `step` — with one
deferred-action queue ordered by due time then insertion order. The demo
drives the synthetic M1 five-stop route of 09 §13 through the production CLI:
every stop fires, none twice, nothing hangs, `Ended` only after the explicit
End.

Setup: the trace (Start, a 1.4 m/s walk past five stops 199.8 m apart, an
explicit End) and the mutation loader used in the proof block are written to a
fixed temp dir; a stale one is removed first:

```sh
rm -rf /tmp/kudy-g0506a-demo && mkdir -p /tmp/kudy-g0506a-demo && node -e '
const fs = require("node:fs");
const stops = [0, 1, 2, 3, 4].map((k) => ({
  stopId: `stop-${k + 1}`,
  lat: 54.4 + k * 0.0018,
  lng: 18.65,
  radius: 30,
  storyBaseId: `story-${k + 1}`,
}));
const events = [{ type: "UserCommand", at: 0, command: { action: "Start" } }];
const stepM = 1.4 * 5;
const metersPerDeg = 111000;
const count = Math.floor((4 * 0.0018 + 0.0009) * metersPerDeg / stepM);
for (let i = 0; i <= count; i++) {
  events.push({ type: "GpsFix", at: i * 5000, lat: 54.4 - 0.0005 + (stepM * i) / metersPerDeg, lng: 18.65, accuracy: 5 });
}
const tail = events[events.length - 1].at;
events.push({ type: "UserCommand", at: tail + 25000, command: { action: "End" } });
fs.writeFileSync("/tmp/kudy-g0506a-demo/m1.json", JSON.stringify({
  route: { routeId: "m1-five-stops", version: "1.0.0", locale: "be", tier: ["base"] },
  stops,
  config: { dwellMs: 6000, audio: { defaultDurationMs: 20000 } },
  events,
}, null, 1) + "\n");
fs.writeFileSync("/tmp/kudy-g0506a-demo/hooks.mjs", [
  "export async function load(url, context, next) {",
  "  const result = await next(url, context);",
  "  if (url.endsWith(\"/core/pipeline/pipeline.ts\")) {",
  "    const source = String(result.source).replaceAll(\"acc.accumulatedMs >= config.dwellMs\", \"acc.accumulatedMs >= 0\");",
  "    return { format: \"module-typescript\", shortCircuit: true, source };",
  "  }",
  "  return result;",
  "}",
  "",
].join("\n"));
fs.writeFileSync("/tmp/kudy-g0506a-demo/register.mjs", "import { register } from \"node:module\";\nregister(\"./hooks.mjs\", import.meta.url);\n");
console.log("trace ready:", JSON.parse(fs.readFileSync("/tmp/kudy-g0506a-demo/m1.json", "utf8")).events.length, "events");
' && node --no-warnings tools/simulate/cli.mjs --trace /tmp/kudy-g0506a-demo/m1.json --out /tmp/kudy-g0506a-demo/report.json && node -e '
const r = JSON.parse(require("node:fs").readFileSync("/tmp/kudy-g0506a-demo/report.json", "utf8"));
console.log("fired stops:");
for (const s of r.firedStops) console.log(`  ${s.stopId} ${s.storyId} at=${s.at}ms origin=${s.origin} latency=${s.latencyMs}ms`);
console.log("heard:", r.session.heard.join(", "));
console.log("finalPhase:", r.session.finalPhase, "| endedAt:", r.session.endedAtMs, "| stuckPlaying:", r.stuckPlaying);
console.log("autoFired:", r.session.autoFired.join(", "));
'
```

All five stops fired once with the dwell window visible in every latency
(≥ 6000 ms), nothing hangs, and the session is `Ended` — the M1 acceptance of
09 §13. Determinism: the same trace run twice gives byte-identical reports:

```sh
node --no-warnings tools/simulate/cli.mjs --trace /tmp/kudy-g0506a-demo/m1.json --out /tmp/kudy-g0506a-demo/report-2.json && h1=$(sha256sum /tmp/kudy-g0506a-demo/report.json | cut -d' ' -f1) && h2=$(sha256sum /tmp/kudy-g0506a-demo/report-2.json | cut -d' ' -f1) && if [ "$h1" = "$h2" ]; then echo "byte-identical reports, sha256 $h1"; else echo "DIFFER: $h1 vs $h2"; fi
```

```output
byte-identical reports, sha256 926768763eda93675189e556403e68b8247a9236620d7b1a93427d02dcecf90b
```

A corrupt trace yields named diagnostics and runs nothing (exit 2):

```sh
node -e '
const fs = require("node:fs");
const doc = JSON.parse(fs.readFileSync("/tmp/kudy-g0506a-demo/m1.json", "utf8"));
doc.events.splice(5, 0, { type: "quake", at: 7000 });
fs.writeFileSync("/tmp/kudy-g0506a-demo/corrupt.json", JSON.stringify(doc, null, 1));
' ; node --no-warnings tools/simulate/cli.mjs --trace /tmp/kudy-g0506a-demo/corrupt.json --out /tmp/kudy-g0506a-demo/nope.json; echo "exit=$?"
```

```output
simulate: the trace is corrupt — 1 diagnostic(s)
  [unknown-event] events[5]: unknown trace event type 'quake'
exit=2
```

The proof: the simulator imports the production modules, so replacing the
imported pipeline with a copy that skips the dwell requirement must break the
M1 expectation. The loader swaps `core/pipeline/pipeline.ts` for a copy whose
dwell gate is `>= 0` — and every stop now fires on the first fix inside its
radius, with latency collapsed to 0: «no stop before dwell» fails:

```sh
node --no-warnings --import /tmp/kudy-g0506a-demo/register.mjs tools/simulate/cli.mjs --trace /tmp/kudy-g0506a-demo/m1.json --out /tmp/kudy-g0506a-demo/report-mutated.json && node -e '
const r = JSON.parse(require("node:fs").readFileSync("/tmp/kudy-g0506a-demo/report-mutated.json", "utf8"));
console.log("mutated pipeline latencies:", r.firedStops.map((s) => s.latencyMs).join(", "));
const broken = r.firedStops.some((s) => s.latencyMs < 6000);
console.log(broken ? "M1 expectation FAILED under the mutated pipeline — the simulator runs the production modules" : "expectation held — the simulator does not exercise the imported pipeline");
'
```

```output
mutated pipeline latencies: 0, 0, 0, 0, 0
M1 expectation FAILED under the mutated pipeline — the simulator runs the production modules
```
