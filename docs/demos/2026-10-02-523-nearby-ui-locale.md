# #523: словы недаступнага «Побач» ідуць за выбарам мовы UI

*Showboat-доказ bug-выпраўлення #523: экран «Побач» браў лякалю з
nearby-байнінгу, а байнінгу кампазіцыйны корань заўсёды даваў
`localePreference[0]` = `'be'` (прываляльнасць паказу зместу, не выбар
інтэрфейсу). Таму пасля выбару English або Українська загаловак, тлумачэнне
карты і паведамленне пра недаступнасць заставаліся беларускімі — кнопка
вяртання пераключалася, бо чытала `services.locale` у момант рэндэру. Створана
2026-10-02.*

<!-- showboat-id: nearby-locale-523 -->

Выпраўленне: хром-словы экрана чытаюць рэактыўны store выбару мовы
(#305, `useUiLocale` — та сама падпіска, што ў радка мовы My KUDY і каталога);
байнінг не пераствараецца, таму новай падпіскі GPS пераключэнне не дае;
аўтарскі змест картак і актыўнае аўдыё сваёй мовы не мяняюць. Гард — тры
паводзінныя тэсты на рэальным store і рэальным экране (implementation-rules 1):

```sh
LD_LIBRARY_PATH="$HOME/.local/lib" node_modules/.bin/jest app/map.test.tsx --runInBand -t "UI-locale" 2>&1 | grep -E "^(Test Suites:|Tests:|Snapshots:)"
```

```output
Test Suites: 1 passed, 1 total
Tests:       15 skipped, 3 passed, 18 total
Snapshots:   0 total
```

Эксперымент па зняцці фікса (implementation-rules 1) выкананы ў гэтай сесіі:
`git restore --source=46e3c0d --worktree -- app/map.tsx` вяртае стары крыніцу
лякалі — тыя самыя тры тэсты чырванеюць, пярэднія сюіты экрана застаюцца
зялёнымі; пасля `git restore --source=HEAD --worktree` той жа запуск —
зялёны. Паўторана і ў адваротным парадку (фікса → база → фікс) з тым жа
вынікам.

Жывая праверка на прыладзе (таго ж дня, AVD `kudy-test`, Android 16 / API 36,
віртуальны Pixel 6): dev-client сабраны з гэтай галінкі (`npx expo prebuild -p
android` + `gradlew assembleDebug`), Metro з галінкі задачы, халодны старт праз
дэв-лаунчар на `http://10.0.2.2:8081`. Каталожны порт на зборцы не сканструяваны
— экран паказвае сумленны недаступны стан, як у рэпра issue. Абодва крокі
рэпра паўтораныя на адпраўным і выпраўленым кодзе (адпраўны — праз
`git restore --source=46e3c0d --worktree -- app/map.tsx` і перазапуск бандла):

1. Выбар English на экране KUDY → экран «Побач»: да выпраўлення — «Побач»,
   «Карта горада зʼявіцца…», «Каталог недаступны» пры кнопцы «← Back»; пасля —
   «Nearby», «The city map arrives after the tiles decision», «Catalog
   unavailable».
2. Выбар Українська → экран «Побач»: да — тыя самыя беларускія словы пры кнопцы
   «← Назад»; пасля — «Поруч», «Карта міста з’явиться після рішення про тайли»,
   «Каталог недоступний».
