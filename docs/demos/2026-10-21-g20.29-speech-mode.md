# G20.29 — speech-рэжым да запуску гуку

*2026-10-21T13:09:27Z by Showboat 0.6.1*
<!-- showboat-id: ffdeb1fa-8042-41c3-91a0-6a546d94cf99 -->

Дэма на Linux з замененай толькі мяжой expo-audio. Першы тэст правярае, што Moment і гід чакаюць SPEECH_AUDIO_MODE; адмова дае бачную памылку без фізічнага запуску, а паўторны выклік працуе. Натыўнае фонавае прайграванне на прыладзе тут не праверана.

```bash
set -o pipefail; node --test-isolation=none --test --experimental-strip-types --experimental-test-module-mocks --test-reporter=tap controllers/device-playback.integration.test.ts 2>/dev/null | rg "^(ok|# (tests|pass|fail))"
```

```output
ok 1 - G20.29 AC1–4: device Moment and guide starts await one speech-mode initialization; failure, retry, supersession and stop are observable
ok 2 - G20.29 AC4: device composition binds the same production mode setter to the one audio service
# tests 2
# pass 2
# fail 0
```

Закрыццё сэрвісу да завяршэння наладкі не дазваляе старому запуску пачаць гук.

```bash
set -o pipefail; node --test-isolation=none --test --experimental-strip-types --experimental-test-module-mocks --test-reporter=tap controllers/device-playback-dispose.test.ts 2>/dev/null | rg "^(ok|# (tests|pass|fail))"
```

