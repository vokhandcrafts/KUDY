# G07.01 — Побач: прапановы з пазіцыяй, ручны агляд без яе, ніякага аўдыё

*Showboat demo for issue #281 (G07.01), created 2026-09-27.*

<!-- showboat-id: g0701-nearby -->

Дэма ганяе рэальны шлях каталога (`loadNearby` — тая самая валідацыя
індэкса з sha256-пінам, што і гарадскі спіс) над апублікаванымі фікстурамі
`fixtures/discovery-contract/`, потым чыстыя рашэнні паверхні: два парадкі
прагляду, вартавы ўзбраення па рэжымах і дысцыпліна лакацыі/гуку над адзінай
`LocationService` з аудыё-портам сесіі побач. Скрыпт убудаваны ў дэму і
ідзе праз дынамічныя імпарты (крос-зонны драйвер — той самы прыём, што і
дэма issue #324). Поўны шлях рэндэру праз кампазіцыйны корань — у сюітах
(`app/map.test.tsx`, jest; `controllers/nearby/nearbySurfaceController.test.ts`,
node --test). Вывад дэтэрмінаваны: фіксаваныя ўваходы, без гадзіннікаў.

```sh
node --experimental-strip-types --disable-warning=MODULE_TYPELESS_PACKAGE_JSON --input-type=module -e "
import { createHash } from 'node:crypto';
import { readFileSync } from 'node:fs';
import { pathToFileURL } from 'node:url';
const root = process.cwd();
const { loadNearby } = await import(pathToFileURL(root + '/services/catalog/catalogService.ts').href);
const { nearbyArmingDecision, nearbyOrder, nearbyStrings } = await import(pathToFileURL(root + '/controllers/nearby/nearbySurfaceController.ts').href);
const { AudioService } = await import(pathToFileURL(root + '/services/audio/service.ts').href);
const { FakeAudioPlayerPort } = await import(pathToFileURL(root + '/services/audio/fake-port.ts').href);
const { FakeLocationOsPort } = await import(pathToFileURL(root + '/services/location/fake-port.ts').href);
const { LocationService } = await import(pathToFileURL(root + '/services/location/service.ts').href);
const FIX = 'file://' + root + '/fixtures/discovery-contract/';
const POINTER_PATH = 'discovery/city-a/r-2026-09-14-1/index.json';
const sha256 = (bytes) => createHash('sha256').update(bytes).digest('hex');
const loader = (relPath) =>
  Promise.resolve(readFileSync(new URL(relPath === POINTER_PATH ? 'index-valid.json' : relPath === 'catalog.json' ? 'catalog-with-discovery.json' : relPath, FIX), 'utf8'));
const opts = { localePreference: ['be', 'en'] };
const state = await loadNearby({ loader, sha256 }, opts, null);
if (state.kind !== 'ready') { console.log('load: ' + state.kind + ' ' + (state.reason ?? '')); process.exit(1); }
const review = nearbyOrder(state.offers, { state: 'absent' });
console.log('review: ' + review.map((offer) => offer.offer_id + (offer.distance_m === null ? '' : '(' + offer.distance_m + 'm)')).join(' '));
const proximity = nearbyOrder(state.offers, { state: 'proximity', note: null });
console.log('proximity: ' + proximity.map((offer) => offer.offer_id + (offer.distance_m === null ? '(—)' : '(' + offer.distance_m + 'm)')).join(' '));
console.log('guard: ' + ['idle', 'city-surface', 'active-guide', 'paused'].map((mode) => mode + '→' + nearbyArmingDecision(mode)).join(' '));
const locationPort = new FakeLocationOsPort();
const audioPort = new FakeAudioPlayerPort();
new AudioService({ createPort: () => audioPort });
const location = new LocationService({ port: locationPort, clock: { now: () => 0, schedule: () => () => {} }, permissions: { foreground: 'fg', background: 'bg' } });
if (nearbyArmingDecision(location.currentMode()) === 'arm') location.setMode('city-surface');
locationPort.emitFix(1, { lat: 54.35, lng: 18.65, accuracy: 5, at: 0 });
console.log('arm: mode=' + location.currentMode() + ' regions=' + locationPort.regions.length + ' audio=' + audioPort.commands.length);
console.log('be: ' + nearbyStrings('be').title + ' — ' + nearbyStrings('be').cardHint);
console.log('en: ' + nearbyStrings('en').title + ' — ' + nearbyStrings('en').cardHint);
"
```

```output
review: offer-b1-guide(3200m) offer-a1-place(800m) offer-c1-place offer-e1-place(400m) offer-g1-place(800m) offer-h1-place(800m)
proximity: offer-e1-place(400m) offer-a1-place(800m) offer-g1-place(800m) offer-h1-place(800m) offer-b1-guide(3200m) offer-c1-place(—)
guard: idle→arm city-surface→arm active-guide→hold paused→hold
arm: mode=city-surface regions=0 audio=0
be: Побач — Картка прапановы. Аўдыё не запускаецца.
en: Nearby — Offer card. Audio does not start.
```

Што тут доказана: review — канонічны парадак 21 §4 правіла 6
(`editorial_order`, нічыя па `offer_id`; коллекцыя `offer-f1-collection`
скінутая — яе прыносіць G07.02); proximity — па апублікаванай аўтарскай
адлегласці, прапанова без лічбы (`offer-c1-place`) пасля ўсіх вядомых —
ніколі не выдуманая (P02); вартавая ўзбраення не чапае рэжым жывой
прагулкі; фікс унутры горада не ставіць геафенс-акна і не стварае
аўдыё-падзеі (крытэрый 3); словы чытаюцца па-BE і па-EN (крытэрый 5).
Адкат праверкі: даданне аўдыё-трыгера або `setGeofenceWindow` у nearby-шлях
валіць jest-сюіту экрана («a radius entry and a card tap start no audio…»)
і node-сюіту `nearbyOrder`, што і ёсць Proof задачы.
