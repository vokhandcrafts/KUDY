Крытэры 1–2 — нямецкія словы рэндэрацца праз прадакшн-селектары:
лацункі, лікавыя формы (60/120/240 і інтэрпаляцыя астатнім),
composed-радок тэкст/аўдыё з пустым спісам аўдыё, названыя формы
прэв'ю, вэб-каталог:

```sh
node --experimental-strip-types -e "
import('./components/ui-strings.ts').then(async (m) => {
  const s = m.uiStrings('de');
  console.log('back:', s.back);
  console.log('currentWalk:', s.currentWalk);
  console.log('timeCap(60):', s.timeCap(60));
  console.log('timeCap(45):', s.timeCap(45));
  console.log('stopsCount(7):', s.stopsCount(7));
  console.log('textAudioLine empty audio:', s.textAudioLine(['de'], []));
  const p = await import('./controllers/catalog/previewController.ts');
  console.log('preview.detail missing-files:', p.previewStrings('de').detail({ kind: 'missing-files', count: 2 }));
  console.log('preview.reason purchase:', p.previewReasonText('preview#purchase-required', p.previewStrings('de')));
  const w = await import('./web/lib/i18n/de.ts');
  console.log('web privacyTitle:', w.de.privacyTitle);
  console.log('web catalogTitle:', w.de.catalogTitle);
});
" 2>&1 | grep -vE "Reparsing|trace-warnings|eliminate this warning|Warning: Module type"
```

```output
back: Zurück
currentWalk: Aktueller Rundgang
timeCap(60): Bis zu einer Stunde
timeCap(45): Bis zu 45 Min.
stopsCount(7): Stationen: 7
textAudioLine empty audio: Text: de
preview.detail missing-files: Fehlende Dateien: 2
preview.reason purchase: Kauf erforderlich.
web privacyTitle: Datenschutz
web catalogTitle: Stadt-Guides
```
