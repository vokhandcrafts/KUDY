# G07.05 — падказкі гідаў у адкрытым дадатку (R07)

*Showboat demo for issue #284 (G07.05 — кантролер падказак `controllers/useNearbyController.ts` на прынятым кантракце ADR G07.04), created 2026-10-01.*

Сцэнар на рэальным прадакшн-кодзе (`controllers/useNearbyController.ts` + сапраўдныя `services/location`, `services/audio`, `services/db` над фейкавымі OS-портамі, кананічны `contracts/hints/guide-hints.values.v1.json`):

1. **Dwell і паказ:** першы прыдатны фікс у зоне адкрывае адлік `dwell_s` (20 с) — «hidden (dwell)»; праз 21 с бесперапыннай прысутнасці картка гатовая («ready»), shown-запіс напісаны ў `guide_hint_state` (1 радок), падзея `guide_nearby_shown` запісаная лакальна.
2. **Адхіленне і cooldown:** dismiss піша `dismissed_at`, картка хаваецца («limited»); паўторны ўваход у зону праз 99 с не абыходзіць ліміт — `foreground_cooldown_s` (3600 с) трыма гід заблакаваным.
3. **Адкладзеная картка пры аўдыё:** dwell цягнецца, аўдыё гучыць — цішыня («quiet»); фіксы працягваюць ісці, прысутнасць не ламаецца; пасля аўдыё першы свежы фікс паказвае картку **без другога dwell** (R07: адкладзеная прапанова пераправярае блізкасць).
4. **Састарэлы фікс:** калі паток фіксаў маўчаў даўжэй за `fix_freshness_s` (30 с), стары GPS-callback не выконваецца — новы фікс перазакрепляе прысутнасць, картка чакае новы dwell, нічога не паказваючы са старога фіксу.

(`export LD_LIBRARY_PATH` — хоставае патрабаванне node, не частка змены.)

```sh
export LD_LIBRARY_PATH=$HOME/.local/lib
node --experimental-strip-types --input-type=module -e '
import { pathToFileURL } from "node:url";
const { FakeAudioPlayerPort } = await import(pathToFileURL("services/audio/fake-port.ts"));
const { AudioService } = await import(pathToFileURL("services/audio/service.ts"));
const { FakeLocationOsPort } = await import(pathToFileURL("services/location/fake-port.ts"));
const { LocationService } = await import(pathToFileURL("services/location/service.ts"));
const { listGuidesInHintCooldown, openDatabase, recordGuideHintDismissed, recordGuideHintShown } = await import(pathToFileURL("services/db/db.ts"));
const { nodeSqliteDriver } = await import(pathToFileURL("services/db/test-fixture.ts"));
const { loadGuideHintValues } = await import(pathToFileURL("services/config.ts"));
const { createNearbyHintController } = await import(pathToFileURL("controllers/useNearbyController.ts"));

const VALUES = loadGuideHintValues();
const offer = (routeId, access) => ({
  offer_id: `offer-${routeId}`, kind: "guide", route_id: routeId, place_id: null,
  editorial_order: 0, title: `Гід ${routeId}`, summary: null, distance_m: null,
  text_locales: ["be"], audio_locales: ["be"], access, estimated_duration: null,
});
const HERE = { lat: 54.4, lng: 18.6 };
const FAR = { lat: 54.4 + 0.006, lng: 18.6 };

function world() {
  const clock = { nowMs: 0 };
  const locationPort = new FakeLocationOsPort();
  const location = new LocationService({ port: locationPort, clock: { now: () => clock.nowMs, schedule: () => () => {} }, permissions: { foreground: "fg", background: "bg" } });
  location.setMode("city-surface");
  const audioPort = new FakeAudioPlayerPort();
  const audio = new AudioService({ createPort: () => audioPort });
  const driver = nodeSqliteDriver();
  openDatabase(driver);
  const runRef = { current: { phase: "Idle" } };
  const runSource = { get run() { return runRef.current; }, subscribe: () => () => {} };
  const foregroundRef = { current: true };
  const binding = createNearbyHintController({
    location, audio,
    catalog: { loadNearby: async () => ({ kind: "ready", offers: [offer("route-near", "free"), offer("route-other", "paid")], degraded: null }) },
    store: {
      recordShown: (input) => recordGuideHintShown(driver, { guideIds: input.guideIds, scope: input.context === "active" ? "session" : "foreground", sessionId: input.sessionId ?? undefined, at: input.at }),
      recordDismissed: (input) => recordGuideHintDismissed(driver, { guideIds: input.guideIds, scope: input.context === "active" ? "session" : "foreground", sessionId: input.sessionId ?? undefined, at: input.at }),
      sessionShown: () => [],
      cooldownBlocked: (nowMs, cooldownMs) => listGuidesInHintCooldown(driver, nowMs, cooldownMs),
    },
    points: () => [{ guideId: "route-near", lat: HERE.lat, lng: HERE.lng }, { guideId: "route-other", lat: FAR.lat, lng: FAR.lng }],
    values: VALUES,
    liveRun: () => runSource,
    foreground: () => foregroundRef.current,
    telemetry: { record: () => {} },
    now: () => clock.nowMs,
  });
  const sub = Number(locationPort.commands.find((c) => c.startsWith("start ")).slice("start ".length));
  const emitFix = () => locationPort.emitFix(sub, { lat: HERE.lat, lng: HERE.lng, accuracy: 10, at: clock.nowMs });
  const state = () => {
    const st = binding.store.getState();
    return st.kind === "ready"
      ? `ready [${st.guides.map((g) => g.title).join("; ")}]`
      : st.kind === "hidden" ? `hidden (${st.reason})` : "absent";
  };
  const rows = () => driver.prepare("SELECT COUNT(*) AS n FROM guide_hint_state").all()[0].n;
  return { clock, binding, emitFix, state, rows, audioPort, audio };
}

const settle = () => new Promise((resolve) => setTimeout(resolve, 0));

const w1 = world();
await settle();
w1.emitFix();
console.log(`fix-1 (0 s):          ${w1.state()}`);
w1.clock.nowMs = 21_000;
w1.emitFix();
console.log(`fix-2 (21 s):         ${w1.state()}`);
console.log(`                      guide_hint_state rows=${w1.rows()}`);
w1.binding.dismiss();
console.log(`dismiss:              ${w1.state()}`);
w1.clock.nowMs = 120_000;
w1.emitFix();
console.log(`re-entry (120 s):     ${w1.state()} — the cooldown is ${VALUES.foreground_cooldown_s}s`);

const w2 = world();
await settle();
w2.emitFix();
w2.clock.nowMs = 12_000;
w2.emitFix();
w2.audioPort.snapshotValue = { state: "playing", positionMs: 0, durationMs: 30_000 };
await w2.audio.play({ token: { kind: "moment", ref: "m1", seq: 1 }, path: "bundles/x/audio/story.m4a" });
w2.clock.nowMs = 13_000;
w2.emitFix();
console.log(`\ndwell at 12 s, audio:  ${w2.state()}`);
for (const at of [23_000, 33_000, 41_000]) { w2.clock.nowMs = at; w2.emitFix(); }
console.log(`fixes kept flowing:   ${w2.state()}`);
w2.audio.stop();
w2.audioPort.snapshotValue = { state: "idle", positionMs: 0, durationMs: 0 };
w2.clock.nowMs = 42_000;
w2.emitFix();
console.log(`audio over, fresh fix: ${w2.state()} — shown without a second dwell`);

const w3 = world();
await settle();
w3.emitFix();
w3.clock.nowMs = 12_000;
w3.emitFix();
w3.audioPort.snapshotValue = { state: "playing", positionMs: 0, durationMs: 60_000 };
await w3.audio.play({ token: { kind: "moment", ref: "m1", seq: 1 }, path: "bundles/x/audio/story.m4a" });
w3.clock.nowMs = 13_000;
w3.emitFix();
console.log(`\ndwell at 12 s, audio:  ${w3.state()}`);
w3.clock.nowMs = 100_000;
w3.audio.stop();
w3.audioPort.snapshotValue = { state: "idle", positionMs: 0, durationMs: 0 };
console.log(`audio over, no fixes:  ${w3.state()} — the re-decision waits for the next fix`);
w3.clock.nowMs = 101_000;
w3.emitFix();
console.log(`new fix (fresh):       ${w3.state()} — the presence re-anchors, nothing from the old fix`);
' 2>/dev/null
```

Ліміты, dwell і цішыня — прынятыя лікі ADR G07.04 праз values-файл: у дэмавым сцэнары ніводнага ліка няма, толькі сэмантанка. Прыёмачная сюіта крытэраў 1–5 з issue #284 зялёная (тэсты кантролера, db, назіральніка фіксаў, лоўдэра лікаў, carry-тэст паверхні); render-сюіта карткі над рэальным коранем зялёная. Revert-эксперыменты (зняты paused-гейт, зняты мантаж на Побач, зняты carry) робяць адпаведныя тэсты чырвонымі.
