Executable proof for issue #59 (services/db). Zone A (bundle_asset, catalog_cache, discovery_cache) rebuilds; zone B (session, settings, event_queue, feedback) survives every rebuild and migration failure. The demo runs on the built-in node:sqlite engine through the driver interface — no driver package is pinned (open stack-baseline row, TR-10).

node --experimental-strip-types -e "const { openDatabase, startSession, checkpointProgress, pauseSession, setSetting, appendEvent, rebuildDerived } = await import('./services/db/db.ts');
const { nodeSqliteDriver } = await import('./services/db/test-fixture.ts');

A migration step that fails mid-way rolls back its own DDL, keeps user_version at 1 and keeps every row; the open surfaces named diagnostics with the original error as cause.

```sh
node --experimental-strip-types -e "const { openDatabase } = await import('./services/db/db.ts');
const { migrationSteps } = await import('./services/db/schema.ts');
const { nodeSqliteDriver } = await import('./services/db/test-fixture.ts');
const d = nodeSqliteDriver();
openDatabase(d);
const steps = [migrationSteps[0], { version: 2, up: (x) => { x.exec('CREATE TABLE half_applied (id)'); throw new Error('boom'); } }];
try { openDatabase(d, steps); } catch (e) {
  console.log('rule   :', e.rule);
  console.log('message:', e.message);
  console.log('cause  :', e.cause.message);
}
console.log('user_version    :', Number(d.prepare('PRAGMA user_version').get().user_version));
console.log('half_applied    :', d.prepare('SELECT name FROM sqlite_master WHERE name = ?').get('half_applied') === undefined ? 'rolled back' : 'leaked');" 2>/dev/null
```

```output
rule   : migration-failed
message: migration step 2 failed; the store stays at version 1 with its data intact
cause  : boom
user_version    : 1
half_applied    : rolled back
```

The one_live_session partial unique index decides simultaneous Start/switch races at the schema level (ADR G01.03 §3.1); a losing switch rolls back both legs.

```sh
node --experimental-strip-types -e "const { openDatabase, startSession, pauseSession, switchSession, getLiveSession, getSession } = await import('./services/db/db.ts');
const { nodeSqliteDriver } = await import('./services/db/test-fixture.ts');
const d = nodeSqliteDriver();
openDatabase(d);
startSession(d, { sessionId: 's-demo-1', routeId: 'gdansk-old-town', version: '2026-09-09.1', locale: 'be', startedAt: 1 });
try { startSession(d, { sessionId: 's-demo-2', routeId: 'r2', version: 'v', locale: 'be', startedAt: 2 }); } catch (e) {
  console.log('second Start    ->', e.name + '/' + e.rule);
}
try { d.prepare('INSERT INTO session (session_id, route_id, version, locale, started_at) VALUES (?, ?, ?, ?, ?)').run('s-demo-raw', 'r', 'v', 'be', 3); } catch (e) {
  console.log('raw second row  ->', e.message);
}
pauseSession(d, 's-demo-1');
switchSession(d, 's-demo-1', { sessionId: 's-demo-2', routeId: 'gdansk-motte', version: 'v', locale: 'be', startedAt: 4 }, { finishedAt: 9 });
const oldRow = getSession(d, 's-demo-1');
const live = getLiveSession(d);
console.log('after switch    -> old row:', oldRow.state + ', finished_at=' + oldRow.finishedAt, '| live:', live.sessionId + '@' + live.routeId);" 2>/dev/null
```

```output
second Start    -> DbError/live-session-exists
raw second row  -> UNIQUE constraint failed: index 'one_live_session'
after switch    -> old row: finished, finished_at=9 | live: s-demo-2@gdansk-motte
```
