Доказ (revert-эксперымент, implementation-rules 1): прыбраць пласт збожжа
з wrapper — падаюць чатыры тэсты (кампанентныя і абедзве паверхні);
вярнуць — зелёныя. Эксперымент пачынаецца і сканчаецца аднаўленнем файла
з копіі, таму пасля дэмы код застаецца ў камітнутым стане.

```sh
cp components/paper-surface.tsx .scratch/g0610e-grain/wrapper-backup.tsx
node --input-type=module -e '
import { readFileSync, writeFileSync } from "node:fs";
const p = "components/paper-surface.tsx";
const t = readFileSync(p, "utf8");
const cut = t.replace(/      <Image\n(?:.*\n)*?      \/>\n/, "");
if (cut === t) { console.error("no mutation"); process.exit(1); }
writeFileSync(p, cut);
'
node_modules/.bin/jest components/paper-surface.test.tsx app/explore.test.tsx app/my.test.tsx 2>&1 | grep -E "^Tests:"
```

Жывы прагон (кантэкст, не крок дэмы — натыўны рантайм не дэтэрмінаваны):
незалежны рэндэр з кантэнтам на прыладзе не ўтвараецца — каталожны сэрвіс
не канструюецца без digest-порта (expo-crypto — пазарадавы блокер G06.01,
гл. дэму `2026-09-30-g0610b-fonts.md`), таму фактуру доказвае спекімен з
камітнутага тайла.
