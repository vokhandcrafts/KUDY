The module surface reader (`tools/arch-surface/arch-surface.mjs`, issue #166)
prints a directory's files, exports and external imports. Below: the real
`core/discovery` surface (hand-verified line by line in the results file), the
committed fixture surface (every supported export/import form), and a corrupt
input answered with a diagnostic, not a crash.

The real zone-A module from doc 19, as the code stands:

```sh
node tools/arch-surface/arch-surface.mjs core/discovery
```

```output
# arch-surface: core/discovery

## selectDiscovery.test.ts
exports: (none)
imports: node:assert/strict, node:fs, node:path, node:test, node:url

## selectDiscovery.ts
exports: DiscoveryCollection, DiscoveryCriteria, DiscoveryDifference, DiscoveryIndexV1, DiscoveryMatch, DiscoveryOffer, DiscoveryReason, DiscoveryRef, DiscoveryResult, DiscoverySeason, DiscoverySeasonRecommendation, LocalizedText, selectDiscovery
imports: (none)
```

The committed fixtures exercise the forms the printer extracts — named
const/function/class/type/interface/enum exports, `export default`, brace and
destructured exports, `export * as ns`, multi-line `import type`, side-effect
and dynamic imports — while internal `./` specifiers stay out and `../`
escapes plus bare packages stay in:

```sh
node tools/arch-surface/arch-surface.mjs tools/arch-surface/fixtures/sample
```

```output

## alpha.ts
```
