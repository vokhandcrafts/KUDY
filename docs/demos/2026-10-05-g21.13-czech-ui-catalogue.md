Крытэры 1–2 — чэшскія словы рэндэрацца праз прадакшн-селектары:
лацункі, лікавыя формы (60/120/240 і інтэрпаляцыя астатнім),
composed-радок тэкст/аўдыё з пустым спісам аўдыё, названыя формы
прэв'ю, вэб-каталог:

```sh
node --experimental-strip-types -e "
import('./components/ui-strings.ts').then(async (m) => {
  const s = m.uiStrings('cs');
  console.log('back:', s.back);
  console.log('currentWalk:', s.currentWalk);
  console.log('timeCap(60):', s.timeCap(60));
  console.log('timeCap(45):', s.timeCap(45));
  console.log('stopsCount(7):', s.stopsCount(7));
  console.log('textAudioLine empty audio:', s.textAudioLine(['de'], []));
  const p = await import('./controllers/catalog/previewController.ts');
  console.log('preview.detail missing-files:', p.previewStrings('cs').detail({ kind: 'missing-files', count: 2 }));
  console.log('preview.reason purchase:', p.previewReasonText('preview#purchase-required', p.previewStrings('cs')));
  const w = await import('./web/lib/i18n/cs.ts');
  console.log('web privacyTitle:', w.cs.privacyTitle);
  console.log('web catalogTitle:', w.cs.catalogTitle);
});
" 2>&1 | grep -vE "Reparsing|trace-warnings|eliminate this warning|Warning: Module type"
```

```output
back: Zpět
currentWalk: Aktuální procházka
timeCap(60): Do hodiny
timeCap(45): Do 45 min
stopsCount(7): Zastavení: 7
textAudioLine empty audio: Text: de
preview.detail missing-files: Chybí soubory: 2
preview.reason purchase: Vyžaduje se nákup.
web privacyTitle: Soukromí
web catalogTitle: Průvodci po městě
```
