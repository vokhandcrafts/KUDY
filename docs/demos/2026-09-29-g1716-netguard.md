# G17.16: гард сеткавага шляху — толькі публічныя http/https адрасы (issue #375)

*Showboat demo для G17.16: перад кожным сапраўдным запытам калектара
(`netguard.mjs`) адрас правяраецца — схема толькі http/https, хост толькі
публічны. Кампанія з сідамі на 127.0.0.1, 10.x і 192.168.x праганяецца праз
сапраўдны CLI: ніякага запыту не робіцца, кожны сід атрымлівае чытальную
дыягностыку ў журнале крокаў, тры запар адмовы спыняюць ран (серыйная мяжа),
чацвёрты сід чакае ў чарзе. Выпадковы ідэнтыфікатар кампаніі ў віводзе
замаскіраваны сэдам — астатняе дэтэрмінавана. Створана 2026-09-29.*

<!-- showboat-id: g17-16-netguard -->

Крытэр 1 + 4 — прагон кампаніі з прыватнымі сідамі праз сапраўдны CLI:
адмовы з чытальнымі прычынамі, нулявы вынік збору, серыйны прыпынак:

```sh
rm -rf tools/collector/runtime/demo-375 && mkdir -p tools/collector/runtime/demo-375 && cat > tools/collector/runtime/demo-375/campaign.yaml <<'YAML'
city: gdansk
seeds:
  - http://127.0.0.1/start
  - http://10.1.2.3/mid
  - http://192.168.0.44/end
  - http://127.0.0.1/last
topics: [history]
fence:
  depth: 3
  extra_domains: []
  delay_s: [0.05, 0.1]
youtube: []
YAML
node tools/collector/collector.mjs run --campaign tools/collector/runtime/demo-375/campaign.yaml --db tools/collector/runtime/demo-375/db.sqlite 2>&1 | sed -E 's/\([0-9a-f]{12}\)/(XXXXXXXXXXXX)/' | grep -v "snapshots root"
```

```output
collector: run stopped — error series: 3 consecutive crawl failures, last at http://192.168.0.44/end (net guard: 192.168.0.44 is a private (RFC1918) address — request not made) — run stopped, queued steps resume on the next run
collector: campaign gdansk (XXXXXXXXXXXX) — steps done 0, failed 3, running 0, pending 1
collector: raw_records total 0
```

Крытэр 1 (дыяпазоны) — клясыфікатар называе прычыну для кожнага дыяпазону з
задачы, гарда адмаўляе не-http(s) схему да ўсякага рашэння хоста:

```sh
node -e "import('./tools/collector/netguard.mjs').then(async ({ classifyAddress, createNetGuard }) => { for (const host of ['127.0.0.1','::1','10.1.2.3','172.16.9.9','192.168.0.44','169.254.169.254','0.0.0.0','fd00::1','93.184.216.34']) { console.log(host, '→', classifyAddress(host) ?? 'public'); } try { await createNetGuard({})('ftp://files.example/doc'); } catch (e) { console.log(e.message); } });"
```
