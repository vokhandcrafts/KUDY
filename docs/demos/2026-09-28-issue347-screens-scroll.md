# UX 01: экраны скроляцца (issue #347)

*Showboat demo для эпіка дызайн-выпраўленняў #346, задача #347: ніводзін
экран не скроліцца — галоўная дзея прэв'ю гіда і апошнія карткі спісаў
застаюцца за фолдам. Пяць экранаў (прэв'ю гіда, «Побач», «My KUDY»,
дэталь месца, панэль Run) атрымалі ScrollView; сямейная мапа Run і

Дэма ганяе пяць render-гвардаў (адзін на экран): кожны правярае прысутнасць
кантэнту ўсярэдзіне ScrollView экрана — зняцце абгорткі валіць свой тэст.

```sh
node_modules/.bin/jest app/preview.test.tsx app/map.test.tsx app/place/place.test.tsx app/run.test.tsx app/my.test.tsx -t "UX 01" 2>&1 | grep -E "^(Test Suites:|Tests:|Snapshots:)"
```

Эксперымент па зняцці фіксу (implementation-rules 1) выкананы ў гэтай сесіі:
`app/map.tsx` адкінуты да HEAD праз stash — гвард «Побач» зачырвонеў
адзіным упалым тэстам свайго сюту; пасля `stash pop` той жа запуск —
зелёны.

Жывая праверка ўбудовы (таго ж дня, AVD `kudy-test`): Metro з галінкі
задачы з `EXPO_PUBLIC_FAKE_CATALOG=1` і `EXPO_PUBLIC_CATALOG_ORIGIN=http://10.0.2.2:8788`
(лакальны фейк-сервер каталога на свабодным порце — дэфолтны 8787 быў
заняты паралельнай сесіяй; перавызначэнне прадугледжана дэв-сцягам), у
лакальнай некамічанай копіі дэв-сцяжкі дадатковы дэв-порт сховішча пакетаў,
каб галоўная кнопка прэв'ю рэндэрылася ў сумленным стане «Загрузіць».
Халодны старт → каталог «Гданьск» → прэв'ю «Дванаццаць кропак: прабны
доўгі гід» — «Кропкі: 12», стопы да пятай на першым экране; пасля
пракруткі відаць апошнія стопы і кнопку «Загрузіць» з сумленным
прычынай недаступнасці загрузкі на гэтай зборцы. «Побач» — спіс прапановаў
скроліцца да апошняй карткі. Натыўны хедар з сыравай назвай рута — гэта
задача UX 02 (#348, закрывае #344), тут не кранутая.
