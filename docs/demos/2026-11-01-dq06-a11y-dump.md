# DQ-06 — праверкі даступнасці з дампа UI

*2026-11-01 by Showboat 0.6.1*
<!-- showboat-id: 7c31e5a9-2f60-4d18-8b44-dq06a11ydumprpt -->

Задача [#916](https://github.com/vokhandcrafts/KUDY/issues/916). Справаздача
`npm run visual:check` дадае вымяраныя факты даступнасці з дампа ўзнаўлены
(uiautomator) для ўсіх здымных паверхняў: клікабельны вузел без тэксту і без
`content-desc` — `RULE` па каноне §9, мішэнь менш за 48 dp — `OPINION` да
рашэння ўладальніка (спец §12, пытанне 4). `hitSlop` дамп не бачыць — рэестр
читае яго з кода `app/` + `components/` і прывязвае да dump-вузлоў праз
testID. Усе блокі ідуць з кораня рэпазітарыя і на эмульятар не спадзяюцца.

Першы блок — сее фікстуры: два ідэнтычныя здымкі/узоры (піксельная паўна —
PASS), дамп з падкладзенай іконкай-кнопкай без подпісу (RULE) і дробнай
маркіраванай мішэнню 12×12 dp (OPINION), маніфест са шчыльнасцю 2 px/dp.
Прагон тулу — радок вердыкту і радок a11y.

```bash
node -e '
const fs = require("fs");
const { PNG } = require("pngjs");
const root = "/tmp/dq06-demo";
fs.rmSync(root, { recursive: true, force: true });
fs.mkdirSync(root + "/captures", { recursive: true });
fs.mkdirSync(root + "/baselines", { recursive: true });
const png = (() => { const p = new PNG({ width: 108, height: 240 }); for (let i = 0; i < 108 * 240; i++) { p.data[i*4] = 200; p.data[i*4+1] = 180; p.data[i*4+2] = 160; p.data[i*4+3] = 255; } return PNG.sync.write(p); })();
for (const scale of [1, 1.5]) { fs.writeFileSync(root + "/captures/explore-a_font" + scale + "-be.png", png); fs.writeFileSync(root + "/baselines/explore-a@font" + scale + "-be.png", png); }
fs.writeFileSync(root + "/captures/manifest.json", JSON.stringify({ a11y: { densityPxPerDp: 2 } }) + "\n");
const dump = `<?xml version='"'"'1.0'"'"' encoding='"'"'UTF-8'"'"' standalone='"'"'yes'"'"' ?>\n<hierarchy rotation="0">\n` +
  `<node text="" resource-id="probe/icon-send" class="android.view.View" content-desc="" clickable="true" bounds="[10,100][58,148]"><node text="" resource-id="" class="android.widget.ImageView" content-desc="" clickable="false" bounds="[18,108][50,140]" /></node>\n` +
  `<node text="" resource-id="probe/tiny" class="android.view.View" content-desc="дробная" clickable="true" bounds="[0,300][24,324]" />\n` +
  `</hierarchy>`;
for (const scale of [1, 1.5]) fs.writeFileSync(root + "/captures/dump-explore-a-font" + scale + ".xml", dump);
console.log("seeded: an unlabeled icon button (RULE) + a 12×12 dp labelled node (OPINION)");
' && node tools/e2e-android/visual-check.mjs --from /tmp/dq06-demo/captures --baselines-dir /tmp/dq06-demo/baselines --out /tmp/dq06-demo/out --surface explore-a 2>/dev/null | head -2
```

```output

visual:check — PASS 2 · DIFF 0 · FAIL 0 · NOT-VERIFIED 0
a11y — RULE 2 · OPINION 2 · NOT-VERIFIED 1
```
