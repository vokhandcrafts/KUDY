# G17.08 — pilot campaign Gdansk: local pipeline portions (run resume, clean idempotency, review bundle)

*Showboat demo for issue #163 (`tools/collector`), created 2026-09-29.*

<!-- showboat-id: g1708-pilot-gdansk -->

The pilot campaign ran live on the author's machine (pl.wikipedia.org via the
MediaWiki API, 8 YouTube videos via yt-dlp); the live-site fetches themselves
are recorded as outputs in `docs/agent-tasks/results/G17.08.md`. This demo
drives the same real CLI offline over a `file://` fixture and proves the local
pipeline portions the pilot relies on: a run followed by a rerun adds nothing
(resume, not restart — spec criterion 7's mechanism), a second `clean` writes
no versions (convergence), and `export-review` produces the author-review
bundle whose document opens with the visible citation. Record ids and
collection timestamps are volatile by design, so the printed excerpts mask
them — the captured output is otherwise byte-identical between runs.

```sh
node --input-type=module -e '
import fs from "node:fs";
const dir = "/tmp/kudy-g1708-demo";
fs.rmSync(dir, { recursive: true, force: true });
fs.mkdirSync(dir, { recursive: true });
fs.writeFileSync(dir + "/seed-page.html", [
  "<!DOCTYPE html>",
  "<html lang=\"pl\">",
  "<head><title>Motława — the river of Gdansk</title></head>",
  "<body>",
  "  <p>The <a href=\"https://pl.wikipedia.org/wiki/Gda%C5%84sk\">Motława</a> flows through Gdansk.</p>",
  "  <p>It is a left tributary of the Vistula.</p>",
  "  <p>Its name comes from the Old Prussian language.</p>",
  "</body>",
  "</html>",
  "",
].join("\n"));
fs.writeFileSync(dir + "/campaign.yaml", [
  "city: gdansk",
  "seeds:",
  "  - file:///tmp/kudy-g1708-demo/seed-page.html",
  "topics: [history]",
  "fence:",
  "  depth: 1",
  "  extra_domains: []",
  "  delay_s: [2, 5]",
  "youtube: []",
].join("\n") + "\n");
console.log("fixture ready");
' && node tools/collector/collector.mjs run --campaign /tmp/kudy-g1708-demo/campaign.yaml --db /tmp/kudy-g1708-demo/db.sqlite && node tools/collector/collector.mjs run --campaign /tmp/kudy-g1708-demo/campaign.yaml --db /tmp/kudy-g1708-demo/db.sqlite && node tools/collector/collector.mjs clean --campaign /tmp/kudy-g1708-demo/campaign.yaml --db /tmp/kudy-g1708-demo/db.sqlite && node tools/collector/collector.mjs clean --campaign /tmp/kudy-g1708-demo/campaign.yaml --db /tmp/kudy-g1708-demo/db.sqlite && node tools/collector/collector.mjs export-review --campaign /tmp/kudy-g1708-demo/campaign.yaml --db /tmp/kudy-g1708-demo/db.sqlite && node --input-type=module -e '
import fs from "node:fs";
const dir = "/tmp/kudy-g1708-demo/snapshots";
const [campaign] = fs.readdirSync(dir);
const review = `${dir}/${campaign}/review`;
const files = fs.readdirSync(review).sort();
console.log("review files:", files.length);
const [doc] = files.filter((name) => name !== "index.md");
console.log(fs.readFileSync(`${review}/${doc}`, "utf8").split("\n").filter((line) => !line.startsWith("Забрана: ") && !line.startsWith("record: ")).join("\n").trimEnd());
'
```
