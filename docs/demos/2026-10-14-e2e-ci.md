# G23.08 — CI запуск скразных тэстаў

*2026-10-14T19:29:45Z by Showboat 0.6.1*
<!-- showboat-id: d758f6b3-3f30-4dca-ac78-1a3235be593e -->

Гэты лакальны доказ правярае, што абодва workflow выклікаюць сапраўдныя E2E-каманды, Android прапусканне лічыцца памылкай, а ўсе actions замацаваны поўнымі SHA. Жывыя запускі GitHub Actions пазначаныя ў выніку задачы.

```bash
set -o pipefail; node --test tools/ci/e2e-workflows.test.mjs 2>&1 | grep -E "^ℹ (tests|pass|fail) "
```

```output
ℹ tests 4
ℹ pass 4
ℹ fail 0
```
