# G20.31 (#793): рэактывацыя пашкоджанага слоя — exists бачыць дырэкторыі

*2026-10-17T01:36:21Z by Showboat 0.6.1*
<!-- showboat-id: 765cb74a-d320-4d4f-b12e-063c4cb7724f -->

Showboat-дэма задачы #793 (G20.31, эпік #470). Кантракт: `DownloadStore.exists` адказвае і для файлаў, і для дырэкторый — як node-адаптар праз `stat`; рэактывацыя пашкоджанага слоя замяняе яго па фінальным шляху і ніколі не ўкладвае новы слой унутры старога.

Дэфект аўдыту (finding `directory-existence-misclassified`): `File.exists` у expo-file-system 19.0.24 на Android — гэта `isFile` (дырэкторыя чытаецца як «няма»), а `Directory.move` ва ўжо існуючую дырэкторыю ўкладвае ўнутр (`FileSystemPath.getMoveOrCopyPath`, `mv a b` → `b/a`). Гэта дэтэрмінаванае ўзнаўленне адаптара, не прыладны E2E. Хост:

```bash
node --version && uname -sr
```

```output
v26.11.1
Linux 7.2.9-2-cachyos
```

Рэгрэсійная сюіта (крытэрыі 1–3): дырэкторыі і файлы ў `exists`; паўторная актывацыя аднаўляе байты на фінальным шляху, без укладання; заменнік файлавай сістэмы трымае натыўныя семантыкі Expo, а не Node. Сюіта едзе ў `npm test` праз існуючы глаб `services/**/*.test.ts` (раннеры не краналіся):

```bash
node --no-warnings --experimental-strip-types --test --test-reporter=tap services/download/expo/expo-download-store.test.ts 2>/dev/null | grep -E '^# (tests|pass|fail)'
```

```output
# tests 3
# pass 3
# fail 0
```

Узнаўленне сцэнару аўдыту: актывацыя двухфайлавага слоя → пашкоджанне фінальнага `stops.json` (байт `x`) → паўторная актывацыя. Прадфіксавы класіфікатар «толькі файл» пабудаваны тут жа з бягучага адаптара (адакат адной лініі фікса); прадукцыйны магазін — як ён ёсць. Прадфіксавы радок — назіранне аўдыту: `complete` пры байце `x` на фінальным шляху і ўкладзеным `base/base/…`; прадукцыйны — байты слоя вернутыя, укладання няма:

```bash
node --no-warnings --experimental-strip-types --input-type=module <<'JS'
import { createExpoDownloadStore } from './services/download/expo/expo-download-store.ts';
import { createAccessPort } from './services/download/access.ts';
import { activate } from './services/download/download.ts';
import { nodeSha256 } from './services/download/nodeDownloadStore.ts';
import { GOOD, lockFrom, openFresh } from './services/download/test-fixture.ts';
import { makeFakeFs, makeFakeFsModule } from './services/contentRepo/expo/fs-test-fixture.ts';

const KEY = { routeId: 'r', version: '1', locale: 'be', tier: 'base' };
const FINAL = '/root/bundles/r/1/be/base';
const EXPECTED = ['/stops.json', '/audio/story-1.m4a'];
const lock = await lockFrom(GOOD);

async function scenario(mode) {
  const fs = makeFakeFs();
  const { File, Directory } = makeFakeFsModule(fs);
  const root = new Directory('/root');
  const base = createExpoDownloadStore({ File, Directory, freeBytes: () => 1_000_000 }, root);
  const store = mode === 'file-only' ? { ...base, exists: async (rel) => new File(root, ...rel.split('/')).exists } : base;
  const deps = {
    store,
    fetch: async (rel) => GOOD[rel] ?? (() => { throw new Error('no source bytes for ' + rel); })(),
    sha256: nodeSha256,
    driver: openFresh(),
    access: createAccessPort(),
  };
  const input = { ...KEY, lock };
  const first = await activate(input, deps);
  fs.files.set(FINAL + '/stops.json', new TextEncoder().encode('x'));
  const resumed = await activate(input, deps);
  return JSON.stringify({
    first: first.status,
    reactivate: resumed.status,
    stops: new TextDecoder().decode(fs.files.get(FINAL + '/stops.json')),
    nested: [...fs.files.keys()]
      .filter((p) => p.startsWith(FINAL + '/') && !EXPECTED.includes(p.slice(FINAL.length)))
      .sort(),
  });
}

console.log('file-only exists   :', await scenario('file-only'));
console.log('production (fixed) :', await scenario('production'));
JS
```

```output
file-only exists   : {"first":"complete","reactivate":"complete","stops":"x","nested":["/root/bundles/r/1/be/base/base/audio/story-1.m4a","/root/bundles/r/1/be/base/base/stops.json"]}
production (fixed) : {"first":"complete","reactivate":"complete","stops":"{\"stops\":[]}\n","nested":[]}
```
