# G339 — халодны старт адкрывае каталог, nonscreen-модулі па-за app/

*Showboat demo for issue #339 (device-run), created 2026-09-27.*

<!-- showboat-id: g339-cold-start -->

Дэма друкаваныя вердыкты з драйвера `test/demo-g339-cold-start.mjs`: класіфікацыя
`app/` тая самая, што ў guard-сюіце `test/app-router-purity.test.mjs` — толькі
маршруты (default export), спецфайлы роўтэра (`+*`, `_layout`) і калакалізаваныя
сюты; nonscreen-модуляў у `app/` нуль (яны ў `components/`), а index-маршрут
зрабіў пераход на кананічны ўваход.

```sh
node test/demo-g339-cold-start.mjs
```

```output
app/: routes=8 special=2 suites=5 nonscreen=0
cold start: index Redirect -> /explore
components/: design-tokens, guide-card, guide-card.test, placeholder, walk-button
```

Поўны ланцуг доказаў задачы (гэта ж сесія): на AVD `kudy-test` халодны старт
(`am force-stop` → `monkey -p by.kudy.app -c android.intent.category.LAUNCHER 1`,
без дып-лінкаў і тыкаў) паказвае `(tabs)/explore` з каталогам («Гданьск», «Побач»,
«Каталог недаступны»), а лог Metro (радок `Android Bundled` у Evidence PR) — без
WARN пра недахоп default export: папярэднія чатыры WARN больш не ўзнікаюць.
Адкат праверкі (праверана перад push): зламаць `href` index-рэдырэкту — тэст
халоднага старту ў `app/navigation.test.tsx` чырвоны; пакінуць nonscreen-файл у
`app/` — guard `test/app-router-purity.test.mjs` чырвоны; зрабіць runtime-імпарт
зоны з `components/` — `npm run arch:check` чырвоны (правіла
`components-zone-closed`).
