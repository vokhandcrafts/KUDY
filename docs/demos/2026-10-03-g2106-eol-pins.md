# Issue #539: кананічны тэкст трымае байты на чекаўце з core.autocrlf=true

*Showboat дэма задачи #539 (G21.06): на свежым чекаўце з
`core.autocrlf=true` фікстура `index-stop-places.json` апыналася CRLF
(14982 байты замест 14475), таму sha256-пін каталога не збігаўся, і
preview-праверка цэласнасці падала; гэтая ж хвароба ламала byte-wise
праверкі wire-types, traces і authoring-рэпартаў. Фікс — вузкія піны
`eol=lf` у `.gitattributes` для байт-параўноўванага кананічнага тэксту
плюс LF-ідыём у тэкставых guards. Створана 2026-10-03.*

<!-- showboat-id: g2106-eol-pins -->

Дэфект на pre-fix каміце (`4207036` — HEAD рэтэсту 2026-10-03): свежы
клон з `core.autocrlf=true`, фікстура перачытаная пад pre-fix
`.gitattributes` без піна — 14982 байты і чужы хэш:

```sh
rm -rf /tmp/kudy-g2106-prefix
git clone -q -c core.autocrlf=true file://"$(pwd)" /tmp/kudy-g2106-prefix
git -C /tmp/kudy-g2106-prefix checkout -q -f 42070367485bdc764843433a0e2c203bcfa89506
rm -rf /tmp/kudy-g2106-prefix/fixtures/discovery-contract
git -C /tmp/kudy-g2106-prefix checkout -q -f 42070367485bdc764843433a0e2c203bcfa89506 -- fixtures/discovery-contract
wc -c < /tmp/kudy-g2106-prefix/fixtures/discovery-contract/index-stop-places.json
sha256sum /tmp/kudy-g2106-prefix/fixtures/discovery-contract/index-stop-places.json | cut -d' ' -f1
```

Негатыў па крытэры 4: псаванне аднаго пінаванага байта мяняе хэш —
прадакшн-брама (`index-pin-mismatch`, `services/contentRepo/
discoveryIndex.ts`) такі ввод адхіляе; чысты файл пін трымае:

```sh
node -e "const fs=require('node:fs');const{createHash}=require('node:crypto');const cat=JSON.parse(fs.readFileSync('fixtures/discovery-contract/catalog-discovery-stop-places.json','utf8'));const raw=fs.readFileSync('fixtures/discovery-contract/index-stop-places.json');const corrupt=Buffer.from(raw);corrupt[0]^=0x20;const sha=(b)=>createHash('sha256').update(b).digest('hex');console.log('clean matches pin      :', sha(raw)===cat.discovery_index.sha256);console.log('corruption is rejected :', sha(corrupt)!==cat.discovery_index.sha256)"
```

```output
clean matches pin      : true
corruption is rejected : true
```
