# Аўтаномная дэманстрацыйная зборка Android

`KUDY Demo` — асобная ўсталёўка (`by.kudy.app.demo`) для праверкі экранаў і
асноўнага сцэнарыя прагулкі. Яна не замяняе KUDY на прыладзе. Каталог,
месца, падборка, тры гісторыі і гукавыя файлы ўбудаваныя ў APK; для іх
адкрыцця не патрэбны сервер. Пакет ствараецца з валіднай тэставай фікстуры
праз звычайныя зборшчык і публікацыю каталога.

На галоўным экране заўсёды паказана, што гэта дэма. Назвы і тэксты гісторый
выдуманыя; гукавыя файлы — кароткія тэставыя тоны, а не агучаныя аповеды.
Каардынаты і адлегласці прыкладныя. Дэма-маршрут не выкарыстоўвайце для
навігацыі па горадзе.

## Зборка

Патрэбныя Android SDK, JDK і ўсталяваныя залежнасці праекта. На Linux:

```sh
node tools/demo/build-demo.mjs --check
EXPO_PUBLIC_DEMO_MODE=1 npx expo prebuild --platform android --no-install
cd android
EXPO_PUBLIC_DEMO_MODE=1 NODE_ENV=production ./gradlew :app:assembleRelease --no-daemon --max-workers=2
```

Калі SDK не знаходзіцца аўтаматычна, задайце `ANDROID_HOME` перад апошняй
камандай. Вынік: `android/app/build/outputs/apk/release/app-release.apk`.
Устаноўка: `adb install -r android/app/build/outputs/apk/release/app-release.apk`.

Гэта **дэманстрацыйны release APK, падпісаны debug-ключом Gradle**. Ён
прыдатны для лакальнага паказу, але не для публікацыі ў краме. Для сапраўднага
выпуску патрэбныя ўласны ключ падпісання, прынятыя кантэнт і іконка,
рэальная публічная крыніца каталога і праверка пакупак ды іншых знешніх
сэрвісаў. Дэма-рэжым уключаецца толькі яўным `EXPO_PUBLIC_DEMO_MODE=1`;
звычайная зборка працягвае працаваць з наладжаным каталогам.
