# MAP-02 — абраны чарнавік для наразання меню

Уладальнік выбраў `map-cutout-v2` 2026-10-30: «бяром другую версію. Адкрывай PR - запішы як драфт для наразання пунктаў меню».

## Рабочыя файлы

- [PNG](map-cutout-v2.png) — карта з празрыстым вонкавым фонам і плаўнымі канцамі рэк, 1351 × 1164 px.
- [SVG](map-cutout-v2.svg) — самадастатковы гібрыдны файл: той самы PNG убудаваны без змены байтаў, вонкавы контур дададзены асобным рэдагуемым шляхам.
- [Прэв’ю на двух фонах](map-cutout-v2-preview.png), [памяншэнне да 240 px](map-cutout-v2-small.png), [лакальная праверка](cutout-preview.html).
- [Брыф для наразання](slicing-brief.md); [промпты карэкцыі канцоў рэк](map-cutout-v2-prompts.txt) захоўваюць паходжанне генерацыі. Прамежкавыя выявы генерацыі не патрэбныя для выкарыстання асета і ў гэты пакет не ўваходзяць.

Гэта абраны **візуальны чарнавік**, а не поўнасцю вектарная майстар-карта або гатовае меню. Унутраныя раёны, вуліцы і расліннасць застаюцца растравай выявай. SVG не дадае дэталяў і не робіць растр неабмежавана маштабаваным.

## Каардынаты і наступны падзел

Агульная сістэма: `viewBox="0 0 1351 1164"`. Адна адзінка — адзін піксель PNG. Пласт `map-artwork` утрымлівае малюнак. Схаваны пласт `cut-outline-layer` можна ўключыць для рэдагавання вонкавага контуру; у `defs` ёсць `outer-outline` і `outer-cut`.

Вонкавы шлях атрыманы з альфа-канала: парог 128, спрашчэнне 0,6 px. Ён апісвае сілуэт асета, не гістарычны GIS-контур. Маска `outer-cut` не ўжываецца па змаўчанні: PNG ужо мае ўласную празрыстасць.

Для будучых частак ствары контуры раёнаў у гэтай жа сістэме і выразай іх маскамі з адной крыніцы. Не перамалёўвай і не маштабуй кавалкі незалежна. Дакладныя контуры, суседствы, праверка зборкі і асобныя экспарты яшчэ не створаныя.

## Праверка і паўторная ўпакоўка

З кораня рэпазіторыя:

```sh
node docs/design/brand/outputs/MAP-02/verify-cutout.mjs
python docs/design/brand/outputs/MAP-02/package-cutout.py map-cutout-v2.png
```

Праверка выкарыстоўвае npm-залежнасці праекта і ўсталяваны Google Chrome. Скрыпт упакоўкі патрабуе Python з OpenCV і паўторна стварае толькі SVG з гатовага PNG; ён не запускае генерацыю і не змяняе PNG. Для адкрыцця PNG або SVG гэтыя інструменты не патрэбныя.

Выява створаная і рэдагаваная праз убудаваны ImageGen паводле рэферэнсаў уладальніка. Варыянты да v2 і скрыншоты з прыватнымі дадзенымі ў PR не публікуюцца. Правераная гістарычная геаметрыя і права на вытворчае выкарыстанне першакрыніцы яшчэ патрабуюць асобнай зверкі паводле [MAP-01](../../../../agent-tasks/results/MAP-01.md).
