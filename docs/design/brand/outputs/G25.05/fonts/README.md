# Лакальныя шрыфты дошкі G25.01

Гэта копіі ўжо замацаваных у `package-lock.json` пакетаў `@expo-google-fonts/*` версіі 0.4.2. Крыніца файлаў — лакальны `node_modules` гэтай версіі; у HTML няма CDN-запыту. Файлы патрэбныя толькі для рэдагуемай дызайнерскай дошкі, не змяняюць загрузку шрыфтоў у дадатку.

| Файл | Пакет і пачатковы шлях | Роля | Ліцэнзія |
|---|---|---|---|
| `GolosText_400Regular.ttf` | `@expo-google-fonts/golos-text/400Regular/` | асноўны тэкст | [GolosText-OFL.txt](GolosText-OFL.txt) |
| `GolosText_600SemiBold.ttf` | `@expo-google-fonts/golos-text/600SemiBold/` | UI-загалоўкі і кнопкі | [GolosText-OFL.txt](GolosText-OFL.txt) |
| `Alegreya_600SemiBold.ttf` | `@expo-google-fonts/alegreya/600SemiBold/` | назвы гісторый | [Alegreya-OFL.txt](Alegreya-OFL.txt) |
| `Caveat_400Regular.ttf` | `@expo-google-fonts/caveat/400Regular/` | кароткая рэпліка дракона | [Caveat-OFL.txt](Caveat-OFL.txt) |

Поўныя правілы выкарыстання і аўтары — [візуальны канон, раздзел 3](../../../../visual-language.md). Усе чатыры файлы распаўсюджваюцца паводле OFL 1.1; тэксты ліцэнзій змешчаныя побач з імі.
