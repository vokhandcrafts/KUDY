# Пяць прапаноў свячэння

Статус: 2026-10-31 уладальнік выбраў варыянт 1, бурштынавы, і дадаў напрамак тонкіх павольных плаўных нітак святла. Аснова — пяць яго меню-частак і існая светлавая трансфармацыя. Правераны дасланы відэазапіс працэсу: шэрая залівка ўзнікае пасля светлага сілуэта, пры вяртанні колераў.

У існым web-эскізе інтэрпалюецца `filter` ад `brightness(0) invert(1)` да звычайнай выявы. Пры сярэдніх значэннях brightness/invert колеры ператвараюцца ў амаль аднолькавы шэры. У гэтых пяці пробах колеры горада заўсёды застаюцца ў асноўным PNG; зверху змяняецца толькі празрыстасць асобнага каляровага сілуэта. Геаметрыя, ручны магніт і націскі не перапраектаваныя.

Гэта назіранне датычыцца дасланага web-запісу. У native-кампаненце ўжо выкарыстоўваецца асобны светлы PNG з празрыстасцю; для яго тут прапануюцца колеры і дадатковыя элементы эфекту, а не новая нарэзка.

| № | Напрамак | Святло і дадатковы рух |
|---|---|---|
| 1 | Бурштынавае святло | Выбрана: мядовы арэол, залатыя колы і тонкія плаўныя ніткі |
| 2 | Марская біруза | Мята, біруза і тонкая залатая хваля; папярэдняя альтэрнатыва |
| 3 | Перламутр | Малочны цэнтр, бэзавы/ружовы водбліск, два лёгкія абручы |
| 4 | Паўночнае ззянне | Зялёныя і блакітныя стужкі, якія падымаюцца знізу |
| 5 | Сонечны россып | Персік, каралавы і залаты россып чатырохпрамянёвых іскраў |

Параўнанне паказвае аднолькавы момант для ўсіх пяці. Паўзунок дазваляе спыніць любую фазу, кнопка прайгравае адзін цыкл 2,7 с. Няма аўтазапуску і бясконцага паўтарэння. Сістэмны reduced motion паказвае вынік без прайгравання.

Каб адкрыць старонку, сервер павінен абслугоўваць агульны каталог `outputs`, а не толькі папярэднюю тэчку:

```sh
python -m http.server 4390 --bind 127.0.0.1 --directory docs/design/brand/outputs
```

Адрас: `http://127.0.0.1:4390/menu-glow-options/`. Асеты і ліцэнзаваныя шрыфты бяруцца з суседняга `menu-map-city-only`; дадатковых залежнасцей або CDN няма. Дасланы прыватны відэафайл у пакет не капіраваўся.

Шрыфтавы драфт з упадабанага макета захаваны асобна: [typography-draft.md](typography-draft.md). Выбраная бурштынавая палітра і ніткі перанесеныя ў native-кампанент і асноўнае web-дэма. Рэферэнс нітак задае характар, а не форму для капіравання.
