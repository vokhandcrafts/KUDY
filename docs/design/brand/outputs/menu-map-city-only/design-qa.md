- Native-кампанент разам з існай рэгрэсійнай праверкай WalkProgress: 9/9, дзве Jest-сюіты.
- Існыя Node-праверкі падключэння Jest: 2/2. Новыя мадэльныя тэсты і native-сюіта ўключаныя ў npm test.
