KUDYГданьск

Куды сёння?

Пяць частак горада. Свая гісторыя ў кожнай.

Націсні — адкрыць. Утрымлівай — рухаць.

Твае пяць частак.
Адна карта.

  1. Абласці 1–5 з тваёй абводкі — асобныя пункты меню.
  2. Магніт спрацоўвае толькі падчас перацягвання, калі патрэбныя бакі апынаюцца побач.
  3. Пасля апошняга злучэння святло з-пад частак ператварае іх у цэлую карту.
  4. Пяць частак адкрываюць свае раздзелы. Новыя часткі карты рэагуюць на клік без пераходу.

Кнопка анімацыі ёсць толькі ў гэтым праглядзе. У мабільным кампаненце часткі злучае карыстальнік.

Клавіятура: Tab і Enter — выбар раздзела. Стрэлкі — перамяшчэнне. S — злучыць з суседам. Escape — скасаваць рух.

Усе сем слаёў выразаныя з аднаго арыгінала. Назвы — асобны тэкст.
