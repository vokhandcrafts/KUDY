# Пяць частак адкрываюць карту

Абноўлены пакет паводле абводкі ўладальніка ад 2026-10-31. Пяць меню-частак — заходняя зялёная, цэнтральная ружовая, усходняя жоўтая, ніжняя ружовая і ніжняя зялёная. Верхняя і вузкая светлыя палосы адкрываюцца са сцэнай. У вобласці 3 захаваны ўнутраны канал, бо ён уваходзіць у абведзеную вобласць.

Гатовы мабільны кампанент — [native/CityMapMenu.tsx](native/CityMapMenu.tsx), [інструкцыя інтэграцыі](native/README.md). У мабільным пакеце няма аўтазборкі: магніт спрацоўвае толькі ад сапраўднага перацягвання. Існыя экраны Expo і production-навігацыя не змененыя.

## ID і флоў

| Нумар на абводцы | ID | Назва ў прыкладзе |
|---|---|---|
| 1 | `nearby` | Побач |
| 2 | `guides` | Гіды |
| 3 | `discovery` | Чым заняцца |
| 4 | `reserve-1` | Хутка |
| 5 | `kudy` | KUDY |

Кожны ID адкрывае сваю дэма-панэль і да зборкі, і пасля яе. Для інтэграцыі прывяжы гэтыя ID да адпаведных аплікацыйных флоў. `reserve-1` не мае прыдуманага production-маршруту; яго можна прызначыць патрэбнаму раздзелу. Для `guides` бяры горад з актуальнага кантэксту аплікацыі.

Усе формы паходзяць з таго ж PNG з PR #924, 1351 × 1164 px. Цёмная структурная абводка ўнутры пяці частак замененая пясочна-залатой; цень стаў лягчэйшым і цяплейшым. Арыгінальны `source.png`, альфа і геаметрыя захаваныя; сцэна па-за кавалкамі не перафарбавана. Новая графіка горада не генеравалася. Маркер і лічбы не перанесеныя ў асеты.

## Каардынаты і націскі

Адна адзінка manifest — піксель крыніцы. Для ўсіх слаёў патрэбны адзін маштаб `s`: `left = originX + x*s`, `top = originY + y*s`, памер `width*s × height*s`. Для UI-версіі пачатак зрушаны на `−72*s`, памер павялічаны на `144*s`.

Правільнае злучэнне параўноўвае зрухі адносна зыходных каардынат і дазволеныя пары суседзяў. Часткі захоўваюць арыентацыю і прамежкі для невыбраных каналаў. Злучаныя часткі рухаюцца групай. Край і цень знікаюць, форма не падмяняецца.

Пяць гарадскіх масак маюць прыярытэт пры праверцы націску і захоўваюць свае ID падчас светлавога эфекту. Два дадатковыя слаі маюць `interaction: feedback-only`: націск дае толькі кароткі водгук. Правяраюцца сапраўдныя альфа-пікселі, а не прамавугольнікі PNG. Схаваныя часткі сцэны не прымаюць націск. Святло і іскры ніколі не перахопліваюць жэсты.

## Рух і тэкст

Кароткі націск адкрывае раздзел. Утрыманне 300 мс уключае перацягванне; рух больш за 8 dp да ўтрымання скасоўвае націск. На адлегласці да 22 dp правільны сусед счапляецца толькі падчас сапраўднага руху і заканчвае гэты жэст. Час, простае ўтрыманне, адпусканне і блізкасць без руху нічога не злучаюць. Для руху групы яе можна ўзяць яшчэ раз. S у браўзерным прыкладзе злучае з суседам пры кіраванні стрэлкамі; Escape скасоўвае незавершаны рух.

Пасля пятага злучэння: цэнтраванне 400 мс, нарастанне святла 650 мс, светлы сілуэт 350 мс, радыяльнае праяўленне сцэны 850 мс, згасанне святла 450 мс. У браўзерным прыкладзе частковае счапленне мае пераход 220 мс. Native адразу фіксуе стык у межах 22 dp і дае светлавы водгук 380 мс; пасля поўнай зборкі карта застаецца на цэнтры, клікабельная. Гэта адзін светлавы момант, без паўторнага мігання. Reduced motion адразу паказвае вынік; змена гэтай налады скасоўвае незавершаныя эфекты.

Рэферэнс прынцыпу ператварэння: [афіцыйны кліп Pokémon](https://www.youtube.com/watch?v=op99cJ5dk0M), фаза каля 2:11. Відэа і графіка Pokémon не выкарыстоўваюцца ў асетах.

Падпісы — асобны тэкст з існага каталога для be, en, uk, de, es, fr, cs, sv, zh. Змена мовы і рэдагаванне не зрушваюць фрагменты. Доўгая назва абмежаваная двума радкамі з шматкроп’ем; поўны тэкст застаецца ў accessibility-назве, рэдактары і панэлі. Пустое поле вяртае назву з каталога.

## Запуск

Гатовы пакет працуе без зборкі і знешніх залежнасцей:

```sh
python -m http.server 4389 --bind 127.0.0.1 --directory docs/design/brand/outputs/menu-map-city-only
```

Адкрый `http://127.0.0.1:4389/`. Кнопка «Паглядзець анімацыю» ёсць толькі ў браўзерным дызайн-прыкладзе, каб прагледзець эфект. Калі поўны пакет распакаваны асобна, перадай у `--directory` шлях да яго каталога. Для мабільнай інтэграцыі выкарыстоўвай асобны `menu-map-mobile.zip` і інструкцыю ў `native/README.md`.

Перагенерацыя ў рэпазіторыі выкарыстоўвае ўсталяваныя OpenCV/NumPy, існыя каталогі перакладаў і шрыфты:

```sh
python docs/design/brand/outputs/menu-map-city-only/build.py
python docs/design/brand/outputs/menu-map-city-only/verify.py
node --test docs/design/brand/outputs/menu-map-city-only/magnet.test.mjs
```

`verify.py` незалежна чытае гатовыя PNG: правярае абласці 1–5, невыбраныя палосы, кантраляваную маску перафарбоўкі 11 390 пікселяў, UI-версіі, нязменную сцэну, граф суседзяў, усе native-маскі і сілуэты. Усе 1 143 233 бачныя пікселі стылізаванай карты аднаўляюцца дакладна без пропускаў і перакрыццяў.

Native-тэсты і Metro-зборкі для Android/iOS правераныя. Існыя экраны аплікацыі не замененыя. Фізічная прылада, FPS і экранныя чытальнікі на ёй не правяраліся. Правы і гістарычная дакладнасць першакрыніцы асобна гэтым пакетам не пераглядаліся.


## Удакладненне свячэння

Выбраны ўладальнікам варыянт — бурштынавы №1 з тонкімі павольнымі плаўнымі ніткамі вакол карты. Ён падключаны ў асноўным web-прыкладзе і native-кампаненце. Агульны `amber-light.mjs` задае палітру, рух і межы эфекту. Маскі частак і націскі не змяняліся. У web шэры пераход brightness/invert заменены асобным бурштынавым сілуэтам з празрыстасцю.
