# Схемы экранаў і пераходаў (G06.06)

Канонічныя схемы экранаў KUDY: для кожнага экрана з прататыпнага пакета
G06.08 — пераходы (адкуль/куды), мапа Back на паверхню-крыніцу і сумленныя
станы. Ухваленне заснавальніка — крок рэвью PR, які закрые issue #179
(крытэрый 5); да мержу дакумент працоўны, пасля мержу — канон, на які
спыняюцца production-задачы G06.01+ (горад, рубрыка, прэв'ю),
G06.02–G06.05, G07/G08.

Назвы экранаў і станаў скапіяваныя **даслоўна** з
`spikes/G06.08-prototype/package/screens.md`, а тыя — з кананічных крыніц:
ADR G01.01–G01.03, `11` (NAV1–NAV11 у §16.9), `20/21`, `09` §6.5. Гэты
дакумент нічога не пераўзначае і не пераглядае — ён раскладвае прынятыя
кантракты па экранах. Візуальныя токены (колеры, шрыфты, інтэрвалы,
кампаненты) — G06.07 (#180) і тут не задаюцца.

Крыніцы: `screens.md` (станы, responsive, a11y-плашка), `11` раздзел 16,
`20` §11 (D01–D07, F01–F04, L01–L02), `21` §3–§5, ADR G01.01–G01.03,
backlog `16` §G06.

## Агульныя правілы пераходаў (усе экраны)

- **Back — навігацыя, не каманда** (`11` §16.2): не завяршае сесію, не
  спыняе аўдыё, не падае форму ацэнкі. Кожнае адкрыццё прэв'ю запісвае
  **паверхню-крыніцу**; Back вяртае на яе.
- **«Прагулка»** даступная на ўсіх паверхнях раздзела 16 і вяртае ў Run у
  ранейшым становішчы панэлі; агляд горада, гідаў і прэв'ю не спыняе
  гучанне (NAV7).
- **Пустыя рубрыкі не рэндэруюцца** (NAV2): без апублікаванага кантэнту
  раздзел не паказваецца нідзе — ні заглушак, ні тэставых гідаў.
- **Сумленная дэградацыя** (`11` §7): збоі GPS/сеткі/сховішча трымаюць тую
  ж паверхню і паказваюць іменаваны стан; крытычныя паведамленні ніколі не
  mascot-only.
- **Форма ацэнкі — часовая паверхня** (`11` §16.7): не ўваходзіць у стос
  навігацыі, не стварае пункта Back; Back/«Прапусціць» вяртаюць на
  паверхню-крыніцу.
- **Пакупка, загрузка і Start — асобныя дзеянні** (`11` §16.4): націск на
  платную прапанову або замок адкрывае прэв'ю — не купляе, не пачынае Run,
  не раскрывае private (NAV6, D06).

## Кантроль покрыцця станаў

Сям'і станаў: **Пусты** (няма кантэнту ці вынікаў), **Offline**
(дэградацыя без сеткі), **Denied** (адмова дазволу), **Error** (збой
сховішча/каталога/сэрвісу). Дзе сям'я на экране не магчымая — гэта
запісана з прычынай, а не прапушчана. Назвы станаў — з кананічных крыніц
без перафразавання.

| Экран | Пусты | Offline | Denied | Error |

| Guides (рубрыка) | Няма — рубрыка без апублікаванага кантэнту не рэндэрыцца (NAV2) | Спадкуе банэр Explore | Няма — доступ да рубрыкі не залежыць ад дазволаў | Няма — рэндэр ідзе з валідаванага каталога Explore |
| Guide preview (RouteDetail) | Няма — прэв'ю адкрываецца толькі з існуючай карткі | Бясплатны пакет з кэша; платная праверка пакета патрабуе сеткі — Start недаступны з прычынай | Няма — прэв'ю не выкарыстоўвае GPS | Праверка пакета не прайшла → галоўная кнопка не дае Start, паказ прычыны (`11` §7) |

## Схемы экранаў

### Explore (горад)

**Пераходы:**

- Уваход: старт дадатка або вяртанне; «Прагулка» → Run у ранейшым
  становішчы панэлі, аўдыё не спыняецца (NAV7).
- Explore → рубрыка «Гіды» → картка гіда → прэв'ю: кананічны ланцуг
  (`11` §16.1, NAV1); адзін гід — адна картка, тая самая на Explore (D02).
- Explore → selector «Чым заняцца» → Discovery result; вынікі не
  замяняюць горад і не мяняюць мову запыту маўчкі (`20` §3, D04).
- Explore → Побач, My KUDY (NAV3).
- Back: горад — ніжні рубеж; Back з Explore не адкрывае выбару горада
  (`11` §16.2).

**Станы:** пусты горад NAV3; offline-банэр і error-падзенне каталога —
21 §3.3; рубрыкі без кантэнту не рэндэруюцца (NAV2). Responsive: адна
калонка < 821 px, дзве ≥ 821 px. Візуальныя значэнні — G06.07.

### Guides (рубрыка)

**Пераходы:**

- Спіс гідаў → прэв'ю гіда; кожны гід у спісе адзін раз; карткі аднаго
  гіда з розных шляхоў вядуць да таго самага прэв'ю (`11` §16.1).
- Спіс гідаў → горад па Back (NAV9).
- Адзін гід: роўна адна картка; Explore паказвае тую самую, не «другога
  гіда» (NAV1, D02).

**Станы:** пустога стану не існуе — рубрыка схаваная (NAV2); offline і
error спадкуюцца ад Explore. Парадак — `editorial_order`, затым
`offer_id` (21 §4).

### Guide preview (RouteDetail)

**Пераходы:**

- Прэв'ю → **адна галоўная кнопка** са зменай сэнсу `Download → Start`
  (09 §6.5). Start пры актыўнай або прыпыненай сесіі → адзіны дыялог
  пацверджання `11` §4.1: «Завяршыць “A” і пачаць “B”?»; «Скасаваць»
  вяртае ў прэв'ю без якой-небудзь змены сесіі (NAV8).
- Платная прапанова або замок → прэв'ю; не пакупка, не Start, не private
  (NAV6, D06); Start для `paid` — толькі пасля пакупкі і поўнай праверкі
  пакета (`11` §16.4).
- Back з прэв'ю → паверхня-крыніца: рубрыка «Гіды», спіс падбору, картка
  падборкі або падказка R07; сесія, гук і прагрэс нязменныя (NAV9,
  `11` §16.2).

**Станы:** замкнёная кропка — назва, месца, кароткі анонс і замок; поўны
тэкст/транскрыпт/медыя адсутнічаюць у бясплатным пакеце і ў сеткавых
запытах (NAV5, N7). Мовы па факце `availability`; L01: тэкст без аўдыё
не ўключае Start з абяцаннем аўдыё. `free_stop_count` для paid (09 §3;
21 §3.2).

### Place card

**Пераходы:**

- Месца → картка месца: толькі публічная праекцыя (21 §3.1).
- «ацаніць месца» → форма ацэнкі — часовая паверхня з пацверджэннем
  «быў/была тут» (`20` §7, F01); Back з формы → картка месца
  (`11` §16.7).
- Back з карткі месца → паверхня-крыніца (NAV9).

**Станы:** публічная праекцыя толькі; уласная ацэнка — толькі яўнае
дзеянне; форма не запісвае ацэнку пры прапуску і не блакуе нічога (F01).

### Collection card (падборка)

**Пераходы:**

- Падборка → член; Back з члена → падборка (`11` §16.5, NAV11).
- Падборка не стварае Run, не з'яўляецца пакупкай і не мае аўдыё:
  `audio_locales` заўсёды пустыя — кнопкі «паслухаць падборку» не існуе
  (21 §3.2, NAV11).
- Падборка з платным членам — пазнака `mixed`; яна не адкрывае платны
  кантэнт члена (D07, `20` §6).

**Станы:** `overlap_note` пры гідзе і яго стартавым месцы як членах;
выбар не мяняе актыўную/прыпыненую сесію, версію, прагрэс і аўдыё (D07).

### Discovery result

**Пераходы:**

- exact ёсць → паказваюцца толькі яны; адзін дакладны вынік — адна
  самастойная картка без дапаўнення непадыходзячым (21 §4 правіла 7,
  D02/D04).
- Нуль exact → сумленнае паведамленне + alternatives са сваім загаловкам
  і differences; горад і мова альтэрнатыў супадаюць з запытам (NAV4).
- Картка выніку → прэв'ю гіда / картка месца / падборка (`21` §3.1);
  Back → спіс падбору → горад (NAV9).

**Станы:** прычыны на кожнай картцы (`editorial`, `theme_match`,
`within_time`, `season_recommended`) і пазнака paid (D06); offline —
апошні валідны кэш з бачным банэрам, без кэша — старонка горада без
падбору (21 §3.3).

### Побач (Map, вольная прагулка)

**Пераходы:**

- Moment: тэйзер з **яўным Play** — без аўтаматычных картак пасярэдзіне
  гіда (ADR G01.02 §3.6 пункт 6); Moment без сесіі грае на тым самым
  адзіным плееры з moment-токенам і не мяняе стан сесіі (ADR G01.02 §3.8).
- Побач → Run праз «Прагулку» (NAV7).
- Ручны агляд месцаў без пазіцыі; радыусны ўвод ніколі не запускае аўдыё
  сам (G07.01).

**Станы:** пусты спіс — сумленны; denied GPS → ручны агляд; кэшаваныя
Moments без сеткі.

### Run

**Пераходы:**

- Адна паверхня: мапа як фонавы рэжым + панэль у трох становішчах
  Peek/Half/Full (09 §6.5, `11` §3.2).
- Тап маркера адкрывае прэв'ю, ніколі не гук; R07-падказка (ціхая
  неаўдыё-картка ІНШАГА гіда, схаваная падчас аўдыё/паўзы/камерцыйнага
  дыялогу, адзін факт — паказу за сесію на гіда) → тап → толькі прэв'ю,
  стан сесіі read-only (`11` §15, G07.04).
- Сесійнае меню: Прыпыніць прагулку, Завяршыць, Змяніць гіда — лейблы з
  `screens.md`; паўзавыя правілы — `11` §4.2; Start іншага гіда (у тым
  ліку «Змяніць гіда») — толькі праз дыялог §4.1 (NAV8); End → экран
  завяршэння; завершаная сесія не адраджаецца — паўторная прагулка — новая
  сесія.
- Прыпыненая прагулка: «Прагулка прыпынена» + адзіны «Працягнуць»
  (`11` §4.2); прыпыненая аўтаматыка (пасля Play Moment / ручнага стопу /
  страты фокусу): бачны радок «Працягнуць гід» — адзіны шлях назад;
  нічога не гучыць сама (ADR G01.02 §3.6, C19).
- Выхад на паверхні раздзела 16: «Прагулка» (NAV7); унутры Run — свая
  мапа Back (`11` раздзел 2).

**Станы:** маркеры па ADR G01.01 §4.5, адзінца — stop: `locked` /
`playing` / `played` / `available` / `pending`; Peek-плеер: радок
now-playing (owner `guide` або `moment`), індыкатар live-паўзы; Half —
картка **inspected**: транскрыпт належыць inspected, а не now-playing;
радок «Зараз грае: …» з tap-back, калі inspected ≠ playing (`11` §3.2);
далейшыя (extended) гісторыі — толькі праз яўны UserSelectedStory пасля
unlock; замкнёная дадатковая — анонс + замок. Autoplay-абяцанне роўна
адзін раз пасля Start (`11` §5). Denied GPS: іменаваная прымета, autoplay
off, ручны Play працуе; storage full / download-failed: тая ж паверхня +
ручны выхад (G06.05). Прыпынак сесіі спыняе гід-аўдыё і вызваляе
GPS/geofences/wakelock, пакуль Moment працягвае гучаць (ADR G01.02 §3.4).


### End (завяршэнне)

**Пераходы:**

- «Яшчэ можна адкрыць»: адзінца — `story_id`, замкнёныя выключаны,
  магчымасці ніколі не называюцца няўдачай (ADR G01.01 §4.6).
- Запрашэнне ацэнкі: неабавязковае, немадальнае, максімум адно за сесію,
  не падчас аўдыё (`11` §16.7); прапуск нічога не запісвае і не блакуе
  (F01); форма — часовая паверхня, Back → экран завяршэння (NAV10).
- Паўторны Start іншага гіда — праз прэв'ю і дыялог §4.1 (NAV8).

**Станы:** завяршэнне фіксуе сесію `finished` (ADR G01.03 §3.1); водгук
`pending` чакае сеткі сумленна (F03).

### My KUDY

**Пераходы:**

- Гісторыя прагулак: адзін нязменны радок на сесію; старыя радкі ніколі
  не выдаляюцца і не перапісваюцца (ADR G01.03 §3.1).
- Кіраванне загрузкамі і сховішчам — тут, не ў long-press (09 §6.5).
- Пераключэнне мовы інтэрфейсу захоўваецца яўна; новая мова UI не
  замяняе locale актыўнага Run — радок сесіі паказвае свой locale (L02).
- Мае ацэнкі: змена замяняе, выдаленне прыбірае са справаздачы (`20` §7);
  форма ацэнкі з My KUDY — часовая паверхня, Back → My KUDY
  (`11` §16.7, NAV10).

**Станы:** радкі сесій — `state` active/paused/finished, session locale,
heard count; мае ацэнкі — даслоўна з 21 §5.4:
`draft → pending → sending → sent`, збой → `pending`, 409 → `conflict`,
401/422 → `action_required`; выдаленне, што чакае сеткі, пра гэта кажа
(F03). Пустая гісторыя — сумленны стан.

### Feedback form (temporary surface)

**Пераходы:**

- Не ўваходзіць у стос навігацыі, не стварае пункта Back; Back або
  «Прапусціць» → паверхня-крыніца (экран завяршэння, My KUDY, картка
  месца), нічога не запісана і не заблакавана (`11` §16.7, F01, NAV10).
- Падача, адпраўка і памылка не мяняюць Run і навігацыю; другое
  запрашэнне на тым жа End немагчыма (NAV10).

**Станы:** target-загаловак называе адрасата і мэту (гід — ацэньваецца
увесь досвед; месца — фізічнае месца; ніколі не агрэгаванае — F02,
21 §5.1);
ачкі 1–5 без дэфолту; замкнёныя спісы прычын па віду target, максімум 3
унікальныя; locale запісваецца як мова фактычна выкарыстанага кантэнту.
Дастаўка даслоўна з 21 §5.4: `draft → pending → sending → sent`, збой →
`pending`, 409 → `conflict`, 401/422 → `action_required`; conflict
паказаны сумленна, сляпых паўтораў няма (F03). CAS-кансістэнтнасць —
21 §5.
