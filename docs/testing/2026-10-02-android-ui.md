## Памылкі мовы

### MEDIUM — «Побач» ігнаруе English і Українська

Пасля выбару English у KUDY каталог паказвае `Nearby →`, але адкрыты экран мае беларускія «Побач», «Карта горада зʼявіцца пасля рашэння пра тайлы» і «Каталог недаступны». Кнопка вяртання ўжо англійская: `Back`. Пасля выбару ўкраінскай праблема паўтараецца.

Месца: `app/map.tsx:199` і `controllers/nearby/nearbySurfaceController.ts:126`. Без падключанай службы экран атрымлівае фіксаваную мову `be`, замест выбранай мовы інтэрфейсу.

Доказ: [пасля English](evidence/2026-10-02-android-ui/nearby-after-en.png), [пасля Українська](evidence/2026-10-02-android-ui/nearby-after-uk.png); дзве няўдалыя праверкі ў `results.json`.

### MEDIUM — недаступны шпацыр ігнаруе ўкраінскую мову

Пры выбранай Українська спасылка `kudy:///run/android-ui-test` паказвае беларускае «Сесія недаступная» замест «Сесія недоступна». Для гэтага недаступнага шпацыру няма сесіі з уласнай захаванай мовай.

Месца: `app/run/[id].tsx:356`. Пры адсутнасці гатовай сесіі слоўнік выбірае `be`.

Доказ: [экран шпацыру](evidence/2026-10-02-android-ui/run-unavailable-uk.png), праверка `Unavailable run uses Ukrainian` у `results.json`.

## Межы праверкі

У `app/_layout.tsx:15` яшчэ няма сістэмных адаптараў каталога, файлаў, гісторыі, гуку і месцазнаходжання. Таму ўсталяваны дадатак паказвае недаступныя каталог, падбор і гісторыю. Праходжанне сапраўднага маршруту, прайграванне, фонавае аўдыё, загрузкі і геалакацыя гэтым прагонам не пацверджаныя. Тэставыя заменнікі службаў у прыкладанне не дадаваліся.

Пры змене сістэмнага шрыфту ў адкрытай службовай зборцы навігацыя скінулася да каталога, а Metro запісаў `Looks like you have configured linking in multiple places.` Чысты запуск з ужо павялічаным шрыфтам прайшоў. Гэты збой падчас жывой змены налады захаваны ў [журнале Metro](evidence/2026-10-02-android-ui/metro.log); для высновы пра рэлізную зборку патрэбны асобны прагон. Android не зафіксаваў аварыйнага падзення.

Фізічны тэлефон і iOS не выкарыстоўваліся. Правераная службовая зборка, а не падпісаны рэліз.

## Усталяванне і завяршэнне

Для гэтага прагона ў `D:\KUDY-Android` усталяваныя Android command-line tools 22.0, platform-tools 37.0.1, emulator 37.2.12, Android API 36, build-tools 36.0.0, NDK 27.1.12297006, CMake 3.22.1 і Temurin Java 17.0.20.1. Gradle 8.14.3 загружаны штатнай абгорткай праекта. Загружаныя архівы Java, Gradle і камандных інструментаў правераныя паводле афіцыйных кантрольных сум.

На C не хапала месца для зборкі. Згенераваныя файлы і кэшы захоўваліся на D; спасылкі каталогаў захавалі сумяшчальныя з React Native шляхі на C. Асобная копія рэпазіторыя не стваралася. Першы сумесны запуск зборкі і эмулятара спыніўся праз недахоп памяці Windows; паспяховая зборка і праверкі выконваліся паслядоўна.

Вялікія ўсталяваныя файлы засталіся на D для паўторных прагонаў. Аднаразовыя скрыпты, налады асяроддзя і поўныя журналы захаваныя ў `.scratch/ui-2026-10-02/` і `D:\KUDY-Android`; яны не ўваходзяць у Git. Сістэмны памер шрыфту эмулятара вернуты да пачатковага `1.0`.

Пасля захавання доказаў тэставыя эмулятар і сервер Metro спыненыя; астатнія праграмы не закраналіся.
