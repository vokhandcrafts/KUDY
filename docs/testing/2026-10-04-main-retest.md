Пасля прагону шрыфт пацверджаны як `1.0`; толькі створаныя для гэтага тэставання эмулятар і Metro спыненыя.

## Новая ўзноўленая праблема

[web/lib/content/exported-language.ts:34](../../web/lib/content/exported-language.ts) дзеліць шлях толькі па `/`. Для `en/app.html` функцыя вяртае `en`; для Windows-шляху `en\app.html` — `be`. Таму правільна створаныя English-старонкі адхіляюцца завяршальнай праверкай зборкі. Два паводзінныя тэсты гэтай функцыі таксама падаюць; гэта адна прычына двух збояў.

Каманда ўзнаўлення з кораня рэпазіторыя:

```powershell
node --experimental-strip-types docs/testing/evidence/2026-10-04-retest/reproduce-document-language.mjs
```

Вынік: `en/app.html → en`, `en\app.html → be`, код 1. [Журнал узнаўлення](evidence/2026-10-04-retest/document-language-reproduction.log). Наступнае выпраўленне павінна нармалізаваць раздзяляльнікі шляхоў і дадаць Windows-прыклад у паводзінныя праверкі. У гэтым прагоне код не выпраўляўся.
