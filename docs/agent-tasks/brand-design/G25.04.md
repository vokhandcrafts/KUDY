## Acceptance criteria

1. [ ] Inventory existing UI/map icons and create a table of action/state, current asset, recommended Lucide icon or justified custom SVG, accessible name and paired text. Include playback, download/offline, language, location, paid/locked, settings, feedback and collection candidates.
2. [ ] Show normal, selected, disabled and focus samples at actual intended sizes; preserve touch targets and distinguish canonical stop states without relying only on color. Do not replace the whole implemented icon family.
3. [ ] Separate decorative compass, navigate action and a real directional indicator. Mock missing/stale/denied position or heading with a manual alternative; do not show a working bearing in a static prototype. Secret-point navigation stays deferred.
4. [ ] Deliver SVG sources for justified additions, an HTML contact sheet and an export/naming checklist. Launcher icon selection remains #693 and integration remains #429.

## Out of scope

Shipping sensor logic, changing stop-state contracts, adding a second icon library or redesigning the launcher icon.
