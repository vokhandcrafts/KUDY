## Acceptance criteria

1. [ ] Build a proportion/silhouette sheet from accessible original figurine photos and the selected G24.02 direction. Record provenance; if originals are unavailable, deliver the input request and mark likeness unverified. A1/B2 are sketches, not photographic evidence.
2. [ ] Show calm, curious/surprised, inviting and quietly celebrating poses at large and small sizes, with rules for face, wings, neck and permitted simplification. Raised head is a characteristic gesture, not the only pose.
3. [ ] Rehearse the complete brief scene with marked lines, 95 seconds of planned silence and S1/S2 placeholders. Record actual read duration, interruptions and observer feedback if observed; otherwise provide a repeatable test script and mark performance testing pending.
4. [ ] Write concise voice examples for greeting, invitation, mistake, pause and ending. Map each appearance to purpose; preserve explicit user actions, one audio owner and no pressure. Give sound handoff to #694 without producing a second competing motif.
