## Acceptance criteria

1. [ ] Audit the brief against the visual canon; keep existing paper, green, ink and font roles. Show proposed clay and amber only in named semantic roles, with measured text/control contrast pairs and color-independent state cues.
2. [ ] Deliver a side-by-side palette/type/material board at phone and web sizes, including dense text, Run without grain, large text and disabled/focus states. Use existing font files with license records; no CDN dependency.
3. [ ] Record accepted versus proposed values, owner decisions, affected tokens and migration/handoff references in docs/design/brand/decisions.md. Leave unapproved values explicitly pending; do not silently promote the two candidate hex values.
4. [ ] Specify spacing, relief, texture and motion/reduced-motion use by component role; reuse established values where the brief does not change them. Dark-mode decisions remain in #436.

## Out of scope
