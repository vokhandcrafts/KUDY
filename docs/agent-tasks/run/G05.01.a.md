## Acceptance

1. [ ] Names are copied verbatim from 09 §6.1; the snake_case ↔ camelCase mapping is declared once (the 19 §3 boundary).
2. [ ] `step(state, event, now, config)` is pure: no clock, no I/O, no React Native import; `npm run arch:check` is green.
3. [ ] States Idle/Active/Paused/Ended: Ended never returns to Active; Pause and End clear `queued` and emit `ClearGeofences`.
4. [ ] Start refuses a package without a verified tier or with `accessible_stop_ids` outside the pinned package.
5. [ ] `AccessReady` is accepted only when all six checks of ADR G01.03 §3.5 pass; on any mismatch the state stays deep-equal. On acceptance `tier_available` widens, `accessible_stop_ids` is recomputed and `SetGeofenceWindow` is emitted, with no Play; a repeat is a no-op.
6. [ ] Stop status (locked → playing → played → available → pending) is computed, not stored.
