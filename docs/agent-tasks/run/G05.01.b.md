## Acceptance

1. [ ] The autotrigger fires only when all conditions of ADR G01.01 §4.8 hold; each condition has an isolated negative test.
2. [ ] `auto_fired` and `heard` are monotonic; a manual replay after played is allowed, and an interrupted replay keeps `heard` (C7).
3. [ ] The queue is one cell: the newest other stop wins, the displaced one goes to `auto_fired`, a stop never displaces itself; a deferred play re-checks freshness ≤ 30 000 ms, accuracy ≤ radius and distance ≤ 2 × radius, bounds inclusive.
4. [ ] The three outcomes of a trigger that did not play stay distinct (player busy / automation suspended / inactive session or stale position).
5. [ ] `AudioFinished` is accepted only on a matching `(session_id, play_id)` and matching `story_id` when present; a late callback from a previous session is ignored (C10); `play_seq` grows by 1 per `PlayStory`.
6. [ ] P01: a base story heard never credits extended; extended plays only through `UserSelectedStory`; locked never plays and never enters `auto_fired` or «Яшчэ можна адкрыць» (C33, C36–C37).
7. [ ] All six permutations of three stops pass (C31).
