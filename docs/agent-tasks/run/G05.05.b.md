# G05.05.b — Pause, Resume, End and restart recovery

**Status:** not-started. **Model class:** strong. **Dependencies:** [G05.05.a](G05.05.a.md) complete. Parent task: G05.05.

## Scope

The rest of the session lifecycle in `useRunController`: Pause releases GPS, wakelock and the queue; Resume re-arms without restarting audio; End at any moment; a new walk is a new session; after a process restart the pinned version and progress come back and audio does not start by itself.

Read: [11](../../11_run_interaction.md) §4.1–§4.3, §7, criteria for pause/finish/restart; [09 §9.1](../../architecture/09_technical_architecture.md) (restore after the process was killed: "continue the saved walk?"); [ADR G01.03](../../architecture/decisions/G01.03-session-access.md) §3.1–§3.4, §3.10; [ADR G01.02](../../architecture/decisions/G01.02-audio-ownership.md) §3.2, §3.8 (Pause/End stop only guide audio); [19 §4.3, §6.5–§6.6](../../architecture/19_class_and_module_map.md).

## Acceptance

1. [ ] Pause: the row becomes `paused` durably, the location service goes to `paused` (no subscription, no geofences), the wakelock port is released and the queue is empty; guide audio stops, a playing Moment does not.
2. [ ] Resume: the row becomes `active`, geofences are re-armed from a fresh fix, and no audio starts until an explicit action (`autoplay_suspended = true`).
3. [ ] End is accepted in every state including mid-audio and after one story; the row is `finished` with a final checkpoint; the next Start creates a new `session_id` and row, and the ended one is never reactivated.
4. [ ] Restart recovery: a process restart with an active or paused row restores `version`, `locale`, `heard`, `auto_fired` and `play_seq`; `playing` and `queued` are empty; audio does not start; the controller exposes "continue the saved walk" as a state, not an action it takes.
5. [ ] A newer catalog version after restart does not replace the pinned version of the live session (ADR G01.03 §3.4); the package files of that version are still required and their absence is reported, not silently swapped.
6. [ ] A callback, fix or `AccessReady` that arrives after End changes nothing in the session (disk-only for downloads).

## Out of scope

The UI for these states (G06.03–G06.04); library deletion guard (G04.04.b); iOS/Android process-kill behaviour on devices (G00.01.b matrix, G11.02).
