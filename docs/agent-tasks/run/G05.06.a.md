# G05.06.a — Deterministic simulator on production functions

**Status:** not-started. **Model class:** strong. **Dependencies:** [G05.05.b](G05.05.b.md) complete. Parent task: G05.06 ([16 row G05.06](../../16_delivery_backlog.md)).

## Scope

`tools/simulate`: replay a JSON trace through the **same** pipeline, reducer and run orchestrator the app uses, with one deterministic queue of deferred actions, fault injectors and a report. A simulator that re-implements logic tests nothing; it imports production modules.

Read: [09 §11](../../architecture/09_technical_architecture.md) (`simulate`: determinism, trace format, injectors, generators, report), §12, §13 (M1 acceptance); [19 §7.2](../../architecture/19_class_and_module_map.md) (run-model is frozen and is not a second engine); `docs/run-model/README.md`; results G05.01.d, G05.04, G05.05.b.

## Acceptance

1. [ ] The simulator imports `acceptFix`, `step` and the run orchestrator from their production modules; a dependency-cruiser rule forbids `tools/simulate` from importing `docs/run-model`, and a deliberate violation fails `arch:check`.
2. [ ] Determinism: one queue of timers and audio completions ordered by due time then insertion order; no `Date.now()`, no `Math.random()` (the injected clock and a seeded generator only); the same trace run twice gives byte-identical reports.
3. [ ] Trace events `GpsFix`, `AppBackground`, `AppForeground`, `UserCommand`; injectors for accuracy degradation, timestamp jump, signal gap and a call (focus loss). A corrupt trace (unknown event, missing field, non-monotonic time where the schema forbids it) yields diagnostics, not a crash.
4. [ ] The report lists fired stops, the command stream, per-stop trigger latency, timers that never fired, and `stuck_playing` when a segment is still playing at the end.
5. [ ] A synthetic 5-stop route passes the M1 acceptance of 09 §13: all stops fire, none twice, nothing hangs; a partial walk is not reported as a failure and `Ended` appears only after an explicit End.
