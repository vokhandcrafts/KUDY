# G05.05.a — Durable Start and checkpoints (useRunController)

**Status:** not-started. **Model class:** strong. **Dependencies:** [G05.04](G05.04.md) and [G04.02.c](../storage/G04.02.c.md) (#191, the `AccessReady` channel) complete; G04.01 (#59) and G04.03 (#60) closed. Parent task: G05.05 ([16 row G05.05](../../16_delivery_backlog.md)).

## Scope

`useRunController` as the only writer of the `session` row: Start in one transaction, command execution, checkpoints after accepted progress, `play_seq` write-through. The orchestrator from G05.04 is the core; the hook is a thin Zustand wrapper over it. Pause/Resume/End and restart recovery are [G05.05.b](G05.05.b.md).

Read: [ADR G01.03](../../architecture/decisions/G01.03-session-access.md) §3.1–§3.5, §3.9 (durable fields, pinned version, the Start transaction and the R07 carry-over), §3.10; [09 §6.4, §7](../../architecture/09_technical_architecture.md); [19 §2.2, §3.7, §4.3, §5.1–§5.4, §6.1, §6.6](../../architecture/19_class_and_module_map.md); results [G04.01](../results/G04.01.md), [G04.03](../results/G04.03.md), G04.02.c, G05.04.

## Acceptance

1. [ ] Start runs only on a ready package (G04.03 readiness for the selected tier) and inserts the session row with `version`, `locale`, `play_seq = 0` and the R07 carry-over in **one** transaction; an injected failure mid-transaction leaves no row and no half carry-over.
2. [ ] The one-unfinished-session rule of G04.01 holds through the controller: a second Start while a session is active or paused is refused with a named reason, not a thrown error.
3. [ ] Every `PlayStory` increments `play_seq` in the durable row **before** the play command reaches the audio service (write-through); a crash injected between the two leaves a `play_seq` that no later callback can match.
4. [ ] `PersistProgress` checkpoints `heard` / `auto_fired` after accepted `AudioFinished`; a callback rejected by `step()` writes nothing.
5. [ ] `AccessReady` reaches `step()` only from the `services/download` capability channel; a look-alike event from any other source is not accepted (test).
6. [ ] The controller never reads the clock or the GPS itself; `now` and fixes come through injected ports.

## Out of scope

Pause/Resume/End, restart and pinned-version restore (G05.05.b); UI (G06.03–G06.04); analytics `EmitEvent` (G09.01).

## Proof
