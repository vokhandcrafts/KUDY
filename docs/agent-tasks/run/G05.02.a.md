## Acceptance

1. [ ] Stage order is fixed and each stage rejects **before** any state mutation: a rejected fix leaves the smoothing window and every dwell accumulator deep-equal (one test per stage).
2. [ ] Accuracy gate: > 40 m rejected, 40 m accepted. Spike rejection: with increasing time, implied speed > 12 km/h rejected; with non-increasing time, displacement > 5 m rejected. Bounds are tested on both sides.
3. [ ] Smoothing is the plain mean of the last 3 accepted coordinates and never leaves their bounding box (property test).
4. [ ] Dwell accumulates on the smoothed point while the stop stays a candidate and resets when it stops being one; `DwellCompleted(stop_id)` is emitted once per continuous dwell of `dwell_ms` (6000 by default, taken from `PipelineConfig`, not a literal).
5. [ ] Candidates are all passed-in stops regardless of route position; simultaneous candidates are ordered by distance, then by stable `stop_id` (property test with shuffled input gives the same output).
6. [ ] Corrupt input — NaN / Infinity coordinates, latitude outside ±90, negative or missing accuracy, a timestamp in the future relative to `now` — is rejected with a named reason, never thrown and never accepted.
7. [ ] `core/` imports nothing from React Native, the network, the disk or the clock; `npm run arch:check` is green.
