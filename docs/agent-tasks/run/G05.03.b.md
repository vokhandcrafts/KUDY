# G05.03.b — Android audio adapter (expo-audio, background, lock screen)

**Status:** not-started. **Model class:** strong. **Dependencies:** [G05.03.a](G05.03.a.md) complete; [G06.09.b](../app/G06.09.b.md) complete. Parent task: G05.03.

## Scope

The device implementation of the player port from G05.03.a on `expo-audio`: background playback, speech audio mode (ducking and focus are left to the OS), lock-screen metadata and prev/next, focus-loss mapping. Prev/next on the lock screen is an explicit choice of accessible audio in the recommended list; locked items are skipped without changing progress; the lock screen never starts manual Moment content.

Read: [09 §6.3](../../architecture/09_technical_architecture.md) (`audio` row), §9; [ADR G01.02](../../architecture/decisions/G01.02-audio-ownership.md) §3.5–§3.7; [ADR G00.01](../../architecture/decisions/G00.01-platform-evidence.md) §5; [ADR G00.04](../../architecture/decisions/G00.04-stack-baseline.md) §1, §6 (expo-audio `1.1.1`, `enableBackgroundPlayback`); [device matrix G00.01.b](../../../spikes/G00.01-location-audio/evidence/G00.01.b-device-matrix.md).

**Device decision (2026-09-23, founder):** no device and no Android SDK in this wave. Host proof: pure mapping tests, `tsc`, `expo-doctor`, `expo prebuild --platform android --no-install`. Every device cell stays `not-run`; the device part is `blocked-external`, and row G05.03 does not close until the matrix cells below pass.

## Acceptance

1. [ ] The adapter implements the G05.03.a port exactly; status mapping is tested on synthetic player statuses, including an interruption status (→ focus loss, never finished), an error status (→ failure with reason), and NaN / zero durations.
2. [ ] Lock-screen next/prev maps to an explicit "select story" command on the accessible recommended list; a test on a list with a locked item shows it is skipped and progress is not touched; there is no lock-screen path to a Moment.
3. [ ] The audio mode is set once for speech with background playback enabled; `expo prebuild --platform android --no-install` succeeds with the expo-audio plugin options (output recorded).
4. [ ] `npm run typecheck`, `npm test`, `npm run arch:check`, `npx expo-doctor` are green; the adapter is reachable only through the composition root.
5. [ ] The results file lists, as `not-run` with steps to run each later, the Android cells of the G00.01.b matrix this adapter serves: locked screen, background, call / other audio, Pause/End/explicit Resume, rapid Play/Stop and file repeat, battery saver.
