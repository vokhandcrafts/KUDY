# G05.02.b — Location service: one subscription, geofence window, watchdog

**Status:** not-started. **Model class:** strong. **Dependencies:** [G05.02.a](G05.02.a.md) complete. Parent task: G05.02.

## Scope

`services/location` as a plain class over an injected OS port (the pattern of `services/db` and `services/contentRepo`). It owns the single subscription, the ≤ 20-region geofence window and the watchdog; it does not own the position and makes no trigger decision. The real `expo-location` adapter is [G05.02.c](G05.02.c.md).

Read: [09 §6.3](../../architecture/09_technical_architecture.md) (`location` row), §9, §9.1, §20 (the shared fix stream for R07, no second owner); [19 §2.3, §3.3, §4.3, §6.8](../../architecture/19_class_and_module_map.md) (`LocationService` interface, `LocationMode`, sequence, no-permission walkthrough); [11](../../11_run_interaction.md) §7 (degradation states); [ADR G00.01](../../architecture/decisions/G00.01-platform-evidence.md) (what is and is not proven on devices).

## Acceptance

1. [ ] One OS subscription at most: repeated `setMode` calls and a mode change never leave two subscriptions (the fake port counts them); `idle` and `paused` hold none.
2. [ ] The geofence window holds at most 20 regions: the nearest eligible stops of the whole selected set by the latest accepted fix, not the next by route position; it is recomputed on a fresh fix, after a trigger and after `AccessReady` widens access. A 25-stop fixture proves the cap and the choice.
3. [ ] Watchdog states `acquiring → live → recovering → stalled` with the 15 s threshold, bounded backoff on resubscribe and a generation counter: a callback from the previous generation or the previous session is dropped (test with an injected clock).
4. [ ] Permission denied and permission revoked mid-session are a `status()` value with a reason, never an exception; the service keeps no stale "live" state after revocation.
5. [ ] Raw fixes are forwarded to the controller unchanged (the pipeline runs in the controller, 19 §5.2); the service never calls `step()` and imports nothing from `core/engine`.
6. [ ] No coordinates are logged or emitted as events (a test captures the logger).

The `expo-location` / task-manager adapter and Android foreground service ([G05.02.c](G05.02.c.md)); the controller that wires fixes to the pipeline and engine (G05.04, G05.05); R07 consumers (G07.05); config delivery (G09.05).
