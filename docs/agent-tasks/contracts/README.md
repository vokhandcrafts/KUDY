## Публікацыя ў GitHub — выкананая 2026-09-23

Адсочвальныя задачы радкоў: G01.05 — [#185](https://github.com/vokhandcrafts/KUDY/issues/185), G07.04 — [#207](https://github.com/vokhandcrafts/KUDY/issues/207) (апублікаваная пятай хваляй); кожная частка мае ўласную задачу (спасылкі ў табліцы) з `Epic:` і `Blocked-by:`. Бачнасць на дошцы dispatcher з сесіі не правяраецца (асобнай дошкі-праекту ў рэпазітара няма).
