# G23.02 — Web E2E suite on the existing CDP driver

Issue: [#660](https://github.com/vokhandcrafts/KUDY/issues/660).

## Epic

Epic: #658

## Goal

The site journeys checked by hand in the 2026-10-06 retest run as a committed suite against the real static build (`web/out`), on the existing `web/test-browser/cdp-browser.mjs` driver.

## Scope

`web/e2e/*.browser.test.ts` (planned), helpers next to the CDP driver, an npm script (planned `e2e:web`), wiring into `npm test` or a documented separate command.

## Acceptance criteria

1. [ ] Catalog → guide page → free stop (audio element present and playable, duration > 0) → locked stop (no audio, no full text, calm offer visible).
2. [ ] The be ↔ en switch keeps the equivalent path; every published UI-locale route opens (#554); the document `lang` matches the locale.
3. [ ] The `/app` page with store links and QR is present; the privacy page opens in each locale; an unknown route shows the not-found page.
4. [ ] Keyboard-only navigation reaches and activates the main links; focus is visible.
5. [ ] At 320, 390 and 1440 px: no horizontal scroll, primary actions visible.
6. [ ] Map-provider refusal shows the localized message and guide links stay usable (reuse `city-map.browser.test.ts`, do not duplicate it).
7. [ ] No external network: non-localhost requests are blocked, and any page error fails the case.
8. [ ] Removing the locked-stop audio guard or the locale-switch mapping makes a named case fail (revert check recorded in the result).

## Out of scope

Vercel publication (#320), pixel-diff screenshots, a new browser dependency.

## Dependencies

Blocked-by: none

## Execution boundaries

Current checkout only. Backlog only: creating this issue is not execution permission; `agent:ready`/`prio:*` are set by the operator. Follow AGENTS.md, `docs/agent-rules/implementation-rules.md`, `issue-workflow.md`, `code-review.md` and `showboat.md`. No secrets, production data or personal data in fixtures, logs or screenshots. No new npm dependency or third-party automation tool without a separate operator decision: the repo deliberately drives browsers through its own CDP driver (`web/test-browser/cdp-browser.mjs`, G21.03), and the Android driver follows the same zero-dependency principle. A suite that cannot run (no Chromium, no adb, no emulator) skips visibly with the reason; it never passes silently. Named test files and commands are planned deliverables, not existing tests.
