# G23.05 — Android E2E: interruptions, restart and failure paths

Issue: [#663](https://github.com/vokhandcrafts/KUDY/issues/663).

## Epic

Epic: #658

## Goal

The "pause, return and failures" rules of `docs/03_user_journeys.md` are proven on the emulator: user progress survives interruptions, and failures show honest states.

## Acceptance criteria

1. [ ] Background during an active walk and return: session and progress unchanged.
2. [ ] Force-stop during an active walk and relaunch: the app offers to continue the saved walk with the same content version; heard stops stay heard.
3. [ ] Origin failure during download (G23.01 fault switch): the guide is not marked ready, a retry is offered, and it succeeds after the fault is cleared.
4. [ ] Location permission revoked (`adb shell pm revoke`): no crash; manual mode is offered and works.
5. [ ] Starting another guide while one is active or paused asks to end the current one; cancelling keeps it.
6. [ ] An ended session cannot be resumed; a new pass creates a new session.
7. [ ] Clearing downloaded content does not remove session history or progress.

## Out of scope

Phone calls and audio focus from other apps on a physical device (#297); purchase failures (G23.09).
