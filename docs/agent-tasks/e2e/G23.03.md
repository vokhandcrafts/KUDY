# G23.03 — Android E2E driver and smoke suite

Issue: [#661](https://github.com/vokhandcrafts/KUDY/issues/661).

## Epic

Epic: #658

## Goal

A small zero-dependency Node driver controls the Android emulator through `adb` (install and launch, uiautomator dump, tap by `testID`/resource-id or text, Back, background/foreground, force-stop, geo fix, screenshot on failure), and a smoke suite proves the app starts and navigates on main.

## Scope

`tools/e2e-android/` (planned driver and tests); stable `testID`s added to screens where the suites need them, with no behaviour change; an npm script (planned `e2e:android`); `docs/development_setup.md`.

## Acceptance criteria

1. [ ] The driver waits on conditions with timeouts, never fixed sleeps, and fails readably (selector, screen dump); each failure saves a screenshot and the UI dump into a git-ignored artifacts folder.
2. [ ] Smoke cases: cold start reaches Explore; each tab opens; Back returns; an unknown deep link shows the not-found screen and Back returns to Explore.
3. [ ] Without a catalog origin the app shows its honest unavailable states for guide, run, place, collection and city guides (the list from the 2026-10-06 retest).
4. [ ] With the G23.01 origin the catalog loads and the fixture guide card is visible.
5. [ ] Without `adb` or a booted emulator the suite skips with the reason and never reports a pass.
6. [ ] The driver has unit tests over recorded UI-dump XML: selector lookup, wait timeout, missing element.
7. [ ] Removing a `testID` the suite relies on makes the named case fail.

## Out of scope

Maestro, Detox, Appium (a separate decision if ever wanted); iOS; building the APK (#592).

Blocked-by: #592, #659

## Execution boundaries

Current checkout only. Backlog only: creating this issue is not execution permission; `agent:ready`/`prio:*` are set by the operator. Follow AGENTS.md, `docs/agent-rules/implementation-rules.md`, `issue-workflow.md`, `code-review.md` and `showboat.md`. No secrets, production data or personal data in fixtures, logs or screenshots.
