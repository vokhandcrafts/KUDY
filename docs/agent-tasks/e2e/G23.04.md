# G23.04 — Android E2E: free guide walk from Explore to End

Issue: [#662](https://github.com/vokhandcrafts/KUDY/issues/662).

## Epic

Epic: #658

## Goal

Journey 1 and the free part of Journey 2 (`docs/03_user_journeys.md`) run end to end on the emulator against the G23.01 origin.

## Acceptance criteria

1. [ ] Explore → city → Guides → guide preview shows theme, language, open and locked stops.
2. [ ] Download completes and the button changes from Download to Start; the guide is never shown as ready before verification.
3. [ ] Start opens Run; `adb emu geo fix` at stop 1 starts its story automatically; moving to stop 3 out of order also works (any open stop, order is not enforced).
4. [ ] Pausing the walk stops audio and location; resuming is an explicit action; Back from Run navigates away without ending the session.
5. [ ] End finishes the session; "still can open" lists unheard available stories; My KUDY shows the session in history.
6. [ ] Without a fresh position no story starts automatically; manual play of a stop still works.
7. [ ] Every step asserts screen state through `testID`s, not fixed sleeps.

## Out of scope

Purchase (G23.09), interruptions and failures (G23.05).
