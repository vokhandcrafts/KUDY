# G23.07 — Android E2E: eight locales and large-font regression

Issue: [#665](https://github.com/vokhandcrafts/KUDY/issues/665).

## Epic

Epic: #658

## Goal

The locale and accessibility checks done by hand in the 2026-10-06 retest become a regression suite. Acceptance of the eight interfaces stays with #555.

## Acceptance criteria

1. [ ] Each of be/en/uk/de/es/fr/cs/sv can be selected, is marked selected, and Explore shows that locale's strings, compared with the shipped message files rather than hardcoded copies.
2. [ ] The selection survives force-stop and relaunch (#549).
3. [ ] At font scale 1.5 all eight locale buttons and the primary actions of Explore, preview and Run are visible and tappable; the font scale is restored after the suite.
4. [ ] Primary actions expose accessibility labels (content-desc) in the selected locale.
5. [ ] Reverting the persisted-locale storage makes the restart case fail.

## Out of scope

Translation quality review, physical devices, iOS (owned by #555).
