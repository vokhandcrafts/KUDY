## Перадумовы і межы бяспекі

Патрэбныя асобнае тэставае backend/storage асяроддзе, RevenueCat project/app, non-consumable sandbox product у Apple/Google, тэставыя акаўнты і спосаб запускаць зборкі. Правер наяўнасць без вываду сакрэтаў. Недаступнае пералічы канкрэтна; падрыхтуй код і інструкцыі, але не абыходзь праверку receipt або права, каб атрымаць зялёны вынік.

Файлы толькі `spikes/G00.03-sandbox-grant/`, `docs/architecture/decisions/G00.03-payment-evidence.md`, свой result/demo. Выкарыстоўвай адзін бясшкодны прыватны файл. Ні рэальных плацяжоў, ні production-ключоў, ні чужога кантэнту. Новыя платныя рэсурсы або публікацыя патрабуюць асобна пацверджанага дазволу; лакальны код і сінтэтычныя праверкі рабі незалежна.

## Праца і вынік

1. Мінімальная device-ідэнтычнасць з бяспечным сакрэтам; кліент не выбірае сервернага ўладальніка права праз адвольны user_id. Ключы сервера толькі ў env тэставага backend, значэнні не ў README/логах.
2. Адзін серверны mapping product→route/tier і allowlist маніфеста route/version/locale/tier/path. Private storage без пастаяннага public URL; у кліенце няма service-role ключа.
3. Кліент запускае sandbox purchase і затым grant. Сервер сам правярае права ў правайдара і вяртае кароткачасовую спасылку толькі на дазволены файл. Тэкст «куплена» ў кліенце не прапускае authorization.
4. Тая самая store-пакупка аднаўляецца праз restore для новай тэставай ўстаноўкі; iOS→Android перанос не абяцаецца. Перадача правоў паміж test-device IDs дакументуецца без іх сакрэтаў.
5. Збой правайдара правярай праз кіраваны лакальны transport-test або тэставае асяроддзе, не ламаючы сапраўдны сэрвіс. Без кэшу — 503/retry, без права — 403. Запішы мяжу пазітыўнага кэшу, калі ён у спайку ёсць; не рабі кэш абыходам патрэбнага route/tier/environment.

## Абавязковыя праверкі

| Праверка | Вынік |
|---|---|
| Без purchase, але client bought=true | Няма байтаў прыватнага файла |
| Сапраўдны sandbox purchase у iOS і Android | Сервер бачыць права, grant дае файл, webhook выключаны |
| Restore у той самай краме на новай ўстаноўцы | Права знаходзіцца, няма паўторнай аплаты |
| Чужы device_secret / route / tier / version / locale / path | Адмова да падпісання URL |
| `..`, URL, абсалютны шлях, невядомы файл | Адмова, няма раскрыцця storage-структуры |
| RevenueCat недаступны, кэшу няма | 503, не 403 і не fallback-доступ |
| TTL URL скончыўся | Новая выдача патрабуе authorization; эфекты CDN правераныя паводле правайдара, не выдуманая гарантыя імгненнага адклікання |
| Sandbox credential супраць production-рэсурсу | Няма доступу; сам production не выкарыстоўваць для разбуральнага эксперыменту |

## Кантэкст, які не трэба шукаць у размове

KUDY — аўтарскі гарадскі гайд. Першы горад — Гданьск, першая аўдыторыя і аўдыё — беларускія; UI BE/EN. Горад → Гіды → канкрэтны гід; іншыя рубрыкі могуць існаваць без прагулкі. Кожная гісторыя мае асобны аўдыёфайл і транскрыпт. Парадак кропак вольны, рэкамендаваны шлях неабавязковы, End магчымы пасля любой гісторыі.

Аўтагук толькі абранага гіда пасля яўнага Start, для даступнага кантэнту пры свежай пазіцыі і dwell. Ручны Play не патрабуе блізкасці. Moments адкрываюцца рукамі і самі не гавораць. Падказка іншага гіда паблізу — ціхая foreground-картка, не аўтастарт; у Paused/падчас аўдыё/ў фоне яе няма (R07 у `15`). Адзін плэер і адзін уладальнік геалакацыі. Паўза/званок не лічацца праслухоўваннем; пасля іх няма аўтапрацягнення без чалавека. Перапынены файл можна запусціць з пачатку.

Start патрабуе поўнага праверанага выбранага пакета. Аплата ≠ загрузка. Locked мае публічны анонс, але не поўны тэкст/медыя. Права выдае сервер, не сцяг кліента. Версія сесіі замацаваная да End, у тым ліку пасля restart і на наступны дзень. Лакальны прагрэс і ліміты падказак не залежаць ад згоды на серверную аналітыку. Імпарт чужых гідаў, фонавыя discovery-паведамленні, акаўнты і маркетплэйс — не гэтая задача.
