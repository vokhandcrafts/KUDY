## Acceptance

1. Device A cannot read, replace or delete B's rating using a supplied identifier.
2. Scores 0,6,3.5 and wrong-kind reasons return 422 without data changes.
3. Identical mutation retry gives the original outcome, different payload with same ID gives 409.
4. Concurrent same-revision writes yield one success and one conflict; delete cannot be overwritten by an old revision.
5. Deleted device credentials cannot recreate rows; direct anon/authenticated table access is denied.

## Shared invariants

No runtime LLM, weather engine, public ratings, user-profile inference or automatic rating-based ranking. No new GPS/player owner. No disclosure of paid content from public previews. A collection cannot start a Run or create an entitlement. Feedback is voluntary, authenticated to the submitting installation and separate from analytics consent. Never log coordinates, secrets or free-text feedback. Unknown locale/time/season is not silently accepted as a match.
