## Steps

- [ ] 1. Stop page: place name, story text (transcript) in the page's locale, be audio via the standard HTML audio element — playback starts only from an explicit user action; no autoplay, no preloading tricks that auto-start.
- [ ] 2. Recommended-order navigation: prev/next by `RouteStop.position` — display order only (09 §3: «толькі рэкамендаваны парадак паказу, ніколі ўмова прайгравання»); any stop can be opened directly by URL.
- [ ] 3. Locked stop: render the public preview (name, announce) with the padlock and the app CTA; no audio element, no transcript, no partial paid text.
- [ ] 4. Unknown or missing version/locale: a defined safe state («версія недаступная» + path back), never a partial or dangerous render (16 G10.01: «невядомая версія не рэндэрыцца небяспечна»).
- [ ] 5. Missing audio file: user-visible failure state with the transcript still readable; silence is not a state.
- [ ] 6. No progress storage: no cookies, no localStorage, no analytics events in this release.

## Acceptance

1. [ ] Free stop: transcript renders in `be`/`en` as real server-rendered text (M3: «тэкст індэксуюцца»); audio plays after a tap and never starts by itself.
2. [ ] Locked stop: HTML contains the four preview fields and no transcript/paid text; the audio element is absent.
3. [ ] A URL with a nonexistent or unknown-version route/stop renders the safe state; negative test included in the suite.
4. [ ] Missing audio file shows the failure state and keeps the transcript readable.
5. [ ] `npm test` includes the new cases; the result file records evidence per criterion.

## Shared invariants

The web walk is manual by contract: no GPS, no geofence, no session, no `heard` accounting, no autoplay. Playback state lives only in the open tab and is discarded; nothing about the visitor is persisted.
