# G20.34 — Make the full guide catalog scrollable with virtualized rows

Issue: https://github.com/vokhandcrafts/KUDY/issues/796

## Epic

Epic: #470

## Goal

Explore and the Guides rubric expose every matching guide through a scrollable virtualized list while preserving the current visual canon and navigation.

## Evidence

Audit task ID: G20.34. Severity: MEDIUM. Finding key: `catalog-list-unbounded-and-unscrollable`.

GuideCardsList creates every card with guides.map inside View. Its Explore/PaperSurface and Guides parents are also non-scrolling View containers. This remains true on main 85c020c2cb99453f291e68479a9708372843669a (PR #759 changes only the unavailable banner). A catalog longer than the viewport has unreachable lower cards and mounts the entire collection. No device FPS or memory benchmark was run in the audit.

## Scope

components/guide-card.tsx; app/(tabs)/explore.tsx; app/city/[id]/guides.tsx; affected render tests. Keep decorative PaperSurface and design tokens intact.

## Acceptance criteria

1. [ ] Use a virtualized scroll container for both surfaces; place existing headings, links and walk control in its header and avoid nesting the list in a same-direction ScrollView.
2. [ ] With at least 100 synthetic guides, scroll to and open the last guide; preserve order, unique keys, locale filtering, offline/error/empty states and current routes.
3. [ ] Keep one column below 821px and two at/above 821px; changing width retains a usable list without key/column-count errors. Verify large text on a narrow viewport.
4. [ ] Add render regressions for the list structure and navigation and record a reproducible UI scroll check with screenshots where available. The test must fail if the full map-in-View implementation returns; do not claim device FPS from a mocked render.

## Out of scope

G26 redesign, new palette or component language, G27 interest filtering, server pagination or modifying other claimed tasks.

## Dependencies

None.

No open prerequisite. This is a functional layout fix under the existing canon, not G26.14 implementation. #663/#664 and active #670 do not currently edit these scoped files; recheck before claiming.
