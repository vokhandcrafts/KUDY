## Goal

A single index of domain terms so that commits, issues and documentation stop
drifting in terminology. implementation-rules §2 treats *signature* drift; this
treats *term* drift. The file cross-indexes existing canon only — it introduces no
new definitions and no new behavior.

## Placement

`docs/architecture/25_domain_vocabulary.md` — number 24 is taken by the web
collection spec draft (PR #152, `docs/24_web_collection.md`); 25 is the next free
number of the shared chronological series, and `architecture/` fits because the
vocabulary indexes 01/09/15/19/21.

## Format (from the plan)

One row per term: **term / short definition / canonical source link / `_Avoid_`:
how it must not be called**. Every definition points at its canonical source
(01, 09, 15, 19, 21); nothing is defined here for the first time.

## Acceptance criteria

1. Every term row carries exactly one canonical source link, and every link
   resolves at push time (implementation-rules §16).
2. Every row carries an `_Avoid_` example.
3. No new behavior or definition is introduced: anything not present in the canon
   is either absent or explicitly marked as a proposal («прапанова»), never stated
   as decided.
4. The update rule — a new term lands in its canonical source first, the
   vocabulary only indexes it afterwards — is one paragraph inside the file itself.
5. A structural guard test (place it under `tools/validate/`, already covered by
   the `npm test` glob — no new wiring) fails when the file is removed or when a
   row loses its source link or `_Avoid_` cell.

## Out of scope

- renaming anything in code, docs or issues;
- translating or i18n-ing terms;
- new definitions, product decisions, or a second rules file.

## Proof

`node --test tools/validate/vocabulary-guard.test.mjs` — fails if the vocabulary
file or any row's source/avoid structure is removed.

## Notes for the executor

Candidate starter terms come from the canonical sources themselves (e.g. зона A/B,
бандл, пласт, Moments, кропка, гід, падборка, discovery, feedback-мэта — pick what
the five sources actually define; do not invent). The file is human-facing
documentation: Belarusian (documentation-language.md).
