## Вынік

Створаная матрыца [G00.04-stack-baseline.md](../../architecture/decisions/G00.04-stack-baseline.md):

- §1 — адзін кандыдатны набор шасцю радкамі (Node/npm, Expo/RN/натыўны runtime, аўдыё/лакацыя, map reader, тайлы/транспарт, Store SDK/плацежы, backend runtime), для кожнага — фактычная версія, крыніца доказу, статус верыфікацыі і абмежаванні; версіі ўзятыя з [VERSIONS.lock.json спайку G00.01](../../../spikes/G00.01-location-audio/VERSIONS.lock.json) і ADR спайкаў, не «найноўшыя».
- §2 — адзіны пералік паводзін, што патрабуюць development build (background location, background audio, натыўны рэндэр карты) — абгрунтаванне, чаму Expo Go не можа быць доказам стэку.
- §3 — адзіныя env-назвы (кліент/сервер) даслоўна з `.env.example` спайку G00.03, толькі назвы, без значэнняў; strict env-gate цытуецца як mock-proven факт.
- §4 — несумяшчальнасці і адкрытыя пункты: Node-разыходжанне lock vs сесійных асяроддзяў; адсутнасць `package-lock.json`; адсталая мадэль спайку G00.01 супраць ADR G01.01 §4.2; PMTiles/MBTiles у MapLibre Native; CRLF-блокер G00.02; поўная адсутнасць OS/live-верыфікацыі.
- §5 — дакладная перадача `.b` (адзін набор, правілы «не капіраваць спайкі цалкам», развядзенне application IDs) і яўны пералік незамарожанага.

Ключавы выснова для `.b`: прамой канфлікт версій паміж спайкамі адсутны (G00.02/G00.03 — чысты Node без npm-залежнасцей), рызыка — у прагалах верыфікацыі і адсутным lockfile, не ў несумяшчальнасці пакетаў.
