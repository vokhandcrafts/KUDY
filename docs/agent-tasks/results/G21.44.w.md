Ключавое абмежаванне класаў 1–2: марка ў публічным base-пласце аднолькавая для ўсіх (адзін файл раздаецца ўсім), таму payload даказвае «кантэнт наш» (версія/маршрут/лакаля), але **не** «хто выцягнуў». Атрыбуцыю асобнай копіі — крыніцы ўцечкі — дае толькі canary-мадэль: унікальны варыянт на кожную раздачу (для аўдыё — асобны рэндэр на атрымальніка) — фізічна немагчыма на публічным вэб/CDN, рэальна толькі на пер-атрымальніцкіх каналах (прыватны пілат G19, рэвью-копіі).

Для KUDY тэкст гідаў — чалавечы (аўтарскі/перакладны), таму **статыстычныя LLM-ватэрмаркі да існых тэкстаў непрымянільныя ў прынцыпе**: яны працуюць толькі на генерацыі кантраляванай мадэллю (SynthID-Text, Kirchenbauer). Гэта фактычная мяжа, не прадмет выбару.

### Дэтэкцыя: як копія сочыцца да нас

Агульны ланцуг для любых марак: (1) марка ўбудоўваецца ў зборку з payload-ам (ідэнтыфікатар кантэнту/раздачы) і сакрэтным ключом; (2) паверхні-маніторынгу — пошукавікі, файлавыя хостынгі, тэлеграм-каналы, люстэркі — праходзяць выбарачна; (3) знойдзеныя копіі праганяюцца праз дэтэктар (аўдыё: `audiowmark get` — адкрыта, лакальна; тэкст: статыстычны тэст або паўторнае супастаўленне варыянтаў) ці фінгерпрынтынг-сэрвіс; (4) расшыфраваны payload + уласныя запісы раздач даюць доказ паходжання. Два камерцыйныя профілі: Digimarc (ватэрмарк + пошук уцечак, расшыфроўка ID сувязі з уласнымі транзакцыямі — [digimarc.com](https://www.digimarc.com), доступ 2026-10-11) і fingerprint-платформы (Audible Magic/Pex — ідэнтыфікацыя без маркі). **Без кроку 2–3 ватэрмарк мёртвы**: сёння ў KUDY маніторынгу няма — аўтаматычны маніторынг адкладзены як эпік G21.44.m ([#684](https://github.com/vokhandcrafts/KUDY/issues/684)), дзеючы аўдыт — ручны (К5 ADR G21.44).
