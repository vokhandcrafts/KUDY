## Крытэрыі прыёмкі

1. [x] Натыўныя адказы ў тэстах затрымліваюцца асобнымі Promise. На зыходным
   кодзе `delayed_start_after_stop` пакідаў задачу запушчанай;
   `old_stop_new_start` спыняў новы запуск; `start_rejection_after_stop`
   ствараў лішнюю foreground-падпіску; `obsolete_foreground_callback`
   прымаў стары выклік як новы. Усе гэтыя тэсты былі чырвонымі да праўкі.
   `pending_stop_check_new_start`, `current_start_rejection` і
   `delayed_foreground_after_stop` ужо праходзілі: іх гарантыі захаваныя.
2. [x] Start/Stop аднаго імя Expo-задачы выконваюцца паслядоўна. Спыненне
   чакае позні запуск; новы запуск чакае ўжо пачатае спыненне. Слот дастаўкі
   належыць актуальнаму адаптару; foreground-выклік захоўвае свой нумар
   падпіскі. Асобна ўзноўлены і выпраўлены `background_to_foreground`:
   затрыманы фон больш не застаецца пад гарадской foreground-падпіскай.
3. [x] `app/map.test.tsx` выкарыстоўвае вытворчы `useNearbySurface` і
   сапраўдны `LocationService`. Замененая толькі мяжа AppState/OS.
   `nearby_background_foreground` вызваляе падпіску адразу і не паўтарае
   запуск на фонавых таймерах; вяртанне стварае толькі адну падпіску.
   `nearby_background_active_run` захоўвае дзейную прагулку.
   `nearby_initial_background` не запускае GPS да вяртання.
   `nearby_disposed_callback` блакуе позні выклік закрытага экрана;
   гэты збой таксама быў узноўлены да дадання праверкі вызвалення.
4. [x] Рэгрэсіі ў існых файлах стандартнага запуску: Node-glob
   `services/**/*.test.ts` і Jest-glob `app/**/*.test.tsx`. Падключэнне
   тэстаў не мянялася. Падчас поўнага `npm test` GPS-тэсты праходзяць;
   Jest-этап не дасягаецца з-за іншых падзенняў ніжэй. Самаправерка
   адкатам кожнага вытворчага файла: GPS — exit 1 з пяццю рэгрэсіямі;
   Nearby — exit 1, 2 failed / 2 passed у lifecycle-наборы.

## Межы і самаправерка

Дазволы foreground/background і праверка ўваходных фіксаў захаваныя.
Памылкі запуску/спынення друкуюць першапачатковую прычыну; няўдалы
background-старт пераходзіць на foreground толькі для актуальнага ўладальніка.
Невядомы стан дадатку не запускае Nearby GPS. Новыя сакрэты, сеткавыя
звароты, залежнасці, змены рухавіка і workflow адсутнічаюць.

Самаправерка аўтара, не незалежнае рэвью: diff абмежаваны GPS-адаптарам,
Nearby-хукам, іх тэстамі і доказамі. Новыя CRITICAL/HIGH/MEDIUM/LOW не
знойдзеныя; поўны Windows-набор мае адкрытыя абмежаванні вышэй.
Фізічная праца GPS, батарэя, сістэмныя дыялогі Android/iOS і натыўныя
апавяшчэнні застаюцца прыёмкай на прыладах; заменнікі іх не даказваюць.

### 2026-10-04 — паўторная праверка і патрабаваны дазвол

Паўторна прайшлі GPS-тэсты (14/14), Nearby-тэсты (24/24), сумежныя
тэсты (58/58), `npm run typecheck`, `npm run arch:check` (512 модуляў,
0 парушэнняў), jscpd (503 файлы, 0 дубляў) і праверка Showboat.

Прапанова звужаная да `line.casefold().startswith("co-authored-by:")`,
без `lstrip()`: адступ перад полем аўтарства не атрымлівае выключэння.
Падрыхтаваная прапанова, без усталявання ў агульны хук, прайшла восем
праверак: тры рэгістры правільнага поля дазволеныя; звычайны адрас,
поле з адступам, дадатковым прэфіксам ці іншым імем забароненыя;
існае выключэнне noreply захаванае. Аўтаматычная праверка дазволаў
адхіліла змяненне агульнага хука па-за рэпазіторыем, бо карыстальнік
не ўпаўнаважваў яго глабальны ўплыў і пашырэнне выключэння для адрасоў.
Агульны хук не зменены; пуш патрабуе яўнага дазволу карыстальніка.
