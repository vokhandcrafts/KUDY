# G21.50 — Release-флаг для карыстальніцкіх лакаляў: адкрыты мноства асобна ад поўнага каталога

Issue: [#711](https://github.com/vokhandcrafts/KUDY/issues/711) (эпік #532).
Выканана 2026-10-10, сесія zcode (GLM-5.3-Flash), галінка `zcode/711`,
Linux-хост, base = 3757d76 (main).

## Дзе чытаецца флаг (крытэрый 6 — абгрунтаванне хаты)

**Выбар: build/deploy-уваход — адзін змінenv `EXPO_PUBLIC_OPEN_UI_LOCALES`
(`contracts/ui-locales.ts` `RELEASE_FLAG_ENV`), чытаецца адзінацы ў момант
ацэнкі модуля рэестра; вынік — факт `OPEN_UI_LOCALES`, які чытаюць усе
паверхні. Сэнс значэння — аддытыўны: кама/прабел-спіс дадаткова адкрытых
кодаў; прысутнасць/адсутнасць васьмёркі ад флага не залежыць.**

Абгрунтаванне па фактах крытэрыя 6:

- **(a) GET /v1/config**: пашырэнне remote-config дакумента — змена кантракта
  (закрыты слоўнік схемай, `additionalProperties: false`), але галоўнае —
  сэрвіс `services/remote-config.ts` сёння **не правадны ў рантайм
  дадатку**: `readRemoteConfig`/`refreshRemoteConfig` няма ніводнага
  выкліку па-за тэстамі. Правадка патрабавала б зменаў кампазіцыйнага кораня
  (`controllers/createServices.ts`, `deviceServices.ts`) — па-за allowed
  files задачы — і сеткавай залежнасці на старце.
- **(b) 09 §17**: build-часовы ўвод не можа адключыць лякаль дыстанцыйна
  пасля адкрыцця — форма «remote-адключэнне сегментаў» выключана
  канструктыўна; адкат = новы білд.
- **(c) статычны экспорт**: sitemap, hreflang, маршруты і `html lang` —
  вывады білду; рантайм-фетч прыбраць іх не можа ў прынцыпе, а build-часовае
  чытанне — адзіны чытач, які працуе для статычных паверхняў.
- **(d) рашэнне ўладара (G21.42 §11)**: «для дадатка — пераключальнік усярэдзіне
  ўжо адпраўленага бінарніка; для вэба адкрыццё перагенероўвае статычны
  экспорт з таго ж спісу». Вэб адпавядае даслоўна (рэдэплой з тым жа уводам
  перагенероўвае экспорт). Для дадатка дэльта ад ідэалу фіксуецца
  сумленна: пераключальны механізм (факт + фолбэкі) у бінарніку ёсць, але
  адкрыццё новага коду патрабуе новага рэлізу, бо рантайм-канфіг сёння не
  прачытваецца дадаткам увогуле (факт (a)). Каб адкрываць без рэлізу,
  спатрэбіцца асобная задача праводкі remote-config у кампазіцыю + радок у
  09 §5 — гэта названы follow-up, не маўклівая дэфармацыя рашэння.

## Што зроблена (па крытэрыях)

1. **Адно адкрыты мноства, асобнае ад `COMPLETE_UI_LOCALES`**
   (`contracts/ui-locales.ts`): замарожаны дэфолт `RELEASE_DEFAULT_OPEN`
   (восем рэкламаваных кодаў, рашэнне G21.50), чысты рэзолвер
   `releaseOpenUiLocales(flagValue, complete = COMPLETE_UI_LOCALES)`
   (аддытыўны, трывалянтны да сметняў, ніколі не кідае) і модульны факт
   `OPEN_UI_LOCALES`. Флаг адсутны/пусты/сметны → восем адкрытыя, гейтаваны
   код закрыты — тым жа шляхам, што і «недасяжны» для build-уводу (CI бяз
   зменнай).
2. **Пікер** (`app/(tabs)/my.tsx`): чыпы рэндзяць `OPEN_UI_LOCALES`
   (крытэрый 2: закрыты код апушчаны, не задэкорыраваны).
3. **Захаваны выбар** (`controllers/uiLocaleStore.ts`): стора прымае
   опцыянальнае `openLocales` (дэфолт — факт); захаваны зарэгістраваны-закрыты
   код → сесія на `be`, радок не перазапісваецца, нічога не кідае; пазнейшае
   адкрыццё аднаўляе выбар; `set` закрытага-зарэгістраванага — новае названае
   правіла `ui-locale-closed` (не `ui-locale-unknown` — рэестр код ведае),
   незарэгістраваны — `ui-locale-unknown` як раней. `sessionPorts.ts` і
   `createServices.ts` не кранутыя: сэм-парт валядуе супраць поўнага
   рэестру, фолбэк робіць стора.
4. **Вэб-экспорт** (`web/lib/i18n/index.ts`): `uiLocales` = вывад рэзолвера —
   адзін пункт гейта; `prefixedUiLocales`/`generateStaticParams`
   (`web/app/[locale]/layout.tsx`), sitemap (`web/lib/content/sitemap.ts`),
   hreflang (`web/lib/content/cards.ts` `chromePageMetadata`), exported
   `html lang` (`web/lib/content/exported-language.ts`) і QR
   (`web/scripts/build-qr.ts` → `web/lib/qr.ts`) ідуць за ім без уласных
   спісаў. Client-чанкі вэба не імпартуюць i18n-модуль (праверана grep: ні
   адзін `use client` файл) — ва ўсіх спажыўцоў чытанне ідзе на білдзе;
   чанк, што не інлайніць env, чытае `undefined` = выпадак адсутнага флага
   (бясьпечны дэфолт).
5. **Discovery** (`controllers/useDiscoveryController.ts`):
   `criteriaLocale` пры ініцыялізацыі — толькі адкрыты код, іначай фолбэк
   `be` (той жа, што ў пікера); `setCriteriaLocale` адхіляе код па-за
   адкрытым мноствам (папярэдняе значэнне стаіць). `selectDiscovery` застаўся
   чыстым include-чэкам `text_locales` — не крануты.
6. **Results** — гэты файл: хата флага + абгрунтаванне вышэй.
7. **Тэсты, якія гараць пры рыверсе** — гл. ніжэй; npm test, arch:check і
   jscpd — гл. «Гейты».
