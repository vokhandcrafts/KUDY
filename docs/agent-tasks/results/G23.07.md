# G23.07 — падрыхтаваныя праверкі моў Android

Дата: 2026-10-12. Задача: [#665](https://github.com/vokhandcrafts/KUDY/issues/665).
Картка: [G23.07](../e2e/G23.07.md). База: `e2ff0476513c018869e6efd5eb377d5e870ea5fa`.

Статус: заблакавана; набор тэстаў падрыхтаваны, прыёмка на эмулятары не пацверджана.
Карыстальнік дазволіў падрыхтаваць тэсты і пазначыць праверку прагулкі заблакаванай.
[Праца над Start #727](https://github.com/vokhandcrafts/KUDY/issues/727) занятая іншым выканаўцам.

## Крытэрыі прыёмкі

| № | Падрыхтаваная праверка | Фактычны вынік |
|---|---|---|
| 1 | Выбар усіх васьмі моў, стан selected і подпісы Explore з сапраўдных каталогаў паведамленняў | На эмулятары не праверана |
| 2 | Force-stop, запуск і паўторная праверка выбранай мовы | На эмулятары не праверана |
| 3 | Межы і націсканне кнопак пры font scale 1.5; аднаўленне налад у finally | Аднаўленне праверана асобнымі тэстамі; інтэрфейс і прагулка не правераны |
| 4 | Дакладныя content-desc з каталогаў для Explore і preview; Run захоўвае мову сесіі be паводле ADR G01.03 | На эмулятары не праверана |
| 5 | Праверка selected пасля перазапуску павінна адхіліць страту выбару | Адхіленне страты выбару праверана асобным тэстам; адкат сховішча на эмулятары не выкананы |

## Запуск

`npm run e2e:android -- --suite locales` запускае сцэнарыі праз існуючы Android driver.
Адсутная прылада дае бачнае SKIP без PASS. Набор аднаўляе зыходную мову і памер шрыфту;
памылкі сцэнарыяў захоўваюць здымкі і XML у ігнараваным каталогу artifacts.

Спрабаваў асобны эмулятар `emulator-5558`, асобныя парты 8085/8795 і копію ўсталяванага
dev-client. Усталяванне спынілася з `cmd: Can't find service: package`, exit 1, да запуску
сцэнарыяў. Ніводная мова або прагулка гэтым запускам не пацверджана. Уласны эмулятар,
яго часовы дыск і копія APK прыбраны; прылада іншага выканаўцы не змянялася.
