## What was decided (for G02.01)

1. **Catalog envelope.** `catalog.json` is a versioned envelope `{catalog_schema_version: 1, generated_at?, routes: [...], discovery_index?}`; route entries keep their `09` §4 shape inside `routes`; city/discovery fields are never added to individual route entries. A catalog without `discovery_index` is a first-class input; unknown top-level fields are ignored; unknown major version means "guides only, no discovery, never blocks Run"; a bare route array (legacy v0) reads as a catalog without discovery. Recorded in `21` §3.3.
2. **Schema limits** (recorded in `21` §3.2, overflowing cases in `index-invalid-limits.json` + `catalog-invalid-oversized.json`): offers ≤ 64, collections ≤ 32, members ≤ 50 (no duplicates), themes ≤ 32 / ≤ 8 per offer, ≤ 8 locales per localized object (MVP allowlist `be`/`en`/`uk`; `pl`/`de` reserved), title ≤ 140 chars, summary/why_recommended/conditions/description/overlap_note ≤ 400, season reason ≤ 280, `editorial_order` 0–9999, duration integer 1 ≤ min ≤ max ≤ 1440 (guide range must include `duration_min`), `distance_m` ≤ 100000, identifiers and `revision` ≤ 64 chars of `[a-z0-9._-]`, index file ≤ 512 KiB verified by catalog `bytes`/`sha256` before fetch. Locale-count ≤ 8 cannot overflow independently with a 3-code allowlist; G02.01 still encodes max 8.
3. **`detail_ref` kinds:** `place_public`/`collection_public` (safe relative path, no `private`/`extended`/`..` segments) and `guide_preview` (no path; the known route preview). Private transcripts, extended media paths, full paid texts and raw ratings never enter the index (`21` §3.2 + §2 trace table).
4. **`overlap_note`:** required when members contain a guide G and a place P equal to that guide offer's `suggested_start_place_id` (`21` §3.2). Positive: `collection-f1`. Negative: `index-invalid-missing-overlap-note.json`.
5. **Registry revisions.** The publisher registers every target actually contained in a release manifest: guide `{route_id, version, locale}` per published text locale, place `{place_id, content_version, locale}` for the published public projection; superseded historical versions stay registered and keep accepting feedback; collections and single stories are not targets this release; `prepared → published` flow unchanged (`21` §5.2).
6. **Unknown stays unknown.** Missing `estimated_duration` and empty `season_recommendations` are the only honest representations of unknown/not-assessed; `null`, invented enums (`all`) and auto-filled defaults are rejected (`21` §3.2, negative fixtures). `index-valid.json` exercises this positively: `offer-c1-place` deliberately omits `estimated_duration` and has empty `season_recommendations` — that omission is contractual, not accidental.
