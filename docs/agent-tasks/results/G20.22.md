# G20.22 — вынік: дазвол аператара на змены workflow, 2026-10-02

Задача [#493](https://github.com/vokhandcrafts/KUDY/issues/493) (закрытая
2026-10-02 як completed), спецыфікацыя
[verification-integration.md §V2](../../specifications/architecture-hardening/verification-integration.md),
эпік [#470](https://github.com/vokhandcrafts/KUDY/issues/470).

## Рашэнне

Оператар ухваліў канкрэтны набор CI-змен у чаце ZCode-сесіі 2026-10-02 (адказ
на пытанне пра наступную задачу: «Дазвол #493 → бяру #484»). Поўны запіс
рашэння — каментарем у самой задачы:
[#493 (каментар)](https://github.com/vokhandcrafts/KUDY/issues/493#issuecomment-5956926031).
Выканаўца выступаў толькі сакратаром запісу; рашэнне — аператара.

## Што дазволена (сем названых зонаў, `.github/workflows/*.yml` толькі)

1. Deno type-check прадукцыйных энтрыпоінтаў (G20.13) — асобны producing job.
2. Рэальны арх-скан рэпазіторыя ў GitHub (G20.15).
3. Праверкі JavaScript-інструментаў (G20.16).
4. Пераносныя Windows-тэсты (G20.17).
5. Замацаванне actions поўнымі 40-hex SHA (G20.27).
6. Правераны checksum-спампоўкі gitleaks (G20.27).
7. `engine:regressions` у абавязковай праверцы (G20.28).

Абмежаванні (апісаныя ў запісе як абавязковыя): без паслаблення існых
checks і гвардаў; без пашырэння `permissions`; без зменаў канфігурацыі
dispatcher, branch protection або налад рэпазіторыя; кожная наступная
змена workflow — новае рашэнне аператара.

## Крытэры

1. ✅ Дазвол на названыя шляхы/крокі запісаны ў задачу спасылкай вышэй.
2. ✅ Запіс называе producing jobs і забараняе паслабленні/пашырэнні правоў
   (раздзел «Constraints (binding)» каментара).
3. ✅ Метад вярыфікацыі статусаў — чытанне producing jobs адкрытага PR праз
   `gh` (checks API). Неразвязаная перадумова запісаная ў каментары: токен
   сесіі не мае `read:project`, таму бачнасць required statuses у branch
   protection праграмна не пацвярджаецца — гэта застаецца на аператары, не
   лічыцца аўтаматычна пройдзеным.
4. ✅ Целы задач рэалізацыі ўжо лінкуюць гэтую задачу (`Blocked-by: #493` у
   #484, #486, #487, #488, #500, #501); з закрыццём #493 спасылкі рашацца на
   закрыты запіс дазволу да першага edit-у `.github/`.
