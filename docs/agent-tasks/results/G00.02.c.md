# G00.02.c — Рашэнне пра карту і тайлы

**Дата:** 2026-09-15
**Статус:** `decision-required` — канкрэтны ADR гатовы ([G00.02-offline-map](../../architecture/decisions/G00.02-offline-map.md)), але ён **не прыняты**: залежнасць G00.02.b завяршылася `blocked-external` (прыладавая матрыца `not-run`), а заданне .c загадвае ў гэтым выпадку «не accepted, а канкрэтны наступны эксперымент для .a». Адзін вынік задачы — дакумент рашэння — створаны і ўтрымлівае рэкамендацыю, пярэдумовы прыняцця і эксперымент.

## Вынік

- Створаны ADR `docs/architecture/decisions/G00.02-offline-map.md`: адзіная рэкамендацыя-кандыдат (варыянт A — штатны `OfflineManager` MapLibre RN з уласнымі тайламі з OSM-экстракта на ўласным/ліцэнзаваным хостынгу; пры правале — B; C не рэкамендаваны як стратэгія тайлаў), складнікі незалежныя ад A/B/C (reader, пастаўшчык/хостынг, required assets, ліцэнзіі, атрыбуцыя, формула кошту з датай крыніцы), кантрактнае следства A («другая крыніца гатоўнасці» супраць G01.03), сцэнары з адзінымі імёнамі палёў і канкрэтны наступны эксперымент для .a з пярэдумовай ліквідацыі CRLF-блокера і яўным запісам неэквівалентнасці фікстур A/C.
- Рэкамендацыя **не прымаецца** гэтым файлам: `09` аддае выбар A/B/C замеру («вырашаецца замерам у M0b, не абмеркаваннем»), а замер не адбыўся; таму ніякі прадуктовы выбар тут не лічыцца зацверджаным, і залежны G00.04 не разблакоўваецца.
- Бацькоўскі result `G00.02.md` не ствараўся і не дапаўняўся (толькі пасля апошняй часткі пакета); агульны `09` не тыкаўся (інтэграцыя — G00.04).
- Showboat: **не ўзнікае** — змена толькі дакументальная, ніводная ўмова decision rule `showboat.md` (1–5) не выканана; дэма не стваралася.
