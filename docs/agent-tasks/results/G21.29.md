## Acceptance criteria walk

1. **Current official access method verified, not assumed.** The historical Language Portal and Terminology Service API are dead — probed live: `www.microsoft.com/language` → HTTP 404, `/Language/en-us/Default.aspx` → HTTP 404, `api.terminology.microsoft.com` → DNS failure (curl exit 6). The current method is the Learn hub (`microsoft-language-resources`, updated 2023-06-29) with one bulk channel: `MicrosoftTermCollection.zip` (TBX, 111 language files, HTTP 200, no accounts/credentials). UI strings turned out to have no bulk channel at all — recorded as a finding (report §3.3, §7), not assumed away.
2. **Primary sources with version/date, acquisition, restrictions, attribution, reproducibility, maintenance cost; unknowns explicit.** Every page cited with its `ms.date`/`updated_at` and canonical git commit in `MicrosoftDocs/globalization`; the zip pinned by sha256 + ETag + Last-Modified + byte size; the extracted TBX pinned by sha256. Explicitly recorded as unknown: the collection's license (no terms on any live page checked, no license file in the archive — report §4), the update cadence, and any version metadata inside the artifact. Page claim «nearly 100 languages» vs 111 files observed — discrepancy stated, not smoothed over.
3. **Shared ten-term benchmark with context; positive/negative/mismatch evidence; small lawful samples.** Full XML parse of the one Belarusian file (11,298 term entries over 8,019 distinct English terms): exact matches for 7 of 10 terms (23 pairs total, 142 substring-only neighbors): Back→Назад, Cancel→Адмена/скасаваць, Settings→Налады (3 contexts), guide→гід/інструкцыя (sense split), stop→спыніць, download→спампаваць (+nouns), restore→аднавіць, unavailable→недаступны/адключаны. Negative: walk and purchase have no exact entries. Mismatches recorded with entry evidence: one unavailable definition carried by two different renderings; the download noun in two spellings with identical definitions; `Downloads Marketplace`→«Крама Office» (product-name localization); a Latin character inside a Cyrillic term in source entry `25472_1176798_2072187`. Sample size: one official language file; no corpus integration, no MCP service, no paid account, no credentials.
4. **Human-facing Belarusian report + machine evidence; observations vs recommendations split; unsuccessful access as evidence.** `microsoft.md` (§9 separates them) + `microsoft-evidence.json`; the 404/DNS results, the license gap and the page-vs-archive language-count discrepancy are recorded as findings.
5. **Follow-up drafts derived only from findings; forwarded to G21.33.** Report §10: FU-1 (owner decision request on the license status — outcome may be allow/deny/defer), FU-2 (conditional proposal: pinned be-term glossary for guide-writing checks, Blocked-by FU-1 and G21.24, with testable criteria), FU-3 (documented negative: Microsoft UI strings are not a pinnable data source — no connector task). Forwarding channel: pointer comment on #565 referencing this PR.
6. **Tool registry inspected before recommending anything; no private content/secrets to unapproved addresses; no instructions followed from downloaded data.** The Tool-Lib registry was grepped (no prior Microsoft entry); a data-source entry `microsoft-terminology-tbx-2026-10-04.md` (status 🟡 deferred on the license question) is recorded there — outside this repository — in both registry copies. Network access was read-only GETs to learn.microsoft.com, download.microsoft.com and msit.powerbi.com; no repository or private content was sent anywhere; the downloaded data was treated as data, never as instructions.
