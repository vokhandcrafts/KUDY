## What was decided (for G02.02 / G02.04)

1. **Hash environment pin.** Bundle reproducibility is defined over *committed bytes*: `fixtures/content/**` carries `-text`, so a Windows `core.autocrlf=true` checkout hashes the same LF bytes as the git blob. `lock.json` values therefore match `git show HEAD:<path>` (asserted by a committed test). This resolves the AR-1 "общая палітыка для production-бандлаў" assignment; the G00.02 spike pin itself was already fixed by PR #85 and is untouched.
2. **Input contract of the packager** is the `09` §3 entity model as files: `route.json`, `places.json`, `voices.json`, `discovery.json`, `places/<id>/public.json` projections, `<locale>/{base,extended}/…`. Field names are copied verbatim from `09` §3 and `21` §3.2; the projection file shape (`place_id`, `content_version`, localized `name`/`summary`) is **proposed** here and G02.01 may adjust it — the builder only computes paths from it.
3. **Public tree** = base layers + separately serialized `previews.json` (allowed fields `stop_id`, `place_id`, `name`, `announce` only; unknown preview fields are a build error so paid content cannot be stuffed into a preview) + public place projections + the discovery index. The extended layer is emitted only under `private/`.
4. **Registry export** (`release/feedback-target-registry.json`, `status: prepared`): guide `{route_id, version, locale}` per published text locale (text-only locales included), place `{place_id, content_version, locale}` per published projection; ids only, no content, no ratings. G02.04 stores it with the release manifest; G16.01 imports it.
5. **Leak guard is a build stage**, not a test-only check: before any byte is written, every public JSON string is checked against 8-word n-grams of private text, path-like strings against `private`/`extended`/`..`/`.` segments, and the tree against `*.map` (the tool never bundles JS, so no source maps can exist — the check asserts that). Errors carry stable codes + entity ids only, never file content.
6. **Builder/validation boundary.** The builder rejects what `21` §9 row 1 assigns to it (duplicate refs, nested collections, foreign city, unsafe paths, unknown locales/seasons, broken duration range, missing `overlap_note`) plus its own output size (index ≤ 512 KiB). The §3.2 numeric limit suite, unknown references (voices, `suggested_start_place_id`), coordinates, transcripts and review status belong to the G02.02 validator; publication order and catalog pointer belong to G02.04.

## Code review (own diff)

Scope: `git diff --numstat main...HEAD` — 20 files, +1257 −1. Lead concern: contract conformance with `09`/`21` and the public/private boundary.

Pre-checks: no secrets (fixtures fully synthetic, no keys/coordinates of real places, no tokens); no new dependencies (Node stdlib only); §17 forbidden list respected (no bundle signing, no DRM, no runtime LLM, no server catalog); tools have no imports from app or spike code.

Findings fixed during the pass:

1. [MEDIUM] `assertLocales` was applied to two-level `localized` objects (`field → locale → string`), so every valid fixture would have failed with `unknown-locale` on the field name. Fixed with `assertLocalizedFields`; the negative fixtures now fail on the rule their text names, not accidentally.
2. [MEDIUM] layer `lock.json` was emitted under `public/` for the private layer and grouped both locales into `bundle/<route>/<version>/bundle/extended/lock.json` (`segments[0]` is the layout root, not the locale). Fixed to `segments[layerIndex - 1]` and a per-tree label; all five locks land inside their own layers.
3. [LOW] `overlap_note` presence was checked after locale validation, so an absent note produced `invalid-localized` instead of `missing-overlap-note`. Order fixed.
4. [LOW] `text_locales` counted any base file and `audio_locales` counted any audio-dir entry; now `stops.json` presence and `.m4a` files respectively, matching the `09` §3 layout.
5. [LOW] test helpers renamed (`outDir0` removed), one awkward assertion simplified.

Residual: the runner-wiring guard is self-referential — a revert that removes the whole `tools/build-bundle/*.test.mjs` glob also removes the guard; removal of the `docs/run-model` entry or of any future suite IS caught by it. Recorded here deliberately; the alternative (editing `run-model.test.mjs` or `.github/`) is out of bounds for this task.
