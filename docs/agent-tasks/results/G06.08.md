## Acceptance criteria — walked from the card

1. ✅ **Можна прайсці Start/ручны Play/паўзу/upgrade/вяртанне з Moment/падказку іншага гіда/End.**
   Interactive browser flow verified end-to-end (IAB session 2026-09-22): Start
   → autoplay on dwell → live pause/resume → manual Play → Play Moment →
   suspended → «Працягнуць гід» → AccessReady upgrade → UserSelectedStory →
   R07 hint → preview → NAV8 dialog → End. Deterministic proof:
   `docs/demos/2026-09-22-g0608-prototype.md` (showboat verify ✅, two runs
   byte-identical); guards in `test/prototype.test.mjs`.
2. ✅ **Responsive і accessibility станы апісаныя.**
   `package/screens.md` — per-screen responsive classes (< 821 px / ≥ 821 px),
   a11y floor (screen-reader labels, big-text, reduced motion, transcripts,
   BE/EN chrome), and the named honest states (empty city, offline cache,
   denied GPS). Draft CSS implements the classes; content rules stay in the
   canon files.
3. ⏳ **Заснавальнік зацвердзіў пратотып.** Human gate: the PR review is the
   approval step. Recorded in `docs/human-actions.md` for the merge moment.
4. ✅ **Макеты, ассеты і станы прывязаныя да задач G06/G07/G08.**
   `package/package-map.md` — layouts/states → backlog rows (G06.01–G06.05,
   G07.01–G07.05, G08.05, G16.01–G16.04), assets declared synthetic, canonical
   homes of every state family anchored.
5. ✅ **Пратотып D01–L02 з `20`, асобныя мовы тэксту/аўдыё і pending/edit/delete водгуку.**
   D01–D07/F01–F04/L01–L02 covered by the walkthrough (showboat demo) and the
   discovery/result, feedback-form and My KUDY screens; separate text/audio
   locales rendered per fact (`availability`), L01 disables a Start that would
   promise uk audio; feedback states `draft → pending → sending → sent` +
   `conflict`/`action_required` with edit/delete in My KUDY.

— published with this results file as a note, no issue invented.

## Accepted residual

The root `npm test` wiring guard (`tools/build-bundle/test-wiring.test.mjs`)
deliberately excludes `spikes/` from its enumeration, so it cannot see the
`spikes/G06.08-prototype/test/*.test.mjs` glob added to the default command —
removing that glob would not fail the guard (implementation-rules 1/7 class,
same accepted-residual shape as PR #105). The glob itself is enumerated in
`package.json` and the suite is 8/8 green (incl. the eol-pin guard); extending
the guard to expected spike globs is left as a follow-up for the guard's owners.
