# G21.44.a — атрыбуцыя публічных вэб-старонак

Issue: [#681](https://github.com/vokhandcrafts/KUDY/issues/681). Галіна: `codex/681`. Крыніца рашэння: [ADR G21.44 §6 М1 і §9](../../architecture/decisions/G21.44-content-protection.md).

## Праверка крытэрыяў

1. Старонкі гіда і кропкі атрымліваюць адзін атрыбуцыйны блок. Крыніцы тэксту бяруцца з `story.sources` толькі адкрытых гісторый адпаведнай мовы. Запісы `media.json` звязваюцца па SHA-256 і памеры толькі з файламі публічнага пласта, якія старонка сапраўды паказвае або прайграе. Закрытая кропка не атрымлівае платныя звесткі: яе блок змяшчае спасылку на правілы. Праверкі: `web/lib/content/attribution.test.ts`, `pages.test.ts`, `stop-page.test.ts`, статычны экспарт у Showboat-доказе.
2. У атрыбуцыі гістарычных матэрыялаў выводзяцца захаваныя радкі крыніцы і `credit`; фармальны радок `license` не выводзіцца. Сінтэтычная кропка ў экспарце паказвае крыніцу і крэдыт аўдыё без `CC0 1.0`. Праверка: `docs/demos/2026-10-08-content-attribution.md`.
3. Для фота з дакладным `media.json.license === 'author_own'` блок паказвае лакалізаванае «Фота аўтара» і захаваны `credit`. Іншая ліцэнзія не ператвараецца ў сцверджанне пра аўтарства. Праверкі: `attribution.test.ts`, інтэграцыйны тэст вокладкі ў `pages.test.ts`.
4. Дададзена старонка `/usage-rules` для ўсіх апублікаваных моў інтэрфейсу; блок спасылаецца на яе ў адпаведнай мове. Сказы і пераклады захаваныя ў кананічным UI-каталозе, праекцыі адноўленыя генератарам. Праверкі: статичны экспарт і `tools/i18n/check-messages.mjs`.
5. `web/scripts/scan-rendered.ts` правярае кожную HTML-старонку гіда і кропкі, у тым ліку стан недаступнай мовы. Выдаленне блока са старонкі гіда перад перазборкай выклікала `missing-content-attribution: guides/demo-route-a1.html`; файл адноўлены, паўторны экспарт і Showboat verify прайшлі.
6. `npm --prefix web run build` завяршаецца з `rendered-output scan: clean`, `document-language scan: clean`, `content-attribution scan: clean`. Уваходны і рэндэрны leak-guards прайшлі ў поўным `npm test`. Схемы, `media.json`, раскладка бандла, дадатак, хостынг і sitemap не змяняліся.

## Запускі і межы доказу

На гэтым Linux checkout 2026-10-08: `npm test` — Node 2418 тэстаў: 2412 прайшлі, 6 прапушчаныя, 0 памылак; Jest 222 прайшлі. `npm run arch:check` — 0 новых парушэнняў; `npx --yes jscpd@5.1.2 --config .jscpd.json --no-tips .` — 0 клонаў. `tsc --noEmit` для кораня і вэба прайшоў; `tools/i18n/generate-messages.mjs --check` пацвердзіў актуальнасць праекцый. `uvx showboat==0.6.1 verify docs/demos/2026-10-08-content-attribution.md` прайшоў.

Экспарт выкарыстоўвае сінтэтычны гід рэпазіторыя. Рэальныя апублікаваныя гіды і вонкавыя правы на іх не правяраліся. Адсутны ці несупадальны запіс крэдыту для паказанага медыя спыняе зборку.

## Самаправерка
