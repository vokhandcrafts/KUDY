   asserts the structural contract: exactly one table with the fixed 4-column header and a
   separator, every row has non-empty term/definition, the source cell carries exactly one
   markdown link (the other three cells none), the link resolves on disk relative to the
   file's directory, and the `_Avoid_` cell is non-empty. Negative tests mutate a temp copy
   of the real file (baseDir pinned to the real `docs/architecture/` so untouched rows still
   resolve) and prove the guard fails on: removed file, lost header/separator, a row losing
   its source link, two links in one row, a dead link target, an empty `_Avoid_`, an empty
   term, and passes on a re-pointed link to another existing canon doc.
3. **`docs/agent-tasks/zcode-lessons/README.md`** — the Issue column placeholders replaced
   with the published issue numbers #164–#167 (same index-sync precedent as G17, commit
