## Станы і памеры (крытэрый 2)

- Значэнні станаў узятыя з канона §5 без зменаў: звычайны (`color.ink` на `color.card`), націснуты чып (фон `color.accent`), выключаны (ghost-пара `#6b7280`, празрысты фон, без полкі — рашэнне ўладара 2026-10-03, issue #430), фокус (outline 3 px `color.accent`, змяшчэнне 1 px — аднолькавы для ўсіх інтэрактыўных элементаў).
- Памеры: гліф 16 px (база) / 20 px (буйны тэкст 1,25×, канон §3); маркер 34 px; кропка пазіцыі 18 px; кнопкі шкалы 40 px; зона дотыку ≥44×44 з hitSlop 8 — прэцэдэнт `BackButton` (UX 02, issue #348). Гэта не іконкавыя памеры: маркеры і кропку гліфамі не падмяняць.
- Станы спынення (`locked` і сям'і Пусты/Offline/Denied/Error) ніколі не чытаюцца толькі па колеры: бачны подпіс + a11y-назва (канон §5, §9; крытычныя паведамленні — не mascot-only).
- Прыватныя пробы ўсіх чатырох станаў — [contact-sheet.html](../../design/brand/outputs/G25.04/contact-sheet.html) §2 (статычны HTML; праверкі на жывой прыладзе не рабілася — пазначана як невыкананая візуальная праверка на прыладзе).

## Праверкі

- `npm run arch:check` — 2026-10-11 на HEAD гэтай галіны: «arch:check: OK — 597 modules cruised, 0 violation(s) pass via the baseline dated 2026-10-02».
- `npx --yes jscpd@5.1.2 --config .jscpd.json --no-tips .` — гейт скануе толькі фарматы javascript/typescript/tsx (`.jscpd.json` → `formats`); дыф гэтай галіны не дадае жаднага js/ts/tsx-файла, таму вынік гейта інварыянтны да дыфа. Поўны прагон на хасце не запускаўся (абмежаванне рэсурсаў карыстальніка, 2026-10-11); яго прабягае CI на PR.
- Грэпы мовы: `[А-Яа-яЁёЎў][A-Za-z]` і рускія асновы па дададзеных файлах — чыста (два хіты знойдзеныя і выпраўленыя да каміта).
- Спасылкі выніку — правераныя рэзалверам адносных шляхоў (усе мэты існуюць на HEAD).
- Showboat: не ўжываецца — дыф без runtime-коду і без зменаў паводзін (правіла showboat.md, парог умоў 1–5 не дасягнуты).
