## Рашэнні перакладу (пратакол)

- **Рэгістр — тыканне (ty)**: сям'я de du (G21.10) / fr tu (G21.12) / es tú (G21.11) — неафіцыйны тон арыгіналу; кнопкі ў інфінітыве (стандарт чэшскага UI). Выключэнне па задуме: пытанне візіту месца — інклюзіўнае «Byl(a) jsi tady?» (прынятая чэшская форма роду), шкала ацэнкі — нэўтральнае сярэдні род «se líbilo».
- **walk → Procházka** (ж. род): адзіны тэрмін праходу; статус-радкі трымаюць род (ukončená, pozastavená, aktivní — апошні нязменны па родах).
- **stop → Zastavení** для кропкі маршруту: словаформа нязменная ў лічбах («Zastavení: 1/2/5» — правільна без ICU); дзеянне спыніць тэйзер — асобнае **Zastavit** (uk/de/es-прэцэдэнт немешвання сэнсаў аднаго слова).
- **guide → Průvodce** (чалавечы род): Průvodci →, Průvodce, Popis průvodce; «гісторыя» → **příběh** (Hlavní/Rozšířený příběh), «падбор» → **doporučení**, «тэйзер» → **ukázka** (медыя-тэрмін разведзены з прэв'ю **náhled**, як es Avance/vista previa).
- **download → stáhnout**: адзін корань для абодвух сэнсаў (Stáhnout, Stažení se nezdařilo, není stažený) — en/uk-прэцэдэнт; **unavailable → nedostupný** (Katalog není dostupný — канструкцыя «není dostupný»); **purchase → nákup** (Vyžaduje se nákup, Zakoupeno · čeká stažení).
- **restore → «pokračuje z uložené relace»**: канон без рэстаўрацыйнай метафары, тая самая пабудова be/en/uk/de/es/fr; «аднаўленне пакета» → oprava (як es reparación).
- **Капіталізацыя і тыпографіка**: сказавы рэгістр, чэшскія двукоссе „ “ у дыялогах, інтэрпаляцыя астатнім для timeCap (Do 45 min), чалавечыя формы 60/120/240 (Do hodiny / Do dvou hodin / Půl dne).
- ID і брэнды не перакладаюцца: KUDY, App Store, Google Play, ODbL, issues, tiles→dlaždice (прыродны чэшскі картаграфічны тэрмін, fr-прэцэдэнт перакладу), `langSwitchName` = «English» (уласная назва мовы прызначэння, uk-прэцэдэнт).

## Сэмантычны рэвью (асобны праход)

Другі поўны праход усіх 280 запісаў супраць пары be||en пасля зборкі і генерацыі, з фокусам крытэрыя 3:

- **Адмаўленні**: «нічого не грае» → «Nic nehraje»; «не апублікавана» → «nezveřejněno / není zveřejněný»; «аўдыё не запускаецца» → «Audio se nepřehrává» (cardHint, markerHint); «не раней, чым дадзена згода» → «až je dán souhlas»; «каардынаты не пакідаюць прыладу» → «Souřadnice neopouštějí zařízení»; «зусім не вызначаецца» → «nezjišťuje vůbec»; «ліст ці заяўку дасылаць не трэба» → «Není potřeba posílat dopis ani žádost».
- **Адмена/незавершанасць пакупкі**: «Пакупка не скончылася» → «Nákup nebyl dokončen»; «Не цяпер» → «Teď ne» (без канфліктнага «nikdy»); «Куплена · трэба загрузіць» → «Zakoupeno · čeká stažení» — факт + наступны крок.
- **Выдаленне/аднаўленне**: «Выдаліць ацэнку» → «Smazat hodnocení»; «Выдаленне чакае сеткі» → «Smazání čeká na síť»; restore-канон — «Procházka pokračuje z uložené relace», працяг — «Pokračovat», «адноўленая сесія» → «pokračovaná relace» (tierUnavailable).
- **Род і лік**: procházka ж. (ukončená, pozastavená), zastavení ср. (zamčené, dostupné, vyslechnuté), průvodce ч. (placený), sbírka ж. (nedostupná) — трымаецца ва ўсіх прыметніках; «праслышана: N» → «vyslechnuto: N» (безасабова, правільна для любой лічбы).
- **Змісціныя праўкі прагляду** (1 запіс перапісаны пасля рэвью): `native.chrome.reasonText.within_time` («hodí se časově» гучала нязграбна → «časově vhodné») — перагенерыравана, гейт ізноў зелены.
- **Скан скажэнняў уласнага тэксту** (правіла 12 + прэцэдэнты карупцыі адлюстравання): смеш-скрыпт, падвоеныя словы і кірыліца ў чэшскіх значэннях — злаўленыя да зборкі 4 дэфекты: польская літара ў беларускім слове, злейка лацінскага слова з кірыліцай (два выпадкі), падвоенае слова і кірылічныя літары ў чэшскім значэнні targetLine — фіксы байт-дакладнымі заменамі, паўторны скан чысты.

## Acceptance evidence

1. **Повын набор паведамленняў з native name «Čeština», усе тыпаваныя домены і подпісы.** Гейт `npm run messages:check` — «shipped locales complete, reviewed and fresh»: план рэндэрыць 280 паведамленняў для cs, усе ёсць; `param_mismatch_denied`/`form_set_mismatch_denied` адсутнічаюць — подпісы параметраў і формы супадаюць з G21.09. Native name «Čeština» — у табліцы рэестра (`uiStrings('cs').languageSelfNames.cs`, тэст рэестра і рэндэр-сюта), ніколі не ў перакладзе. Словы даступнасці/прыватнасці/аплаты/дазволаў перакладзеныя (privacy*-блок, offer*, noteDenied, scaleHint).
2. **Формы ліку/даты/лічбаў, доўгія подпісы, empty-станы.** Лікавыя формы timeCap 60/120/240 + інтэрпаляцыя астатнім (`Do hodiny` / `Do 45 min`), названыя формы прэв'ю damaged/missing-files/stale, composed textAudioLine з пустым аўдыё дае «Text: de» без хваста; units min/km/MB; empty-станы каталогаў («Průvodci s textem v tomto jazyce zatím nejsou.»), уласных ацэнак, месцаў. Дыскрэтныя дні-радкі — pre-formatted радкі (тэст крыніцы на date-параметры), узор numeric-сюту праходзіць для cs. ID і гандлёвыя назвы не перакладаюцца (App Store, Google Play, KUDY, langSwitchName «English» — uk-прэцэдэнт). Доступ/статусы не падмененыя (locked → Zamčené, статус-радкі трымаюць факт, не планаўку даступнасці).
3. **Праверкі ключоў/параметраў + асобны сэмантычны рэвью.** Механіка — гейт і кантракт-лоўдар (праходзяць); сэмантычны рэвью — асобны другі праход усіх 280 запісаў, пратакол вышэй; запіс рэв'ю — у кожным запісе (`review.note`), рашэнні тэрмінаў — з глоссарый-следамі G21.27.
4. **Рэгістрацыя/пікер/публікацыя — не тут.** Пікер выводзіць чыпы з `COMPLETE_UI_LOCALES` (існуючы механізм; тэст пікера: сёмы чып «Čeština» і пераключэнне без рэстарту), новай UI-працы выбару/захавання/фільтрацыі не правілася — гэта G21.15/G21.17; вэб-маршруты cs не ствараліся — G21.22; пераклад кантэнту і голас — па-за задачай.
5. **Кананічныя даныя + provenance + генерацыя + гейты + адзін каміт усіх моў.** Аўтарства толькі ў cs.json; generated-выхады праз `node --experimental-strip-types tools/i18n/generate-messages.mjs`; `npm run messages:check` зелены (паўната+рэвью+свежасць); глоссарый прайшоў кантракт з cs-лакатарамі; source.json НЕ змяняўся — таму перагляд be/en/uk/de/es/fr (G21.19) не патрабуе, іх запісы не кранутыя, і ўсе выпушчаныя мовы ідуць у адным каміце.
