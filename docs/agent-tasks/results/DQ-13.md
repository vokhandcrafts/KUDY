## AC3 — тэлеметрыя выключаная, remote і MCP не ўключаныя

- `.rnstorybook/main.ts`: `core: { disableTelemetry: true }`.
- metro.config.js ставіць `process.env.STORYBOOK_DISABLE_TELEMETRY = "1"` —
  withStorybook паведамляе «dev»-тэлеметрыю пры загрузцы канфігурацыі, калі
  гэтая зменная не ўстаноўлена; настройка зафіксаваная ў рэпе і падгледжаная
  гардам.
- `enableWebsockets: false` у `.rnstorybook/root.tsx` (яўна), host/port не
  перадаюцца, генератар запускаецца без `--host` —requires-файл не атрымлівае
  websocket-канфігурацыі; ветка channel-server/MCP (`experimental_mcp`,
  `websockets`) у withStorybook не выклікаецца, npm-скрыптаў на CLI-сервер
  Storybook няма (гвард правярае, што з «storybook»-скрыптаў існуе толькі
  `storybook:generate`).
