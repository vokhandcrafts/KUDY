Спецыфікацыі і задачы апублікаваныя ў [PR #494](https://github.com/vokhandcrafts/KUDY/pull/494), галіна `feature/architecture-hardening-specifications`, першы каміт `7927ad6`. ## Па крытэрах

1. Тры спецыфікацыі, 23 брыфы, індэкс і гістарычныя доказы даступныя ў галіне PR. Даступнасць у асноўнай галіне патрабуе зліцця; не пазначана выкананай.
2. Бацькоўская задача [#470](https://github.com/vokhandcrafts/KUDY/issues/470), часткі #471–#493. Усе перачытаныя праз GitHub API: адкрытыя, без пазнак запуску; спасылкі і граф залежнасцей вырашаныя, цыклаў няма. Індэкс змяшчае сапраўдныя URLs. Dispatcher і выканаўцы не запускаліся.
3. Існая #288 захоўвае свой кантракт і `agent:running`; #296 захоўвае крытэрыі і пазнакі, да яе зыходных залежнасцей дададзеныя #491/#492. #297 і #330 выкарыстоўваюцца як існыя задачы. Бачнасць новых Issues у адкрытай чарзе пацверджаная. Project-дошка не правераная: `gh project list` вярнуў `authentication token is missing required scopes [read:project]` і пад акаўнтам уладальніка; правы токена не мяняліся.
4. Спасылкі, тыпы, рэестр дакументаў, межы слаёў і дубляванне прайшлі. Поўны набор тэстаў на Windows застаецца чырвоным; вынік ніжэй. Змены толькі ў дакументах і гістарычных скрыптах `.txt`; прадукцыйны код не мяняўся.
