## Criteria → evidence

1. **route_id ↔ UI «Гід» identity; order does not change ids.** `schemas/route.schema.json` + `schemas/stop.schema.json`: `RouteStop.id` is author-assigned (`position` is the recommended order only, `09` §3). Test `criterion 1` reverses the fixture stops and asserts every stop keeps its own record and id. Catalog route entries (`schemas/catalog.schema.json`) key on `route_id`+`version`.
2. **origin/namespace isolation.** Content documents carry an optional `origin` (`official | imported`; absent = official for legacy files). Officialness is decided by registration in publisher-written artifacts (catalog, discovery index, feedback registry — all closed vocabularies, `additionalProperties: false`), not by a file field. Decision documented in `contracts/README.md` with citations to `21` §3.1 and G12.03.
3. **Per-file history, language, transcript, rights, access.** Required fields: `content_version`/`version` (place/route), locale allowlist `be/en/uk` with `pl`/`de` reserved (`localized-text.schema.json`, `voice.schema.json`), `transcript` required on every Story (`09` §3 invariant 1), `license`+`credit` required on Media, `tier`/`access_tier`/`access` enums. Test `criterion 3` proves each by removal.
4. **An import cannot claim official provenance.** `checkOfficialProfile` rejects `origin: "imported"` and any `imp.`-prefixed identifier; `checkImportedProfile` requires the `imp.<namespace>.<id>` namespace for owned ids (city_id excluded — shared taxonomy). Example: `contracts/examples/imported-route.json`; test `criterion 4` covers the masquerade case and feedback targets. The full import format stays with G12.01 (deferred); G02 keeps the compatible boundary per `16` §G12.
5. **DiscoveryIndex/refs, FeedbackTarget, time range, seasonal reasons, separate readiness per 21 §3.2; envelope/legacy per G01.06 (21 §3.3).** `schemas/discovery-index.schema.json` encodes the limits verbatim (64 offers, 32 collections, 50 members, 32/8 themes, 8 locales, 140/400/280 chars, editorial_order 0–9999, duration 1–1440, distance ≤ 100000, id charset ≤ 64, 512 KiB index). `reader.mjs` implements the named cross-record rules (`duplicate-ref`, `foreign-city`, `estimated_duration_range`, `nested-collection`, `duplicate-member-ref`, `missing-overlap-note`) and the catalog reader policies (v1 full, unknown-major keeps routes and drops discovery, legacy-v0 bare array, `discovery-index-oversized` before any fetch). `FeedbackTarget` schema per `21` §5.1. Tests consume the G01.06 conformance fixtures in `fixtures/discovery-contract/` — `index-valid.json` passes; every `index-invalid-*.json` fails on its named rule; both `catalog-legacy.json` and `catalog-legacy-v0.json` read successfully.

## Review round 1 — 2026-09-17 (PR #114, cursor CHANGES_REQUESTED)

All 4 HIGH and 4 MEDIUM findings fixed in `contracts/reader.mjs` / `contracts/contracts.test.mjs`; both LOW items addressed (compiled-pattern cache; pinned failure keywords for the previously bare assertions). `npm test` is now 127/127 (+5 guards for the fixed behaviors); demo outputs are byte-identical and `uvx showboat==0.6.1 verify` still passes; jscpd reports 0 clones.

1. **if/then `required` never enforced (HIGH).** Object keywords (`required`, `properties`, `additionalProperties`, `propertyNames`, `maxProperties`) now apply whenever the value IS an object, not only under an explicit `type: "object"` — `then: { required: [...] }` branches (e.g. `stop.schema.json`) are enforced. Revert guard: `criterion 3: stop tier requires its own story id` (a base/extended stop without its story id fails with `required` naming the field; a story id of the other tier does not satisfy it).
2. **`type: "number"` rejected integers (HIGH).** Draft-07 `number` includes integers; `typeMatches` accepts `integer` under `number`. Revert guard: `kernel: draft-07 number includes integers` (whole `lat: 54` passes, fractional unchanged).
3. **`index-invalid-limits.json` test was a false positive (HIGH).** The test now iterates all 14 `cases` and pins each case's failure keyword. Note recorded in the test: the ≤ 64-chars identifier bound is encoded inside the bounded pattern `^[a-z0-9._-]{1,64}$`, so both identifier cases fail as `pattern`, not as a separate `maxLength`.
4. **No stop tier regression test (HIGH).** Covered by the same `criterion 3` test as fix 1.
5. **`imp.` check too broad (MEDIUM).** `checkOfficialProfile` namespace-checks only owned identifier keys (same `OWNED_ID_KEYS` as the import profile); strings like `credit: "photo: imp.archive/…"` pass. Masquerade and feedback-target rejections unchanged (demo block 2 output identical).
6. **`format: "date-time"` not validated (MEDIUM).** RFC 3339 shape enforced when declared (`catalog.generated_at`); space-separated time fails with keyword `format`.
7. **`duplicate-offer-id` untested in contracts.test.mjs (MEDIUM).** Unit test against `checkIndexRules` added.
8. **Error objects without `path` (MEDIUM).** `fails()` defaults `path` to the document path; asserted in the tier test.
