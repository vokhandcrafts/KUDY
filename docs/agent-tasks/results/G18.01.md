## Вырашальная знаходка: базавая лінія не пустая

Брыф і issue чакалі нуль запісаў («surveyed 2026-09-22»), але знямак быў вузкі:
праверылі толькі дзве рэчы («па-за `core/` ніхто не імпартуе `core/`;
прадукцыйны `core/` без `node:*`») — абедзве сапраўдныя. Поўны машынны скан па
матрыцы знайшоў **6 перакрыжаваных імпартаў `web/` ↔ `tools/`**, з іх 2
прадукцыйныя (`web/lib/content/interim-catalog.ts` і `web/scripts/build-content.ts`
→ `tools/build-bundle`). Рашэнне — з самага issue: «fixing or refactoring
existing violations (baseline only)» ёсць у Out of scope, таму запісы прынятыя
ў базавую лінію ўсвядома, кожны з тлумачэннем у README (табліца «Запісы
базавай лініі»), і вынесеныя як знаходка ў PR — выпраўленні паходзяць асобнымі
задачамі па ўласных рашэннях.

   пясочніца → exit 0; цыкл з двух файлаў → nonzero з назвай `no-cycles`;

   запісу — падае. Тэст выклікае рэальны production-уваход
   (`tools/arch/arch-check.mjs`) праз spawn, не копію логікі.
3. **Базавая лінія датаваная з тлумачэннем кожнага запісу** — `tools/arch/baseline.json`
