   interactive element** — `components/ui-strings.test.tsx` asserts both

   `tokens.fontBigTextFactor = 1.25` (canon `font.big-text-factor`, guarded
   verbatim by `test/design-tokens.test.mjs` with the fractional-number
   comparison added); every user-facing Text renders through
   `components/scaled-text.tsx` with `maxFontSizeMultiplier` = the canon
   factor — OS big text grows the words to the a11y plate and never past it.
   Reduced motion: the dialog shell's `animationType="none"` is pinned by
   `components/modal-dialog.test.tsx` ("the dialog never animates…") —
   restoring an animated transition fails it.
3. **Transcripts for every story as the audio alternative** — the pinned

## Boundaries and honest notes

- The GPS banners read `locationService.status()` per render (any engine or
  panel state change re-renders and re-reads); the location service exposes
  no status subscription yet, so a stall with zero following events shows
  the banner on the next render, not instantly — the named-state contract
  holds, the push latency is the service's next step, not this row's.
- The extended story's hand-play renders only when the engine would accept
  it (the stop accessible and the tier available — the same rule
  `core/engine/state.ts` applies); the button never pretends to work on a
  locked tier.
- UI-locale *selection* stays out (L02/G14.04.d): every word has its EN
  pair, the display locale remains the composition root's first preference.
- What this unblocks: G11.01 (MVP acceptance, issue #296) lists G06.05 as a
  prerequisite — the issue is open in the backlog; no labels changed.
