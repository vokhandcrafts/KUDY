# #727 — Start gate і поўны package lock прылады

Задача: [#727](https://github.com/vokhandcrafts/KUDY/issues/727). Выканана 2026-10-11/12, сесія ZCode (GLM-5.3-Flash), галінка `zcode/727`, worktree Linux-хоста (CachyOS, AVD `kudy-test`, Android 16 / SDK 36, dev-client `by.kudy.app`, Metro :8081, сінтэтычны origin :8791).

## Што зменена

1. **`evaluateLayer` у кампазіцыі прылады.** `controllers/sessionPorts.ts` — новы білдэр `createEvaluateLayer({ bundlesStore })`: вердыкт чытае тыя самыя map-факты, што і паверхня прагулкі (`services/contentRepo/runMapFacts.ts`), таму прэв'ю ніяк не можа прапанаваць Start для пласта, які прагулка адмовіць. Ключ правераны `validateLayerKey` (бязбечныя сегменты — іменаваныя дыягностыкі, ніколі выклік файлавай сістэмы), `extended` адказвае `access-locked` — крыніцы грантаў на прыладзе няма да G20.21. Праводка: `controllers/deviceServices.ts` (`evaluateLayer: createEvaluateLayer({ bundlesStore })`).
2. **Поўны lock апублікаванага пласта.** `tools/build-bundle/build-bundle.mjs` — кожны апублікаваны пласт (base і extended) нясе ўласныя копіі карневых дакументаў бандла `route.json`/`places.json`/`voices.json` (байты кананічных карневых дакументаў; карань бандла застаецца недатыкнутым, 09 §3), а lock пласта іх пінуе. Канал загрузкі прылады фетчыць толькі lock-пінаваныя файлы — гэта адзіны шлях, якім чытальнікі рана атрымліваюць свае дакументы (крытэрый 3: «route/places/voices at the layer root», без ADR на змену чытальніка). Грамы leak-скана выключаюць гэтыя копіі: публічныя дакументы ў прыватным пашыраным пласце — не прыватны тэкст (інакш кожны extended-білд падае на `private-text-leak` супраць уласнага карня).

## Праверка крытэраў

1. **Start пасля завершанай загрузкі.** На AVD чысты dev-client (`pm clear`) праз production-UI: Explore → картка гіда → прэв'ю («Загрузіць») → загрузка завершана → кнопка — «Пачаць», `enabled=true` у дампе UI: [preview-start-enabled.xml](../../testing/evidence/2026-10-11-g727/preview-start-enabled.xml), [preview-start-enabled.png](../../testing/evidence/2026-10-11-g727/preview-start-enabled.png). Да загрузкі той самы вузёл быў `btn-download` [preview-before-download.xml](../../testing/evidence/2026-10-11-g727/preview-before-download.xml). Вывад чытае рэальны вердыкт `evaluate`: кампазіцыйны тэст сцвярджае `enabled`, а не толькі `action` — эксперымент адкату (ніжэй) дае дакладна сімптом прылады.
2. **Deep link без ручнога кладвання.** Пасля force-stop `kudy:///run/e2e-free-guide` на халодным дадатку — паверхня прагулкі з аднаўленнем сесіі (§9.1): банэр «Прагулка працягнута са захаванай сесіі», маркер «e2e-stop-2 — чакае» (назвы з route.json), рад дзеянняў, «Нічога не грае»: [run-deeplink.png](../../testing/evidence/2026-10-11-g727/run-deeplink.png). Свежы старт з прэв'ю даў жывы Active-Run: [run-active.png](../../testing/evidence/2026-10-11-g727/run-active.png). `run-map#route-json-missing` няма.
3. **Lock уключае ўсё, што чытае run.** Тэст упакоўшчыка `#727: every published layer carries and pins the package documents the run reads` правярае ўсе фікстурныя пласты (be/en/uk base + be/en extended): lock пінуе route/places/voices, байты супадаюць з карнямі; а publish-catalog перачытвае кожны lock-запіс супраць файлаў. Новы макет origin пацверджаны прагонам `npm run e2e:origin` (lock пласта: audio/*, places.json, previews.json, route.json, stops.json, voices.json).
4. **Указаўка на выпраўленне.** [G21.47-follow-up.md](G21.47-follow-up.md) — датаваная указаўка дададзеная да ручнога абходу.

## Эксперыменты адкату (implementation-rules 1)

- Без праводкі `evaluateLayer` кампазіцыйны тэст G20.20 падае з дакладна прыладным сімптомам: `{"action":"start","enabled":false,"reason":"preview#verify-unavailable"}` — гэта крытэрый Proof issue («reverting the fix reproduces preview#verify-unavailable»).
- Без блока карневых дакументаў тэст упакоўшчыка падае: `lock.json must pin route.json (issue #727 criterion 3)`.
- Абодва эксперыменты выкананы ў сесіі адпаведнымі аднаразовымі здымкамі правак; фіксы адноўленыя да прагону поўных гейтаў.

## Абмежаванні і самаправерка

- **Паралельны выканаўца на супольным эмулятары.** Падчас праверкі іншая актыўная сэсія (#718) таксама кіравала `emulator-5554` са сваім Metro (:8082, worktree ў /tmp) — яе перазапускі дадатку і разбітыя бандлы падмянялі мае сесіі (адсюль «Network request failed», скокі экранаў; `uiautomator dump` пачаў падаць з `RemoteException` на рэгістрацыі accessibility-сэрвісу). Прыладная фаза 2 (адкат origin да старога макета на жывой прыладзе) таму спынена; сімптом адкату крытэра 3 пакрыты тэстам упакоўшчыка, а сімптом `run-map#route-json-missing` на старым макеце задакументаваны ў першакрыніцы (G21.47-follow-up.md, знаходка 2).
- Здымкі Run зробленыя праз `screencap`: `uiautomator dump` на жывой мапе не дае дампа (continues-анімацыі) — тэкставыя факты актыўнага Run пазычаюцца з дампаў да тыка Start і з Showboat-тэстаў.
- `media.json`/`moments.json` у пласты не пінуюцца: іх чытаюць moment-тэйзеры (G03.04), не run; гэта за абсягам issue. Вэб-чытальнік карня бандла не зменены. Фізічныя прылады і iOS не правяраліся.
- Дыялаг Google Play Services «Location Accuracy» на эмулятары цыкліць незалежна ад дадатку — квирк асяроддзя, не прадуктовая паводзіны.
