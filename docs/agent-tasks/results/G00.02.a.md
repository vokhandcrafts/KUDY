# G00.02.a — Правераны offline-map прыклад

**Дата:** 2026-09-09  
**Статус:** `blocked-external`

## Вынік

Створаны абмежаваны zero-dependency эксперымент варыянта C: нязменны route-scoped пакет з лакальнымі map/style/sprite/glyph/marker-рэсурсамі праходзіць hash/size-праверку ў staging і толькі потым атамарна становіцца `active`. Лакальны дыягнастычны web-renderer паказвае подпісы, pan, zoom 14–16, тры сінтэтычныя візуальна розныя маркеры, бачную клікабельную ODbL-атрыбуцыю і чэсны стан па-за bbox.

Гэта **не complete native offline-map proof**: у checkout/асяроддзі няма MapLibre RN dependency, Android SDK/emulator/`adb`, Xcode/`xcrun`, фізічных iOS/Android-прылад або нават усталяванага browser executable. Забарона задачы на новы network access не дазваляе атрымаць іх або абнавіць праверку upstream-дакументацыі. Таму airplane-mode + restart на iOS і Android, натыўны MapLibre renderer і замеры на прыладзе — `not-run`; web/mock не выдаецца за OS-доказ.

## Зыходны стан і план

- Залежнасцей у G00.02 няма; папярэдняга `spikes/G00.02-offline-map/` і result G00.02 не было.

- Інвентарызацыя знайшла Node `v22.23.2`, npm `10.9.8`; не знайшла `uvx`, native device/build tools або browser executable.
- План выкананы толькі ў дазволеных межах: лакальны пакет і lifecycle-тэсты ў spike, гэты result; task-specific Showboat demo не створаны, бо патрабаваны runner недаступны offline.

## Самарэвю

Primary concern: contract conformance для ўсіх новых файлаў гэтай атамарнай задачы. `git diff --numstat` не паказвае untracked-файлы, таму scope дадаткова правераны праз `git status --short --untracked-files=all`; чужыя файлы не змяняліся. Сакрэтаў, токенаў, production data, сеткавай загрузкі, новых dependencies або кода з Tramio/TourForge няма. Runtime network URL адсутнічае; адзіны HTTPS URL — яўная клікабельная attribution-спасылка. `tsc` непрымяняльны (TypeScript няма), `lint` непрымяняльны (script не вызначаны); залежнасці дзеля review не ўсталёўваліся.

Verdict: needs rework before native merge — package-механіка праверана, але абавязковы рэальны iOS/Android proof заблакаваны асяроддзем.

## Нявыкананае і перадача

Наступны ўваход для працягу **той жа G00.02.a**, не G00.02.b: checkout з дазволеным native MapLibre RN dependency/cache, Android emulator або прыладай, iOS simulator/device на macOS, і дазволенай уласнай/ліцэнзаванай tile source. Паўтарыць адзін bbox/zoom з рэальнымі vector tiles, materialized style/sprites/glyphs, fresh-cache airplane restart на абедзвюх платформах, замеры download/disk/staging/time, failure matrix і свежую official support/cost verification. Толькі пасля фактычных green device checks статус можа стаць `complete`; гэты mock не пераносіць map package ў release і не прымае P01/P02.
