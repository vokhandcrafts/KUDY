# G20.36 — пераносныя праверкі Windows і Linux

Дата: 2026-10-18. Задача: [#816](https://github.com/vokhandcrafts/KUDY/issues/816).
База: `main` на `83bb113357b44c9b04ea1349da475702ceb02760`.
Вынік: рэалізацыя правераная; [PR #827](https://github.com/vokhandcrafts/KUDY/pull/827) чакае рэвью.

## Прычына і межы

На Windows з `core.autocrlf=true` Git ператвараў згенераваныя паведамленні ў CRLF, а генератар параўноўваў іх з LF. Часовыя копіі для праверкі адкату таксама мелі CRLF і не знаходзілі радкі для выдалення. Загрузка модуля прымала шлях дыска замест файлавай URL; паведамленні пра парушэнні вярталі сістэмныя раздзяляльнікі.

Нармалізацыя датычыцца толькі тэксту часовых мутацый і шляхоў у паведамленнях. Дакладныя параўнанні байтаў генератара, сапраўдныя шляхі, абмежаванне каранём дрэва, фікстуры з зафіксаванымі хэшамі і глабальны `core.autocrlf` не змяняліся. Файлы `.github/` не рэдагаваліся.

## Прыёмка

1. Свежы пачатковы прагон на Windows: 43 тэсты, 34 паспяховыя, 9 збояў. Збоі: `adapter-revert-guard` — 2; `windows-android-build-guard` — 1; `check-messages` — 1; `generate-messages` — 3; `attribution-guard` — 1; `exported-language` — 1.
2. Выкарыстаны `pathToFileURL`; назва часовай тэчкі змяшчае прабел, `#` і `%`, каб праверка патрабавала правільнага кадавання на абедзвюх сістэмах. Часовы тэкст перад выдаленнем радкоў прыводзіцца да LF; шляхі нармалізуюцца толькі ў выніках праверак атрыбуцыі і мовы.
3. `.gitattributes` захоўвае LF для выхадаў генератара. Новая праверка ў `tools/ci/eol-pins.test.mjs` перабірае `DOMAINS`, уключаючы `web/lib/i18n/zh.ts`. Асобная выгрузка выхадаў `DOMAINS` праз `git -c core.autocrlf=true checkout-index` у часовую тэчку выдала 17 файлаў, кожны дакладна роўны выніку генератара. Часовая тэчка выдаленая.
4. Фінальны прагон названых шасці набораў: Windows — 43 паспяховыя, 0 збояў; Linux — 43 паспяховыя, 0 збояў. Разам з наборам EOL: па 48 паспяховых на кожнай сістэме. Выдаленыя абароненыя радкі і пашкоджаныя згенераваныя даныя па-ранейшаму адхіляюцца. Праверкі небяспечных шляхоў і спасылак выкананыя асобна, вынікі ніжэй.
