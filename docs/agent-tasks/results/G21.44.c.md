# G21.44.c — вынік для robots.txt

Задача: [#683](https://github.com/vokhandcrafts/KUDY/issues/683). Крыніца рашэння: [G21.44 §6 М3](../../architecture/decisions/G21.44-content-protection.md).

## Крытэрыі

1. `web/app/robots.ts` задае `Disallow: /content/` для ўсіх робатаў і `Allow: /` для старонак. `web/app/robots.test.ts` фіксуе дакладнае правіла. У праверцы адкату выдаленне радка `disallow` выклікала `AssertionError`; пасля аднаўлення тэст прайшоў.
2. Статычны web build згенераваў `web/out/robots.txt` з `User-Agent: *`, `Allow: /` і `Disallow: /content/`. Маршруты гідаў, кропак, карты і каталога застаюцца адкрытымі для індэксацыі. Файлы sitemap, hreflang і `noindex` не змяняліся; мэтавыя праверкі sitemap і метаданых прайшлі.
3. `robots.txt` — рэкамендацыйны маркер палітыкі для добрасумленных пошукавых робатаў, а не тэхнічная брама. Ён не спыняе скрыпт, які ігнаруе правілы.

## Праверкі

- `node --test --experimental-strip-types web/app/robots.test.ts web/lib/content/sitemap.test.ts web/lib/content/cards.test.ts` — прайшло.
- `npm run build --prefix web` — прайшло; згенераваны `robots.txt` правераны непасрэдна.
- `npm run typecheck` і `npm test` — прайшлі. Першая спроба `npm test` спынілася на існым тэсте `web/node_modules` праз сімвалічную спасылку ў ізаляванай копіі; пасля замены яе сапраўдным каталогам паўторны прагон прайшоў без змены кода.
- `npm run arch:check` і `npx --yes jscpd@5.1.2 --config .jscpd.json --no-tips .` — прайшлі.
- [Showboat proof](../../demos/2026-10-08-robots-policy.md) — `uvx showboat==0.6.1 verify` прайшоў.
