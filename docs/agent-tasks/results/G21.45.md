# G21.45 — Амендамент цела ADR G21.20: сэмантыка стана аўдыёпіна па рэзалюцыі ўладара

Issue: [#678](https://github.com/vokhandcrafts/KUDY/issues/678) (эпік #532).
Выканана 2026-10-07, сесія zcode (GLM-5.3-Flash), галінка `zcode/678`,
Linux-хост, base = 4e6b729 (main).

Пазнака калізіі ідэнтыфікатара: дзве задачы тытулаваныя «G21.45» — #678
(гэтая, амендамент ADR) і #669 (пашырэнне кантэнт-лакаляў, zh). Файл
`results/G21.45.md` заняты гэтай задачай; #669 патрэбны суфіксаваны файл,
рэнумераванне — рашэнне ўладара (прэцэдэнт #562/#675; запіс у
`docs/human-actions.md`).

## Што зроблена

Цела ADR `docs/architecture/decisions/G21.20-language-identity.md`
выраўнана з рэзалюцыяй уладара (правкі 1–5, [#552](https://github.com/vokhandcrafts/KUDY/issues/552#issuecomment-6027980281),
2026-10-07) і рэалізаванай сэмантыкай ([#553](https://github.com/vokhandcrafts/KUDY/issues/553))
дзвюма адытыўнымі датаванымі зносамі; гістарычныя радкі не перапісаныя:

1. **§3.2, радок стану** (пасля булета «`RunSessionState` дадае
   `audioLocale: Locale | null`…»): зноска пра замену «`null` — аднамоўная
   сесія» на сэмантыку трох станаў піна (адсутны = аднамоўная, яўны `null` =
   text-only, лакаля = пінаваны аўдыёпласт), пра дэфолтны выбар аўдыё да
   Start паводле правілаў 1–2 уладара (правіла 1 — дакладнай цытатай) і пра
   кананічныя месцы (`core/engine/events.ts` `Start.audioLocale`, `09` §6.1,
   `11` §4.1).
2. **§3.4, радок аднаўлення** (пасля булета «**Аднаўленне:** `NULL` →
   аднамоўная сесія…»): зноска пра форму `NULL` (аднамоўная і text-only
   сесіі) і пра аднаўленне праз availability замацаванай версіі (аднамоўны
   пін уласнай мовы, калі версія шые такое аўдыё, інакш — text-only;
   байт-у-біт legacy паводзіны) + кананічныя месцы
   (`controllers/useRunController.ts` `restoredState`, `services/db/db.ts`
   міграцыя крок 5).

## Па крытэрах (з карты задачы)

1. **§3.2/§3.4 нясуць датаваны аменндамент з трохстанавай сэмантыкай, імёны
   #552/#553, бяз ціхага перапісвання гісторыі** — зносіны на радках 96 і
   131 побач з гістарычнымі; старыя фразы засталіся даслоўна (праверка
   ніжэй), абедзве зносіны назваюць #552 і #553 і маюць дату 2026-10-07.
2. **Код-цытаты «ADR G21.20 §3.2» супадаюць з амандаваным канонам** —
   трохстановая формула і аднаўленне праз availability адны і тыя ж у кодзе,
   `09`/`11` і зносінах (праверка ніжэй); змен кода няма — код цытуе
   §3.2 пасля аменндамента карэктна.
3. **Шапка статуса не зменена** — «прынята (2026-10-07)» на месцы (радок 7),
   аменндамент адытыўны, зацверджаны тэкст рашэння не перапісаны.

Дэфолтны выбар аўдыё — кампазіцыйны, да Start, адным правілам уладара: «Па змаўчанні аўдыё кропкі ідзе на мове тэксту гэтай кропкі; калі такога аўдыё няма — аўтаматычна падстаўляецца ангельскае»; выбранае аўдыё чакае завяршэння загрузкі перад пачаткам адлюстравання (правіла 2); рухавік толькі захоўвае гатовую рэзолюцыю. Кананічныя месцы: `core/engine/events.ts` (поле `Start.audioLocale`), `09` §6.1, `11` §4.1.
129:- **Аднаўленне:** `NULL` → аднамоўная сесія (аўдыё за тэкставай лакаляй) — усе існыя радкі чытаюцца карэктна; не-`NULL` → аўдыёпін аднаўляецца разам з прагрэсам (`heard`, `auto_fired`, `play_seq` — без змен). Пін, невалідны супраць availability замацаванай версіі (напрыклад, стары запіс пасля сервернага адкату), адкідваецца да text-only з дыягностыкай — сесія працягваецца, нічога не губляецца (па духу §3.7 [G01.03](G01.03-session-access.md): чэсны недаступны стан без падмены).
131:> **Амендамент 2026-10-07** — рэзалюцыя ўладара ў [#552](https://github.com/vokhandcrafts/KUDY/issues/552#issuecomment-6027980281), правкі 1–5, рэалізаваная ў [#553](https://github.com/vokhandcrafts/KUDY/issues/553): фраза гэтага радка «`NULL` → аднамоўная сесія (аўдыё за тэкставай лакаляй)» дапоўнена формай запісу і аднаўлення: `NULL` у радку — форма як аднамоўнай, так і text-only сесіі; аднаўленне чытае яго праз availability замацаванай версіі — як аднамоўны пін уласнай мовы радка, калі замацаваная версія шые такое аўдыё, інакш — text-only; абодва чытанні захоўваюць байт-у-біт legacy паводзіны.
