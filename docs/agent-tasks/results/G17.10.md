# G17.10 result — loose and lazy images in the snapshot

- Status: `complete`
- Task: issue #367, branch `zcode/367` (worktree `zcode-367` off `main` @ e29b489)
- What: `extractPage` (tools/collector/extract.mjs) now scans the segments
  between its `<p>`/`<figure>` blocks and collects images standing directly in
  the page's containers; every image source resolves through the lazy chain
  `data-src` → largest `srcset` candidate → `src`, so the decorative
  placeholder of a lazy image never becomes a second photo. The media pipeline
  (150 px threshold, slug filenames, `media` rows, markdown positions,
  crash-safe idempotency) is unchanged — media.mjs has no diff.

## Proven (criteria of issue #367)

1. **Out-of-paragraph images land in the snapshot (file + media row + text
   position)** — the pipeline test in media.test.mjs runs a file:// fixture
   with a hero image inside a page container between two paragraphs through
   the real `runCampaign` and asserts the saved file, the `media` row
   (position 1) and the markdown block between paragraph 0 and 1;
   extract.test.mjs additionally covers a loose image before the first
   paragraph (position 0) and after the last one (appended at the end of
   text.md).
2. **Lazy images by the same rules; the decorative `src` creates no
   duplicate** — with `data-src` beside a placeholder `src` exactly one step
   is enqueued for the real source (the placeholder file does not exist, so a
   step for it would fail the run — `run.failed` stays 0 and no `run_log`
   detail mentions the placeholder); a `srcset`-only image resolves to its
   largest candidate (width, else density, ties keep the earlier candidate,
   a candidate without a descriptor counts as 1x); `data-src` beats
   `srcset` when both are present; an empty `data-src` falls back to the
   visible `src`; a srcset with no candidates falls through to the same
   skip as a srcless tag.
3. **Threshold, naming and crash-safe idempotency unchanged** — the container
   logo (100×90) completes as a `done` skip note under the same
   `MIN_CONTENT_IMAGE_PX` rule (AC4: sub-threshold icons and banners are not
   taken, as before); a second `runCampaign` adds no `media` rows, no files
   and no text.md bytes (the G17.03 resume/idempotency suites stay green
   untouched).
4. **Invisible bodies never yield images** — `<img>` written inside
   `script`/`template` is code, not a page image; `<noscript>` is not scanned
   because it repeats the very lazy image it falls back for (the same address
   as `data-src`) and would double every lazy photo.
5. **Test: fixture with an out-of-paragraph and a lazy image; red on
   revert** — with extract.mjs reverted to `origin/main`, 6 of the 7 new
   tests fail (extract.test.mjs ×5, the media.test.mjs pipeline test ×1);
   the script/template/noscript-strip test stays green on the old code by
   construction (the old code never scanned gaps) and guards the strip rule
   of the new scan instead. File restored, suite green again.
