## Рашэнні перакладу (пратакол)

- **Рэгістр — du-форма**: сям'я de du (G21.10) / es tú (G21.11) / fr tu (G21.12) / cs ty (G21.13) — неафіцыйны тон арыгіналу; кнопкі ў загадным ладзе (стандарт шведскага UI). Пытанне візіту месца «Ці быў ты тут?» → «Var du här?» — шведская форма прыродна безродавая (прэцэдэнт інклюзіўнага cs «Byl(a) jsi tady?» больш не патрэбны).
- **walk → promenad** (en-род): адзіны тэрмін праходу; статус-радкі трымаюць en-форму без суфікса (pågående, pausad, avslutad).
- **stop → stopp** (ett-род): словаформа інварыянтная ў лічбах («Stopp: 1/2/5» — правільна без ICU); дзеянне спыніць тэйзер — асобнае **Stoppa** (прэцэдэнт cs Zastavení/Zastavit немешвання сэнсаў аднаго слова).
- **guide → guide** (запазычанае, як en): Guider →, Guide, Öppna guidebeskrivningen; «гісторыя» → **berättelse** (Huvudberättelse/Utökad berättelse), «падбор» → **förslag** (рэкамендацыі), «тэйзер» → **smakprov** (медыя-тэрмін разведзены з прэв'ю **förhandsvisning**, як es Avance/vista previa).
- **download → ladda ner**: адзін корань для абодвух сэнсаў (Ladda ner, Nedladdningen misslyckades, inte nedladdad) — en/uk-прэцэдэнт; **unavailable → otillgänglig** (глоссарый), радкі стану трымаюць звыклую шведскую канструкцыю «är inte tillgänglig», ад'ектыўнае otillgänglig/-t — у дэградацыйных/часовых радках (згода па родах: katalog en → otillgänglig, index ett → otillgängligt); **purchase → köp** (Köp, Köp krävs, Köpt · väntar på nedladdning, Tillgängligt efter köp).
- **restore → «fortsätter från en sparad session»**: канон без рэстаўрацыйнай метафары, тая самая пабудова be/en/uk/de/es/fr/cs; «аднаўленне пакета» → reparera (як es reparación).
- **Капіталізацыя і тыпографіка**: сказавы рэгістр, шведскія двукоссе ”…” у дыялогах, інтэрпаляцыя астатнім для timeCap (Upp till 45 min), чалавечыя формы 60/120/240 (Upp till en timme / Upp till två timmar / Halva dagen); тайлы → **kartplattor** (прыродны картаграфічны тэрмін, fr-прэцэдэнт перакладу dlaždice); retry/tryAgain → **Försök igen/Prova igen** — пара захавана, як en Retry/Try again.
- ID і брэнды не перакладаюцца: KUDY, App Store, Google Play, ODbL, issues, `langSwitchName` = «English» (уласная назва мовы прызначэння, uk-прэцэдэнт).

## Сэмантычны рэвью (асобны праход)

Другі поўны праход усіх 280 запісаў супраць пары be||en пасля зборкі і генерацыі, з фокусам крытэрыя 3:

- **Адмаўленні**: «нічого не грае» → «Inget spelas»; «не апублікавана» → «ej publicerad / är inte publicerad»; «аўдыё не запускаецца» → «Ljud spelas inte upp» (cardHint, markerHint); «не раней, чым дадзена згода» → «först efter att samtycket har getts»; «каардынаты не пакідаюць прыладу» → «Koordinaterna lämnar aldrig enheten»; «зусім не вызначаецца» → «fastställs … inte alls»; «ліст ці заяўку дасылаць не трэба» → «Brev eller ansökan behövs inte».
- **Адмена/незавершанасць пакупкі**: «Пакупка не скончылася» → «Köpet slutfördes inte»; «Не цяпер» → «Inte nu» (без канфліктнага «aldrig»); «Куплена · трэба загрузіць» → «Köpt · väntar på nedladdning» — факт + наступны крок.
- **Выдаленне/аднаўленне**: «Выдаліць ацэнку» → «Ta bort betyget»; «Выдаленне чакае сеткі» → «Borttagningen väntar på nätverk»; restore-канон — «Promenaden fortsätter från en sparad session», працяг — «Fortsätt», «адноўленая сесія» → «fortsatt session» (tierUnavailable).
- **Род і лік**: promenad en (aktuell/pausad/avslutad без суфікса), stopp ett (låst/tillgängligt; lyssnat — супін), guide en (betald), samling en (är inte tillgänglig) — трымаецца ва ўсіх прыметніках; «праслышана: N» → «lyssnat: N» (супін, безасабова, правільна для любой лічбы); status кропкі — ett-формы (tillgängligt/låst), статус прагулкі — en-формы (pågående/avslutad/pausad).
- **Змісціныя праўкі прагляду** (5 запісаў перапісаныя пасля рэвью): `native.nearby.indexDegraded` (index ett → «otillgängligt»), `native.run.status.available` («tillgängligt» для stopp), `native.run.status.played` («lyssnat» — супін), `native.web.ui.privacyIntro` (кампазіт «stadspromenader»), «rutttens» → «ruttens» (стоп-listHeading + schematicNote), offer.tryAgain «Prova igen» (пара з retry, як en) — перагенерыравана, гейт ізноў зелены.
- **Скан скажэнняў уласнага тэксту** (правіла 12 + прэцэдэнты карупцыі адлюстравання): смеш-скрыпт (з улікам лацінскіх акцэнтаў \u00C0-\u024F), падвоеныя словы, SHY, CJK і кірыліца ў шведскіх значэннях — скан даных і ўласных results/каментароў чысты; чатыры дэфекты аўтарскага чарнавіка (падвоенае слова ў нотцы, змешанае лацінскае ў беларускай нотцы, русізм у нотцы mySection — падзел замест «раздзел», скажаны тэрмін у нотцы appPageTitle) злаўленыя і выпраўленыя да зборкі.
