# G21.21 — Play explicitly selected audio beside translated guide text

Issue: #553 (эпік #532). Спэца:
`docs/specifications/technical-completion/2026-10-03-completion-and-locales.md`,
брыф `docs/agent-tasks/technical-completion/G21.21.md`. Выканана 2026-10-07,
сесія zcode (GLM-5.3-Flash), галінка `zcode/553`, Linux-хост, main = da72b0e
(шапка ADR G21.20 ў main — умова «толькі зацверджаныя межы G21.20»
выканана; ADR прыняты 2026-10-07 з правкамі 1–5 уладара).

## Што зроблена

Кантракт ADR G21.20 §3 увайшоў у рантайм: дзве незалежныя моўныя замацы
аднаго маршруту і версіі, пер-пластавая гатоўнасць і аўтарызацыя,
персістэнцыя піна, выбар аўдыё ў прапанове і кампазіцыйныя доказы.

1. **Рухавік** (`core/engine/state.ts`, `events.ts`, `reducer.ts`):
   `RunSessionState` дадаў `audioLocale: Locale | null` і
   `audioTierAvailable: Tier[]`; Start нясе рэзолюцыю піна (адсутны —
   аднамоўная сесія, `null` — толькі чытанне, лакаля — пін з праверанымі
   пластамі `audioTier`); прадыкат гуку `storyAudible` (тэкст даступны + пін
   зададзены + tier у `audioTierAvailable`); шлях `PlayStory` будзуецца ад
   аўдыёпіна; праверка 3 ідэнтычнасці `AccessReady` расшыраная да двух
   пінаў — падзея тэкставага пласта шыруе `tier_available` + `accessible_stop_ids`
   + акно геафенсаў, падзея аўдыёплата — толькі `audio_tier_available`,
   аднамоўны пін шыруе абодва люстэркі адной падзеяй; тэкстава-даступная
   гісторыя без гатовага аўдыёпласця дае прадстаўленне тэксту без аўдыёкаманды
   (`PlayStory` не выдаецца, `playing` null, нічога не залічваецца,
   аўтаматычная спроба згарае ў `auto_fired`); пін няменны да End.
2. **БД** (`services/db/schema.ts`, `types.ts`, `db.ts`): міграцыя крок 5 —
   `ALTER TABLE session ADD COLUMN audio_locale TEXT NULL` (адытыўна, адна
   транзакцыя; ADR называў «крок 2» на 2026-10-04 — на момант рэалізацыі
   наступны вольны нумар 5, крок той самы); пін пішацца ў транзакцыі Start
   і больш не мяняецца (checkpoint-ы яго не чапаюць); `NULL` — форма радка
   аднамоўнай і text-only сесіі.
3. **Кантролер** (`controllers/useRunController.ts`, `run/runOrchestrator.ts`):
   Start-брама выбранага аўдыёплата (правіла ўладара 2) — крос-лакальная
   лакаля праходзіць поўную ацэнку гатоўнасці; няглядовая адмова
   `audio-layer-not-ready` (загрузка — шлях чакання, ніякай маўклівай
   падмены), няладны пін — `audio-locale-invalid`; аднаўленне §3.4: `NULL`-радок
   чытаецца як аднамоўны пін уласнай мовы, калі замацаваная версія шые такое
   аўдыё, інакш — text-only; не-`NULL` пін выжывае толькі пры наяўнасці ў
   availability замацаванай версіі, чужы пін адкідваецца з дыягностыкай
   (`droppedAudioPin`), прагрэс працягваецца; `audioTierAvailable` сеецца
   толькі з верыфікаваных цяпер аўдыёпластаў.
4. **Выбар аўдыё ў прапанове** (правіла ўладара 1)
   (`controllers/catalog/previewController.ts`, `app/route/[id].tsx`):
   чыпы даступных аўдыёлакаляў (`availability.audio_locales` прапановы);
   дэфолт — мова тэксту гіда, пры яе адсутнасці — ангельская, без аўдыё
   наогул — picker не рэндэрыцца і прагулка ідзе text-only; выбраны
   крос-лакальны пласт далучаецца да кнопкі (няготовы трымае «Загрузіць»)
   і да загрузкі (адзін press актывіруе абодва пласты); выбар ідзе ў run
   паверхню праз route params (`?audio=`), run-сэрвіс правярае яго супраць
   фактаў замацаванай версіі (`resolveAudioPin`) і экспануе эфектыўны пін
   (`surface.audioLocale`).
5. **Кампазіцыйныя факты** (`controllers/sessionPorts.ts`): `audioLocalesOf`
   — лакалялі версіі, чые base-пласты шыюць аўдыё-каталог (ідыём
   `layerShipsAudio` валідатара пакета); recovery payload нясе availability
   версіі і пер-пластовыя чытанні запісанага аўдыёпіна.
6. **Нарматыўная сінхранізацыя** (шапка ADR дазваляе яе пасля прыняцця):
   `09` §6.1 — палі стану, Start/AccessReady, прадыкат гуку; `11` §4.1 —
   дзве замацы, дэфолт і чаканне загрузкі, няменнасць да Finish.

## Тлумачэнне кантрактнай тонкасці (запісана свядома)

ADR да правак меў дзве ўзаемасупярэчлівыя фразы пра сесію без піна
(§3.1.3 «text-only» супраць §3.2/§3.4 «null — аднамоўная сесія»). Правкі
ўладара 2026-10-07 (#552) яўна замяняюць «супярэчлівыя месцы пра паводзіны
без аўдыёпіна адным правілам» (дэфолтны выбар: мова тэксту, інакш ангельская).
Рэалізацыя: `null` у стане рухавіка — text-only сесія (§3.1.3, сцэнары 2 і
planned `text_only_no_audio`); аднамоўная сесія — пін на ўласнай тэкставай
лакаля (сцэнары 3, байт-у-біт як сёння); дэфолтнае правіла 1 — кампазіцыйны
выбар да Start (рухавік не бачыць availability); `NULL` радок аднаўляецца
праз праверку availability (§3.4), таму старыя радкі застаюцца аднамоўнымі,
а text-only гід без аўдыё чытаецца ціха. Усе 9 сцэнараў табліцы §4 маюць
паводзінныя тэсты.

## Па крытэрах (з карты задачы)

1. Дзве замацы + яўны выбар даступнага аўдыё; абодва прывязаныя да аднаго
   route/version/stop mapping (пін не мае ўласнай версіі — §3.1.1, чужы пін
   адкідваецца пры аднаўленні); text-only чытанне захавана — тэсты
   `core/engine/audio-pin.test.ts` (сцэнары 1–3, 8), кантролер-тэсты
   text-only/аднамоўнага старту.
2. Поўная гатоўнасць кожнага выбранага пласта да Start: тэкст — без змен
   (G01.03 §3.6), аўдыё — брама кантролера `audio-layer-not-ready` +
   пер-пластавая брама гуку ў рухавіку; несупадзенне/нягатоўнасць не граюць
   і не падмяняюцца — engine тэсты foreign_grant_denied + «аўдыё-грант не
   цячэ ў тэкст», кантролер-тэст адмовы.
3. fr-тэкст/en-аўдыё Start/Pause/restart/End на сінтэтычным ліцэнзійным
   кантэнце праз рэальны кампазіцыйны корань #491:
   `mixed_language_offline_restart` у
   `controllers/deviceServices.integration.test.ts` — чыпы → загрузка двух
   пластаваў (lock.json абодвух на дыску) → Start з пінам `en` → dwell гучыць
   `en/base/audio/story-1.m4a` для fr-гісторыі → Pause → перазапуск кампазіцыі
   над тым жа драйверам і дыскам: пін, прагрэс (`heard`), `play_seq`
   аднаўляюцца, нічога не гучыць сама → End. Android-вымярэнне: ідыём
   прынятых кампазіцыйных пруфаў (G20.20/G21.15) — сапраўдны SQLite і
   node:crypto над вытворчым пластом, фэйкі толькі на мяжы Expo/OS;
   інструментаванай Android-харнесы ў рэпо няма.
4. Гранты кожнай мовы/tier незалежныя; wrong-locale/wrong-version/expired/
   refunded і пашкоджанае аўдыё: `foreign_grant_denied`, «аўдыё-грант не цячэ
   ў тэкст», AudioFailed без заліку; fail-closed пры ненастроеных сторах —
   недаступны commerce-порт кампазіцыі (`purchase → {kind:'unavailable'}`,
   G20.20 тэст крок 8) і закрыты спіс адмаў гранта ў `services/download`
   (без зменаў); жывыя плацяжы — #492 і поўная прыёмка #296.
5. Аднамоўныя сесіі і text-only сумяшчальныя: `NULL`-радок чытаецца як
   аднамоўны пін (тэст «NULL row restores as monolingual», кампазіцыйны
   тэст G20.20 цяком праходзіць бяз піна); міграцыя адытыўная, адкат
   аднароўны (стары бінарнік працягвае чытаць/пісаць — тэст legacy INSERT);
   аднаўленне чужога піна не губіць прагрэс (`droppedAudioPin` тэст).
