## Decisions recorded

1. **The broken example is a full copy of the valid tree with 7 seeds**, not a separate mini-tree: authors diff the two dirs and see each mistake in context; the test pins the verdict to exactly the 7 documented rules (+1 warning), so the README table cannot silently rot.
2. **`missing-media` is seeded via a place `photo` reference, not a deleted audio file**: git does not track empty directories, so a removed `audio/` file would drop the whole directory from the committed tree and the layer would flip to text-only — the photo seed produces exactly one diagnostic in a committed tree.
3. **The audio placeholder is printable ASCII with no EOL bytes**, so Windows `core.autocrlf` cannot rewrite it on checkout; no `.gitattributes` pin is needed because nothing hashes the committed template bytes (the G02.03 packager hashes at build time from disk).
4. **Format-extension rules live in `content/README.md`** (the only place the backlog row names): closed schemas mean an unknown field is a diagnostic; growing the format is a contract change (schemas + 09/21 + validator) as a separate task, then a template update.
5. **`city_id` is `gdansk` everywhere** (route, index, offers, collection) — the only active MVP city per 21 §3.2; a foreign city would fail the reader's `foreign-city` rule once assembled.
