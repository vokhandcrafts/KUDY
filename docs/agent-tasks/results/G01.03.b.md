## What was modeled (per acceptance scenario)

1. **Same-version unlock without progress reset** — grant events matching the full identity extend `accessibleStopIds`/`tierAvailable` with no `Play`, no `commands`, `heard`/`autoFired` untouched (kept from G01.01.b, now behind the identity gate).
2. **Foreign grant ignored entirely** — `routeId`, `locale`, or `issuer` mismatch (including missing issuer) rejects the whole event before any field mutates; baselines compared with `structuredClone` deep-equal.
3. **Late event does not mutate the session** — a grant arriving after `End` changes nothing; a NEW session pinning that version receives the same grant (files stay under their package key, ADR §3.5). Stale-audio lateness stays covered by C10.
4. **Repeated identical AccessReady is a no-op** — second identical event deep-equals the first result, `commands: []`, no double credit.
5. **Version immutable to End** — nothing writes `version` after Start; foreign-version grant rejected across Pause/Resume (C35 preserved).
6. **`playSeq` write-through** — `sequence` renamed to the §3.1 name; incremented before the audio command; a callback naming an older `playSeq` cannot credit a newer play.
7. **Partial never allows Start (model granularity)** — `start()` throws `RangeError` for a package claiming zero verified layers, an unknown layer (`premium`), or `accessibleStopIds` referencing stops outside the pinned package. Actual disk/hash readiness stays outside the model (README boundary; G04/G05 own it).
8. **Minimal model inputs** — added `routeId`, `locale` (start options with documented fixture defaults), `tier` (informational §3.1 start record; does not grow with `tierAvailable`), `playSeq`. Nothing else.
