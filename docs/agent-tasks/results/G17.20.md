  run --campaign <source_path>`); пад ім — папярэджанне пра рыскі (CDN блакуюць
  Tor-выходы, серыйны стоп, таймаўт 30 с). Кампанія з `browser_user_data_dir`
  разам з «праз Tor» атрымлівае яўнае папярэджанне пра дэананімізацыю трафіку —
  профіль вызначаецца чытаннем файла кампаніі праз прадакшн-парсер
  `parseCampaign` (у сховішчы профіля няма; нячытальны/неправільны файл —
  без папярэджання, блок рэндзіцца далей). Для «напрамую» — мінімальны блок:
  толькі каманда запуску, без згадак Tor. Дыспетчар застаецца цалкам
  чытальным: выбар транспарту — у файле кампаніі, ніякі запыт не піше ў базу
  і ў файлы (гард пашыраны: хэш базы і байты файла кампаніі нязменныя пасля
  запытаў).

## Proven (criteria of issue #415)

1. **Транспарт па-чалавечы з базы, не з YAML** — `dispatcher.test.mjs` («the
   «Як парсіць» block shows the transport from the store row, never from the
   YAML»: у фіксуры YAML кажа `tor`, радок — `direct`, старонка паказвае
   «напрамую» і не згадвае Tor).
2. **Нумараваныя ручныя крокі з камандамі, каманда запуску гэтай кампаніі** —
   тэст «a tor campaign renders the numbered manual steps and the risks»:
   `<ol>` з трох крокаў (дэман, SOCKS5-праверка, `run --campaign` са шляхам
   менавіта гэтага файла кампаніі).
3. **Рызыкі ў інструкцыі** — той самы тэст: «CDN блакуюць Tor-выходы»,
   «таймаўт 30 с».
4. **Папярэджанне пра дэананімізацыю пры Tor + залогінены профіль** — тэст «a
   tor campaign with a login profile in its file warns about
   de-anonymization»; шлях профіля ў старонку не трапляе.
5. **Мінімальны блок для «напрамую»** — тэст 1: толькі каманда запуску,
   `doesNotMatch` на «праз Tor» і «tor-дэман».
6. **Гард read-only зялёны** — тэст «no request writes the database or the
   campaign files it reads»: хэш базы і байты файла кампаніі нязменныя пасля
   `/` і `/records`; існуючы гард «no request writes to the database or the
   snapshots tree» зялёны без зменаў.
7. **Новыя тэсты + старонка не падае на старой базе** — тэст «a store written
   before the transport column falls back to the direct default»: база без
   калоны транспарту (забаіёная міма `openStore`) адказвае «напрамую», 200.
