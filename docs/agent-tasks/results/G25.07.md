## Пакрыццё крытэраў карткі

1. **Сувязныя тэлефон/вэб макеты семі абласцей + інвентарызацыя да малюнка; навігацыя, свабодны парадак і яўны Start захаваныя** — інвентарызацыя: §1 [ліста](../../design/brand/outputs/G25.07/contact-sheet.html) (13 радкоў: экран → кантракт G06.06 → жывы код file → кадар → што адкладзена). Тэлефон: §2, 11 кадраў A–L (без I) — Explore, Guides + Discovery result, прэв'ю бясплатнае і платнае, дыялог §4.1, Run Peek/Half, паўза, End, форма ацэнкі, My KUDY. Вэб: §5 кадры W–Z — каталог, гід, мапа, /app (прыватнасць і правілы — у шапцы/атрыбуцыі і §7). Сувязнасць: пераходы-лэйблы з анкерамі паміж кадрамі + §6 карта пераходаў з табліцай NAV1–NAV11. Навігацыя: «Прагулка» (NAV7) з любой паверхні, Back — навігацыя, не каманда (NAV9), адзіны дыялог замены гіда (NAV8). Свабодны парадак кропак: Run малюе маркеры станаў без нумарнай чаргі + даслоўны `schematicNote` («Схема кропак маршруту — карта горада зʼявіцца пасля рашэння пра тайлы»). Яўны Start: адна галоўная кнопка «Загрузіць»→«Пачаць» (09 §6.5), аўтазапуску з адкрыцця экрана няма ніводнага.
2. **Станы-дэградацыі; адкрыццё экрана/пакупкі/прадмета не запускае нарацыю** — §3 ліста: **M** offline/збой праверкі пакета («Збой загрузкі.» + «Праверка недаступная.» + выключаная «Пачаць» з прычынай побач, 11 §7); **N** недаступная мова кантэнту (`previewTextUnavailable`, `languagesLine`, `textAudioLine`, L01 — тэкст без аўдыё не ўключае Start з абяцаннем аўдыё); **O** замкнёны доступ — прэв'ю кропкі (назва, месца, анонс, замок, NAV5) + вэб-«кропка пад замком»; **P** denied GPS — Побач (`nearby.noteDenied`, ручны агляд) і Run (`run.deniedGps`, autoplay off, ручны Play); **Q** вяртанне з перапынення — My KUDY `прыпыненая` + NAV7 + водгук `statePending`/`stateConflict` (F03). Правіла ненаракацыі: у анках C/D/O/U і ў табліцы §4 — прэв'ю, прапанова, замок і медальён маўчаць; крытычныя паведамленні тэкставыя, не mascot-only (канон §6).
3. **Дракон: з'яўленне, маўчанне, гукавы плейсхолдэр; калекцыя/дасягненні і Nearby-эксперыменты — бачны прататып-статус** — §4 ліста: біты **R** (0:00 Сустрэча, поза «спакойны», S1-плейсхолдэр з арыенцірам 0,5–0,8 с і заўвагай #694), **S** (0:55 правакацыя, поза «цікаўны», без сігналу; біт 1:08 — маўчанне 17 с), **U** (2:40 знаходка па жаданні: плейсхолдэр медальёна «Адлюстраванне» з пазнакай «асет G25.05/#704», S2 пасля рэплікі). Рэплікі даслоўна брыфа; сума маўчання 43+17+35 = 95 с правераная праграмна (proof). Правілы сцэны — табліца §4: нічога не гучыць сама, без адліку і музыкі, без ціску і віны. Статусы: калекцыя/дасягненні — `гіпотэза B08` + `прататып` (паверхні ў production няма, уладальнікі #704/#695/#696); «сакрэтныя кропкі па компасе» — `прататып` у кадры P; «скарбы дракона ў вэб» — `прататып` + `гіпотэза B10` у кадры W.
4. **Вэб-уваход зразумелы без усталёўкі; спасылкавая ўводзіна і працяг у дадатку; зыходнікі, здымкі, карта пераходаў, дакладныя рэвізіі** — §5: каталог → гід → /app — тры клікі; вэб-гід — «прэв'ю прагулкі, не другі прадукт» (без download/start/purchase); CalmOffer — адзін блок унізе без цаны; /app — тры выгады + крамы «Хутка» = поўны адказ, не тупік (16 G10.02). Глыбокая спасылка вэб→дадатак — `прапанова` (маршрутызацыя па-за абсягам). Рэвізіі: брыф `a11ea86`, канон `b6056ff`, слоўнік `cc2b581`, кампаненты `c9677f7` — у шапцы ліста і ў раздзеле «Крыніцы» вышэй. Зыходнікі: HTML/CSS (рэдагуемы), SVG-карта, PNG 1680×13744.

## Што не праверана (пазначана невыкананым)

- Жывая праверка на прыладзе і ў рэальным браўзеры не рабілася — макеты статычныя (прэцэдэнт G25.04/G25.06).
- Арыгінальных фота фігуркі няма — падабенства кіта дракона ў кадрах сцэны **не пацверджанае** (спадчына G25.03).
- Запіс свістулькі няма — S1/S2 паказаныя плейсхолдэрамі з арыенцірамі брыфа (абсяг #694).
- Рэвью носьбіта беларускай мовы подпісаў макетаў не праводзілася; радкі інтэрфейсу — даслоўна каталога, подпісы аўтарскія (Belarusian per documentation-language).
- Кантрасты малюнкаў не праганяліся праз кантраст-гард: макеты спажываюць пары канона без новых значэнняў (гліна/бурштын — толькі пазнакі прапановаў).

## Out of scope — вытрымана

Сайт не публікаваўся; кантракты навігацыі/аўдыё/пакупак не мяняліся; калекцыя не рэалізоўвалася; «install wall» не ўводзіўся. Production-код, токены, `contracts/`, рэестр рашэнняў, налады дыспетчара — без змен. Назвы меню B06 не ўведзеныя: у макетах толькі дзейныя радкі кода; B.3/B.4 пазначаныя як прапановы G25.02. Дрэйфы H1–H8/G25.06 перададзеныя пазнакамі, не фіксамі.
