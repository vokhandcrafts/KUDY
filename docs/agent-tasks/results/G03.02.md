# G03.02 result — the free guide scenario and the paid composition

**Status:** `complete`

The pilot Gdańsk guide is composed in the `authoring/` workspace on top of the
G03.01 pipeline: three stops (town hall, Artus Court, St Mary's Church), each
with a free `base` story and — where the paid layer adds one — an `extended`
story, plus `scenarios/gdansk-first-walk.json`, the machine-checked project of
the walk that links every stop to its own drafts, verified source refs and the
discovery season canon. All facts come from the same pre-1930s public-domain
source (EB1911 «Danzig», vol. VII, print pp. 824–825); eight new fragments
(`fr-005`–`fr-012`) and ten new claims (`cl-007`–`cl-016`) carry exact quotes
with print locators. The validator gained 11 named rules with one-violation
fixtures each (17 → 30 negative fixtures) and the acceptance suite grew
26 → 45 tests. Everything stays `pending` — the agent does not self-approve
(doc 07's iron rule); the author's так/не review is the recorded next step.

## What was built

  scenario project: theme, `path_minutes` (45, the 40–60 min orientation of
  `13` §1), three stops with `place_id`, `title`, `walk_minutes` (the author's

  - `gdansk-townhall-extended-be.json` (`value`: the free-city political
    layer) — 1308/1455 and the free-city rights (`cl-014`, `cl-015`, `cl-016`);
  - `gdansk-artushof-base-be.json` — the Artus Court on the Lange Markt,
    banquet hall turned exchange (`cl-008`, `cl-009`, `cl-013`);
  - `gdansk-artushof-extended-be.json` (`value`: the trade layer) — amber and

- `tools/validate/validate-authoring.mjs` — 11 new rules:
  `missing-orientation`, `base-purchase-hook`, `base-paid-dangle` (13 §3–§4;

## Decisions recorded

1. **The scenario is an authoring-local artifact, not a bundle format.** Like
   G03.01's `mark`/`kind` vocabulary, `scenarios/` lives in the workspace with
   its own rules; the export mapping to the bundle is the packager's business
   (G02/G03.05). Canon names are copied verbatim where they restate contracts:
   `tier` from the story schema, `season_recommendations: [{season, reason}]`
   and the season enum from the discovery-index schema (21 §3.2).
2. **Criterion 3 is staged, not self-approved.** The author's verification of
   sources and fiction boundaries is the review step the pipeline exists for:
   the agent stages quotes, locators, marked artistic blocks and regenerated
   reports, and leaves every claim unmarked and every draft `pending`. This is
   the same pattern PR #136 closed issue #123 with; the human step is recorded
   in `docs/human-actions.md`.
3. **The stop set is a draft proposal.** 13 §1 reserves theme, title and stop
   composition to the author; the scenario therefore carries a «праект» status
   in the README, and the author can reorder, add or drop stops before
   approval — the machine checks survive any such edit.
4. **No new source added.** All new facts fit the same EB1911 article
   (fragments with print locators ¶2–¶4). The medieval crane (Żuraw) is absent
   from this source — the same finding as G03.01 — so it is not a stop; adding
   it would need a new source and is the author's call.
5. **EN stays at St Mary's.** Translating the new stops is G03.04's material
   (EN texts); the existing EN draft only gained its missing orientation block
   so that criterion 1 holds for every story in the workspace.
6. **Every new rule ships with an isolating one-violation fixture** (rule 14),
   and every existing fixture was conformed to the new tier rules so the
   «exactly one violation» contract holds for all 30.
7. **The suite asserts the exact patterns, not a second copy.** (Review round
   2.) `BASE_PURCHASE`/`BASE_DANGLE` are exported from the checker and
   imported by the acceptance suite, which pins every documented alternative
   («набыць», «поўнай версіі», «платнае пашырэнне», «у пашырэнні») and the
   narrowness («пашырэнне гандлю» must not match); the season `reason` accepts
   the draft's plain string and the canon localized object, with the
   export-makes-object rule declared in the README (implementation-rules 1–2
   and 6).
