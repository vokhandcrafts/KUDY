# G21.44.b — вынік для публічнага release-manifest

Задача: [#682](https://github.com/vokhandcrafts/KUDY/issues/682). Крыніца рашэння: [G21.44 §3, §6 М2, §9](../../architecture/decisions/G21.44-content-protection.md). Канон: `docs/architecture/09_technical_architecture.md`, разд. 15, радок «Ізаляцыя платнага».

## Крытэрыі

1. `releases/<route_id>/<version>/release-manifest.json` на публічнай мэце змяшчае толькі запісы `public/`. Тэст `manifest-hygiene: the published release manifest lists only public entries` у `tools/publish-catalog/publish-catalog.test.mjs` чытае файл пасля `publishCatalog` і правярае адсутнасць прыватных шляхоў, іх `sha256` і сегмента `/extended/`.
2. Поўны маніфест застаецца файлам staging `release/release-manifest.json`. Тэст `manifest-hygiene: the staging manifest stays full and the public projection drops private entries` у `tools/build-bundle/build-bundle.test.mjs` фіксуе прыватны запіс на дыску зборкі. Байты гэтага файла на origin не капіююцца: публічны файл параўноўваецца з праекцыяй `publicReleaseManifest`.
3. Гвард `manifest-hygiene` чырвоны, калі прыватны запіс трапляе ў публічны маніфест. Эксперымент адкату ў сесіі дастаўкі: фільтр `public/` у `publicReleaseManifest` заменены на поўны спіс артэфактаў, затым `node --test --test-name-pattern 'manifest-hygiene: the published release manifest lists only public entries' tools/publish-catalog/publish-catalog.test.mjs`. Тэст упаў з `name: 'PublishError'`, `code: 'manifest-hygiene'`, `error: 'manifest-hygiene'`. Фільтр вернуты да каміта; на фінальным дрэве той самы тэст зялёны.
4. `version-immutable` застаецца адмовай пры зруху байтаў. Існуючыя тэсты AC2 зялёныя. Новы тэст `AC2: an already-published full release manifest refuses as version-immutable` падкладае ўжо апублікаваны поўны маніфест і чакае адмову без перазапісу; наступная версія публікуецца асобна, яе маніфест мае толькі `public/`, файл ранейшай версіі не змяняецца. Параўнанне ідзе па байтах публічнай праекцыі, не па поўным файле staging. Каталог і discovery index застаюцца на ранейшым шляху: тэст `parity: the published entry and pointer match deriveInterimCatalog` зялёны. Грант і падпісаныя URL не чапаліся.

## Па-за абсягам

Тэкст канона `09` не змяняўся. Логіка гранта, падпісаныя URL, вывад `catalog.json` і discovery index засталіся ранейшымі. Іншыя публічныя артэфакты, акрамя зместу release-manifest, не чапаліся.
