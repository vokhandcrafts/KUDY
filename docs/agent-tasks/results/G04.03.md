## What was decided

- **Станы карткі:** `ready` (з `tierAvailable` — пласты, поўнасць якіх пацверджаная дыскам і грантам), `incomplete` (структурныя файлы адсутныя/пашкоджаныя або спасылкі не рашацца — старт заблакаваны, крытэрый 1), `needs-recovery` (медыя адсутнае/пустае/нечытэльнае — спіс файлаў для прапановы аднаўлення, крытэрый 4), `access-locked` (платны пласт без гранта — шлях пакупкі, не рамонт). Прыярытэт: incomplete → needs-recovery → access-locked; пашкоджаны пакет нельга стартаваць незалежна ад грантаў, і прапанова рамонту не павінна хавацца за пакупкай.
- **Набор абавязковых файлаў:** `route.json`, `places.json`, `voices.json`, `<locale>/<tier>/stops.json` для патрэбных пластоў (`base` → `['base']`, `extended` → `['base','extended']`), медыя толькі для слаёў з тэчкай `audio`. Discovery-індэкс, коллекцыі і публічныя праекцыі — не ў старце: адсутны індэкс не ламае гід (крытэрый 5).
- **Уласцівасці лічбаў:** прычыны маюць стабільныя правілы (`missing-file`, `invalid-json`, `unreadable`, `identity-mismatch`, `type`, `unknown-ref:<id>`, `unsafe-path:<id>`) — слоўнік супадае з валідатарам там, дзе яны перакрываюцца; праверкі спасылак ідуць толькі па паспяхова разабраным крыніцах (хібныя `unknown-ref` на фоне зламанага файла — толькі шум, прэцэдэнт валідатара). `stops` у route.json абавязковы па схеме G02.01: адсутнасць і не-масіў — адна прычына `route.json#type`; `story_id` са скосамі (`/`, `\`, `..`) — `unsafe-path`, ніколі не шлях да чытання (абедзве паводзіны замацаваныя тэстамі, як і сеткавая чысціня ядра).
- **Гатоўнасць без сеткі (крытэрый 3):** ядро не імпартуе сеткавых API; гард у `wiring.test.ts` мацуе гэту ўласцівасць крыніцы.
- **Кампанентныя межы:** ContentRepo спажывае `grantedTiers` як факт (гэта `tier_available` з ADR) і ніколі не выдае `AccessReady` і не вырашае пакупкі; `accessible_stop_ids` і durable `tier_available` застаюцца ўласнасцю DB/engine — тут толькі вывад з фактаў дыска.
- **Размяшчэнне і typecheck:** `services/` побач з Expo-каркасам, але з асобным `services/tsconfig.json` (прэцэдэнт вэб-трэка: node патрабуе яўных `.ts`-спецыфікатараў, tsc патрабуе `allowImportingTsExtensions`, root Expo-канфіг без яго); root `tsc` выключае `services`, новы праход — у `npm run typecheck`. Абодва гарды правераныя адкатам (правіла 1).
