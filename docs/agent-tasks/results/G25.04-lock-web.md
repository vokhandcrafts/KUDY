# G25.04 — замок зачыненай кропкі ў вэбе

Issue: [#752](https://github.com/vokhandcrafts/KUDY/issues/752) · Эпік: [#346](https://github.com/vokhandcrafts/KUDY/issues/346) · Дата: 2026-10-14.

## Вынік

`LockedStopRow` рэндэрыць SVG з геаметрыяй [прынятага зыходніка](../../design/brand/outputs/G25.04/lock.svg) замест эмодзі. Памер гліфа — 16 × 16 px, колер успадкоўваецца праз `currentColor`. Назва для скрынрыдара паходзіць з `strings.lockedLabel`; спасылка, назва кропкі і яе публічны анонс засталіся ў радку.

Браўзерны сцэнар правярае атрыбуты SVG, прамавугольнік і шлях адносна зыходніка, а таксама беларускую і англійскую назвы, спасылкі і анонсы. Кампанентны render-тэст правярае `lockedLabel` для кожнай мовы з `uiLocales`. Часовае вяртанне эмодзі дало памылку `be: lock must be an inline SVG` і ненулявы код выхаду; пасля вяртання SVG тэст зноў прайшоў.
