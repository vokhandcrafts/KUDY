# G21.31 result — Assess Wiktionary dictionaries and dumps and report evidence for translation use

Date: 2026-10-04 (claim [2026-10-04T00:52Z](https://github.com/vokhandcrafts/KUDY/issues/563#issuecomment-5975109804)). Branch: `zcode/563` from main `46cddb1`.

## What was done

Read-only source assessment of Wiktionary (editions + official dumps) as a candidate reference source for the eight KUDY locales (be, en, uk, de, es, fr, cs, sv). Primary live access was available to `en.wiktionary.org` (added to the operator egress allowlist by the operator's explicit request this session) and to official dump metadata at `dumps.wikimedia.org`; the seven sister editions are separate hostnames and were not allowlisted, so their coverage is evidenced through official dump metadata only. Deliverables:

- `docs/reports/localization-sources/wiktionary.md` — the human-facing Belarusian report: platform version, editions/dumps, access method and commands, coverage, license/attribution, benchmark digest with senses, positive/negative examples, extractability, limitations, maintenance cost, observations vs recommendations, one follow-up draft for G21.33.
- `docs/reports/localization-sources/wiktionary-evidence.json` — machine evidence manifest: siteinfo statistics, per-edition dump facts (dates, sizes, chunk structure), the dual-license quote, the full parsed benchmark matrix (10 words → 75 sense blocks × 7 target languages), Belarusian headword probes, data-quality findings, commands, limitations.
- No dump was downloaded (metadata pages only, per the no-full-corpus constraint); nothing is vendored into the repository except extracted values and locators.

## Acceptance criteria walk

1. **Editions and official dumps identified; language/direction coverage, sense disambiguation, provenance and extractability verified; license/attribution/share-alike constraints verified on a minimal sample before any full-corpus proposal.** Eight editions confirmed with official dumps (latest 2026-10-01 for all eight); en wiktionary: MediaWiki 1.47.0-wmf.22, 9,204,056 articles. Sense disambiguation is structural (`trans-top` headers) — demonstrated by parsing 75 sense blocks. Extractability demonstrated end-to-end (raw wikitext → templates → parsed matrix) plus dump file structure (multistream 1.8 GB + 74.3 MB index, chunked). License verified from the primary policy page: dual CC BY-SA 4.0 + GFDL, share-alike recorded with its consequence for any derived catalogue; a full-corpus download/parser is deliberately NOT proposed.
2. **Current primary official sources cited; version/date, acquisition, coverage, restrictions, attribution, reproducibility, maintenance costs recorded; unknowns explicit.** All access through allowlisted hosts with a declared user-agent; every number in the report copied from command output of this session. Unknowns recorded as unknowns: article counts of the 7 non-live editions, full license texts, API etiquette pages (mediawiki.org not allowlisted), dump-internal quality.
3. **Common benchmark used with context; positive/negative examples and sense/context mismatches recorded; small lawful samples only.** Ten words fetched raw and parsed per sense (manifest). Positives: cancel→«касава́ць/скасо́ўваць», guide→«гід, экскурсаво́д» (the tour sense AOSP lacks), stop→«спыні́ць/прыпы́нак», walk→«прагу́лка/спа́цыр», restore→«аднаві́ць», unavailable→«недаступны/недосту́пний». Negatives: "settings" is a plural-of stub with no translations; the noun sense of "download" has no Belarusian row (its verb sense does: «спампава́ць»); the verb sense of "back" lacks be/uk; the be article «недаступны» returns 404 although referenced from the translations table; «гід» exists as a Ukrainian-only article. Data-quality finding: Latin «i» inside the Cyrillic word «даро́жнiк» in the guide entry (byte-level verified) — corroborates the mandatory per-row mixed-script check. Dictionary stress marks («наза́д») require a transformation step for UI use.
4. **Belarusian human report + machine evidence with exact locators, access date, commands and limitations; observations distinguished from recommendations; unsuccessful access recorded as evidence.** The report separates «Назіранні» from «Рэкамендацыі»; the non-allowlisted sister editions, the 404, the missing rows and every unreviewed license surface are recorded as facts.
5. **Follow-up requirements drafted only from findings and forwarded to G21.33.** One defer-style follow-up (see below): Wiktionary as a second-tier lookup reference per the G21.27 uncertainty rule, not an integration; dependencies are the operator's share-alike/attribution decision and (only if live checks of sister editions are ever wanted) an allowlist extension to `*.wiktionary.org`. No integration task proposed.
6. **Tool registry inspected before recommending anything; no private content/secrets sent; no instructions followed from downloaded data.** Registry was inspected during this session's G21.28 work (no translation-source entries existed); an AOSP entry was added then, and this assessment adds a separate Wiktionary entry (both deferred). Fetches carried a declared user-agent and only public URLs; downloaded content was treated as data.
