# G07.05 result — падказкі гідаў у адкрытым дадатку (R07)

## What was built

- `controllers/useNearbyController.ts` — the R07 hint controller (the module
  name 19 §2.2 reserves): the one grouped quiet card over the accepted
  ADR G07.04 contract. Candidate selection from public points + the catalog's
  guide offers (public previews only — a guide without a public offer or
  title is never a candidate), the dwell anchor (first qualifying fix in the
  zone, continuity through the freshness window), the durable limits
  (`guide_hint_state` session rows + `guide_hint_last` cooldown in both
  contexts) and the quiet gates (audio, manual block, FocusLoss, Paused,
  background — fail closed without the foreground fact). The presentation
  episode mints one `suggestion_id` and one local `guide_nearby_shown` event;
  guides joining the card later are recorded without a second event; the
  dismissal ends the episode. The controller never arms anything: fixes come
  through the location service's read-only raw-fix tap, the live run state
  through the root's resolver — no audio commands, no Start, no purchase.
- `services/location/service.ts` — `onRawFix(handler): () => void`, a
  read-only multicast tap of the fixes the ONE subscription already
  delivers (09 §20's hint context). The 19 §3.3 controller sink, the modes
  and the window stay untouched; observers issue no location commands.
- `services/db/db.ts` + `types.ts` — the R07 record API: `recordGuideHintShown`/
  `recordGuideHintDismissed` (transactional state row + `guide_hint_last`
  upsert; the unique session-scope index is the durable backstop — a repeat
  lands as the named `guide-hint-write-failed`; a dismissal of a never-shown
  guide is `guide-hint-dismiss-unknown-guide`), `listSessionGuideHints`,
  `listGuidesInHintCooldown` (the boundary is exclusive: at exactly the
  window edge the guide is free). Corrupt input answers
  `guide-hint-input-invalid`, never a crash.
- `services/config.ts` + `contracts/hints/guide-hints.d.mts` — the values
  loader: reads the canonical `guide-hints.values.v1.json` and validates it
  through the contract's own `checkGuideHintValues` before anyone sees a
  number; a damaged file fails `hint-values-invalid`/`hint-values-unreadable`.
  The controller consumes the typed shape (type-only import — erased from
  the RN bundle); no second place carries the numbers.
- `controllers/run/runSurfaceController.ts` — `carryGuideHints?: () => readonly
  string[]` dep: the fresh Start's transaction moves the foreground window's
  shown/dismissed ids into session scope (ADR G01.03 §3.9).
- `controllers/createServices.ts` — the `guideHints` port group (store,
  values, points, optional foreground/telemetry) and the ONE `hints` member,
  constructed only with the full seam set (location + audio + catalog + the
  group); the memoized `liveRunSource` wraps the runSurfaces resolver; the
  carry provider rides `run.create`.
- `components/GuideHintCard.tsx` — the quiet card (the G08.05 visual
  language) with the paid marker per row, plus `GuideHintMount`: the screens'
  one mount line reading the binding's store through `useSyncExternalStore`
  (the components zone keeps its no-runtime-controllers rule — the binding
  arrives as a prop, only its type is imported).
- `app/map.tsx`, `app/run/[id].tsx` — the mounts: the idle card on the Побач
  surface, the small quiet card under the Run panel (never a second row over
  the player); a tap opens the guide preview the usual way, the dismissal is
  the card's own quiet action.
- Tests: `controllers/useNearbyController.test.ts` (the criteria suite over
  the real stack — real LocationService/AudioService over fake OS ports, real
  sqlite, the canonical values file), `services/db/db.test.ts` (+4), `services/
  location/service.test.ts` (+2), `services/config.test.ts` (+3),
  `controllers/run/runSurfaceController.test.ts` (+1 carry), and the render
  suite `app/hint-card.test.tsx` over the real composition root (served
  catalog fixtures). The Showboat driver: `controllers/demo-g0705-hints.mjs`,
  demo `docs/demos/2026-10-01-g0705-guide-hints.md`.

## Evidence (per criterion)

1. **Толькі публічныя previews, без аўдыё/Start** — the controller test
   «AC1: hints propose only public guide previews — no audio, no Start, no
   second GPS owner»: the ready card carries the offer's title and the paid
   marker only; a point inside the radius without a public offer renders
   nothing; the audio port's command log stays empty through the whole flow.
   The render suite's tap test: the preview opens the usual way
   (`screen-Route preview`), `audioPort.commands` stays `[]`.
2. **Без паўтораў і другога GPS-ўладальніка** — the db tests (the unique
   session-scope index rejects a second show; the dismissal needs a shown
   row; the cooldown boundary is exclusive), the controller tests «AC2:
   durable limits…» (a dismissed guide never re-presents inside the cooldown;
   `foregroundCarry()` holds the window's shown∪dismissed ids), «AC2: session
   scope…» (one session row, one shown event, repeated fixes show nothing
   new) and «AC2: no second GPS owner…» (the port's non-window command log is
   byte-identical through hint flows, Paused included). The carry test
   «G07.05: the fresh Start carries…» proves the foreground ids move into
   session scope inside the Start transaction — shown and dismissed alike.
3. **Не паказваюцца пры Paused/FocusLoss/фоне** — the PROOF test «PROOF AC3:
   a hint in background, Paused, FocusLoss, manual block or audio renders
   nothing» (five scenarios over the real stack; the render PROOF «the card
   renders only from a ready hint state — background never renders it» proves
   the screen side). Revert experiment: removing the Paused gate turns PROOF
   AC3 red; removing the map mount turns all three render tests red (both
   restored, suites green).
4. **Актуальнасць пераправяраецца пасля аўдыё** — «AC4: after audio the card
   returns only on a new qualifying fix…» (the dwell survives a short quiet
   episode — presence continued; the post-audio show needs no second dwell)
   and «AC4: no fix newer than the quiet episode…» (the pre-audio fix is the
   old GPS callback — the decision waits; the stale variant re-anchors the
   dwell). The demo's scenarios 3–4 print the same two behaviors.
5. **Адкрыццё прэв'ю не губляе сесію Run** — «AC5: openPreview touches no run
   state — the session survives the tap»: the run state object is
   byte-identical after the tap, the opened event carries the session_id;
   structurally the controller has no path to any session mutator (19 §2.2),
   and the render tap test navigates through the existing preview path the
   NAV suites already cover.

## The honest boundaries

- **Крыніца публічных кропак** — порт: корань прымае `guideHints.points` як
  праекцыю публічных каардынат гідаў. Публічны каталог індэкса каардынат не
  публикуе (21 §3.2 — толькі аўтарская `distance_m`), таму вытворчая
  праекцыя (публічныя кропкі спампаваных пакетаў) — справа будучай праводкі
  прыладных адаптараў; фіча становіцца дасяжнай у дадатку, калі ўстануць
  location/audio/db адаптары (той самы правіла, што G07.03 запісаў для
  Moments). У білдзе дадатку сёння `hints` undefined — сумленная адсутнасць.
- **Падпіска idle** — яна належыць адкрытай паверхні (09 §20): кантролер
  нічога не ўзбройвае. Сёння падпіску ставіць паверхня Побач (G07.01);
  на паверхнях Горад/Гіды падказкі чакаюць падпіскі, пакуль іх уласная
  ўзбройванне не прыйдзе асобнай задачай.
- **Факт фону** — опцыянальны порт `foreground`; без яго кантролер нічога не
  паказвае (fail closed). Expo-адаптар AppState — будучая праводка.
- **Гейце «аперацыі пакупкі»** (11 §15 даслоўна) — у кантролера няма
  адпаведнага факту ў сэамах; практычна кампенсавана тым, што картка мантавана
  толькі на Побач і панэлі Run, дзе камерцыйнага дыялогу няма. Запісана
  каментаром у #287 як прадмет скразных праверак G07.06.

  > **Update 2026-10-01 (G07.06, issue #287):** гейт факту больш няма —
  > кантролер прымае опцыянальны порт `commercialDialogUp` і працуе ў
  > цішыні, пакуль ён праўдзіць; у кампазыцыйным корані пакуль не
  > праводзіцца (камерцыйнай карткі яшчэ няма). Скразныя праверкі —
  > `results/G07.06.md`.
- **Ліміт «адзін паказ за foreground-вокна»** трымацца на `guide_hint_last` +
  `foreground_cooldown_s` (3600 с): у схеме табліцы няма ідэнтычнасці вакна,
  таму радкі `scope='foreground'` — факты, не крыніца ліміту. Калі палявая
  каліброўка G11.02 зменшыць cooldown ніжэй даўжыні вакна, ліміт вакна
  патрабуе асобнага носьбіта — гэта змена кантракта, не кода.
- **Retention** запісаў `guide_hint_state`/`guide_hint_last` — G09.03; адпраўка
  падзей са згодай і payload-ліміты — G09.02 (тэлеметрычны порт тут толькі
  лакальны рэкордар).
