- Разбор крытэраў issue:
  1. «Кожны аўдыяфайл супадае з тэкстам і story_id (праверка інструментам)» — прывязка па імені ў сваёй locale × tier; `missing-transcript` (09 §3 інварыянт 1), `duration-mismatch` супраць declared `duration_s`, `duplicate-audio` па sha256, `audio-unreadable`; тэсты: «audio without a transcript fails invariant 1 only», «a declared duration the recording does not carry», «one recording bound to two stories», «garbage bytes yield audio-unreadable»
  2. «Гучнасць узгодненая паміж файламі (вымярэнне зафіксаванае)» — `loudness-target-deviation` (мэта −16 ±2 LU) і `loudness-spread` (паміж файламі ≤ 2 LU), значэнні ў `measurements`; тэсты: «loudness far from −16 LUFS fails the target band only», «two consistent-looking files 3 LU apart fail the spread only»
  3. «Memorial-тон правераны па крытэрах 13» — машынныя радкі чэк-ліста: тэмп-проксі `memorial-tempo-not-restrained` (09 §3: «сцішае тэмп начытвання», адносна медыяны standard-гісторый пакета), `ad-call-in-transcript` (13 §3), `ordering-reference-in-transcript` (13 §2), гайдлін 60–120 с як info (09 §3 інварыянт 7) + тры `human`-радкі аўтара (13 §5/§2/§3); тэсты: «a memorial story reading faster than standard is flagged», «a memorial story no faster than standard stays clean», «an ad call in the transcript is flagged», «narration requiring the previous file is flagged»
  4. «Перапынак/паўтор любой гісторыі не патрабуе пачынаць увесь гід» — адзін незалежны запіс на гісторыю (прывязка па story_id), супольны байт двух гісторый — памылка, наратыў без спасылак на папярэдні файл; тэсты: «the report carries one independent file per story, no shared bytes», «one recording bound to two stories fails criterion 4 only»
