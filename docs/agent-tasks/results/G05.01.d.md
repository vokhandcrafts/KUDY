# G05.01.d — Model parity and invariant properties

Issue #201 · branch `zcode/201` · 2026-09-25 · executor: Zcode session (GLM-5.3-Flash).

This slice proves the production reducer answers identically to the frozen
documentation model, so the model can be frozen as history. The deliverables
are tests and proof tooling — the engine itself (`reducer.ts`, `state.ts`,
`events.ts`, `commands.ts`, `fixtures.ts`) was **not edited**:

- `core/engine/model-parity.test.ts` — 76 tests wired into `npm test` through
  the `core/**/*.test.ts` glob: 67 ported model scenarios running against the
  production `step()` through one name adapter (`toEngine` — every event the
  model's scenarios use maps there, nothing else translates shapes), plus 9
  property tests for the 09 §6.1 invariants.
- `tools/engine-regressions/check-regressions.mjs` — production equivalents of
  the model's 21 reviewed regressions (`docs/run-model/check-regressions.mjs`
  labels kept verbatim): each mutation is applied to a byte-identical temporary
  copy of the engine, and the named guard test must turn red.
- `tools/engine-regressions/parity-count.mjs` — runs both suites end to end and
  compares the title sets, so the ported count is never a hand-typed number.
- npm scripts `engine:parity` and `engine:regressions` (standalone, like the
  model's own `check-regressions.mjs` — both run full suites end to end).
- Showboat demo `docs/demos/2026-09-25-g0501d-model-parity.md` (verified with
  `uvx showboat==0.6.1`).

## Acceptance criteria — walked from the card

1. ✅ **Scenario parity through one name adapter.** All 67 model scenarios run
   against the production `step()`; `tools/engine-regressions/parity-count.mjs`
   prints `PARITY COUNT: 67/67 — every model scenario is ported` after running
   both suites and asserting title-set equality (`the model registers 67
   scenarios; the ported suite registers 76 tests`). Titles are the model's
   own, so a parity failure names the model scenario it contradicts.
2. ✅ **Invariants 1–9 as seeded, deterministic property tests, plus the
   depth-4 equivalent.** Invariants 1, 2, 3, 7, 9 hold across three seeded
   walks (mulberry32, seeds 11/23/47, 400 steps each) and inside the bounded
   exploration over all 4-event sequences of a 16-event alphabet — 69 904
   transitions, asserted (`assert.equal(transitions, 69_904)`). Invariant 4:
   stale-callback probes (other session, earlier launch, foreign story) along
   two seeded walks. Invariant 5: the single 10-minute threshold (600 000 ms
   inclusive, 600 001 closes) for both launch owners and no threshold for a
   manual pause. Invariant 6: a seeded FocusLoss walk never credits or closes
   a launch. Invariant 8: unusable positions never auto-play, immediately or
   through the deferred queue play. Invariant 9: Pause/End clear the queue and
   release geofences; Ended never revives.
3. ✅ **21 production mutation equivalents, each caught by a named test.**
   Anchors live in `reducer.ts` (20) and `state.ts` (1 — the primary swap);
   each anchor must match exactly once, the unmutated copy must pass its guard
   first (harness precheck), and the guard's full title must appear in the TAP
   `not ok` lines. The run prints all 21 `CAUGHT:` lines and
   `21/21 reviewed regressions rejected by the named guards. Repository engine
   unchanged.`; after the run the anchors are re-checked against the
   repository files.
4. ✅ **run-model files not edited.** They are only read/executed
   (`parity-count.mjs` runs the model suite; mutations touch temporary copies
   only). Freeze follow-up for the document owner: with scenario parity 67/67,
   the invariants and the mutation equivalents proven against the production
   reducer, `docs/run-model/` can be marked as frozen history per its README
   («Як перанесці ў дадатак» is now carried out through the name adapter) —
   a separate task for the document owner.
5. ✅ **`npm run arch:check` green.** 225 modules cruised, the same 6 baseline
   violations as `main` (dated 2026-09-22), no new entries. Full local gates at
   final HEAD: `tsc --noEmit` (root, services, core) clean, `npm test` green
   (node:test 909/909 including this suite's 76, jest 9/9), jscpd 0 clones,
   `npx jscpd@5.1.2 --config .jscpd.json` over the whole tree.
