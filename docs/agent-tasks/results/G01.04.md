## What the contract decides

New decisions (written once, in `11` §16, per implementation-rules §2):

1. **Single/multiple guides and no empty rubrics** (§16.1): the «Гіды» rubric renders only when it holds at least one published guide; one guide = one card (also shown on Explore, still one entity); several guides = one list ordered by `editorial_order`, then `offer_id`, each guide once; every path to the same guide (rubric, discovery, collection card, R07 hint) opens the same preview. Rubrics split by content; paid/free is a card attribute, not a rubric axis.
2. **Back and return to Run** (§16.2): every preview remembers its source surface and Back returns there; the guides list returns to the city; the city is the navigation floor (one active city in MVP). Back is navigation only — it never ends the session, stops audio or submits the rating form. The city-mode button («Прагулка») returns to `Run` in the panel state it was left in; browsing never mutates the active/paused session; starting another guide keeps the confirm dialog of `11` §4.1.
3. **Empty city and zero results** (§16.3): a named honest state, no invented cards or test guides; «Побач» and My KUDY keep working; catalog/index failures follow `21` §3.3 (previous valid cache, else plain city page). Zero exact matches: honest message + explicit alternatives with differences, no silent city/language substitution.
4. **Locked preview** (§16.4): preview shows cover, promise, time, actual text/audio locales, free/paid, `free_stop_count`; a locked stop exposes only name, place, short teaser and the lock; full text, transcript and media never load into the free package nor leave via any navigation path; tapping a paid offer or a lock opens the preview only — no purchase, no Run, no private reveal.
5. **Place/collection/guide paths** (§16.5): one `DiscoveryRef` = one card type; a collection creates no Run, has no purchase and no audio (`audio_locales` always empty), members open their own cards and Back returns to the collection.
6. **Rating-return** (§16.7): the rating form is a temporary surface outside the navigation stack; Back/skip writes nothing and blocks nothing (F01); submit/error changes neither Run nor navigation; the End invite is at most once per session.

Existing rules are anchored, not restated: `21` §3.1/§3.2/§3.3 and §4 rule 7, `20` §3/§6/§7, D02/D04/D06/D07/F01, `11` §1/§2/§4.1/§7/§8/§15 (N7), `09` §3/§6.5, R01, `03` Journey 1–2.
