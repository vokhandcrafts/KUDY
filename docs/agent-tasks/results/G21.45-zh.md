## Што зроблена

Дзявяты код `zh` (спрошчанае пісьмо, CLDR-дэфолт `zh-Hans`) прыняты
кантэнтнымі кантрактамі адытыўна; рэліз-гейт G21.50 трымае яго схаваным у вэбе.
Уладар алоўліста — `contracts/schemas/localized-text.schema.json`; усё астатняе
— яго праекцыі. Улада пашырэння — рашэнне ўладара G21.42 (#623), ADR
`docs/architecture/decisions/G21.42-chinese-language.md` §4.

Пін лімітаў (`G21.45: the 8→9 move…`) фіксуе абодва кірункі: пашыраныя месцы —
роўна 9, рэзідуальныя люстры — роўна 8, у тым лісце схемных месцаў (discovery
мапы, place, voice), так і крыніц у tools/ і UI-рэестра
(`LOCALE_ALLOWLIST`, `validate-authoring`, `MEDIA_LOCALES`,
`COMPLETE_UI_LOCALES`). Любы цішы зрух у любым кірунку — чырвоны тэст.

## Скоўп-рашэнні па-за лістам «files allowed»

Два файлы па-за пяццю з крытэрыяў пашыраныя прымусова ўласнай машынерыяй рэпо
(fail-closed люстры, тыя самыя, што пашыраў прэцэдэнт G21.16/#550):

1. `contracts/schemas/catalog.schema.json` (`routes[].locales`) — генератар
   wire-types мае `assertSameSet` супраць уладара; без яго падае
   `npm run contracts:wire:check` з іменаванай дыягностыкай.
2. `supabase/functions/feedback/registry-import.ts` (`REGISTRY_LOCALES`) —
   guard-тэст `feedback-core.test.ts` сварыць канстанту са схемай
   feedback-target; пашыраны з датаваным каментаром.

## Рэзідуалы (свядома НЕ пашыраныя ў гэтай задачы)

Па лісце файлаў issue і табліцы ADR §4 гэтыя люстры алоўліста застаюцца на
васьмёрцы да будучых задач zh-кантэнту/UI (паўтор шляху G21.16 тады):
`propertyNames`-мапы ўнутры `discovery-index.schema.json` (title/reason/
collection title/`text400`), `place.schema.json` (`name_audio_refs`),
`voice.schema.json` (locale + апісанне), `tools/build-bundle/build-bundle.mjs`
(`LOCALE_ALLOWLIST`), `tools/validate/validate-authoring.mjs`,
`tools/validate/validate-package.mjs` (`MEDIA_LOCALES`),
`contracts/ui-locales.ts` (UI-рэестр — тэрыторыя #670). Стан усяго пераліку
пінуецца тэстам `G21.45: the 8→9 move…` — паслабіць або пашырыць без свядомага
каміта нельга. Пакуль zh-кантэнту не існуе, супярэчнасці ніякай: усе
практычныя шляхі zh-даных (аўтарства build-bundle, оўсы воблай) адхіляюцца
сваімі схемамі-люстрамі, не ствараючы ілжывага прыёмку.
