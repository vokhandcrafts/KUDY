## Acceptance criteria — walked from the card

1. ✅ **Single source of design values; draft tokens have an explicit
   replacement.** The canon fixes colors, fonts (with usage rights), spacing,
   card kinds, buttons, markers, panel, dragon and states in one document with
   one machine JSON block. Every `:root` custom property of the prototype CSS
   maps through the `supersession` map to a canon token; component literals
   (map, street, person, hint/moment cards, notice/error, badges, demo note)
   were promoted to tokens and switched to `var()`. The draft header comment is
   replaced by a pointer to the canon.
2. ✅ **Three card kinds; reachable 1–5 scale without public average.** The
   canon declares `cardKinds: base / hint / moment` (base card, R07 hint card,
   Moment card) and `ratingScale` 1–5 with `default: null` and
   `publicAverage: false` (20 §7, «У MVP няма публічнага рэйтынгу»); the guard
   asserts the scale tokens and the `aria-pressed` rendering path (backlog `16`
   line 154, `20`).
3. ✅ **Street readability: contrast and big text verified against the approved
   values (a11y plaque of `screens.md`).** The guard computes WCAG ratios for
   31 declared pairs: 4.5:1 for text (1.4.3), 3:1 for markers/person/focus/
   progress on map and street (1.4.11). Three marker colors
   (`locked #67707a`, `available #8a610e`, `pending #646c77`) and the hint-card
   background (`#f6faff`) are explicit overrides of draft values that failed
   (2.58:1 / 3.62:1 / 3.70:1 white-on-fill, 2.05–2.93:1 on street, 4.49:1
   muted-on-hint); big-text went 19px → 20px (1.25× ≥ the 1.2× plaque floor).
4. ✅ **Component states match G06.06 schemes; no new state names.** The guard
   parses the sources and asserts equality: markers vs ADR G01.01 §4.5
   (`locked/playing/played/available/pending`), state families vs
   `screens-and-transitions.md` (Пусты/Offline/Denied/Error), delivery and
   session states vs `screens.md` My KUDY (`draft → pending → sending → sent`,
   `conflict`, `action_required`; `active/paused/finished`), dragon states vs
   `06` §1 (спакойны/здзіўлены/кліча/святкуе) — verbatim, in order.
5. ✅ **Machine guard.** `test/design-tokens.test.mjs`, 11 tests: token
   completeness, component inventory, contrast pairs, big-text floor, rating
   scale, verbatim marker/state/dragon names, supersession coverage of every
   `:root` token (overrides need a recorded reason and draft value), CSS
   override resolution, and self-wiring into `npm test`. Revert-verified in
   this session: restoring draft `--kudy-locked #9aa2ab` → supersession test
   fails; removing the suite from the `npm test` file list → wiring test fails.
   Rule-8 pointers appended to `results/G06.06.md`, `results/G06.08.md`,
   `package/package-map.md`, `package/screens.md`.
6. ⏳ **Founder approval — human gate.** The PR review is the approval step;
   recorded in `docs/human-actions.md` for the merge moment.
