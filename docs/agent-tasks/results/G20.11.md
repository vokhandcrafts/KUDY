## Крытэрыі

### 1. Верхняя мяжа роўна 600 s; адсутная налада — дэфолт 600; нуль/адмоўнае/дробавае/неканечнае/malformed/> 600 не мінтуюць

- Канон: `docs/architecture/09_technical_architecture.md` разд. 2 «Межы даверу» — `private/` «толькі па падпісаным URL, TTL 10 хв»; спецыфікацыя N5 той самай лічбы. Тэст `isUnsafeUrlTtl: only finite positive integers up to the canonical 600 s pass (N5)` пінуе `GRANT_URL_TTL_SECONDS === 600`, прымае `1/599/600` і адхіляе `0, -0, -1, 0.5, 600.5, NaN, Infinity, -Infinity, 601, 1e9`.
- `600 accepted / 601 rejected` — тэст `the URL TTL cap: 600 mints exactly 600 s, 601 never reaches the signer`: раунд з 600 мінтуе `expires_at = now + 600 000 ms`; наступны раунд з 601 у тым жа гарнусе дае `503 entitlement_unavailable` без адзінага новага мінта і без званка да правайдара (гейт старэйшы за positive-кэш).
- Адсутная налада — існы тэст `a grant mirrors exactly the requested manifest members with short-lived URLs` (config бяз `urlTtlSeconds`) працягвае мінтаваць роўна `GRANT_URL_TTL_SECONDS` = 600.
- malformed string: у ядра лікі, у wiring `Number(raw)` дае `NaN` → `isUnsafeUrlTtl` → throw ( ніжэй, абмежаванне платформы).

### 2. Праверка на канфігурацыйнай і ядравай мяжах; прамы выклік ядра не абыйдзе мяжу; лічба мінтаў = 0 на няверным уваходзе

- Ядравая мяжа: гейт — першы крок `handleGrant`, да `parseGrantRequestBody`. Тэст `an out-of-policy URL TTL fails the whole round closed: the signer never mints and no layer is probed` праганяе `0, -1, 0.5, 601, NaN, Infinity` праз рэальнае ядро і сцвярджае: адказ роўна `{status: 503, code: 'entitlement_unavailable', retryAfterSeconds: 30}`, `h.minted` пусты, `h.manifestLoads` пусты, `h.providerCalls` пусты, радоў кэша нуль.
- Канфігурацыйная мяжа (wiring): `requireCanonicalUrlTtlEnv` кідае на любым значэнні па-за палітыкай — функцыю немагчыма запусціць з небяспечным TTL (fail-closed, той самы шлях, што і памылка канфігурацыі асяроддзя ў G08.02).

### 3. Верыфікацыя правоў і ізаляцыя sandbox/production захаваныя для вернага TTL; кэш-TTL — асобная палітыка

- Усе існыя тэсты гранта зелёныя без змен: `no_entitlement`/outage 403/503, `sandbox → production environment_mismatch`, positive-кэш, мяжы кэша.
- Тэст `the URL TTL and the entitlement-cache TTL are distinct policies`: `{urlTtlSeconds: 600, cacheTtlSeconds: 3600}` мінтуе роўна 600 s і піша кэш-радок з уласнымі ~3600 s.

### 4. Сінтэтычныя тэсты пад npm test; oversized-TTL тэст падае на revert; лівы Storage максімум не сцвярджаецца

- revert-эксперымент (implementation-rules 1): гейт у `handleGrant` часовы адключаны (`if (false && isUnsafeUrlTtl(...))`) — абодва паводзінавых тэсты падалі (`an out-of-policy URL TTL…`, `the URL TTL cap…`), гарда адноўлена, усё зелёнае.
- Назвы тэстаў у issue (`invalid_ttl_no_sign`, `oversized_ttl_no_sign`, `valid_ttl_environment_isolated`) — планавыя; у рэпазіторыі яны ўвайшлі як тры тэсты вышэй (same coverage, рэпавыя імёны).
- Дэма `docs/demos/2026-10-02-g2011-grant-url-ttl-cap.md` — `uvx showboat==0.6.1 verify` зелёны; змесціва дакументуе, што тэст сцвярджае наш сервер, не лівы Storage.
