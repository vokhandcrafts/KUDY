# G17.01.b — Сыравы здымак, пашпарт, дэдуп, рэзюм

Issue #156 · branch `zcode/156` · 2026-09-23 · executor: Zcode session (GLM-5.3-Flash).

`tools/collector/` запісвае здымкі: старонка, атрыманая з loader'а (па
змаўчанні — `file://`-сід з дыску; сеткі няма), кладзецца ў тэчку здымку
(`<слаг>-<хэшURL>/` з `snapshot.html`, `text.md`, `metadata.json`, пустай
`media/`) і рэгіструецца ў `raw_records` з поўным пашпартам і `content_hash`
— sha256 байтаў `text.md` як запісана. Дэдуп дзве ступені: па URL
(`UNIQUE(campaign_id, url)`) і па хэшы тэксту — другі запіс з тым самым
хэшам зьвязаны з арыгіналам праз `canonical_url` арыгінала. Рэзюм: здымок
пішацца адзін раз, паўторнае дастаўленне той жа старонкі нічога не
перапісвае. Новыя модулі: `extract.mjs` (чысты вызначаны выцяг),
`snapshot.mjs` (канвеер); праводка — у `runloop.mjs` (loader па змаўчанні) і
`collector.mjs` (`snapshots root` побач з базай, лічба `snapshots:` у
`status`). Схема і пашпарт не змяніліся — кантракт G17.01.a і табліца
спецыфікацыі даслоўныя. `docs/24_web_collection.md` не чапаўся.

## Acceptance criteria — walked from the card

1. ✅ **Фікстура → файлы здымку; кожны анкер у `text.md` трымае свой URL.**
   Тэст «AC1: the fixture page becomes a snapshot dir; every anchor keeps its
   target URL» (`tools/collector/snapshot.test.mjs`) праз рэальны
   `runCampaign` правярае наяўнасць `snapshot.html` / `text.md` /
   `metadata.json`, пустую тэчку `media/` (ніводнага радка ў `media`),
   `media_dir` = `<здымак>/media`, `source_type=web`, `rights=research_only`;
   парсіць анкеры з `text.md` і параўноўвае з чаканымі resolved-адрасамі
   (абсалютны, адносны `museum/main-hall.html` ад URL старонкі, другі
   абсалютны); табліца `links` люстра анкеры (`anchor_text`, `url`) з
   кантэкстным абзацам. CLI-e2e «run with a file:// seed writes the snapshot;
   status counts it» (`cli.test.mjs`) пацвярджае тую ж раскладку файлаў праз
   рэальны выклік CLI.
2. ✅ **Той самы фіксцур двойчы → адзін радок `raw_records`; той самы тэкст пад
   іншым URL → другі радок з роўным `content_hash`, зьвязаны з першым.** Тэст
   «AC2: the same fixture twice is one record; snapshots are never
   rewritten»: другі `runCampaign` не выконвае крокаў (`done 0`), байты
   здымку не змяніліся; паўторнае дастаўленне той жа старонкі праз
   `processFetchedPage` вяртае `outcome=duplicate-url` і той самы `recordId`.
   Тэст «AC2: same text under a different URL is a second row linked to the
   original»: дзве фікстуры з ідэнтычнымі абзацамі і рознымі загалоўкамі/URL
   праз рэальны ранаў → дакладна 2 радкі, роўны `content_hash`,
   `canonical_url` блізнюка = `canonical_url` арыгінала, арыгінал трымае свой
   уласны адрас. «A declared rel=canonical becomes the original record
   canonical_url» — абвешчаны кананічны адрас трапляе ў першапісаны запіс.
3. ✅ **Сапсаваная фікстура → дыягностыка ў run log, без крэшу.** Пусты дакумент
   (два уводы: `''` і прабельны), старонка без `<title>`, адсутны файл сіда —
   тры тэсты ў `snapshot.test.mjs`: крок ідзе ў `failed`, `run_log.error`
   пачынаецца з `seed <url>: ` і называе прычыну (`empty document`,
   `missing <title>`, `ENOENT`); ран працягваецца — тэст «AC3: a missing seed
   file fails its step; the other steps still run» (`done 1`, `failed 1`);
   файлаў здымку не з'яўляецца.
4. ✅ **`content_hash` па байтах як запісана; тэст перачытвае файл з дыску.**
   Тэст «AC4: content_hash is the sha256 of the stored text.md bytes re-read
   from disk» чытае `text.md` як Buffer (без кадавання) і параўноўвае
   `sha256Hex` з калонкай; дадатковая праверка байта CR — хэш фіксуе LF-байты
   без маўклівай канверсіі EOL.
5. ✅ **Наборы ў дэфолтным `npm test`; jscpd чысты.** Новыя сьюты ляжаць ва
   `tools/collector/` — пакрытыя існым глобам і guard'ам
   `tools/build-bundle/test-wiring.test.mjs` (новы файл трапляе ў праверку
   аўтаматычна). Лічбы канчатковага HEAD (свежыя): калектар — 36/36; поўны
   `npm test` — 540/540; `npm run arch:check` — OK, 146 модуляў, 6
   забазлайненых парушэнняў (без новых); `npx --yes jscpd@5.1.2 --config
   .jscpd.json --no-tips .` — 0 клонаў; `~/.local/bin/uvx showboat==0.6.1
   verify docs/demos/2026-09-23-g1701b-snapshot.md` — exit 0 двойчы.
