# G21.24 result — Define one canonical source record for every UI message

Date: 2026-10-04 (claim [2026-10-03T23:02Z](https://github.com/vokhandcrafts/KUDY/issues/557#issuecomment-5974398017)). Branch: `zcode/557` from main `0a0f5f2` (rebased onto #577 before push).

## What was done

The canonical UI-message source record now exists and is guarded:

- `contracts/ui-messages/source.json` — one record per UI message, `source_schema_version` 1, `source_locale` `be`. 234 records: 72 `native.chrome`, 50 `native.run`, 46 `web.ui`, 23 `native.place`, 18 `native.nearby`, 12 `native.preview`, 9 `native.offer`, 4 `native.guideHint`. Every record carries the stable dotted id (domain-prefixed, mirroring the parity guards' key shapes), the Belarusian source text/pattern verbatim from the catalog it came from, a hand-authored screen/action context (Belarusian, per the owner's specification example), typed parameters, the applicable constraints and the format.
- `contracts/schemas/ui-messages-source.schema.json` — the draft-07 schema (closed dictionaries, id/parameter/hash patterns, envelope locked to `be`/version 1).
- `contracts/ui-messages/ui-messages.mjs` + `.d.mts` — the checker (remote-config idiom: schema keywords mapped to named diagnostics, cross-record rules by hand, corrupt input answers with diagnostics never a throw) and the loader that fails closed on the shipped file.
- `contracts/ui-messages/ui-messages.test.mjs` (17 tests) and `test/ui-messages-inventory.test.mjs` (5 tests, `node:test`, wired by the existing `test/*.test.mjs` and `contracts/**/*.test.mjs` globs).
- `contracts/README.md` — one file-table row for the new module.

The inventory was extracted mechanically: a one-off temp script imported the seven importable be catalogs and dumped every leaf (215 plain strings verbatim, 11 phrase patterns recovered by calling the catalog functions with `${param}` sentinels, 4 composites flagged); the four `GuideHintCard.tsx` records (a JSX module node cannot import) were authored by hand from the file. No count was assumed — the mechanical walk is the inventory.

## Acceptance criteria walk

1. **Inventory actual messages, mapped to stable canonical ids; same wording in a different context not merged blindly.** The 234 ids are the mechanical walk of the actual catalogs; `test/ui-messages-inventory.test.mjs` asserts the walked key set equals the migratedFrom-anchored set per file, one record per anchor, plain words verbatim. Same-wording/different-meaning pairs (e.g. `native.chrome.loading` vs `native.run.loading` vs `native.nearby.loading`, `native.place.audioLabel` vs `native.nearby.audioLabel`, `native.run.status.locked` vs `native.chrome.locked`) kept separate ids with distinct contexts.
2. **Belarusian base; record defines id, source text/pattern, screen/action context, typed parameters, applicable constraints, format.** `source_locale` locked to `be` (schema enum + `source_locale_denied`). Parameters are typed `string | number | list` with `join` (list separator) and `fallback` (e.g. `finishedDay` falls back to `—`). The established safe format is recorded per record: `plain` / `template` (`${name}` placeholders), `composed: true` for the conditional audio segment (`textAudioLine`), `discreteForms` for the per-locale discrete forms that exist today (`timeCap` 60/120/240 хв; `preview.detail` kinds damaged/missing-files/stale). No plural machinery, no ICU — the catalog format is recorded as it is.
3. **Deterministic sourceHash; exact inputs and canonical serialization; hash/review fields excluded.** `sourceHash` = sha256 over the UTF-8 JSON of exactly {id, source, context, parameters (ordered, with types/join/fallback), constraints, format, composed, discreteForms}, object keys lexicographic, array order preserved; `sourceHash` and `migratedFrom` are excluded (provenance edits never invalidate a review). Tests assert every input dimension changes the hash and provenance edits do not.
4. **Translations and review metadata separate; base text authored once; existing exports preserved; be/en/uk output retained.** `source.json` holds no translations and no review fields — the per-locale sets and their review records belong to G21.25/G21.26. No existing catalog was touched; the five-controller and web parity suites still pass unchanged, so current be/en/uk output is intact (G21.25 owns generation from these records).
5. **Schema tests reject duplicate ids, missing context, unknown fields, invalid message/parameter syntax, executable payloads; a changed source/context/parameter yields a different fingerprint.** Named rules `duplicate_key_denied`, `context_required`, `unknown_field_denied`, `message_syntax_denied` (undeclared/malformed placeholder, template without parameters, declared parameter unreachable), `param_syntax_denied` (plain with parameters/discrete forms, join on non-list, fallback on non-string), `executable_payload_denied` (script tags, js urls, eval/import calls, event-handler attributes), `source_hash_mismatch_denied`, `source_locale_denied`, `source_schema_version_denied` — each with an isolating negative fixture, plus a corrupt-input case (null/primitives/foreign array elements answer with diagnostics).
