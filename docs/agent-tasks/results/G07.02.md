# G07.02 result — ручны Play Moment, пераходы да прэв'ю гіда, locked-ахова, кантэкст Побач

**Status: complete.** Branch `zcode/282` (closes issue #282 on merge).

## What was built

- `services/contentRepo/momentFacts.ts` — the moment teaser facts reader: one pass
  over the downloaded packages' root `moments.json` manifests (09 §3 Moment fields,
  schema-shaped validation; the manifest is optional per G03.04 — absent means no
  teasers, never an error). The teaser audio path resolves against the same
  package's base layer with the `<locale>/base/audio/<story_id>.m4a` idiom the
  engine's PlayStory path uses (a full store-relative path — the idle launch is
  cross-route); the teaser text comes from the same layer's `stops.json`. Damage
  answers with named diagnostics, never a throw (rule 14); identifiers from the
  manifest are safe-segment-checked on input (09 §7) — an unsafe one yields a null
  path with a diagnostic, never a path.
- `controllers/moment/momentPlayController.ts` — the single-player controller of the
  no-session context (ADR G01.02 §3.8: in Idle the manual launch lives here, no
  engine, no queue, no `auto_fired`). The play decision reads the physical fact
  (`audio.playbackState()`): a session-owned launch (a guide token, or a moment
  token it did not mint) is taken over only through the live session's engine —
  the `sessionMoment` port (the PreviewRunSessionPort idiom); without the port it
  is a named refusal (`moment#session-unroutable` / `moment#session-refused`) —
  never a second player, never a silent mirror divergence. A repeat of its own
  launch is stopped by command and re-launched with a fresh token (§3.2/§3.4).
  Focus facts are physical: FocusLoss is a live pause; FocusRegain ≤ 10 min offers
  Resume of the same token, > 10 min closes the launch (§3.7). No durable fields.
- `controllers/place/placeDetailController.ts` — the place detail: the place offer's
  facts from the already-validated catalog projection (`loadNearby` — one reader
  policy, no second `place_public` fetch path) plus the place's teasers filtered by
  `place_id`. Per-open binding (the Nearby surface's pattern); a failed catalog
  leaves the teasers rendering (library truth), a failed reader is the honest empty.
- `controllers/createServices.ts` — the root wiring: `ServicePorts.audio?` (the ONE
  AudioService instance the app owns — the `location?` precedent of G07.01; run
  sessions and the moment controller receive the same instance), `sessionMoment?`
  (the live session's moment entry), `nextMomentSeq?`, `now?`; the root's
  process-wide moment counter (ADR §3.2: ONE counter over every moment launch) is
  injected into every run session over the provider's ports
  (`{...runPorts, nextMomentSeq, currentMomentPlay}`); new members `place` (the
  per-open detail factory over the catalog service + the bundles-store reader) and
  `moment` (the singleton binding, only with the audio port).
- `services/audio/service.ts` — `onEvent` now holds a SET of listeners (the run
  orchestrator and the moment controller each add their own sink over the one
  physical player; each filters by its own token — §3.5). The rejection rule stays
  with the subscriber; the service's emit fans out.
- `controllers/run/runOrchestrator.ts` + `useRunController.ts` +
  `runSurfaceController.ts` — the optional `nextMomentSeq` (the shared counter) and
  `currentMomentPlay` (the idle launch facts Start reads): a walk started while a
  no-session Moment sounds inherits the occupied player through Start's
  `playingNow` (ADR §3.3/§3.8) instead of stopping it by autoplay command; without
  the injected ports the orchestrator keeps its own counter (backward compatible).

  (`bundles/<route>/<version>/moments.json` — 09 §7 layout, the release layout
  build-bundle writes); whether today's download activation (G04.02) actually

  belongs to the G04.02 zone, not here.
- **The session-routed teaser path**: a PlayMoment through the live session keeps
  the orchestrator's existing path resolution (empty path → the real adapter fails
  it with `story_play_failed`) — the documented G05.03.a boundary (the G05.05
  resolver concern), unchanged here.
- **The sessionMoment wiring in the app build**: the port is provider-shaped; in
  the app (no run adapters yet) the scenario is unreachable; the run-screen wiring
  belongs to #283/G06.04's context.
- **The place public projection** (`places/<id>/public.json`): no separate fetch
  was built — the criteria do not require it; the facts come from the validated
  index projection.
