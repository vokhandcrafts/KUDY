# G21.30 — Sync the run-model reference with the approved audio-pin contract

Issue: #675 (эпік #532). Выканана 2026-10-07, сесія zcode (GLM-5.3-Flash),
галінка `zcode/675`, Linux-хост, main = 85d2ea8 (мерж G21.21/#553 —
умова `Blocked-by: #553` выканана).

**Пазнака калізіі нумарацыі:** ідэнтыфікатар G21.30 ужо заняты закрытай
задачай #562 («Assess Unicode CLDR», вынікі ў
`docs/agent-tasks/results/G21.30.md`) — таму гэты файл носіць суфікс
`-run-model-sync`. Перанумераванне #675 — рашэнне ўладара; загаловак issue
выканаўца не правіць.

Задача — люстраны сінхранізм замарожанай выканальнай мадэлі
(`docs/run-model/`) з зацверджаным кантрактам ADR G21.20 §3 (у рэдакцыі
правак 1–5 уладара) у рэалізацыі #553; рантайм-код не мяняецца.

## Што зроблена

1. **Стан мадэлі нязменны акрамя піна** (`docs/run-model/run-model.mjs`):
   `start()` прымае неабавязковыя `audioLocale` + `audioTier`; рэзолюцыя
   піна `audioPinOf` — адсутны = аднамоўная сесія (`audioLocale` =
   тэкставая лакаля, `audioTierAvailable` люструе правераныя тэкставыя
   пласты), `null` = text-only (`audioTierAvailable` ніколі не жыве),
   радок = пін з праверанымі пластамі аўдыё; пін-лакаля валідуецца да
   інтэрпаляцыі шляху (не-пусты код, без сепаратараў/травэрсалу —
   `RangeError`), `audioTier` — толькі `base|extended`. Імёны палёў стана —
   даслоўна рухавікавыя `audioLocale` / `audioTierAvailable` (ADR
   §3.1–3.2; camelCase па абвешчанай мапе мадэлі).
2. **Прадыкат гуку** `storyAudible` — люстэрка `core/engine/state.ts`:
   пін зададзены і tier гісторыі ў `audioTierAvailable` (доступ тэксту —
   частка выклікальніка, як у рухавіку).
3. **playStory = playGuide**: аўтаматычная спроба згарае да праверкі
   прадыкату (§4.8.4); без гучнасці — text-only прадстаўленне: без
   `PlayStory`, без запуску, без росту `playSeq`, нічога не залічваецца,
   гучны запуск не перапыняецца (без `StopAudio`); каманда `PlayStory`
   нясе шлях ад піна
   `` `${s.audioLocale}/${tierOf(stop, storyId)}/audio/${storyId}.m4a` ``.
4. **AccessReady пер-пластава**: сцягі `textLayerEvent` /
   `audioLayerEvent` (трымаюцца даслоўна рухавікавыя імёны) рутуюць грант;
   тэкставая падзея шырыць `accessibleStopIds` + `tierAvailable`, аўдыё —
   толькі `audioTierAvailable`, аднамоўная сесія шырыць абодва люстэркі
   адной падзеяй; астатнія праверкі ідэнтычнасці і поўнае ігнараванне пры
   адмове — без змен.
5. **Тэсты** (`docs/run-model/run-model.test.mjs`): восем сцэнарыяў
   ADR §4 — fr тэкст / en аўдыё (піны + шлях + залік `heard`),
   пер-пластавае шырэнне грантаў, text-only (без аўдыёкаманд + спаленая
   спроба), аднамоўны фолбэк (байт-у-біт тэкставы пласт), §4.6 гісторыя
   без уласнага гатовага аўдыёпласта, §4.8 пін чужой версіі пасля скіду
   пры аднаўленні, §4.9 неўзаконены пласт, валідацыя піна ў `start()`.
6. **Адкат-гейты** (`docs/run-model/check-regressions.mjs`): абноўлены
   анкер «accept a grant for another locale» (сцяг тэкставага пласта —
   назіральнае месца ідэнтычнасці; стары радок цэласнай праверкі стаў
   залішнім), новыя анкеры «accept a grant for another audio locale»,
   «play audio without a ready audio layer», «burn the automatic attempt
   only for audible plays».
7. **Парытэт** (`core/engine/model-parity.test.ts`): шым аднамоўнага піна
   зняты — `begin()` праходзіць `audioLocale`/`audioTier` скрозь як ёсць,
   адсутны = уласны аднамоўны дэфолт рухавіка; дададзены `mixedFixture`;
   усе новыя сцэнарыі партыраваныя пад уласнымі назвамі (9: восем радкоў §4 + праверка піна §3.2). README
   (`docs/run-model/README.md`): кантракт піна ў апісанні `run-model.mjs`,
   радок G21.20 у табліцы пакрыцця, межы піна (аднаўленне §3.4 — праца
   кантролера да `start()`).

## Крытэрыі прыёмкі

1. **Стан нясе `audio_locale` + `audio_tier_available` з сэмантыкай
   рухавіка; імёны даслоўна з ADR** — ✔ `docs/run-model/run-model.mjs`
   (`audioPinOf`, вяртаемы стан); імёны `audioLocale`/`audioTierAvailable`
   супадаюць з `core/engine/state.ts:101,110`.
2. **Прадыкат гуку, пер-пластавае шырэнне `AccessReady`, text-only —
   кожнае правіла з падаючым пры адкате сцэнаром** — ✔ сцэнары §4.2/§4.6
   (прадыкат + text-only), §4.1 (шырэнне), §4.9 (неўзаконены пласт);
   анкеры check-regressions «play audio without a ready audio layer»,
   «accept a grant for another audio locale», «burn the automatic attempt
   only for audible plays».
3. **Змешаныя радкі ADR §4 існуюць як сцэнарыі мадэлі, README называем** —
   ✔ fr/en (§4.1 ×3), пін чужой версіі (§4.8), неўзаконены пласт (§4.9);
   радок G21.20 табліцы пакрыцця README пералічвае іх.
4. **Парытэтны сьют партыраваў сцэнарыі, шым зняты/звужаны; поўныя сюты
   зялёныя** — ✔ шым выдалены (каментар і жорсткія
   `audioLocale: locale`), `begin()` праходзіць пін скрозь;
   `core/engine/model-parity.test.ts` 86/86,
   `docs/run-model/run-model.test.mjs` 76/76.
5. **Правіла замарожаных файлаў 19 §7.2**: гэта асобная вырашаная задача
   змены мадэлі — ✔ у ране-зоне змяніліся толькі `run-model.mjs`,
   `run-model.test.mjs`, `check-regressions.mjs`, `README.md`; з
   рухавіковай зоны — толькі `model-parity.test.ts`, названы ў мэце
   задачы; 09/11 і рантайм не чапаліся.

## Рэвью-раўнд 1 (2026-10-07, пр-reviewer) — фіксы

- Medium `start-pin-tier-optional-divergence`: пін без `audioTier` цяпер
  трактуецца як `[]` (люстэрка да `event.audioTier ?? []`,
  `core/engine/reducer.ts`), не адмова — стан ADR §3.3 «пін зададзены,
  аўдыёпласт не гатовы» выразны без яўнага пустога масіву; тэст §3.2
  пашыраны прыёмкай гэтага стану (загаловак абноўлены аднакова на абодвух
  бакох парытэту).
- Low `stale-counts`: лічба партыраваных сцэнарыяў выпраўленая на 9
  (восем радкоў §4 + праверка піна §3.2).
