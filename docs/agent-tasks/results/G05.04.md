# G05.04 — Queue and automation blocking across the real boundaries

Issue #215 · branch `zcode/215` · 2026-09-25 · executor: Zcode session (GLM-5.3-Flash).

The one-cell queue and the three trigger outcomes are now proven where they
break in practice: fixes flow `services/location` → `onFix` →
`core/pipeline acceptFix` → only the accepted events enter `core/engine
step()`, and audio/focus callbacks flow `services/audio` → tagged events →
`step()`. The deliverable is one framework-free orchestrator —
`controllers/run/runOrchestrator.ts` (the RC column of 19 §4.3 minus React and
persistence, which G05.05 owns) — plus 9 scenario tests in
`controllers/run/runOrchestrator.test.ts` over the real modules with the
fakes of G05.02.b/G05.03.a and a manual clock. **No gap in `step()` was
found** — the engine's own re-checks (§4.8 conditions, the deferred 2 × radius
re-check, the token rejection rules) held under every cross-boundary scenario;
the cross-boundary defects the review round caught were orchestrator wiring
gaps, fixed here with their own tests (below), not engine changes.

Wiring decisions recorded once in the orchestrator header: rejected fixes
dispatch nothing (the engine's `last_fix` keeps the last accepted position);
the audio service's `paused`/`resumed` events are not dispatched (the
orchestrator issues them itself; a physical pause without focus loss is the
G05.03.b adapter's contract decision); pipeline candidates are the whole
selected set (AR-5 — the engine re-checks eligibility at the trigger); the
Start window seed filters by `accessibleStopIds` and the tier dimension
refines through the engine's own `SetGeofenceWindow` commands; the moment
token is minted here per ADR G01.02 §3.2; a tagged `finished` of a moment
launch dispatches the engine's `MomentFinished` (an `AudioFinished` would be
rejected by the owner rules and leave a dead launch in the mirror); a Start
after End resets the Ended mirror and the pipeline window (19 §4.3 — a fresh
session), while a Start over a live session stays the reducer's no-op; the
command switch ends in a `never` guard, so a new RunCommand variant is a
compile-visible decision.

## Acceptance criteria — walked from the card

1. ✅ **Newest other stop displaces the queue.** Through the real pipeline: A
   triggers and plays, B then C trigger (three-fix dwell each) — C replaces B
   in the one-cell queue, B lands in `auto_fired`; after A's tagged finish C
   plays (`heard [a]`, `playing c`, audio commands `play a`, `play c`).
   Repeats: the playing stop's re-trigger is ignored (one automatic attempt,
   queue untouched) and the queued stop's own re-trigger never evicts itself
   (leave-and-re-enter through the pipeline re-arms the dwell, the engine's
   `queued.stopId` guard keeps the cell).
2. ✅ **The deferred play re-checks the latest accepted fix, bounds inclusive,
   both sides.** Freshness: finishing exactly 30 000 ms after the last
   accepted fix plays; 30 001 ms sends the queued stop to `auto_fired`
   without a play. Distance: the person at ~38.9 m past the queued stop
   (inside 2 × radius = 40 m) plays; at ~41.1 m it does not. The haversine
   geometry of the pipeline feeds the engine's distances map; the exact
   equality points are the engine's unit territory (G05.01.b).
3. ✅ **A rejected fix never refreshes `last_fix`.** After queueing, the
   person walks away (accepted fixes move the fix ~41 m out), then a spike
   fix jumps back to the stop — rejected by the pipeline (spike-speed), so
   nothing is dispatched: the deferred play stays blocked (`auto_fired`, no
   play) and the session's `last_fix` still carries the last accepted
   position and its distances.
4. ✅ **No automatic start while suspended.** After `UserPausedAudio` (the
   orchestrator pauses the physical player too), after a call
   (`FocusLoss` through the audio service) and after an explicit Moment play,
   a trigger lands in `auto_fired` with manual access (`stopStatus` reports
   `available`, the queue stays empty, no play command). The explicit resume
   of invariant 7 re-arms: the next trigger queues again. The Moment window's
   exit is its own scenario: the tagged finish of the moment frees the mirror
   (`MomentFinished`), `GuideResume` re-arms automation, and the next GPS
   trigger plays instead of queueing behind a dead launch.
5. ✅ **Manual tap and GPS trigger share one path.** One test drives both into
   the same orchestrator entry and compares the audio command streams —
   identical (`play 1:be/base/audio/a.m4a`). The one deliberate engine
   difference is asserted, not hidden: the GPS trigger spends the stop's
   automatic attempt (`auto_fired [a]`), the manual tap never touches it
   (ADR G01.01 §4.8.4).
6. ✅ **A late audio callback from before a Pause/End/new Start is ignored end
   to end.** After a session Pause the stopped source's late finished reaches
   nobody (the service's key check — no heard, no queue, no command). A
   replay after the explicit resume mints a new key: the pre-pause callback
   credits nothing, the live one does. After End a new Start really opens a
   fresh session (`session_id walk-2`, `Active` — 19 §4.3) and the old tag
   stays dead.

## Review round

The first code review caught two real cross-boundary defects (both proven
executable on the branch) and two weak spots, all fixed in the same branch:

- **High** — the audio service's `finished` of a moment launch was mapped to
  `AudioFinished`, which the owner rules reject: the mirror kept the dead
  launch and the guide automation stayed silent after «Працягнуць гід» until
  a manual tap. Fixed: moment finishes dispatch `MomentFinished`; the new
  criterion-4 scenario fails on the reverted mapping.
- **Medium** — `start()` after `end()` was a silent no-op (the reducer accepts
  Start only from Idle). Fixed: from `Ended` the orchestrator resets the
  mirror and the pipeline window; criterion 6 now asserts the fresh
  `session_id` and `Active` phase, so the no-op cannot return unnoticed.
- **Medium** — the exhaustive command switch had no `never` guard, so a new
  `RunCommand` variant compiled silently. Fixed: the default throws.
- **Medium** — the criterion-6 phase assertion was vacuous (`!== 'Idle'` also
  holds for `Ended`). Fixed as above.
