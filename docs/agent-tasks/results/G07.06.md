## Evidence (per criterion)

1. **Два гіды ў адной зоне — адна агульная картка** — «G07.06 AC1: two guides
   in one zone — one grouped card, one shown episode»: dwell з адным гідам,
   кветар бліжэй — другі далучаецца да тае самай карткі (`suggestion_id`
   нязменны), падзея `guide_nearby_shown` адна, durable-радкі два, абодва ў
   `foregroundCarry()`.
2. **Адышоў падчас аўдыё — карткі няма** — «G07.06 AC2: walked away during
   audio…»: аўдыё гучыць (цішыня), чалавек сышоў з зоны, аўдыё скончылася —
   свежыя фіксы па-за зонай даюць `hidden (no-candidates)`, картка не
   вяртаецца (свежасць пераправяраецца, N4).
3. **dismiss → re-entry → restart не паўтарае** — «G07.06 AC3: dismiss,
   re-entry and a restart over the same database never re-present»: поўны
   re-entry dwell — `limited`; новы кантролер над той самай sqlite (эмуляцыя
   рэстарту працэсу) пасля поўнага dwell — зноў `limited`: durable
   shown/dismissed перажывае працэс.
4. **Start пераносіць ліміты ў сесію** — «G07.06 AC4: Start carries the window
   limits into the session — they outlive the cooldown there»: сапраўдны
   `startSession` з `carryGuideHints` пераносіць радкі (foreground пусты,
   session поўны); праз 2 гадзіны (cooldown 3600 с сышоў) адноўленая сесія
   ўсё яшчэ трыма перанесены гід цішым, а ніколі не паказаны гід паказваецца —
   носьбіт ліміту, апроч cooldown, ёсць session scope (ADR G01.03 §3.9).
   Палова Start→transfer ужо была доказаная тэстам паверхні (G07.05).
5. **stale fix / permission denied / locked не праходзяць** — «G07.06 AC5:
   stale fix, imprecise fix and denied permission never present» (стары фікс,
   дакладнасць 500 м > `accepted_accuracy_m`, denied без фіксаў — усе
   `hidden (stale-fix)`, ніводнай гатовай карткі) + «G07.06 AC5: the paid
   guide row carries the public preview facts only»: дакладная форма радка
   `{routeId, title, paid}` — замкнёны кантэнт не выдаецца (N7).
6. **Без згоды на аналітыку ліміты працуюць** — «G07.06 AC6: without the
   analytics recorder the hint limits still hold»: тэлеметрычны порт
   адсутнічае, dwell, dismiss і паўторны ўваход — усе durable-радкі на
   месцы, паўтор абмежаваны, адпраўленых падзей нуль (адпраўка са згодай —
   сэам G09.02).
7. **Камерцыйны дыялог (пункт 1 каментара PR #437)** — «G07.06: the commercial
   dialog keeps the card quiet»: пакуль дыялог адкрыты — `hidden (quiet)`;
   закрыццё + свежы фікс — гатова. Revert-эксперымент: умова гейту знятая —
   тэст чырвоны; вернуты — зялёны (праверана ў сесіі адпраўкі).
8. **Пункт 2 каментара (носьбіт «адзін паказ за вакно»)** — без кода: гэта
   запісаная мяжа кантракта ў results/G07.05.md, змяніць яе можа толькі
