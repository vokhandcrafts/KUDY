## What was decided

- **Кропка ўваходу.** `package.json.main = "expo-router/entry"`; `App.tsx` і `index.ts` выдаленыя (брыф дазваляе «removed»). `app.json` дадаткова атрымаў `scheme: "kudy"` (кантракт G10.02 — толькі ключ, без deep links).
- **Маршруты — дакладна Allowed outputs брыфа.** `demo/reviewer` з `09` §6.5 НЕ ствараўся: яго няма ні ў `19` §2.5, ні ў Allowed outputs. `app/index.tsx` таксама няма: каранаў — `+not-found` (крытэрый 1 патрабуе `+not-found` для невядомых шляхоў; каранины шлях = невядомы, без вынайджанага перанакіравання).
- **Тэксты заглушак — англійскія і мінімальныя** («Explore», «Guides», «Route preview», «Run», «My KUDY», «Map», «Not found», «No session yet — there is nothing to end.»): прадуктовыя радкі і лакалізацыя — G06.06–G06.08/G06.05. Кожны экран называе сябе і свае params (`id: …`), кожны мае тэст-ID (`screen-<імя>`).
- **Літаралы `gdansk`/`r1` у спасылках** — механізм плейсхолдар-навігацыі, патрабаваны крытэрыем 2 («pressing the placeholder links»); гэта не выдуманыя прадуктовыя карткі, кантэнту тут няма па-за межамі URL.
- **Back з Run** — `router.back()`: стэк push-аў Explore → Guides → прэв'ю → Run дае pop на прэв'ю; тэст мацуе, што тэкст «No session yet…» знікае, а прэв'ю застаецца (Back — навігацыя, нічога не завяршае).
- **`PlaceholderScreen`** — адзінае месца хрому заглушак (правіла дублікавання): без яго восем аднакавых экранаў — клоны для jscpd.
- **Гард jest-кроку** — `test/app-jest-wiring.test.mjs` у спісу `node --test` (не ўнутры jest-суіты), таму падае пры зносе `&& jest …` з `npm test` — эксперымент з даказам у Checks. Рэзідуал таго ж класа, што прынятыя гварды `tools/validate`/`tools/docs-ledger` (implementation-rules §7, corpus #105): знос самага гард-файла са спісу ён не бачыць.
- **`app-no-services`** — дакладна правіла краю `19` §4.2, без вынайджаных пашырэнняў (app↛core і г.д. — не ўводзілі); правілы `contracts/web/tools-zone-closed` пакінутыя як былі (іх спісы зон — асобнае ўсвядомае змяненне, па-за Allowed outputs).
- **Дэп-фіксы peer-канфліктаў:** npm без яўных пінаў выбіраў `react-test-renderer@19.3.0` і `react-dom@19.3.0` (peers `react@^19.3.0`) → ERESOLVE супраць react `19.1.0`; фікс — дакладныя піны `19.1.0` у devDependencies. Усе дзевяць пінаў і крыніцы дыяпазонаў — у ADR §6.
