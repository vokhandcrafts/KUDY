Issue: [#544](https://github.com/vokhandcrafts/KUDY/issues/544). Дата: 2026-10-05. Уваходны main: `8331f87` (G20.14 гарды адкату Expo-адаптараў). Брыф: `docs/agent-tasks/technical-completion/G21.10.md`; спецы: `docs/specifications/technical-completion/2026-10-03-completion-and-locales.md` + дадатак `2026-10-03-single-source-translations.md`.

## Што зроблена

- `contracts/ui-messages/translations/de.json` — аўтарскі нямецкі набор: 280 запісаў (усе домены source.json акрамя трох `native.chrome.languageSelfNames.*` — саманазвы жывуць у рэестры G21.09, не ў перакладзе), усе `review.outcome: approved` са запісам прычыны рэв'ю, `reviewedSourceHash` роўны бягучаму хэшу арыгіналу, файлавы `provenance.kind: "authored"`.
- Рэестр `contracts/ui-locales.ts`: `COMPLETE_UI_LOCALES` = be/en/uk/**de** — рэестр-запіс і каталог прыходзяць разам (канон G21.09); `CompleteUiLocaleCode` пашыраны.
- План генератара `tools/i18n/generate-messages.mjs` (DOMAINS): de далучаны да ўсіх дзевяці натыўных выхадаў, у тым лічбе `native.guideHint` (uk трымае дакументаваны be-фолбэк, у de словы ёсць), і новы вэб-выхад `web/lib/i18n/de.ts`.
- Перагенерыраваныя 12 выхадаў генератара (8 натыўных + 4 вэб-файлы) — нічога не правілася рукамі ў generated-файлах.
- Ручныя селектары (8 ланцугоў): `components/ui-strings.ts`, `components/GuideHintCard.tsx`, `controllers/catalog/previewController.ts`, `controllers/run/runMap.ts`, `controllers/place/placeDetailController.ts`, `controllers/nearby/nearbySurfaceController.ts`, `controllers/commerce/commerceController.ts`, `controllers/useFeedbackController.ts` — галінка de; невядомая мова як і раней падае на be.
- Вэб: `web/lib/i18n/index.ts` — імпарт de, `UiStringsLocale = UiLocale | 'uk' | 'de'`, `STRINGS` з de; жывыя маршруты не мяняюцца (публікацыя маршрутаў — G21.22, той жа прынцып release-unit, што uk).
- Глоссарый `contracts/ui-messages/glossary.json`: да сямі запісаў дададзеныя de-тэрміны (Guide, Station, laden, Rundgang, nicht verfügbar, Kauf, fortgesetzt) з G21.27-следамі `reviewed-terminology`, лакатары на рэальныя запісы de.json.
- Тэсты: новы `test/ui-messages-de-render.test.mjs` (5 тэстаў: селектары-маршруты, лікавыя/названыя формы, composed, вэб-парытэт ключоў); абноўленыя `test/ui-locale-registry.test.mjs` (поўны набор з de), `test/ui-messages-number-render.test.mjs` (de-рады timeCap), `test/ui-messages-inventory.test.mjs` (паддрэва selfNames — праекцыя рэестра, не запісы), `tools/i18n/generate-messages.test.mjs` (фіксчура перакладаў выводзіцца з плана), пробы «невядомая мова» перанесеныя з de на es у `components/ui-strings.test.tsx`, `controllers/nearby/nearbySurfaceController.test.ts`, `app/feedback.test.tsx`; новы пазітыўны тэст пікера з нямецкай у `app/my.test.tsx`.

## Acceptance evidence

1. **Повын набор паведамленняў з native name «Deutsch», усе тыпаваныя домены і подпісы.** Гейт `npm run messages:check` — «shipped locales complete, reviewed and fresh»: план рэндэрыць 280 паведамленняў для de, усе ёсць; `param_mismatch_denied`/`form_set_mismatch_denied` адсутнічаюць — подпісы параметраў і формы супадаюць з G21.09. Native name «Deutsch» — у табліцы рэестра (тэст рэестра, criterion 1), ніколі не ў перакладзе. Словы даступнасці/прыватнасці/аплаты/дазволаў перакладзеныя (privacy*-блок, offer*, feedback*, noteDenied).
2. **Формы ліку/даты/лічбаў, доўгія подпісы, empty-станы.** Лікавыя формы timeCap 60/120/240 + інтэрпаляцыя астатнім (`Bis zu einer Stunde` / `Bis zu 45 Min.`), названыя формы прэв'ю damaged/missing-files/stale, composed textAudioLine з пустым аўдыё дае «Text: de» без хваста; units Min./km/MB; empty-станы каталогаў («Guides mit Text in dieser Sprache gibt es noch nicht.»). ID і гандлёвыя назвы не перакладаюцца (App Store, Google Play, KUDY, langSwitchName «English» — uk-прэцэдэнт). Доступ/статусы не падмененыя (locked → Gesperrt, не планаўка даступнасці).
3. **Праверкі ключоў/параметраў + асобны сэмантычны рэвью.** Механіка — гейт і кантракт-лоўдар (праходзяць); сэмантычны рэвью — асобны другі праход усіх 280 запісаў па пары be||de з фокусам на адмаўленні («нічога не грае» → «Es spielt nichts», «не апублікавана» → «nicht veröffentlicht»), адмене/незавершанасці пакупкі («Пакупка не скончылася» → «Der Kauf wurde nicht abgeschlossen», «Не цяпер» → «Nicht jetzt»), выдаленні/аднаўленні («Bewertung löschen», «Löschen wartet auf Netz», restore-канон без рэстаўрацыйнай метафары: «Rundgang aus der gespeicherten Sitzung fortgesetzt»). Запіс рэв'ю — у кожным запісе (`review.note`), пратакол рашэнняў — у гэтым файле.
4. **Рэгістрацыя/пікер/публікацыя — не тут.** Пікер выводзіць чыпы з `COMPLETE_UI_LOCALES` (існуючы механізм, тэст пікера правераны), новай UI-працы выбару/захавання/фільтрацыі не правілася — гэта G21.15/G21.17; вэб-маршруты de не ствараліся — G21.22; пераклад кантэнту і голас — па-за задачай.
5. **Кананічныя даныя + provenance + генерацыя + гейты + адзін каміт усіх моў.** Аўтарства толькі ў de.json; generated-выхады праз `npm run messages:generate`; `npm run messages:check` зелёны (паўната+рэвью+свежасць); глоссарый прайшоў кантракт з de-лакатарамі; source.json НЕ змяняўся — таму перагляд be/en/uk (G21.19) не патрабуецца, іх запісы не кранутыя.
