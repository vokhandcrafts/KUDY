# G23.01 — Deterministic synthetic catalog origin for E2E

Issue: [#659](https://github.com/vokhandcrafts/KUDY/issues/659) (эпік #658). Брыф: `docs/agent-tasks/e2e/G23.01.md`.
Выканана 2026-10-07, сесія zcode (GLM-5.3-Flash), галінка `zcode/659`, worktree Linux-хоста.

## Што зроблена

Адна каманда `npm run e2e:origin` збірае сінтэтычны каталог фікстураў
`fixtures/e2e/*` выключна вытворчым шляхам публікацыі — `tools/build-bundle`
(упакоўшчык strict JSON-пакета) → `tools/publish-catalog` (праверка поўнага
staging-пакета, атомны ўклад, свап поінтара) — і серверытуе цель
публікацыі як каталог-поход. Скрыпт: `tools/e2e-origin/serve-e2e-origin.mjs`
(нулявыя новыя залежнасці; кантэйнмент і mime — праз імпарт
`resolveStaticFile` з `tools/serve-static.mjs`, не копія).

### Кантэнт фікстуры (кантрактныя формы скапіяваныя даслоўна з `fixtures/content/demo-route`, значэнні іншыя)

- Адзін горад `e2e-city`; discovery-рэвізіі `r-e2e-free-1` (free-пакет) і
  `r-e2e-paid-1` (paid-пакет); тэма `theme-e2e-walk`.
- Свабодны гід `e2e-free-guide` (`access: "free_base"`, 3 кропкі
  `e2e-stop-1..3`, усе `base`), пры кропцы 1 — Moment-тэйзэр
  `moment-e2e-place-1` (story `story-free-1`, `cooldown_min: 60`).
- Гід `e2e-paid-guide` (`access: "paid"`): свабодны пласт (кропка 1,
  `story-paid-1`) + зачыненае пашырэнне (кропка 2, `story-paid-2`,
  `preview {name, announce}`), `product_id_route/product_id_extension`.
- Калекцыя `e2e-day` (члены: месца `e2e-place-1` + свабодны гід) з
  `overlap_note` (гэта той самы досвед — месца ёсць першая кропка гіда).
- Тэксты be і en; кароткае сінтэтычнае аўдыё — 10 файлаў m4a па рэцэпце
  #537 (`sine` + `loudnorm I=-16`, AAC 44.1 kHz, 6 с, асобная вышыня тона
  на media-запіс). Тры файлы супадаюць байт-у-байт з дэмапакетам — таго
  жа сігналу; усе 10 media-запісаў у межах пакетаў маюць розныя sha256
  (правіла duplicate-audio, 13 §2). Ліцэнзія/крэдыт — CC0-запісы таго жа
  класа, што і ў дэмапакеце.
- Мадэль «адзін пакет = адна кіроўца»: два пакеты `fixtures/e2e/free-guide`
  і `fixtures/e2e/paid-guide` публікуюцца ў адзін target; `catalog.json`
  злівает абедзве кіроўцы (merge у publish-catalog), а discovery-поінтар —
  ад апошняй публікацыі (free-пакет: у яго discovery — гід, месца з
  маментам, калекцыя — маршрут Explore-сцэнараў G23.04–G23.06). Парадак
  публікацыі (paid → free) зафіксаваны ў кодзе з тлумачэннем.
- Два пакеты праходзяць `tools/validate/validate-package.mjs` (ok, 0
  памылак) і `tools/validate/verify-audio.mjs` (ok) — праверана ў гэтай
  сесіі; збора/публікацыя праходзяць толькі праз вытворчы шлях (крытэрый 2:
  ніякага вынайдзенага поля для тэстаў).

### Скрыпт і каманда

- `tools/e2e-origin/serve-e2e-origin.mjs`: флагі `--port` (дэфолт 8791),
  `--out` (дэфолт `tools/e2e-origin/build/`, gitignored), `--now`
  (дэфолт — запінены `2026-10-07T00:00:00.000Z`), `--fault "KIND:PATH[,…]"`
  (KIND ∈ 404/500/stall), `--stall-ms` (дэфолт 15000), `--no-serve`.
  Друкуе `EXPO_PUBLIC_CATALOG_ORIGIN=http://localhost:<порт>` і
  `http://10.0.2.2:<порт>` для эмулятара (дакументавана ў
  `docs/development_setup.md` §«E2E-каталог»).
- npm-скрыпт `e2e:origin` даданы; тэст-сюіта `tools/e2e-origin/*.test.mjs`
  падключаная глобам у `npm test` (wiring ахаваны існым гардам
  `tools/ci/test-discovery.test.mjs`, G20.28).
- Fault-спец парсіцца з іменаванымі дыягностыкамі
  (`fault-missing-kind`, `fault-unknown-kind`, `fault-unsafe-path`,
  `fault-conflict`, `fault-empty-entry`) — шкодны ўвод не падаўае працэс
  (implementation-rules 14); сегменты шляху ў спецы забароненыя тым жа
  ідыёмам, што і safeSegments у publish-catalog.

## Критэрыі прыёмкі — пацвярджэнні па парадку

1. **Фікстура** — горад, свабодны гід з 3 кропак і маментам, гід з
   свабодным пластом і зачыненым пашырэннем, калекцыя, be/en, сінтэтычнае
   аўдыё сігналу #537 — гл. раздзел вышэй; дрэва `fixtures/e2e/` у дыфе.
2. **Вытворчы шлях + схема** — збора/публікацыя толькі праз build-bundle →
   publish-catalog; каталёк інтэрпрэтуецца адзіным чытальнікам
   `contracts/reader.mjs` (тэст «the production publishing path lays a
   valid two-route catalog»); абодва пакеты валідныя праз
   validate-package.
3. **`npm run e2e:origin`** — бярэ канфігураваны порт (`--port`),
   серверытуе, друкуе значэнне `EXPO_PUBLIC_CATALOG_ORIGIN`; шлях з
   эмулятара праз `10.0.2.2` дакументаваны ў development_setup.md і
   друкуецца камандай. Жывы дым у гэтай сесіі: сервер на :8791 з
   `--fault "500:catalog.json"` — каталог адказаў 500, discovery індэкс і
   аўдыё-файл — 200 (51638 байтаў, дакладны m4a).
4. **Дэтэрмінізм** — два прагоны ў розныя тэчкі кладуць байт-ідэнтычныя
   дрэвы (тэст «two builds lay byte-identical files»; па-за тэстам
   пацверджана `diff -r` — чыста). Зарэгістраваныя дайджэсты пры фінальным
   HEAD (Linux-хост, Node 26.10.0):
   - `catalog.json`: `ced17c5d1db646e71c8111237ea4abacbac3d8513edee38e69385dbf3da740de`
   - `discovery/e2e-city/r-e2e-free-1/index.json`:
     `b68551f051b9d267791f8b11badec26ba725832cd14c80234a3a950a9fe0349f`
5. **Fault-пераключальнік** — тэст «the fault switch answers 404/500/stall
   for named files»: 404/500 без чытання дыска, stall трымае адказ
   `--stall-ms` і потым адказвае звычайна; здаровыя файлы адказваюць 200.
   Прызначэнне: сцэнарыі збояў G23.05 і G23.06.
6. **Гард схемы** — тэст «both fixture packages validate…» валідуе абодва
   пакеты вытворчым валідатарам; тэст «the guard fails when a fixture
   stops validating…» карумпуе копію route.json (access па-за enum) і
   правярае, што валідатар адхіляе — адкат фікстуры робіць сюіту чырвонай.
