## Рашэнні перакладу (пратакол)

- **walk → Recorrido** (не Paseo): актыўны праход па горадзе, мужчынскі род трывае ўсе статус-радкі (activo/finalizado/en pausa); nav-пункт і дыялогі аднаго кораня.
- **stop → Parada** для кропкі маршруту; дзеянне спыніць тэйзер — асобнае **Detener** (uk/de-прэцэдэнт немешвання сэнсаў аднаго слова).
- **guide → Guía** з жаночым родам кнігі-гіда (La guía no está publicada, La guía está incompleta).
- **тэйзер → Avance**, **прэв'ю → vista previa**: медыя-тэрміны разведзеныя, як у арыгінале.
- **гісторыя-раздзел → historial**, гісторыя-кантэнт → historia — адзін арыгінал «гісторыя» мае два словы праз кантэкст (радок стану vs тэкст гісторыі).
- **падбор → recomendaciones**, **ручны агляд → exploración manual** (не revisión — гэта прагляд, не рэцэнзія).
- **водгук/ацэнка → valoración**; шкала і ліміты захаваныя (Motivos, hasta tres).
- Рэгістр: неафіцыйны **tú** па ўсім тэксце (адпавядае ты-форме арыгіналу), кнопкі ў інфінітыве (стандарт іспанскага UI), фрагменты-пазнакі ў нізкім рэгістры трымаюць рэгістр арыгіналу.
- ID і брэнды не перакладаюцца: KUDY, App Store, Google Play, ODbL, issues, tiles; `langSwitchName` = «English» (уласная назва мовы прызначэння, uk-прэцэдэнт).

## Сэмантычны рэвью (асобны праход)

Другі поўны праход усіх 280 запісаў супраць пары be||en пасля зборкі і генерацыі, з фокусам крытэрыя 3:

- **Адмаўленні**: «нічога не грае» → «No suena nada»; «не апублікавана» → «no publicado / no está publicada»; «аўдыё не запускаецца» → «El audio no se reproduce» (cardHint, markerHint); «не раней, чым дадзена згода» → «no se envían … hasta que se da el consentimiento»; «не пакідаюць прыладу» → «no salen del dispositivo»; «зусім не вызначаецца» → «no se determina en absoluto»; «ліст ці заяўку дасылаць не трэба» → «No hace falta enviar carta ni solicitud».
- **Адмена/незавершанасць пакупкі**: «Пакупка не скончылася» → «La compra no se completó»; «Не цяпер» → «Ahora no» (без канфліктнага «nunca»); «Куплена · трэба загрузіць» → «Comprada · falta descargar» — факт + наступны крок.
- **Выдаленне/аднаўленне**: «Выдаліць ацэнку» → «Eliminar la valoración»; «Выдаленне чакае сеткі» → «La eliminación espera a la red»; restore-канон без рэстаўрацыйнай метафары: «Recorrido continuado desde la sesión guardada», працяг — «Continuar», «адноўленая сесія» → «sesión continuada» (tierUnavailable).
- **Род і лік**: guía/parada/colección/caché/sesión — жаночы род трымаецца ва ўсіх прыметніках (bloqueada, escuchada, descargada); recorrido/historial — мужчынскі; «праслышана: N» → «escuchadas: N» (жаночы род historias, як be).
- **Змісціныя праўкі прагляду** (5 запісаў перапісана пасля рэвью): `web.ui.privacyAnalytics` (чысце адмаўленне «не раней»), `web.ui.appBenefitOffline` (tus rutas a mano), `native.nearby.reviewHeader`/`noteDenied`/`noteHeldByWalk` (exploración manual замест revisión).

## Acceptance evidence

1. **Повын набор паведамленняў з native name «Español», усе тыпаваныя домены і подпісы.** Гейт `npm run messages:check` — «shipped locales complete, reviewed and fresh»: план рэндэрыць 280 паведамленняў для es, усе ёсць; `param_mismatch_denied`/`form_set_mismatch_denied` адсутнічаюць — подпісы параметраў і формы супадаюць з G21.09. Native name «Español» — у табліцы рэестра (`uiStrings('es').languageSelfNames.es`, тэст рэестра і рэндэр-сюта), ніколі не ў перакладзе. Словы даступнасці/прыватнасці/аплаты/дазволаў перакладзеныя (privacy*-блок, offer*, noteDenied, scaleHint).
2. **Формы ліку/даты/лічбаў, доўгія подпісы, empty-станы.** Лікавыя формы timeCap 60/120/240 + інтэрпаляцыя астатнім (`Hasta una hora` / `Hasta 45 min`), названыя формы прэв'ю damaged/missing-files/stale, composed textAudioLine з пустым аўдыё дае «Texto: de» без хваста; units min/km/MB; empty-станы каталогаў («Todavía no hay guías con texto en este idioma.»), уласных ацэнак, месцаў. Дыскрэтныя дні-радкі — pre-formatted радкі (тэст крыніцы на date-параметры), узор numeric-сюту праходзіць для es. ID і гандлёвыя назвы не перакладаюцца (App Store, Google Play, KUDY, langSwitchName «English» — uk-прэцэдэнт). Доступ/статусы не падмененыя (locked → Bloqueada, статус-радкі трымаюць факт, не планаўку даступнасці).
3. **Праверкі ключоў/параметраў + асобны сэмантычны рэвью.** Механіка — гейт і кантракт-лоўдар (праходзяць); сэмантычны рэвью — асобны другі праход усіх 280 запісаў, пратакол вышэй; запіс рэв'ю — у кожным запісе (`review.note`), рашэнні тэрмінаў — з глоссарый-следамі G21.27.
4. **Рэгістрацыя/пікер/публікацыя — не тут.** Пікер выводзіць чыпы з `COMPLETE_UI_LOCALES` (існуючы механізм; тэст пікера: пяты чып «Españол» і пераключэнне без рэстарту), новай UI-працы выбару/захавання/фільтрацыі не правілася — гэта G21.15/G21.17; вэб-маршруты es не ствараліся — G21.22; пераклад кантэнту і голас — па-за задачай.
5. **Кананічныя даныя + provenance + генерацыя + гейты + адзін каміт усіх моў.** Аўтарства толькі ў es.json; generated-выхады праз `npm run messages:generate`; `npm run messages:check` зелёны (паўната+рэвью+свежасць); глоссарый прайшоў кантракт з es-лакатарамі; source.json НЕ змяняўся — таму перагляд be/en/uk/de (G21.19) не патрабуецца, іх запісы не кранутыя, і ўсе выпушчаныя мовы ідуць у адным каміце.
