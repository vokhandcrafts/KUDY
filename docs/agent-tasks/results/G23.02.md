# G23.02 — Web E2E suite on the existing CDP driver

Issue: [#660](https://github.com/vokhandcrafts/KUDY/issues/660) (эпік #658).
Выканана 2026-10-07, сесія ZCode (GLM-5.3-Flash), галінка `zcode/660`,
worktree Linux-хоста.

## Што зроблена

Сюіты скразных джорні сайта `web/e2e/*.browser.test.ts` на ўласным CDP-драйверы
(`web/test-browser/cdp-browser.mjs`, G21.03) супраць рэальнай статычнай зборкі
`web/out` — дарожкі, правераныя рукамі ў retest 2026-10-06, цяпер committed-кейсы.
Адна каманда `npm run e2e:web` (`web/e2e/run-e2e.mjs`): сінтэтычны origin (G23.01)
→ `npm --prefix web run build` з `KUDY_CONTENT_ROOT` на таргет публікацыі → свап
экспартаванага люстэрка кантэнту → прагон сюіт. Нулявыя новыя залежнасці.

### Кампазіцыя

- `web/test-browser/e2e-harness.mjs` — сервер статыкі з Next-фолбэкамі
  (clean URL → `.html`, невядомы шлях → экспартаваны `404.html` са статусам 404;
  кантэйнмент праз агульны `resolveStaticFile` з `tools/serve-static.mjs`),
  CDP-старонка пад сеткавым лакдаўнам (крытэрый 7) і чытачы обслужанага дрэва
  публікацыі (указальнік discovery — праз обслужаны catalog.json, тая ж ланцуг,
  што ў data-слоі сайта).
- `web/e2e/free-journey.browser.test.ts` — крытэрый 1.
- `web/e2e/locale-routes.browser.test.ts` — крытэрыі 2–3.
- `web/e2e/keyboard-viewport.browser.test.ts` — крытэрыі 4–5.
- Крытэрый 6 — спасылка на існуючы `web/city-map.browser.test.ts` (G21.03,
  адмаўленне map-правайдэра: лакалізаванае паведамленне + працоўныя лінкі гідаў),
  без дублявання.
- Драйвер CDP атрымаў `extraArgs` (напрыклад, autoplay-палітыка для
  скрыптовага play()); рэжым map-доводаў не змяніўся.

### Змяненні ў e2e-origin (G23.01, абароненыя сваімі тэстамі)

- `--packages "paid-guide[,free-guide]"` — падзбор пакетаў фіксаванага
  парадку публікацыі; поўны горад з двух пакетаў застаецца дэфолтам
  (`parsePackageSet`, дыягностыкі `packages-*`, тэсты ў e2e-origin.test.mjs).
  Вэб-E2E публікуе адзін пакет `paid-guide`: вэб-рыдэр разрэшае кожны роўт
  каталога па АКТЫЎНАЙ discovery-рэвізіі (site.ts `resolvedCatalogRoute` →
  `guideOffer`), таму двухпакетны зліты catalog.json з указальнікам ад
  апошняй публікацыі ламае зборку сайта (`not-found at
  discovery:offers:e2e-paid-guide@1`) — аднапакетны горад трымае каталог і
  ўказальнік згуртаванымі без змянення вытворчага шляху. У paid-пакета
  base-кропка — свабодны аўдыё-стоп, extended-кропка — зачынены (крытэрый 1
  цэлым).
- Фікстура `fixtures/e2e/paid-guide/places/e2e-place-4/public.json` —
  публічная праекцыя base-месца paid-гіда: вэб-рыдэр чытае імёны кропак
  з праекцый (site.ts `siteStopRows`), а paid-пакет быў без праекцый
  (G23.01 пісаўся пад сцэнарыі мабільнага дадатку). Пакет праходзіць
  `validate-package` і `verify-audio` (ok, вынікі ніжэй).
- `web/e2e/run-e2e.mjs` чысціць `tools/e2e-origin/build/` перад зборкай:
  версіі публікацый іммутабельныя, і змена складу пакетаў у брудным
  таргеце падае з `version-immutable`.

### Сувязь сюіт з `npm test`

Сюіты ідуць у звычайным `npm test` праз існы глоб `web/**/*.test.ts`
(node-runner, дадаўкі не трэба). Без `web/out` кожны кейс бачна прапускаецца
з прычынай (implementation-rules 7) — runner `e2e:web` і ёсць шлях, які
зборку робіць; дакументавана ў `docs/development_setup.md` §«Вэб-E2E».

## Адказ на крытэрыі прыёмкі

1. **Каталог → гід → свабодны стоп → зачынены стоп** — `free-journey`:
   картка гіда ў каталогу; старонка гіда (загаловак/summary з served
   discovery-оферу, два рады кропак — свабодная + зачынены з🔒 і імем з
   served previews); свабодны стоп: транскрыпт + па адным аўдыятрэку на
   мову бандла з файлам (be, en — сорціроўка data-слоя), be-трэк рэальна
   грузіцца (`loadedmetadata`, duration > 0) і грае (`play()`, `!paused`);
   зачынены стоп: 0 audio-элементаў, анонс з previews, спакойны афер
   (aside, бачны, CTA → `/app`), загаловак гісторыі адсутнічае, канарэйка
   ўцечкі extended-транскрыпту не знаходзіцца ў bodyText, у served дрэве
   няма ніводнай тэчкі `extended` (прагулка па web/out/content/bundle).
2. **be ↔ en + усе мовы** — `locale-routes`: чыпы ўсіх 8 моў па self-name,
   бягучая пазначана `aria-current`, астатнія вядуць на той жа шлях праз
   localePath; en-чып → `/en/guides/e2e-paid-guide` з `lang="en"` і en-загалоўкам
   з served оферу; кожная мова адкрывае свой корань з дакументнай `lang`;
   be/en паказваюць картку, астатнія 6 — лакалізаваны empty-catalogue стан
   (#554: фільтр па факце публікацыі), без падстаноўкі кантэнту.
3. **/app + privacy + not-found** — `/app`: загаловак, store-радок фактам з
   `appLinks` (live → спасылка, unpublished → «Хутка»); QR на старонцы не
   рэндэрыцца канструктыўна, бо `siteOrigin.kind === 'unpublished'`
   (lib/qr.ts: нічога не генэруецца, пакуль origin не live — праверана
   тэстам-фактам адсутнасці; калі origin стане live, крытэрый трапіць у
   G10.02.b/#320); privacy адкрываецца ва ўсіх 8 мовах са сваім `lang`,
   кантакт — адзіны знешні URL `supportIssuesUrl`; невядомыя шляхі
   (`/never/anywhere`, `/en/never/anywhere`) → экспартаваны 404.html са
   статусам 404, `lang="be"`, спасылка дадому.
4. **Клавіятура** — Tab ад пачатку дакумента даходзіць да карткі гіда
   (≤12 націскаў), кожны сфакусаваны элемент мае бачны контур
   (`outline-style != none`, `width != 0px` — сайт не скідвае outline),
   Enter на сфакусаванай спасылцы пераходзіць на старонку гіда.
5. **320/390/1440** — Emulation-вьюпорты на 4 класах старонак: гарызантальнага
   скролу няма, першасныя дзеянні (картка, лінк кропкі, audio, назад да гіда,
   CTA аферу) існуюць і ў межах вьюпорта.
6. **Адмаўленне map-правайдэра** — покрыта існуючым `city-map.browser.test.ts`
   (G21.03: InternetDisconnected → data-map-error + лакалізаванае паведамленне
   + працоўныя лінкі гідаў, recovery, чысты unmount). Не дублиравана: E2E-горад
   толькі пацвярджае, што лінкі гідаў, на якія абапіраецца той довод, рэальныя.
7. **Лакдаўн** — харнэс блакуе праз CDP Fetch усе не-лакальныя запыты
   (BlockedByClient) і запісвае іх; uncaught-выключэнні старонкі запісваюцца;
   `assertCleanJourney` у канцы кожнага кейса роняе яго з дакладнымі
   URL/тэкстамі памылак пры любых запісах.
8. **Revert-праверкі** — абедзве праведзены на роўні зборкі+кейса
   (поўны цыкл build→swap→test; вынікі ніжэй).

## Revert-праверкі (крытэрый 8)

- **Audio-гард зачыненага стопа.** У `site.ts readSiteStopPage` зачыненая
  галінка пачала вяртаць `audio` + `transcript`, у `stop-page.tsx` умова
  рендэру павернута на leaks-сцяг (`data.locked && LEAK_LOCKED_BRANCH`, тып
  захаваны кастамі). Поўная перазборка + свап кантэнту →
  `free-journey` ПАДАЕ: `AssertionError: a locked stop must render no audio
  element — 1 !== 0`. Адкат → зелена.
- **Locale-мапінг.** `site.ts localePath` заменены на тоеснасць (без
  прэфікса мовы). Поўная перазборка + свап → `locale-routes` ПАДАЕ:
  `AssertionError: 'be' !== 'en'` — en-чып пакінуў дакумент на be-версіі
  (route: locale-routes.browser.test.ts:59). Адкат → зелена.

### Урокі ўстойлівасці ўлиты ў харнэс

- Сістэмныя пашырэнні хост-Chromium (укадзіроўкі `chrome-extension://` у
  старонку) траплялі ў запіс лакдаўна як знешнія запыты — запуск сюты цяпер
  ідзе з `--disable-extensions`: асяроддзе дэтэрмініраванае, сцвярджэнне
  крытэрыю 7 — пра сайт, а не пра хост.
- Хуткая навігацыя касуе перахоплены запыт да дастаўкі вердыкту
  (`Fetch.*: Invalid InterceptionId` пад нагрузкай паралельных сьют npm
  test) — такі resume маўча закідваецца: запыт у сетку не патрапіў, а
  запісаны вердыкт (continue/block) застаецца аўтарытэтным для кейса.
