## What was decided

- **Станы.** `ready` — усе файлы lock-у прысутнічаюць з дакладным размерам; `partial (N missing)` — хаця б адзін адсутнічае/нечытэльны/не таго размеру; `not_downloaded` — версія вядомая толькі з каталогу; `stale` — пласт поўны, але каталог рэкламуе навейшую версію таго ж маршруту. Прэцэдэнт: няпоўны пласт застаецца `partial` і побач з новейшым каталогам — дзеючы факт (неспаўнасць), не рэклама абнаўлення. Лікавае параўнанне версій праз `BigInt` (да 64 знакаў — па-за `Number.MAX_SAFE_INTEGER`); не-лікавая версія дыска не параўноўваецца і ніколі не `stale`.
- **`stale` — толькі з каталогу** (пруф крытэрыю 2): вывад са сесійнай версіі зламаў бы спынена-прыпыненую сесію; тэст AC2 мацуе тройча: запіс `stale`, `evaluatePackage` на тым жа пласты = `ready`, дрэва дыска байт-ідэнтычнае да/пасля.
- **Read-only (крытэрый 3).** Порт `BundlesStore` не мае мутатараў; гарды крыніцы забараняюць `services/db` і write-API ў абодвух рантайм-файлах. Памеры вытворяцца на кожны выклік: `declared` = Σ lock, `onDisk` = Σ файлаў, што прайшлі праверку размеру; файл не таго размеру не лічыцца «на дыску».
- **Карупцыя (крытэрый 4)** — дыягностыкі ў выніку, ніколі не выняткі: `catalog#type`, `catalog.routes#type`, `catalog.routes[i]#type`, `.route_id/.version/.locales/.layers…#type`, `#unsafe-path:<значэнне>`, `lock.json#missing-file/#unreadable/#invalid-json/#type`, `lock.json[i]#type`, `.[path|bytes|sha256]#type`, `#size-mismatch`. Недавераныя ідэнтыфікатары каталогу правяраюцца як бяспечныя сегменты (`09` §7: без раздзяляльнікаў, `..`, NUL) **да** любога звароту да fs — тэст з портам-запісвальнікам мацуе, што probe няма. Нябяспечны шлях lock-у таксама адхіляецца да probe (ідыём валідатара: `'/'`-сегменты, без абсалютных, без зваротнай косай).
- **Энумерацыя.** Дыск — крыніца радкоў для ўсіх версій (старыя не знікаюць — яны і ёсць `stale`); каталог дапаўняе `not_downloaded`. `staging` побач з фінальным лэйаўтам — не версія (G04.02), пропускаецца. Локалі на дыску — адкрыты набор (радок), тыры — толькі `base`/`extended` (іншыя тэчкі = дыягностыка `#type`). Парадак вываду дэтэрмінаваны (маршрут, версія лікава, локаль, тыр).
- **Пустое дрэва `bundles/`** — пустая бібліятэка, не збой: без дыягностык, радкі `not_downloaded` з каталогу.
