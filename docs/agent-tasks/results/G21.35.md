## Крытэрый 1 — прычэпленая памылка ўзнаўленая да змены

Каманда з issue (node --experimental-strip-types, не зменены код базы b647977) у гэтай сесіі да змены дала: `en/app.html → en`, `en\app.html → be` — паўтор рэтэсту 2026-10-04. Гэта тлумачыць шэсць `wrong-document-language` парушэнняў Windows-зборкі: кожная старонка /en правільна дэкларуе `en`, але gate чытае першы сегмент толькі пасля дзялення па `/`, таму `en\app.html` цалкам трапляе ў «прэфікс», не праходзіць allowlist і падае ў дэфолт `be`.

## Крытэрый 2 — нармалізацыя на існуючай мяжы, усталяваны ідыём

`rel` прыходзіць у gate з `listFiles` (leak-guard.ts) як `path.relative(...)`, што на Windows дае `\`. Нармалізацыя `replaceAll('\\', '/')` дададзеная ў пачатак `expectedDocumentLocale` — функцыі, што інтэрпрэтуе URL-лакаль, — перад распазнаннем прэфікса. Ідыём не прыдуманы: той самы `replaceAll('\\', '/')` ужо ёсць у `unsafeSegments` таго ж пакета (правіла 3 — пошук існага дапаможніка). Сямантыка захаваная цалкам: дэфолт `be` для карэння і агульнага `404.html`, allowlist зарэгістраваных локаляў (`uiLocales` без дэфолту), плоскія (`en.html`) і ўкладзеныя (`en/index.html`) макеты, скід trailing `index`, невядомы прэфікс → дэфолт. Мова не выводзіцца з адвольных падрадкоў — змена тычыцца выключна раздзяляльнікаў шляху.

## Крытэрый 3 — паводзінныя тэсты на абодва сепаратары, чырвоныя на рэверце

Новы тэст «backslash rel paths (a Windows export walk) resolve the same URL locale as slash paths»: матрыца з дзевяці фігур старонак — `en.html`, `en/app.html`, `en/index.html`, `en/guides/demo-route-a1.html`, `en/guides/demo-route-a1/stops/stop-1.html` (чакаюць `en`), `index.html`, `app.html`, `guides/demo-route-a1/stops/stop-1.html`, `404.html` (чакаюць `be`) — кожная праганяецца ў slash- і backslash-выглядзе, дыягностыка называе шлях. Астатняе з крытэрыю ўжо пакрытае існымі тэстамі без змен: чысты экспорт з дзевяці be/en старонак і 404 праходзіць; en-старонкі з `be` падаюць спісам са шляхам і парай expected/actual; старонка без `lang` дае `missing-document-language`.
