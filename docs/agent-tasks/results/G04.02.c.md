## What was decided

- **Канал без пашыральных шляхоў.** Адзіны публічны сродак дастаўкі — `onAccessReady(handler)`; `emitAccessReady` прымае **толькі** (порт, ключ плясту, чытальнік пакета) — аб'ект падзеі ніводзін публічны сігнатура не прымае, таму падзея, збудаваная па-за модулём, не мае шляху дастаўкі (крытэрый 1, runtime-тэст: forged-аб'ект праз чужы порт → `access#no-channel`, праз tamper-паля на ўваходзе `activate()` — ігнаруецца, падзея будуецца з ганаровага ключа). Слабы канал (WeakMap): порт, не створаны `createAccessPort()`, не дастаўляе нічога і адказвае дыягностыкай — fail closed.
- **Пасля каміта, не да** (Proof з issue): эмісія стаіць пасля фінальнага rename'а (fresh шлях) і пасля перазапісу рэестру (fast path). Revert-эксперымент: перанос эмісіі перад rename → тэст criterion 4 (crash-ін'екцыя на фінальным rename) падаў; код адноўлены байт-у-байт.
- **`stop_ids` — з пакета актываванага плясту.** Крыніца — `route.json` **кораня пакета** (`bundles/<route>/<version>/route.json`, фільтр `access_tier === tier`), не layer `stops.json` (там спіс гісторый са `story_id`), і не выклікальнік (у `ActivateInput` поля няма; тэст паносіць event-падобныя палі на ўвод — яны ігнаруюцца). Бязрадковы/чужы tier/не-строкавы `id` — прапушчаны; адсутны/пашкоджаны route.json → `[]` + іменаваная дыягностыка (`access#route-json-missing`/`-invalid`): рэдуктар прымае пусты payload як пашырэнне tier (парытэт run-model), праверка 5 ADR перадбачаецца рухавіком (па-за scope'ам, G05.01.a).
- **Дэдуплікацыя — у канале, па ідэнтычнасці** `route|version|locale|tier` за ўсё жыццё порта (адзін запуск дадатку). Паўторная актывацыя (fast path) камітуе стан зноў, але другой эмісіі няма (крытэрый 3; revert-эксперымент: зняты `emitted.add` → тэст падаў). Іншая ідэнтычнасць (extended) — асобная эмісія.
- **Recovery on open без эмісіі.** `recoverOnOpen()` = перабудова `bundle_asset` рэ-хэшаваннем фінальнага плясту + адказ `ready`/`not-ready` з фактаў дыска. Эмісію сюды не мантавалі свядома: 19 §3.5 называе паспяховую актывацыю адзіным месцам эмісіі; самалякаванне радка крэшу «пасля rename да AccessReady» — вывад з дыска (ADR §3.7), а наступная актывацыя ў новым запуску дастаўляе падзею адзін раз (тэст фіксуе абедзве паводзіны).
- **Зона B недатыкальная.** `services/download` піша толькі ў зону A (`bundle_asset`); тэст інспэктуе live-схему: `PRAGMA table_info` па ўсіх табліцах `ZONE_B_DDL` — ніводнай калоны з `ready`, набор калонаў `session` — дакладна §3.1; радок сесіі ідэнтычны байт-у-байт да/пасля актывацыі — і пасля End (крытэрый 5), і ў жывой сесіі.
- **Ізаляцыя handler'а.** Кіданне handler'а кантролера не губляе падзею для астатніх і не кідае пасля каміта: астатнія атрымліваюць падзею, збой ідзе дыягностыкай `access#handler-threw:<message>` у выніку актывацыі (правіла 4: чыннік зберагаецца, маўклівага swallowing няма).

## Criteria

1. **Адзін каміт — адзіная эмісія толькі праз порт:** тэст criterion 1 (адзін каміт → адна падзея, поле за полем даслоўна: `type/routeId/version/locale/tier/stopIds/issuer`); forged-аб'ект па-за модулём: `Object.keys(port) === ['onAccessReady']`, чужы порт → `access#no-channel`, tamper-палі ўводу ігнаруюцца.
2. **`stop_ids` з пакета актываванага плясту:** тэсты criterion 2 (base → `[stop-1, stop-2]`, extended → `[stop-3]`, безыменная кропка прапушчаная; адсутны/пашкоджаны route.json → `[]` + дыягностыка; юніт-тэст `parseRouteStops`).
3. **Паўтор ідэнтычнасці — без другой эмісіі:** тэст criterion 3 (паўтор → fast path, падзей па-ранейшаму адна; extended → другая, бо ідэнтычнасць іншая).
4. **Restart паміж rename і эмісіяй → вывад з дыска; зона B бяз ready:** тэст criterion 4 (crash на фінальным rename → падзей нуль, плясту на диску няма; `recoverOnOpen` → `not-ready`, рэестр pending; рэтрай → рэзюм без перакачкі + адна падзея на новым порце; поўны рестарт → `recoverOnOpen` → `ready` з дыска, recovery нічога не дастаўляе, наступная актывацыя — адна падзея) + асобны тэст зоны B (`PRAGMA` па ўсіх табліцах, дакладны набор калонаў `session`).
5. **Загрузка пасля End не мутуе радок сесіі:** тэст criterion 5 (файлы пад `bundles/<route>/<version>/<locale>/<tier>/`, staging знік, `bundle_asset` complete, радок `session` ідэнтычны да/пасля) + тэст жывой сесіі.
