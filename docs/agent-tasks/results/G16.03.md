## Acceptance criteria — one by one

1. **Skipping a rating never blocks End, purchase, download or playback.** — The invitation renders after End as a plain card (not a `ModalDialog`); dismissing it leaves the ended surface intact (`app/run.test.tsx` «after End the quiet invitation offers the walk's own target; dismissing keeps the ended walk»); the form writes nothing until an explicit Send (`ui-controller.test.ts` «no preselected star and dismissal writes nothing» — `feedback_local` stays empty); the controller has no purchase/download/playback reference.
2. **Place visit is self-report and never emits stop_reached or a verified-visit claim.** — The place action only opens the visit confirmation dialog; the confirm navigates to the form (`app/place/place.test.tsx` «the published place card rates through the visit confirmation into the bound form»); the feedback path touches no events port (`ui-controller.test.ts` «analytics denied: the wired events port records nothing during a full feedback round» — the full `createServices` wiring with a telemetry spy); the disclosure names the self-report (the canonical `native.feedback.placeVisitBody`: «Ацэнка месца — самаацэнка візіту, не праверанае наведванне.»).
3. **Guide audio complaint stays a guide reason, not a place score.** — `reasonsFor('place')` excludes `audio_problem`; a forced `toggleReason('audio_problem')` on a place form throws the named `feedback-input-invalid` rule (`ui-controller.test.ts` «the guide form offers audio_problem; the place form refuses it by name»); the route renders only its kind's chips.
4. **Analytics denied permits explicit feedback with no events upload.** — The same full-wiring test: a put reaches the feedback transport (`transport.calls.length === 1`) while the telemetry port records zero events; the controller module holds no telemetry dependency structurally (the port set is driver + sync + repository).
5. **New catalog/UK UI cannot change the rated content version/locale or active Run audio.** — The invitation's target is the ended session's own pinned `version/locale` (`app/run.test.tsx` «the rate action opens the form bound to the ended session's pinned identity» — the form's facts line renders `targetLine("1", "be")` from the session, no catalog read on submission); the place target binds at card-open from the opened card's facts; the UI-locale switch re-renders the words only — the target's content locale is a separate fact (the facts line), and the run's pinned audio is out of the feedback controller's reach by construction (no session/audio reference).
