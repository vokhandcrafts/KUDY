## Decisions recorded (for G02.04 / G12)

1. **Authoring `discovery.json` is not a `DiscoveryIndexV1` document.** It lacks `schema_version`, `availability` and `access` because the G02.03 packager computes them; the full schema applies to the assembled index (proven by the criterion-5 fixtures), the authoring doc gets cross-record checks (refs, themes, members, detail_ref, duration range, reader named rules).
2. **Diagnostics are content-free** — stable rules + entity paths only, matching the G02.03 leak boundary.
3. **Stop-id stability contract**: same id must keep `place_id`, `access_tier` and story refs (`stop-id-drift`); a removed stop reappearing under a new id at the same place+tier is `stop-id-renumbered`; inserting a genuinely new stop is clean.
4. **`unsafe-path` denylist** (`..`, `.`, `private`, `extended`) is validator-owned: `..` and `private` pass the schema charset patterns, so only this layer catches them.
5. **Radius overlap** compares place geofences pairwise via haversine and emits a warning only; stop-level `trigger_radius_m` overrides stay a runtime concern.
