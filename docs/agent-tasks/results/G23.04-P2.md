## Самаправерка аўтара

Правераны diff гэтай задачы; асноўны фокус — адпаведнасць кантракту End і
доступу да гісторый. Новы спіс віртуалізаваны праз FlatList. Новых залежнасцей,
сакрэтаў, сеткавых выклікаў або запісаў прагрэсу няма. Вялікія файлы Run і
кантролера захоўваюць сваіх існуючых уладальнікаў: экран паказвае вынік,
кантролер адаптуе кананічны селектар; другога кантракту для вылучэння няма.

Тэсты праходзяць праз Run і рэальную кампазіцыю кантролераў. Правілы locked,
heard, additional і empty правераныя сінтэтычнымі станамі; Android правярае
вольны пакет G23.01, а не пакупку або закрыты платны пласт.
