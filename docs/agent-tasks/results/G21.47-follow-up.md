# G21.47 follow-up — кнопкі прагулкі пры маштабе 200%

Задача: [#719](https://github.com/vokhandcrafts/KUDY/issues/719). Першапачатковае назіранне: [G21.47](G21.47.md).

У `app/run/[id].tsx` рад `sessionActions` атрымаў `flexWrap: "wrap"`. Пры вялікім шрыфце кнопка завяршэння пераносіцца на наступны рад. Дзеянні кнопак і абмежаванне маштабу `ScaledText` не змяняліся.

## Праверка крытэрыяў

1. **Пералік паверхняў.** Пошук `flexDirection: "row"` у `app/` і `components/` даў пералік ніжэй. Здымкі арыгінальнага прагону ZCode ад 2026-10-11 захаваныя ў [каталогу доказаў](../../testing/evidence/2026-10-11-g219/). Гэта AVD `kudy-test`, Android 16 / SDK 36, акно 1080×2400, `by.kudy.app`, Metro :8081 і сінтэтычны origin :8791; факты прылады запісаныя ў `rows-scale1.json` і `rows-scale2.json`.
2. **Выпраўленне і 100%.** [Актыўная прагулка пры 100%](../../testing/evidence/2026-10-11-g219/run-resumed-scale1.png) паказвае кнопкі побач; [пры 200%](../../testing/evidence/2026-10-11-g219/run-resumed-scale2.png) яны ў двух радах. Абодва подпісы цалкам бачныя. Паўза і вяртанне да прагулкі таксама захаваныя.
3. **Праверка абразання.** У захаваных JSON `horizontalClipScan` і `essentialMissing` пустыя. Межы з UIAutomator самі па сабе не даказваюць адсутнасць абразання: Android можа вяртаць ужо абрэзаныя межы. Таму вынік для выпраўленага рада абапіраецца таксама на агляд двух здымкаў вышэй. Машынны тэст правярае наяўнасць абодвух подпісаў у стане `resumed` пры абодвух маштабах, кадра паўзы і файлаў усіх пазначаных здымкаў.
4. **Праверка адкату.** `npx jest --config jest.config.js app/run.test.tsx -t "pinned 200%"` правярае стыль сапраўднага рада ў адрэндэраным Run і cap яго подпісаў. Jest не вылічвае натыўную геаметрыю; яе паказваюць здымкі. Тэст уваходзіць у штатны `npm test`.

| Рад | Паверхня | Што праверана |
|---|---|---|
| `sessionActions` | Run | Актыўныя кнопкі пры 100% і 200%, паўза і вяртанне; перанос выпраўлены |
| `barRow` | Run | Стан без аўдыё бачны на здымках; спалучэнне назвы і кнопкі прайгравання не праверанае на прыладзе |
| `layerRow` | Run | Пашыранага пласта ў фікстуры няма, таму пераключальнік не паказваецца; `flex: 1` у кодзе не выдаецца за прыладны доказ |
| `factRow` | Прэв’ю гіда | Іконкі і подпісы бачныя пры абодвух маштабах |
| `row` | BackButton | Кнопка вяртання бачная на здымках прэв’ю і Run |
| `row` | LoadingIndicator | У кодзе ёсць `flexShrink: 1`; асобны кадр загрузкі не здымаўся |
| `cardMeta` | Мапа | Метаданыя карткі бачныя на здымках мапы |

`audioPicker`, `chipRow`, `localeRow`, `feedbackInviteRow` і `guide-card.grid` ужо маюць перанос. Экран feedback зафіксаваны ў стане «Водгук недаступны»: парты формы адсутнічалі ў прыладнай кампазіцыі. Probe выключаны з абсягу задачай.

## Паходжанне доказаў і абмежаванні

Codex працягнуў спыненую сесію ZCode `sess_8342a139-18e5-44cc-980f-4b92ac062881` 2026-10-11. Арыгінальны кадр `card-open` насамрэч паказваў адноўленую актыўную прагулку: ён перайменаваны ў `resumed`, адпаведны тэг JSON выпраўлены. Новы прыладны прагон не заяўляецца. `run-main-scale1.png` паказвае паўзу, таму для параўнання актыўных кнопак выкарыстоўваецца `run-resumed-scale1.png`.

Драйвер абноўлены: захоўвае поўны спіс тэкстаў, патрабуе актыўную прагулку і абодва подпісы, правярае адсутнасць неабходных элементаў, завяршаецца памылкай пры абразанні. Памылка цяпер кідае выключэнне, каб выканаўся `finally` з вяртаннем `font_scale`. Агульныя функцыі adb вынесены з папярэдняга драйвера G21.47 у `device-run-lib.mjs`, каб не дубляваць іх. Абноўлены драйвер не быў паўторна выкананы на AVD; гэтая мяжа адрозніваецца ад праверкі захаваных доказаў.

Для дасягнення Run папярэдняя сесія ўручную паклала апублікаваныя дакументы `route.json`, `places.json`, `voices.json`, `media.json`, `moments.json` у каталогі пласта на эмулятары. Гэта праверка макета з сінтэтычным пакетам, не доказ працоўнай спампоўкі ці Start. Адсутны `evaluateLayer` і няпоўны замак пакета ўжо запісаныя ў [#727](https://github.com/vokhandcrafts/KUDY/issues/727); яны не выпраўляюцца ў #719. Фізічная прылада і iOS не правяраліся.

## Эканомны рэжым праверак

Пасля паведамлення ўладара пра падзенні Codex цяжкія працэсы спыненыя. Зборка і эмулятар не запускаюцца разам. Далейшыя аўтаматычныя праверкі выконваюцца паслядоўна; для цяжкіх каманд задаецца ліміт памяці, swap і CPU праз асобную systemd scope. Пры недахопе рэсурсаў спыняецца праверка, а не павялічваецца яе ліміт.

## Вынікі аўтаматычных праверак

Актуальныя каманды і вынікі будуць дапоўненыя пасля фінальных праверак. [Showboat-доказ](../../demos/2026-10-11-issue719-actions-row-200.md) правярае захаваныя даныя і запускае render-тэст.

## Самаправерка

Асноўная рызыка — перабольшаныя сцвярджэнні пра прыладны прагон. Памылковы подпіс адкрытай карткі выпраўлены; непаказаныя станы пазначаныя асобна. Run застаецца адным уладальнікам паверхні прагулкі; праўка стылю не ўводзіць новага ўладальніка, сэрвісу ці кантракта.
