# Issue #862 — забарона несанкцыянаванага запуску Run

Дата: 2026-10-28. Галіна: `chatgpt/862` (ад `main` на `f5a8704`).

## Вынік па крытэрыях

1. Рэалізаваная праверка `approvedStart`: толькі пасля `handover` у preview ствараецца новая сесія. Прамы пераход на Run без жывой сесіі атрымлівае `run#start-requires-preview`, а не выклікае `start()`. Падмена `confirmedSwitch` не павінна абыходзіць праверку.
2. У `tools/e2e-android/gps-ownership.mjs` зменены сцэнар паўторнага ўваходу пасля End: патрабуе нуля актыўных location operations і нязменнага спісу запісаў гісторыі. **На эмулятары пакуль не праверана.**
3. Тэсты кантролера захоўваюць станоўчыя сцэнары preview-пацверджанага запуску, змены гіда і аднаўлення жывой сесіі. Сцэнар пасля End цяпер спачатку патрабуе адмовы, потым дазваляе новы Start з preview.
4. Новыя паводзінскія праверкі дададзены ў `controllers/run/runSurfaceController.test.ts`, `app/run.test.tsx` і Android GPS suite. **Вынік праходжання CI пакуль невядомы; revert-test не выконваўся.**

## Фактычныя праверкі і абмежаванні

- `npm run typecheck` у лакальным абмежаваным MCP worktree: **не выканалася**, exit 127 — `tsc: command not found` (адсутнічаюць `node_modules`).
- `npm test`, `npm run arch:check`, `npx --yes jscpd@5.1.2 --config .jscpd.json --no-tips .`: **не выконваліся**.
- `node tools/e2e-android/run-e2e.mjs --suite gps`: **не выконваўся**; доступ да Android эмулятара не пацверджаны.
- Showboat: **не створаны і не правераны** — у абмежаваным асяроддзі няма пацверджанага выканання кода актуальнай аддаленай галіны.
- Актуальны лакальны `main` (`7bd2438`) мае староннія незахаваныя змены. Таму змены гэтай задачы ўнесеныя выключна ў GitHub-галіне, створанай ад актуальнай аддаленай `main`; лакальныя файлы не перазапісаныя.

## Перад завяршэннем

Правесці CI, абавязковыя аўтаматычныя праверкі, Showboat і Android GPS прагон, праверыць, што рэгрэсійны тэст падае пры адкаце guard, атрымаць code review. PR не мерджыць да ўсіх патрэбных станоўчых вынікаў.
