## What was done

The runtime message catalogues are now reproducible generated projections of the canonical source records plus the reviewed locale data:

- `contracts/ui-messages/translations/en.json` (234 records) and `uk.json` (230 — the four `native.guideHint` records keep their documented be fallback, uk-release-scope §6.4). Every record carries the message value (with `${name}` patterns), `forms` for the `discreteForms` records (same keys as the source), `reviewedSourceHash` pinning exactly the reviewed source-record version, and the review outcome; the set carries the migration provenance (reviewer: owner, evidence referencing the shipped-catalog PRs and the uk review role). The words were recovered mechanically from the shipped hand catalogs by calling them with `${name}` sentinels — the same method proved itself by reproducing every `be` source text verbatim (the G21.24 walk idiom); a one-off probe, not committed.
- `contracts/schemas/ui-messages-translations.schema.json` + `contracts/ui-messages/translations.mjs` + `.d.mts` — the translation-set contract and checker (source-checker idiom: schema keywords → named diagnostics, cross-record rules by hand, corrupt input answers with diagnostics never a throw, the shipped files fail closed). Named rules: `translation_schema_version_denied`, `locale_denied`, `source_locale_denied`, `unknown_id_denied`, `duplicate_key_denied`, `stale_translation_denied` (a changed source record makes every translation pinning the old hash stale — the re-review trigger), `form_set_mismatch_denied`, `param_mismatch_denied`, `executable_payload_denied`, `value_blank_denied`, `unknown_field_denied`, plus the schema layer.
- `tools/i18n/generate-messages.mjs` — the catalogue generator. Supported patterns only: plain; `${name}` templates over the typed parameters (number / string / `readonly string[]`, list join and the canonical parameter fallback from the record); numeric `discreteForms` (sorted numerically, ternary chain); named `discreteForms` (the one record whose argument is a state object — `native.preview.detail` — through a structural signature config, no import of the controller vocabulary); `composed` (the segment before the last parameter renders only when that parameter is non-empty — the conditional audio segment of `textAudioLine`). Static text is escaped (backslash, backtick, `${`, CR/LF/tab); dictionary text is data — no eval, no executable template snippets, no runtime LLM or remote calls. The generator fails closed: source and translations load through their contract checkers, every source record must be covered by exactly one planned output, every planned output locale must have a translation record.
- 10 generated outputs, each marked `GENERATED FILE — do not edit`: `components/ui-strings.generated.ts` (annotated `Record<CompleteUiLocaleCode, UiStrings>`, `languageSelfNames` still the registry call — a language is never named through a translation), `components/guide-hint-strings.generated.ts` (annotated against the contracts type), five `controllers/**/*-strings.generated.ts` (data-only; the hand adapters annotate against the existing interfaces, so no hand↔generated cycle exists for the `no-cycles` arch rule) and `web/lib/i18n/be.ts` / `en.ts` / `uk.ts`. The hand files (`ui-strings.ts`, `GuideHintCard.tsx`, the five controllers, `web/lib/i18n/index.ts`) keep only the selectors, interfaces and wiring — the base text and context never live there. `native.guideHint` keeps be+en outputs; the card's selector keeps the documented uk→be fallback.
- `npm test` wiring: `"tools/i18n/*.test.mjs"` joined the node glob list (owned by the existing test-discovery guard); scripts `messages:generate` / `messages:generate:check`.
- Tests: `tools/i18n/generate-messages.test.mjs` (7 — `generator_reproducible`, `generated_catalogue_fresh` incl. missing/edited/stale naming and a fail-closed translation violation, `message_rendering_safe` with a hostile-text round-trip through real generated code, unsupported-shape refusals, no eval/Function/import in outputs), `contracts/ui-messages/translations.test.mjs` (17 — every named rule with an isolating fixture, corrupt-input diagnostics, the shipped sets pass their own contract, uk coverage = all records minus the guideHint fallback), `test/ui-messages-render-golden.test.mjs` (1 — a 1484-row golden matrix captured from the pre-generation hand catalogs: plain words verbatim and every template over a fixed argument matrix including quotes, newlines, empty lists, the null fallback and the `PreviewDetail` variants; every row re-renders byte-equal through the live selectors). The inventory guard now reads the guideHint words from the generated module instead of its own restatement.

## Acceptance criteria walk

1. **Translation record with message value/forms, reviewedSourceHash and review/provenance metadata; canonical parameter types and the #542 selector/function signatures preserved.** The schema and the checker define the record; `reviewedSourceHash` equals the current `sourceHash` (staleness rule, tested on a real re-hashed edit); the generated catalogues satisfy the existing interfaces (`typecheck` green, strict), the runtime shape/arity guard (`test/ui-message-types.test.mjs`) passes unchanged, and the golden matrix pins the exact per-locale output of every leaf.
2. **Native/controller and web catalogues generated from one canonical source plus locale data; outputs marked generated; no duplicated base text/context in hand-maintained files.** Ten outputs across `components/`, `controllers/`, `web/lib/i18n/` render from `source.json` + `translations/`; every generated file opens with the do-not-edit header and the source pointers; the hand files retain selectors only (the catalogs' text is gone from them).
3. **Supported message patterns and safely escaped static output; dictionary text is data.** The generator implements exactly the recorded format (plain/template/list-join/fallback/discreteForms/composed) and refuses unsupported shapes by name; the escaping round-trip test imports the generated code and asserts the original characters render back; the emitted outputs contain no `eval(`/`Function`/`import(`; no runtime translation or network calls exist.
4. **Byte-identical repeated generation; check mode fails for removed/edited/stale output; existing messages, plural/count/date examples, quotes/newlines render without code execution.** `collectOutputs()` twice is deep-equal and equals the committed files; `--check` on the committed tree is fresh and names every missing/edited file in the fake-root test (no real-tree mutation); the golden matrix renders counts, quotes, newlines and the composed conditional (`Тэкст: be` vs `Тэкст: be; аўдыё: en`) without any code execution (Showboat demo blocks).
5. **Tested on Linux without altering media/hash-pinned content fixtures; layer boundaries and existing be/en/uk behavior kept.** Portable by construction — node stdlib only in the generator and checkers, `join()` paths, LF writes, no platform assumptions (no Windows host ran in this session; the criterion's Windows leg is unverified here); no fixture under `contracts/fixtures/` touched; `arch:check` green (0 violations, no cycles); the golden matrix is the be/en/uk behavior proof.
