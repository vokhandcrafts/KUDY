## Што зменена

- `supabase/functions/_shared/grant-wire.ts` (новы) — вытворчы апрацоўшчык
  `/v1/grant` вынесены з Deno-энтрыпоінта ў shared-модуль (прэцэдэнт G20.01
  `device-wire.ts`): `handleGrantRequest`, `serveGrantRequest` (адзіная мяжа
  збою з рэдакцыяй дыягностыкі — issue #311), `loadManifestDoc`, `signObject`,
  RevenueCat-адаптар, `serialize`, `requestDeps`. Вузкія структурныя тыпы
  `GrantRequestLike` / `GrantSqlClient` / `GrantRuntimeConfig` (ідыёма
  device-wire) — модуль без Deno-глобалаў, імпартуецца node-сюітамі.
- **N7-гвард у `loadManifestDoc`**: адмова парсінгу захаваных байт
  (`response.json()`) і не-аб'ектнае цела (`null`, масіў, прымітыў) даюць
  `null` → `403 manifest_not_found`. Шырокага catch няма: толькі парсінг
  байт закрыты лакальна; сапраўдны збой транспарту (адмова `fetch`)
  распаўсюджваецца ў мяжу збою → `503 entitlement_unavailable` з
  `Retry-After`. Адсутны маніфест (не-ok Storage) — як і раней `null` → 403
  (дакументаваны кантракт G08.02).
- `supabase/functions/grant/index.ts` — тонкая Deno-абалонка: `resolveConfig`
  (Deno.env, N5-палітыка TTL) + `Deno.serve((req) => serveGrantRequest(req,
  database, resolveConfig))`. Злучэнне і канфіг адкрываюцца ўжо ўнутры мяжы
  збою, таму іх fail-closed брамы (DATABASE_URL, N5) адказваюць тую ж
  закрытую 503, што і раней.
- `supabase/functions/_shared/grant-wire.test.ts` (новы) — адаптарныя тэсты:
  сапраўдны bearer-шлях праз device-core, сапраўдны загрузчык маніфеста,
  сапраўдны RevenueCat-адаптар і сігнер; фейкі — толькі транспарты (SQL-фейк
  адказвае pinned канстантам стэйтмэнтаў, `globalThis.fetch` маршрутызаваны
  па URL на фейкавы Storage/RevenueCat край). Кожны адказ спраўджаны супраць
  закрытага спісу `GRANT_ERRORS` кліента (19 §3.6).
- `docs/agent-tasks/results/G08.02.md` — датаваны пакажчык стану wire-узроўню
  (правіла 8); Дэма: [2026-10-02-g2025-manifest-denial.md](../../demos/2026-10-02-g2025-manifest-denial.md).

Кліенцкі кантракт не зменены: `403 manifest_not_found` і
`503 entitlement_unavailable` ужо ў закрытым спісе `GRANT_ERRORS`.

## Па крытэрах

1. **Кожная пашкоджаная форма праз вытворчы апрацоўшчык → 403
   manifest_not_found, нуль выклікаў правайдара і подпісаў.** Названыя
   прозвы: `corrupt_manifest_403_no_provider` (абрэзаны JSON),
   `null_manifest_403` (захаваны `null`), плюс 10 форм у адным прозве
   (масівы, прымітывы `42`/`"manifest"`/`""`, пусты аб'ект, радковы
   `paths`, не-радковы элемент `paths`, пусты і не-радковы `lock_url`) —
   усе `403 manifest_not_found`, `provider: 0`, `sign: 0` (лікі fetch-выклікаў
   фейкавага транспарту).
2. **Пашкоджаны/адсутны маніфест адрозніваецца ад сапраўднага збою
   транспарту.** `storage_failure_status`: адмова fetch (ECONNREFUSED) →
   `503 entitlement_unavailable` + `retry-after: 30` + раўна адзін
   рэдакціраваны дыягностык (`<redacted-url>`, без `storage.test` у stderr);
   асобны прозва — збой звароту да RevenueCat праз вытворчы адаптар → той жа
   закрыты 503 без подпісаў. Дзве прычыны — два розныя шляхі (403 лакальны,
   503 рэтрайны).
3. **Сапраўднае членства ўсё яшчэ аўтарызуе толькі запытаныя бяспечныя
   шляхі і тое ж асяроддзе.** `valid_manifest_membership`: кэш-трапленне
   таго ж асяроддзя → `200`, `lock_url` з маніфеста без зменаў, minted
   роўна запытаны шлях-сябр, `sign: 1`, `provider: 0`; не-сябр → `403
   path_not_allowed`; чужое асяроддзе ў кэшы не аўтарызуе — правайдар
   выклікаецца (`environment_undeterminable` → 503, вытворчая fail-closed
   паводзіны адаптара). Шырокі catch не ператварае невядомую аўтарызацыю ў
   дазвол: мяжа збою адказвае закрытай 503, json-гвард — 403.
4. **Тэсты ў стандартнай камандзе і падаюць пры паўторным уцяканні.** Файл
   падхоплены існым глобам `supabase/**/*.test.ts` у `npm test`.
   **Рэверт-эксперымент** (правіла 1): старая негвардаваная форма
   `loadManifestDoc` (парсінг без try/catch + доступ да поліў) → роўна два
   названыя тэсты чырвоныя (`corrupt_manifest_403_no_provider`,
   `null_manifest_403` — 503 замест 403), астатнія 5 зелёныя; з гвардам —
   7/7. Доказ фейкавага транспарту Storage: fetch-фейк у тэсце і дэме,
   жывога дэплою і сеткавых выклікаў няма.
