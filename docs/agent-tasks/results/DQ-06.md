## Рашэнні дызайну

- **Імя доступу з улікам нашчадкаў.** Строгае чытанне крытэрыя 1 «клікабельны
  вузел без тэксту і без content-desc» па плоскім спісе пазначала б усякую
  тэкставую кнопку (тэкст жыве ў дачынным `TextView`) — ілжывыя RULE на ўсіх
  экранах. TalkBack агучвае паддрэва кантэйнера, таму вузел лічыцца
  падпісаным, калі імя ёсць у яго нашчадкаў. Фіксчара «unlabeled icon» —
  клікабельны вузел + `ImageView` без desc: злоўленая.
- **Адзін вузел — адна знаходка:** RULE перамагае OPINION (літару спраўляць
  першай; памер пераацэньваецца пасля з'яўлення подпісу).
- **48 dp — толькі OPINION:** правіла у каноне адсутнічае, рашэнне ўладальніка
  адкрытае (спец §12, пытанне 4; design-qa.md DQ-05). RULE дазволены толькі
  з цытатай прынятай крыніцы — канон §9.
