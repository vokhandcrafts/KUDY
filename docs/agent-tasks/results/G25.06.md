4. **Экспарты і карта кода** — [contact-sheet.html](../../design/brand/outputs/G25.06/contact-sheet.html) (рэдагуемы, шрыфты OFL локальна ў `fonts/`), вектар маркераў [markers.svg](../../design/brand/outputs/G25.06/markers.svg), растравы [contact-sheet.png](../../design/brand/outputs/G25.06/contact-sheet.png); кожны спецімен мае «Дзе ў кодзе» (file:line); implementation gaps — раздзел «Handoff» ніжэй (H1–H8), не фіксы.

## Што не праверана (пазначана невыкананым)

- Візуальная праверка на жывой прыладзе і ў рэальным вэб-браўзеры не рабілася — спецімены статычныя (прэцэдэнт G25.04).
- Сям'і станаў denied/delivery паказаныя тэкставымі ўзорамі без жывой сесіі крамы/сеткі.
- G25.05 (прадметы калекцыі) і G24.02 (іконка) свае асеты не рэндэраць: у спеціменах дракон/кампас/прадмет — толькі ўзгадванні, не выявы.
