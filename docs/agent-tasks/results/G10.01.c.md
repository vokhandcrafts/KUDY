## What was decided

1. **The player is the standard element with zero client JS.** `<audio
   controls preload="none">` per existing audio locale, rendered by a server
   component: playback starts only from the visitor's tap (native controls),
   nothing preloads, nothing autostarts, and playback state lives only in the
   open tab (task step 6 is structural — there is no script to store it).
   A committed guard pins the markup contract and rejects `'use client'`,
   storage APIs and autoplay on the stop sources.
2. **Audio availability by fact, probed where it is served.** The page data
   probes `bundle/<route_id>/<version>/<locale>/base/audio/<story_id>.m4a` for
   each catalog locale of the route and offers one entry per existing file
   (the demo fixture: be + en; a text-only locale never claims audio). The
   same tree the prebuild mirrors into `web/public/content/` is what the
   probe reads, so what the player references is what the site serves. An
   empty probe list is the user-visible failure state while the transcript
   stays readable (task step 5) — verified by a test that removes the audio
   files from a served-tree copy.
3. **The locked boundary sits in the data shape.** `LockedStopPageData` has no
   `audio`/`transcript` fields — the leak guard of this task is the type plus
   a key-set assertion, not a rendering-time filter. The locked page shows the
   padlock, the preview announce and the existing calm-offer block; per-row
   CTAs remain forbidden.
4. **Unknown URLs are the static 404 state.** `stopStaticParams` prerenders
   exactly the catalog's route × stop pairs, so an unknown or stale URL never
   renders partially — the export's `404.html` («Версія недаступная» + path
   home, both UI languages) is the defined safe state; unknown route/stop are
   additionally defined `SiteDataError` rejections at build time (negative
   tests in the suite).
5. **Bundle assets are served from one mirror.** The prebuild copies the
   public tree to `web/public/content/` (gitignored in the same change); the
   URL base lives in one constant (`CONTENT_ASSET_BASE`). Real publication
   (G02.04/G10.02.b) may repoint the constant — no page hardcodes a URL (the
   existing no-hardcode guard passes).
6. **jscpd refactor, not a second variant.** The shared catalog-route
   preamble of the guide and stop pages moved into `resolvedCatalogRoute`
   after the gate flagged the duplication.

## Acceptance → evidence

1. **Free stop: transcript server-rendered in be/en; audio plays after a tap,
   never by itself** — demo block 3 (`transcript server-rendered: true`,
   `autoplay in html: false`); suite ties the rendered transcript to the
   fixture bytes for both locales. Playback was verified in a real browser
   against the locally served export: both elements sit `paused` at
   `currentTime 0` after load (twice, including after a reload), and an
   explicit user action (keyboard focus + Space on the native player) moved
   the first element to `playing` with `currentTime` advancing and no media
   error. Method note: the committed fixture audio is a printable-ASCII
   placeholder (G02.05 decision 3), which the browser correctly refuses to
   decode, so the playback proof used a locally generated AAC (sine tone)
   dropped into a throwaway copy of the served tree; nothing of it is
   committed.
2. **Locked stop: four preview fields, no transcript/paid text, no audio
   element** — `LockedStopPageData` key set (test); export greps
   (`audio on locked stop: false`); the paid-text scan over page data still
   passes (`pages.test.ts`).
3. **Nonexistent/unknown-version URL renders the safe state; negative test in
   the suite** — unknown route/stop rejections + prerender list exactly the
   catalog pairs + static `404.html` (`stop-page.test.ts`, demo).
4. **Missing audio file → failure state, transcript readable** — the
   served-tree copy test (both files removed → `audio: []`, transcript kept;
   be-only removed → en still offered by fact).
5. **`npm test` includes the new cases; evidence per criterion** — 354/354
   (347 at the base `8a82624`, re-run in a detached worktree at that commit —
