`{ title: "components/guide-card", component: GuideCard }`), тып
`GuideCardStory` аб'яўлены мясцова — ніякіх runtime-імпартаў Storybook
(крытэрый 1). Чатыры іменаваныя гісторыі: `free`, `paid`, `mixed`,
`long-title` — доўгая сінтэтычная беларуская назва. Args — толькі
сінтэтычныя фікстуры праз `syntheticCard` (`routeId: "synthetic-guide"` у
каталозе не існуе). Адзіная крыніца станаў — экспартаваны масіў `stories`
(спец §4.4: другога спісу няма); тэст single-source звязвае іменаваныя
экспарты з масівам — экспарт без запісу ў масіве робіць сюіту чырвонай.

## AC2 — dev-only маршрут

`app/dev-specimen.tsx`: export default; гейт `if (!__DEV__) return null;`
перад першым выклікам хукоў — ідыём `app/han-probe.tsx:143`. Глыбінная
спасылка `kudy:///dev-specimen?component=guide-card` (схема `kudy` у
`app.json`); параметр `component` выбірае модуль гісторый з REGISTRY — V1
адзін кампанент (спец §8.1), G26.11 дадае запісы сюды. Кожная гісторыя —
блок `dev-specimen/story-<name>` з подпісам па імені
`dev-specimen/label-<name>`. Невядомае або адсутнае імя кампанента —
гонарны стан `dev-specimen/unknown` са спісам даступных, нічога не
выдумляецца.
