## Крытэрыі прыёмкі

1. **Сталая старонка privacy, 200 і поўны тэкст на be/en, не заглушка** — даказана: `npm run build`
   у `web/` → `out/privacy.html`, `out/en/privacy.html`; сервінг праз `tools/serve-static.mjs` +
   `curl` → `200`/`200` (блок у дэмо). Чысты URL `/privacy` без `.html` — канфігурацыя хостынгу
   (Vercel, G10.02.b #320), гл. «Не праверана».
2. **Тэкст пакрывае патрабаваныя сцвярджэнні** — даказана маркерамі гарда (якія даныя аперуе
   праект; лакацыя толькі ў дадатку падчас актыўнай прагулкі; каардынаты не пакідаюць прыладу і
   не перадаюцца на сервер; аналітыка толькі па яўнай згодзе; шлях выдалення праз My KUDY;
   кантакт падтрымкі) — у абедзвюх лакалях, у рэндэры таксама праверана curl'ам у дэмо.
3. **Крыжаваная праверка з #286 (G09.02) і #288 (G09.03)** — даказана супраць канона 09 §10
   (крыніца праўды абодвух кантрактаў): «ніякіх каардынат, ніякіх імён, ніякага вольнага тэксту»;
   згода да першай адпраўкі, адмова = лог толькі лакальна + дадатак працуе цалкам; тэрмін сырых
   падзей 14 месяцаў, агрэгаты без `device_id`; выдаленне `DELETE /v1/device` / кнопкай у My KUDY,
   «не ліст на пошту», загрузкі застаюцца; пакупкі праз крамы — у логу толькі `purchase_*` без
   плацёжных палёў. Супярэчнасцяў не знойдзена. Спасылкі на кантракты — у PR-апісанні.
4. **URL унесены ў чэк-ліст #299 як адзінае месца праўды** — каментар у #299: шляхі `/privacy`,
   `/en/privacy` для палёў Privacy Policy абедзвюх крам; абсалютны URL дапоўніцца вызначэннем
   `siteOrigin` (#320).

## Не праверана (implementation-rules §9)

  старонкі з'явяцца з публікацыяй G10.02.b (#320).
- Чысты URL `/privacy` без пашырэння — хостынгавы rewrite, не частка статычнага export-у.

  іх прынятаму кантракту (09 §10), не рэалізацыі.
