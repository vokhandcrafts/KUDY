## Знаходкі пілота і зробленыя выпраўленні

- **F-3 (выпраўлена ў гэтым PR): жывой MediaWiki API больш не вяртае `parse.revisions`.** `action=parse&prop=text|revisions` адказаў толькі `pageid/text/title` — усе 12 вікі-крокаў першага жывога прагону ўпалі (`missing revision metadata (parse.revisions)`). `revisions` адсутнічае ў спісе дапушчальных `prop` для action=parse (праверана праз `action=paraminfo`). Выпраўленне: `tools/collector/wiki.mjs` — адзін выклік `action=query&prop=revisions&rvprop=ids|timestamp|user|content&rvparse=1` (дае і тэкст, і метаданыя рэвізіі; `rvparse` дэпрэкацыйны — абмежаванне запісанае ў каменце кода), парсер чытае `query.pages[].revisions[0]`. Фікстуры `wiki.test.mjs` перабудаваныя на жывую форму адказу; адмоўныя тэсты (missing pages, null revid, без HTML, API-памылка) застаюцца ізавалянымі. Праверка на зварот: адкат парсера роніць сьют карупцый (`missing 'parse' section` супраць новых дыягностык).
- **F-4 (выпраўлена ў гэтым PR): HTTP 429 ад вікі-API без ветлівасці.** Другі жывы прагон: 3 вікі-крокі ўпалі з 429 — вікі-выклікі і паўзук мелі незалежныя гейты ветлівасці, сумарная хуткасць на pl.wikipedia.org удвая перавышала спецыфікацыйную «затрымка 2–5 с паміж запытамі да аднаго хоста». Выпраўленне: адзін гей `createPoliteness` на прагон, падзелены паміж паўзуком (`createCrawler` прымае ін'екцыйны `gate`) і вікі-выклікамі; тэст на ветлівасць у `wiki.test.mjs` (адкат гейта → тэст чырвоны). Фінальны прагон: 12/12 вікі-крокаў `done`, 0 × 429.
- **F-1 (не выпраўляецца ў гэтым PR): сеткавы транспарт медыя адсутнічае** — гл. крытэр 4. Межа дакументаваная яшчэ ў G17.02/03; пілот паказаў яе маштаб (2812 адмоваў-крокаў на 72 старонках).
- **Назіранне: URL-фрагменты (`#cite_note-N`) ствараюць асобныя запісы.** Паўзук бярэ анкеры з тэксту як ёсць; 15 запісаў `Motława#cite_note-N` маюць той самы `content_hash` і `canonical_url` (звязаныя, не дублі). Пашырае бібліятэку шумам; патэнцыйнае паляпшэнне — зрэзаць фрагменты таго ж хоста пры разглядзе спасылак (па-за абсягам пілота).
- **Назіранне: `&nbsp;` у транскрыптах.** VTT цьюба дае `&nbsp;`-сутнасці, youtube-v1 іх не чысціць (напрыклад, «the best&nbsp; Viewpoint»). Касметычнае; правілы-пакет — змена версіі, па-за пілатам.
