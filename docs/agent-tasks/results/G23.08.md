# G23.08 — запуск скразных тэстаў у CI

Issue: [#666](https://github.com/vokhandcrafts/KUDY/issues/666). Галінка: `codex/666`.

## Вынік

`web-e2e.yml` запускаецца для кожнага PR у `main`. Ён усталёўвае залежнасці з
lock-файлаў, Chromium версіі, замацаванай Playwright 1.63.0, збірае сапраўдны
статычны сайт і запускае `npm run e2e:web`. Памылка тэста спыняе job. Новы job
пакуль неабавязковы: асобнага рашэння ўладара зрабіць яго required няма,
таму `tools/ci/check-required-checks.mjs` не змяняўся.

`android-e2e.yml` запускаецца ўручную і штодня па раскладзе. PR, які змяняе
сам workflow, таксама запускае яго для першай праверкі. Job усталёўвае Android
SDK/AVD, збірае debug APK, запускае эмулятар і паслядоўна выклікае існыя smoke
і walk сюіты. Калі ранер выдае `SKIP`, job падае. Пры няўдачы захоўваюцца логі,
скрыншоты і UI-дампы. Усе `uses:` маюць поўны commit SHA; сакрэты не патрэбныя.

## Крытэрыі і доказы

1. Вэб-зборка і тэсты: `.github/workflows/web-e2e.yml`; лакальна
   `KUDY_CHROMIUM=/usr/bin/chromium npm run e2e:web` — 5 тэстаў прайшлі.
2. Новы check неабавязковы; рашэнне зрабіць яго required не запісана.
3. Android CI: `.github/workflows/android-e2e.yml`; жывы запуск CI — чакаецца.
4. Праверка SHA і выклікаў: `node --test tools/ci/e2e-workflows.test.mjs` —
   3 тэсты прайшлі. [Showboat-доказ](../../demos/2026-10-14-e2e-ci.md)
   прайшоў `uvx showboat==0.6.1 verify`.
5. Няўдалы запуск на часовай галіне і паспяховы запуск — чакаюцца спасылкі CI.
