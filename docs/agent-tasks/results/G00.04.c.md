# G00.04.c result — доказ паўтаральнай зборкі і інтэграцыя высноў

**Дата:** 2026-09-16
**Статус:** `blocked-external` — уся дасяжная на хосце частка доказу зялёная (чыстая копія без env/node_modules: `npm ci` з lockfile, адна копія кожнага натыўнага модуля, `expo-doctor` 18/18, `tsc` чысты, **prebuild android стварыў натыўны праект з кантрактнымі дазволамі**), піны верыфікаваныя па рэестры і запісаныя ў [ADR §6](../../architecture/decisions/G00.04-stack-baseline.md), агульныя дакументы сінхранізаваныя. Але development build Android/iOS і прыладавы інтэграцыйны smoke — `not-run`: на хосце няма Android SDK/ADB (`adb`, `ANDROID_HOME` адсутнічаюць), macOS/Xcode і прылад; EAS-зборка патрабуе акаўнцай сесіі, якой няма. Гэта той самы знешні блокер, што ва ўсіх трох спайках, .a і .b; па ўмове атамаркі такой прыёмкі поўнае `complete` немагчыма.

## Вынік

### 1. Доказ паўтаральнай зборкі на чыстай часовай копіі

Часовая копія `mktemp -d` па-за checkout-ам (не worktree, не скід), у яе скапіяваныя **толькі** scaffold-файлы: `package.json`, `package-lock.json`, `tsconfig.json`, `app.json`, `eas.json`, `index.ts`, `App.tsx`, `.env.example`, `.gitignore` — без env, сакрэтаў, node_modules і асабістых файлаў. Правяраны кантэнт — `package.json`/`app.json` на main (`expo ~54.0.37`, RN 0.81.5, набор без зменаў у гэтай працы).

| Крок | Чакана | Фактычна |
|---|---|---|
| `npm ci` у чыстай копіі | паўторальнае ўсталяванне са strict lockfile | **added 733 packages in 1m** (Windows-хост; дрыфт лічбы па платформах задакументаваны ў development_setup); EBADENGINE — папярэджанне, не памылка (аб'ява 22/npm10, хост 24/npm11) |
| `npm ls expo-asset expo-constants` | па адной копіі кожнага натыўнага модуля | **expo-asset 12.0.13 (deduped ва expo-audio і expo), expo-constants 18.0.14** — дублёў няма, фікс .b трымаецца |
| `npx expo-doctor` | 18/18 | **18/18 checks passed. No issues detected!** |
| `npm run typecheck` | exit 0 | **tsc --noEmit без вываду** |
| `npx expo prebuild --platform android --no-install` | праект генеруецца, плагіны прымяняюцца | **«✔ Finished prebuild»**, `android/` створаны; `AndroidManifest.xml` змяшчае ўсе пяць кантрактных дазволаў лакацыі (`ACCESS_COARSE_LOCATION`, `ACCESS_FINE_LOCATION`, `ACCESS_BACKGROUND_LOCATION`, `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_LOCATION`) і аўдыё (`RECORD_AUDIO`); ланцуг плагінаў expo-location → expo-audio → @maplibre/maplibre-react-native → expo-asset рэзолвіцца без памылак |
| `npx expo prebuild --platform ios --no-install` | платформавая мяжа | карэктная адмова генератара: «Skipping generating the iOS native project files. Run … again from macOS or Linux» |

**Што гэта даказвае:** першая фактычная (не кантрактная) праверка кандыдатных plugin-наладаў і дазволаў з ADR §1 радка «аўдыё/лакацыя» — канфіг прымяняецца да рэальнага натыўнага шаблону; lockfile строгі і ўзнаўляльны. **Чаго не даказвае:** натыўны рантайм (фонавы GPS/аўдыё, рэндэр карты) — гэта толькі development build на прыладзе.

- **react-native-purchases `10.9.1`** — = latest; peers выкананыя.
- **expo `~54.0.37`** — вяршыня лініі SDK 54 (`npm view "expo@>=54.0.37 <55"` → 54.0.37); `dist-tags.latest` → **57.0.23** — навейшая SDK-лінія наўмысна не бралася (кандыдатны набор з верыфікаванай лініі 54).
- **Node/npm:** афіцыйная падлога стэку — поле `engines` react-native `0.81.5`: **node `>= 20.19.4`** (поле expo 54.0.37 пустае); абедзве правераныя лініі (22.23.2/npm 10.9.8 спайку; 24.13.0/npm 11.6.2 сесій .b/.c) — вышэй падлогі. Аб'ява каркаса `>=22.12.0 <23` / `>=10.9.8 <11` застаецца; пашырэнне дыяпазону на 24 LTS — аднарадковая змена `package.json`, якая не ўваходзіць у дазволеныя файлы гэтай атамаркі (уваход для наступніка, ніжэй).
- **Supabase:** пакета ў дрэве няма (кліенцкі каркас не імпартуе; грант-сервер спайку G00.03 — Node без вонкавых `require`, праверана парсам файла). Пін Supabase **непрыдатны** да з'яўлення першага пакета — адкрыты пункт «пін Supabase — .c» зняты як несфарміраваны, бэкенд-пін упершыню запатрабуецца ў G08.
- **npm audit (перагляд):** 19 (10 moderate, 9 high) — як у .b; `npm audit --omit=dev` дае тыя ж 19: дзёркавыя transitive (`uuid@7.0.3`, `postcss@8.4.49`, `image-size@1.2.1`) цягнуцца expo-інструмантарыяй (`@expo/config-plugins`→xcode, `@expo/metro-config`, `@expo/metro`→metro), не прамымі залежнасцямі; прапанованае «выпраўленне» — перастаноўка expo `57.0.23` (скачок SDK) адхіленая. Прынята як задакументаваны рызыка інструмантарыі; перагляд — з чарговай верыфікацыяй SDK-лініі.

- Development build Android/iOS і прыладавы smoke (foreground→background→ручны працяг, offline-map) — `not-run`: няма Android SDK/ADB, macOS/Xcode, прылад; EAS — няма акаўнцай сесіі. - Parent result `G00.04.md` — не дапаўняўся: дапаўняецца пасля апошняй часткі толькі калі ўсе папярэднікі complete (`.a` — decision-required, `.b`/`.c` — blocked-external).
