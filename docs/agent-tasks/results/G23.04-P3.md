# G23.04-P3 — аўдыё загружанага гіда на Android

Issue: [#749](https://github.com/vokhandcrafts/KUDY/issues/749). Дата: 2026-10-13. Аснова: `a865771` (`main`).

## Вынік па крытэрыях

1. **PlayStory адкрывае файл замацаванага пакета.** Каманда рухавіка і аўдыё-пін засталіся адноснымі. На мяжы прылады шлях `be/base/audio/story-1.m4a` дапаўняецца `bundles/<route>/<version>/` і ператвараецца ў `File.uri`. Інтэграцыйны тэст кампазіцыі правярае URI моўнага піну `en` пасля загрузкі і пасля аднаўлення сесіі.
2. **Moment карыстаецца той жа мяжой.** Яго ўжо пакетны шлях падаецца ў той самы рэзолвэр. Нябяспечны, адсутны і пусты файл не даюць URI; пры адсутным файле існы пераход няўдалага прайгравання прыпыняе аўтаматычны гук. Тэсты `expo-package-store.test.ts` і `runSurfaceController.test.ts` правяраюць гэтыя выпадкі.
3. **Праводка і рэгрэсія.** Тэст `G23.04-P3: guide and session Moment use the injected device audio URI boundary` выкарыстоўвае вытворчы Expo-рэзолвэр з сінтэтычнымі файламі і правярае абодва шляхі праз кантролер да плэера. Часовы адкат перадачы `audioUriFor` у `useRunController.ts` зрабіў менавіта гэты тэст чырвоным; пасля аднаўлення ён прайшоў. Поўны прагон уключае ранейшыя тэсты аўдыё-піну, прайгравання і рэстарту.
4. **Прылада.** На чыстым эмулятары `kudy-e2e` (Android 16, API 36) усталяваны debug APK з SHA-256 `d344acd113350ed8a33f488daedb35d2d2f4cdb5786b95453a06b7858837cc0c`. Metro падаў JS гэтай галіны, лакальны G23.01-origin — сінтэтычны бясплатны гід. Каманды запуску: `npm run e2e:origin`, `EXPO_PUBLIC_CATALOG_ORIGIN=http://10.0.2.2:8791 npm start -- --port 8083 --host localhost --clear`, `adb -s emulator-5556 reverse tcp:8083 tcp:8083`, далей `adb shell input tap` і `adb shell uiautomator dump` для назірання. Пасля «Загрузіць» кнопка стала «Пачаць»; пасля Start ручны націск на першую кропку і «Граць» паказаў «гучыць», затым «праслухана». Націск быў ручны: аўтаматычны GPS-трыгер застаецца ў асобным крытэрыі #662. Скрыншоты: [загружана](../../testing/evidence/2026-10-13-issue749/downloaded.png), [гучыць](../../testing/evidence/2026-10-13-issue749/playing.png), [праслухана](../../testing/evidence/2026-10-13-issue749/heard.png); станы uiautomator [падчас гуку](../../testing/evidence/2026-10-13-issue749/playing.xml) і [пасля гуку](../../testing/evidence/2026-10-13-issue749/heard.xml), [праверка прылады](../../testing/evidence/2026-10-13-issue749/device-check.txt). ## Сумежная перашкода SQLite

На першым чыстым прагоне загрузка спынялася на `database is locked` пры `BEGIN IMMEDIATE`: стары Expo-адаптар пакідаў падрыхтаваны statement незачыненым. Адаптар цяпер выклікае `runSync`, `getFirstSync`, `getAllSync`, якія закрываюць свае statements. Тэст `read and write statements release their cursor before a transaction starts` чырванеў з тым жа `database is locked` пры часовым вяртанні старога `prepareSync().executeSync()`; пасля аднаўлення прайшоў. Пасля выпраўлення чыстая загрузка на эмулятары дайшла да Start.
