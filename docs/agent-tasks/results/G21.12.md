# G21.12 — Поўны французскі каталог інтэрфейсу

Issue: [#546](https://github.com/vokhandcrafts/KUDY/issues/546). Дата: 2026-10-05. Уваходны main: `ced4db0` (G22.06 порцыі гісторыі My KUDY, #637). Брыф: `docs/agent-tasks/technical-completion/G21.12.md`; спецы: `docs/specifications/technical-completion/2026-10-03-completion-and-locales.md` + дадатак `2026-10-03-single-source-translations.md`.

## Што зроблена

- `contracts/ui-messages/translations/fr.json` — аўтарскі французскі набор: 280 запісаў (усе домены source.json акрамя трох `native.chrome.languageSelfNames.*` — саманазвы жывуць у рэестры G21.09, не ў перакладзе), усе `review.outcome: approved` са запісам прычыны рэв'ю, `reviewedSourceHash` роўны бягучаму хэшу арыгіналу, файлавы `provenance.kind: "authored"`.
- Рэестр `contracts/ui-locales.ts`: `COMPLETE_UI_LOCALES` = be/en/uk/de/**fr** — рэестр-запіс і каталог прыходзяць разам (канон G21.09); `CompleteUiLocaleCode` пашыраны.
- План генератара `tools/i18n/generate-messages.mjs` (DOMAINS): fr далучаны да ўсіх дзевяці натыўных выхадаў, у тым ліку `native.guideHint` (uk трымае дакументаваны be-фолбэк, у fr словы ёсць), і новы вэб-выхад `web/lib/i18n/fr.ts`.
- Перагенерыраваныя 13 выхадаў генератара (8 натыўных + 5 вэб-файлаў) — нічога не правілася рукамі ў generated-файлах.
- Ручныя селектары (8 ланцугоў): `components/ui-strings.ts`, `components/GuideHintCard.tsx`, `controllers/catalog/previewController.ts`, `controllers/run/runMap.ts`, `controllers/place/placeDetailController.ts`, `controllers/nearby/nearbySurfaceController.ts`, `controllers/commerce/commerceController.ts`, `controllers/useFeedbackController.ts` — галінка fr; невядомая мова як і раней падае на be.
- Вэб: `web/lib/i18n/index.ts` — імпарт fr, `UiStringsLocale = UiLocale | 'uk' | 'de' | 'fr'`, `STRINGS` з fr; жывыя маршруты не мяняюцца (публікацыя маршрутаў — G21.22, той жа прынцып release-unit, што uk і de).
- Глоссарый `contracts/ui-messages/glossary.json`: да сямі запісаў дададзеныя fr-тэрміны (guide, étape, visite, télécharger, indisponible, achat, reprise depuis la session enregistrée) з G21.27-следамі `reviewed-terminology`, лакатары на рэальныя запісы fr.json.
- Тэсты: новы `test/ui-messages-fr-render.test.mjs` (5 тэстаў: селектары-маршруты, лікавыя/названыя формы, composed, вэб-парытэт ключоў); абноўленыя `test/ui-locale-registry.test.mjs` (поўны набор з fr + пазітыўны store.set('fr')), `test/ui-messages-number-render.test.mjs` (fr-рады timeCap), `app/my.test.tsx` (пяты чып пікера «Français» + пазітыўны fr-тэст пераключэння); пробы «няпоўная мова» перанесеныя з fr на es: `controllers/run/runSurfaceController.test.ts` (allowlist-fallback) і `components/guide-card.test.tsx` (empty_locale_catalogue, два тэсты) — fr рэндэрыць свой каталог з G21.12; тая сама рыга-ротацыя, што de→es у G21.10.
- **jscpd-лік** — супольны імпарт-блок дэ- і fr-сют (15 радкоў) стаў клонам пры далучэнні fr: выцягнуты хэлпер `test/ui-locale-families.mjs` (адзін імпарт-паверхня сямействаў селектараў + reason-роўтэры), абедзве сюты (de і fr) пераведзеныя на яго; сцвярджэнні дэ-сюты не мяняліся. Гэта праскрыбільны фікс: наступныя каталогі (cs, sv) бяруць імпарты адтуль жа.

## Acceptance evidence

1. **Поўны набор паведамленняў з native name «Français», усе тыпаваныя домены і подпісы.** Гейт `npm run messages:check` — «shipped locales complete, reviewed and fresh»: план рэндэрыць 280 паведамленняў для fr, усе ёсць; `param_mismatch_denied`/`form_set_mismatch_denied` адсутнічаюць — подпісы параметраў і формы супадаюць з G21.09. Native name «Français» — у табліцы рэестра (тэст рэестра, criterion 1), ніколі не ў перакладзе. Словы даступнасці/прыватнасці/аплаты/дазволаў перакладзеныя (privacy*-блок, offer*, noteDenied).
2. **Формы ліку/даты/лічбаў, доўгія подпісы, empty-станы.** Лікавыя формы timeCap 60/120/240 + інтэрпаляцыя астатнім (`Jusqu'à une heure` / `Jusqu'à 45 min`), названыя формы прэв'ю damaged/missing-files/stale, composed textAudioLine з пустым аўдыё дае «Texte : fr» без хваста; units min/km/Mo; empty-станы каталогаў («Il n'y a pas encore de guides avec du texte dans cette langue.»). ID і гандлёвыя назвы не перакладаюцца (App Store, Google Play, KUDY, langSwitchName «English» — uk-прэцэдэнт). Доступ/статусы не падмененыя (locked → Verrouillé, не планаўка даступнасці).
3. **Праверкі ключоў/параметраў + асобны сэмантычны рэвью.** Механіка — гейт і кантракт-лоўдар (праходзяць); сэмантычны рэвью — асобны другі праход усіх 280 запісаў па пары be||fr са скрынявымі спісамі: рэгістраўная адзінасць (tutoiement, прыбаўленая вы-форма адсутнічае — 0 знаходак), чужыя дэ-тэрміны не працёкчы (0 знаходак), 33 адмаўленні прагледжаныя вочна: «нічога не грае» → «Aucune lecture en cours», «не апублікавана» → «non publié», адмена/незавершанасць пакупкі («Пакупка не скончылася» → «L'achat n'a pas été terminé», «Не цяпер» → «Pas maintenant»), выдаленні/аднаўленні («Supprimer l'évaluation», «Suppression en attente de réseau», restore-канон без рэстаўрацыйнай метафары: «Visite reprise depuis la session enregistrée»). Запіс рэв'ю — у кожным запісе (`review.note`), пратакол рашэнняў — у гэтым файле.
4. **Рэгістрацыя/пікер/публікацыя — не тут.** Пікер выводзіць чыпы з `COMPLETE_UI_LOCALES` (існуючы механізм; fr-чып пакрыты тэстамі пікера), новай UI-працы выбару/захавання/фільтрацыі не правілася — гэта G21.15/G21.17; вэб-маршруты fr не ствараліся — G21.22; пераклад кантэнту і голас — па-за задачай.
5. **Кананічныя даныя + provenance + генерацыя + гейты + адзін каміт усіх моў.** Аўтарства толькі ў fr.json; generated-выхады праз `npm run messages:generate`; `npm run messages:check` зелёны (паўната+рэвью+свежасць); глоссарый прайшоў кантракт з fr-лакатарамі; source.json НЕ змяняўся — таму перагляд be/en/uk/de (G21.19) не патрабуецца, іх запісы не кранутыя.
