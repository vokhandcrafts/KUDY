## Што было вырашана

1. **Правайдар — OpenFreeMap, адзіны канфіг.** Рашэнне заснавальніка вышэй; `lib/map-config.ts` — адзінае месца тайл-URL-аў. Гард `web/lib/map-config.test.ts` (правіла 1): тайл-хосты не сустракаюцца ніде, акрамя канфіга — рэвёрс канфігу на чужы хост або зашыты URL у крыніцах роніць тэст.
2. **Маркеры без фільтра па `access`.** Дэма-фікстура мае `access: "paid"`, `published: false` — і яе рэндэраць існыя каталог і гід-старонкі (ранейшыя PR); набор «апублікаванага бясплатнага» вызначае `catalog.json` (публікацыя — G02.04). Карта чытае той самы набор, што і каталог — без другой інтэрпрэтацыі мяжы.
3. **Атрыбуцыя ODbL серверная і клікабельная** (09 §6.3.1 — юрыдычнае абавязацельства): бачная ў статычным HTML без JavaScript + MapLibre attributionControl; тэкст — з UI-радкоў, URL — з канфігу.
4. **Кліенцкая карта — агляд без узаемадзеяння:** маркеры-кропкі (base — зялёныя, locked — шэрыя), `fitBounds` па маркерах без зашытага цэнтра горада, ніякіх popup'аў/лінкаў/прайгравання; нічога не залежыць ад пазіцыі наведвальніка.
5. **GeoJSON збіраецца ў чытальніку, не ў кампаненце:** `[lng, lat]` парадак зафіксаваны тэстам; без JavaScript старонка паказвае атрыбуцыю і спіс маршрутаў (тэкст).
6. **TR-8 зняты свядома:** старая хоўванія мела guard `mapHref not in page` — ён перавернуты ў адваротнае (`mapHref === '/map'` / `'/en/map'`), каб рэвёрс быў заўважным (правіла 1).
