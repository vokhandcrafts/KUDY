## What was decided

1. **Interim catalog derivation, one implementation.** The catalog envelope is G02.04's publication contract and does not exist in the packager output, and the `catalog-with-discovery.json` fixture references routes the demo bundle does not contain. The prebuild therefore derives `web/content/public/catalog.json` from the built public tree itself (routes by fact, sizes from disk, discovery pointer with `bytes`/`sha256`); `lib/content/interim-catalog.ts` is the single implementation serving both the script and the test fixture. When G02.04 publishes the real pointer, the derivation is deleted, not adapted.
2. **A broken pointer fails the build, never renders empty.** `readSiteCatalog`/`readSiteGuidePage` unwrap every reader result and throw `SiteDataError` with the reader's rejection code (`not-found`, `schema-invalid`, `unknown-locale`, `invalid-preview`); `generateStaticParams` only prerenders cataloged routes. The site layer additionally requires the v1 envelope to carry the discovery pointer (a legacy catalog is a defined build failure).
3. **Locked stops render from `previews.json` only.** `route.json` also embeds a `preview` field per stop, but the closed 09 §5 set in `previews.json` is the public-preview contract; the page data carries exactly `stop_id`, `place_id`, `name`, `announce` plus the renderer's `locked` flag — asserted by the key-set test.
4. **`be` at the root, `/en` prefixed; `uk` gets no page yet.** UI strings exist for be/en per the brief; the demo's uk text shows up as a fact in the languages row (`uk (толькі тэкст)`) and nowhere claims audio. View models keep contract field names verbatim; `href`/`languages`/`stop_count` are site-derived and declared as such.
5. **The calm offer is one block, config-driven, and `/app` is still G10.02.a.** The block resolves every href through `lib/app-links.ts`; empty store URLs render the «хутка» state. The CTA target `/app` does not exist until G10.02.a builds the transition page, and the home's map entry points at the `/map` route step 3 will create — both are documented interim targets of this partially blocked task, not dead ends by design. A committed test forbids literal `href="` and any external URL in `web/app`/`web/components`.
6. **Rendered-output verification without JSX in the runner.** `node --experimental-strip-types` does not transform JSX, so components are not imported by the node tests. Instead the page data is tested directly (9 tests), the rendered export is scanned at build time by `scan-rendered.ts` (wired + revert-guarded), and the demo greps the real HTML (padlock, preview, calm offer, 0 paid-text hits).
