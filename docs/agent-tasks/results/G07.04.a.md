# G07.04.a result — кантракт падказак гідаў побач (R07): ADR, values і фіксчары

**Status: complete (ADR `proposed` — чакае рашэння заснавальніка).** Branch
`zcode/220` (closes issue #220 on merge).

## What was built

- `docs/architecture/decisions/G07.04-guide-hints.md` — ADR, статус
  `proposed`: пяць лікаў з адзінкай і прычынай (§3), жыццёвы цыкл па кантэкстах
  idle/Active/Paused з даслоўнымі цытатамі крыніц (§4), мапінг абароны ад
  паўтораў на `guide_hint_state`/`guide_hint_last` (§5), падзеі даслоўна з
  прынятай табліцы G01.05 (§6), пытанні заснавальніка (§7) і дзеянне (§8).
  Аўдыё-радыус кропкі не пераўжываецца як рэкламны — зафіксавана ў статусе
  схемы і закрытым слоўніку values.
- `contracts/hints/guide-hints.values.v1.json` — машынначытальны файл лікаў
  (`guide_hints_values_version: 1`; 300 м / 100 м / 30 с / 20 с / 3600 с);
  ён жа — positive-прыклад для тэсту.
- `contracts/schemas/guide-hints.schema.json` — draft-07 схема: закрыты
  слоўнік (`additionalProperties: false`), абавязковыя палі, `minimum: 1` на
  усе лічбы.
- `contracts/hints/guide-hints.mjs` — `checkGuideHintValues`: валідацыя па
  схеме праз `reader.mjs` + іменаваныя дыягностыкі (`hint-value-non-positive`,
  `hint-value-non-finite`, `hint-cooldown-required`, `hint-unknown-field`) +
  cross-field правіла `hint-accuracy-exceeds-radius`, якое адзін JSON-дакумент
  выражаць не можа. Псеўданы ўвод дае дыягностыкі, не кідак.
- `contracts/fixtures/guide-hints/invalid-*.json` — чатыры фіксчары, кожны
  ізаляваным парушэннем адной правілы (implementation-rules §14).
- `contracts/contracts.test.mjs` — пяць новых тэстаў: values файл праходзіць
  сваю схему; кожны invalid-фіксчар падае на сваёй named-правіле; псеўданы
  ўвод (null, масіў, 42, радок, дрэнны version) — дыягностыкі без кідка;
  мяжа правілы accuracy (≤ радыуса — збой, менш — праход); не-канечныя
  лічбы (NaN/±Infinity) — дыягностыка `hint-value-non-finite` (праграмны
  ўвод: JSON такіх літэралаў не мае).

## Evidence (per criterion)

1. **Лікі з нумарам, адзінкай і прычынай; аўдыё-радыус не рэкламны** — ADR §3
   (табліца пяці параметраў з прычынамі пачатковых лікаў, анкеры на `15` R07 і
   `11` §13); закрыты слоўнік схемы адхіляе `audio_trigger_radius_m`
   (`invalid-unknown-field.json` → `hint-unknown-field`).
2. **Жыццёвы цыкл па кантэкстах** — ADR §4: idle (падпіска па адкрытай
   паверхні, зняцце пры закрыцці/фоне), Active (агульны паток прынятых
   фіксаў, без змены геафенсаў), Paused (падказкі выключаныя, GPS не
   аднаўляецца); цішыня пры аўдыё/званку/камерцыйным дыялогу/ручной блакіроўцы;
   пасля аўдыё — рашэнне толькі па свежым фіксе, без чаргі.
3. **Абарона ад паўтораў на існуючых назвах** — ADR §5; абедзве радкі табліцы
   ADR G01.03 §3.9 скапіяваныя даслоўна (праверана `grep -F`: байт-у-байт з
   крыніцай); перанос на Start у транзакцыі Start; перажыванне restart;
   cooldown — `guide_hint_last` + `foreground_cooldown_s`.
4. **Падзеі даслоўна з табліцы G01.05** — ADR §6: імёны
   `guide_nearby_shown/opened/dismissed`; `suggestion_id` (identifier,
   required), `shown_guide_ids` (масіў identifier, `minItems: 1`, required),
   `context` (enum `idle|active`, required), `session_id` толькі пры наяўнасці
   сесіі; `local_recording: always`, `sending: consent_gated`; без каардынат,
   трэка, адлегласцей і URL.
5. **Іменаваныя дыягностыкі + тэст падае пры зняцці правілы** — зваротныя
   эксперыменты:
   - зняты `foreground_cooldown_s` са `required` схемы → тэст
     «each invalid values fixture fails on its own named rule» падае
     (22 pass / 1 fail);
   - знятая cross-field правіла з `guide-hints.mjs` → падаюць тэст фіксчараў і
     мяжы accuracy (21 pass / 2 fail).
   Абодва эксперыменты адноўленыя; фінальная суіта зялёная. Правіла
   `hint-value-non-finite` (знаходка код-рэвью: NaN/±Infinity абходзяць
   `minimum` схемы) мае праграмны negative-тэст — JSON літэралаў NaN/Infinity
   не мае, таму фіксчара для яго быць не можа.
6. **Адкрытыя кропкі — рашэнні заснавальніка** — ADR §7 (пяць пытанняў) і §8.

## The honest boundaries

- **Values — прапанова**: нішто ў дадатку яшчэ не чытае
  `guide-hints.values.v1.json`; падключэнне `services/config` — G07.05 пасля
  прыняцця ADR заснавальнікам.
- **Адлік dwell** — прапанова «ад першага прыдатнага фіксу ў зоне» (пытанне 2
  ADR §7): крыніцы не вызначаюць сэмплінг GPS; прыняцце можа змяніць трактоўку.
- **Каліброўка G11.02** не правіць гэты ADR сама па сабе — толькі праз
  асобную змену кантракта (запісана ў статусе ADR).
