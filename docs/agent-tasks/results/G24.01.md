### 3.4 Word mark vs combined (word + dragon) — the verified rule and the trade-off

Verified rule (EUIPO practice; EUTMR — the sign is protected **as registered**): a **word mark** protects the word in any visual form; a **figurative/combined mark** protects the composite as filed, with weight on its distinctive elements — it does **not** protect the word standing alone. Sources: [EUIPO Guidelines](https://guidelines.euipo.europa.eu) (comparison of marks; figurative elements), corroborated by practitioner analyses of CJEU practice.

Trade-off for KUDY: the combined word+dragon mark carries the brand identity (08.10 recommendation), but if only the composite is registered, competitors could use the bare word "KUDY". Conversely, a bare word mark is the strongest defence of the name but is exposed to the Czech/Slovak descriptiveness argument (§1.3). This is exactly attorney question Q2 — do **not** pre-decide here.
