## Праблема і выбар

Цяперашні `heard: Set<stop_id>` не адрознівае два наратывы адной кропкі. Праслухаў base → купіў extended: новая гісторыя не павінна стаць played ад старога факта. Асобны файл на кропку сам гэтага не вырашае.

Асноўная прапанова P01: адзін асноўны story для аўтаматыкі, асобны дадатковы story для ручнога Play; `auto_fired` па stop_id, праслухоўванне па story_id у замацаванай версіі сесіі. Параўнай яе з заменай асноўнага аўдыё пашыраным; апішы кошт і наступствы, дай канкрэтную рэкамендацыю. Не прадстаўляй прапанову як прынятую без рашэння заснавальніка. Да прыняцця можна напісаць табліцу сцэнароў і прапанаваны кантракт, але не перапісаць нарматыўную мадэль паводле непацверджанага выбару.

## Крытэрыі прыёмкі

| Сцэнар | Чаканы вынік |
|---|---|
| Base скончыўся, extended толькі адкрыўся | Base heard, extended не heard; сесія тая ж; няма новага Play |
| Extended выбраны рукамі, перапынены, запушчаны зноў | Не heard да ўласнага AudioFinished; іншыя heard захаваныя |
| Paid-only stop заблакаваны, затым same-version AccessReady | Да адкрыцця не грае; пасля — звычайная прыдатная кропка, без запуску ад самой пакупкі |
| Чалавек слухаў асноўны рукамі да падыходу | Падыход не дае паўторнага асноўнага аўтагуку |
| У чарзе stop, чалавек паспеў праслухаць яго асноўны рукамі | Чарга не паўтарае ўжо праслуханае |
| Спознены callback старога story/play/session | Не залічвае бягучы наратыў |
| Падыход у іншым парадку, End пасля адной гісторыі | Няма ўмовы position, няма прымусовага завяршэння |

## Кантэкст, які не трэба шукаць у размове

KUDY — аўтарскі гарадскі гайд. Першы горад — Гданьск, першая аўдыторыя і аўдыё — беларускія; UI BE/EN. Горад → Гіды → канкрэтны гід; іншыя рубрыкі могуць існаваць без прагулкі. Кожная гісторыя мае асобны аўдыёфайл і транскрыпт. Парадак кропак вольны, рэкамендаваны шлях неабавязковы, End магчымы пасля любой гісторыі.

Аўтагук толькі абранага гіда пасля яўнага Start, для даступнага кантэнту пры свежай пазіцыі і dwell. Ручны Play не патрабуе блізкасці. Moments адкрываюцца рукамі і самі не гавораць. Падказка іншага гіда паблізу — ціхая foreground-картка, не аўтастарт; у Paused/падчас аўдыё/ў фоне яе няма (R07 у `15`). Адзін плэер і адзін уладальнік геалакацыі. Паўза/званок не лічацца праслухоўваннем; пасля іх няма аўтапрацягнення без чалавека. Перапынены файл можна запусціць з пачатку.

Start патрабуе поўнага праверанага выбранага пакета. Аплата ≠ загрузка. Locked мае публічны анонс, але не поўны тэкст/медыя. Права выдае сервер, не сцяг кліента. Версія сесіі замацаваная да End, у тым ліку пасля restart і на наступны дзень. Лакальны прагрэс і ліміты падказак не залежаць ад згоды на серверную аналітыку. Імпарт чужых гідаў, фонавыя discovery-паведамленні, акаўнты і маркетплэйс — не гэтая задача.
