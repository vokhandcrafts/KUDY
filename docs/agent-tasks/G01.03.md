1. Ствары `docs/architecture/decisions/G01.03-session-access.md` з канчатковымі імёнамі/тыпамі/nullable/default для persisted session і вытворных палёў. Для кожнага — уладальнік, крыніца праўды, момант запісу/аднаўлення. Не дубліруй гатоўнасць файлаў як незалежны некантраляваны сцяг.
2. Зафіксуй Start/Resume/End/switch-guide як транзакцыйныя межы: не больш за адну active/paused сесію; новы session_id для паўтору; аднаўленне не запускае гук само. Памылка durable-міграцыі не дазваляе сцерці базу.
3. Развядзі entitlement, загружаныя і правераныя файлы, прыдатны наратыў і стан праслухоўвання. Вызнач trusted AccessReady з ідэнтычнасцю патрэбнага route/version/locale/tier; позняя загрузка старой сесіі не муціруе новую. Паўторная падзея ідэмпатэнтная.
4. Для free Start патрабуй поўны выбраны base, не closed extended. Для upgrade — поўны same-version пласт, атамарная актывацыя, без скіду праслухоўвання і аўтагуку. Пры паспяховай аплаце і збоі файлаў — паўтор загрузкі, не аплата нанова.
5. Версія не мяняецца падчас active/paused. Апішы частковую staging-загрузку, crash на verify/activate/persist, адсутны файл пасля restart, новую версію каталога, ачыстку пакета і адкат каталога. Стары працаздольны пласт не выдаляецца пры няўдалым upgrade.
6. Апішы лакацыю R07 shown/dismissed і перанос з foreground-scope у session пры Start. Калі cooldown яшчэ не вызначаны ў G07.04, перадай гэтую задачу як уладальніка параметра, не прыдумляй лічбу. Аналітычная згода не кіруе лакальнымі лімітамі.
7. Аддзелі session lifetime ад сервернага retention старых версій. Калі старое пашырэнне недаступнае — чэсны стан без падмены файлаў; не вызначай новы тэрмін захавання без эксплуатацыйнага рашэння G11.03.

## Крытэрыі прыёмкі

| Сцэнар | Вынік |
|---|---|
| Start пры partial або hash mismatch | Няма active сесіі і аўдыё; паказаны стан загрузкі |
| Купіў, сетка знікла | Права не губляецца, файл не ready, няма паўторнай аплаты |
| Base праслуханы → поўны same-version upgrade | Прагрэс захаваны паводле G01.01, дадатковае не heard, няма аўтагуку |
| Чужы route/version/locale або стары completion | Няма актывацыі ў чужой сесіі |
| Crash каля activate/persist | Пасля аднаўлення адзін адназначны стан; partial не выдаецца за ready |
| Дзве спробы Start або switch адначасова | Не больш за адну active/paused сесію; старая гісторыя не выдалена |
| Паўза ўчора → новая версія каталога сёння → Resume | Старая версія і прагрэс захаваныя |
| Выдаленне выкарыстоўванага пакета | Пакуль сесія не завершана — файлы не выдаленыя |
| Restart без згоды на аналітыку | Heard і R07-ліміты захаваныя, адпраўкі няма |

## Кантэкст, які не трэба шукаць у размове

KUDY — аўтарскі гарадскі гайд. Першы горад — Гданьск, першая аўдыторыя і аўдыё — беларускія; UI BE/EN. Горад → Гіды → канкрэтны гід; іншыя рубрыкі могуць існаваць без прагулкі. Кожная гісторыя мае асобны аўдыёфайл і транскрыпт. Парадак кропак вольны, рэкамендаваны шлях неабавязковы, End магчымы пасля любой гісторыі.

Аўтагук толькі абранага гіда пасля яўнага Start, для даступнага кантэнту пры свежай пазіцыі і dwell. Ручны Play не патрабуе блізкасці. Moments адкрываюцца рукамі і самі не гавораць. Падказка іншага гіда паблізу — ціхая foreground-картка, не аўтастарт; у Paused/падчас аўдыё/ў фоне яе няма (R07 у `15`). Адзін плэер і адзін уладальнік геалакацыі. Паўза/званок не лічацца праслухоўваннем; пасля іх няма аўтапрацягнення без чалавека. Перапынены файл можна запусціць з пачатку.

Start патрабуе поўнага праверанага выбранага пакета. Аплата ≠ загрузка. Locked мае публічны анонс, але не поўны тэкст/медыя. Права выдае сервер, не сцяг кліента. Версія сесіі замацаваная да End, у тым ліку пасля restart і на наступны дзень. Лакальны прагрэс і ліміты падказак не залежаць ад згоды на серверную аналітыку. Імпарт чужых гідаў, фонавыя discovery-паведамленні, акаўнты і маркетплэйс — не гэтая задача.
