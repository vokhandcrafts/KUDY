# G27.02 — Add the Settings route and move the UI-language control

## Epic

Epic: #346

## Goal

Give KUDY one Settings entry and one UI-language picker without changing the active walk's pinned content or audio language.

## Acceptance criteria

1. [ ] KUDY opens Settings and Back returns to KUDY without ending, pausing or changing an active Run. The two-tab navigation remains intact.
2. [ ] Move the existing UI-language control to Settings using the same store and open-locale registry. Switches re-render UI copy in place, persist as before and do not change text/audio pins.
3. [ ] Render real settings rows only; preserve large text, screen-reader names, offline use and an honest error state for failed preference persistence.

## Out of scope

New content locales, dark tokens, guide filtering, achievements and account profiles.

## Dependencies

Blocked-by: #781, #774, #775.

## Proof

Navigation and locale tests fail if the route, single store or Run isolation is reverted; Showboat screen proof when runtime changes land.
