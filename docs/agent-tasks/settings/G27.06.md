# G27.06 — Test one earned dragon accessory

## Epic

Epic: #346

## Goal

Decide from one small and large rendering whether an earned accessory can add delight while preserving the real figurine's silhouette.

## Acceptance criteria

1. [ ] After #776 and the collection pilot, draw one reversible accessory on the approved dragon asset at 32/48 px and on a large scene; record recognizability and contrast evidence in both themes.
2. [ ] Prototype explicit equip/remove, locked, unavailable-asset and reduced-motion states. An accessory is tied only to an approved, verifiable achievement and does not change the base dragon image.
3. [ ] Present an owner go/no-go verdict and a concrete follow-on implementation issue only if the pilot is accepted; keep this task as design/prototype until then.

## Out of scope

A full wardrobe, paid cosmetics, random drops or silently equipping on unlock.

## Dependencies

Blocked-by: #785, #776.

## Proof

Editable asset and phone-size comparison sheet, state prototype and recorded owner verdict. No runtime claim from mockups.
