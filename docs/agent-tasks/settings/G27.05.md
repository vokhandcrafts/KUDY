# G27.05 — Link settings to an honest collection view

## Epic

Epic: #346

## Goal

Show the collection entry only when the collection can display provenance and the approved achievement state accurately.

## Acceptance criteria

1. [ ] Reuse G25.05's approved visual states after #769; distinguish user-saved souvenir from condition-verified achievement in visible copy and accessibility names.
2. [ ] Show a truthful empty/unknown state and hide the Settings entry until the feature is released. Opening the view never starts audio or asserts a physical visit.
3. [ ] Read the durable collection record from #789 without relabeling unknown provenance; test the empty, saved, verified and unknown states.

## Out of scope

Inventing achievement conditions, persistence schema, full gamification, counters, treasure hunts or accessory unlocks.

## Dependencies

Blocked-by: #782, #769, #789.

## Proof

State/provenance tests fail if a saved souvenir is mislabeled as an achievement; Showboat demonstrates entry and empty/detail states.
