# G27.04 — Persist guide preferences and filter suggestions

## Epic

Epic: #346

## Goal

Let a person hide unwanted guide suggestion groups and restore the unfiltered view without losing access to any guide.

## Acceptance criteria

1. [ ] Store a set of excluded community-angle and guide-depth (`audience_level`) groups locally, with default show-all, multiple exclusions, reset and a migration/unknown-tag rule; selected chips mean “hide.” Changes work offline and survive restart. The depth choices use G27.01’s approved guide aggregation and the index output from G27.03, not a second depth field.
2. [ ] Apply exclusions to the browsable Guides list and discovery recommendations, with a visible show-all escape. Explicit search, direct links, purchased/saved/downloaded guides and active Run remain reachable; unknown/untagged offers remain visible.
3. [ ] Amend canonical 21 §4 with the presentation step after `selectDiscovery`: filter exact and alternatives before display, preserve order and the closed `reasons`/`differences`, and show a filtered-empty explanation plus “show all.” An authored tag may label a card but must not claim the user selected it. Add negative tests for mixed tags, empty exact/alternatives, unknown tags and stale catalogs.

## Out of scope

Location/SIM inference, remote user profiles, entitlement changes and new guide content.

## Dependencies

Blocked-by: #782, #783.

## Proof

Selector and UI tests fail if the default, community/depth exclusion step after selection or escape action is removed; Showboat proves a filtered and reset flow.
