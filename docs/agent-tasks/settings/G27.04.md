# G27.04 — Persist guide preferences and filter suggestions

## Epic

Epic: #346

## Goal

Let a person hide unwanted guide suggestion groups and restore the unfiltered view without losing access to any guide.

## Acceptance criteria

1. [ ] Store preferences locally with default show-all, multi-select interests, reset and a migration/unknown-tag rule; changes work offline and survive restart.
2. [ ] Apply preferences to the browsable Guides list and recommendations, with a visible show-all escape. Explicit search, direct links, purchased/saved/downloaded guides and active Run remain reachable; unknown/untagged offers remain visible.
3. [ ] Explain a personalized card's reason only when backed by an authored tag. Empty results name the filter and offer one action to show all guides. Test mixed tags, zero results and stale catalog revisions.

## Out of scope

Location/SIM inference, remote user profiles, entitlement changes and new guide content.

## Dependencies

Blocked-by: #782, #783.

## Proof

Selector and UI tests fail if the default, exclusions or escape action is removed; Showboat proves a filtered and reset flow.
