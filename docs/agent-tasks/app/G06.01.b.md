## Allowed outputs

- `app/route/[id].tsx` — the preview surface: cover, stops (locked stops show name, place, short teaser and lock only — no full texts, transcripts or media in the preview, NAV5), the counts line, languages per availability (L01: text without audio must not promise audio), `free_stop_count` for paid, the tariff badge.
- The preview controller (extends the catalog controller or sits beside it): preview state per `route_id`; the main button's state derives from the real inventory state (`not_downloaded` → `partial` → `ready` → `stale`) and access — never from fiction; the verify-failure reason is carried to the surface (11 §7).
- Preview data assembly in the catalog service/controller from route entry facts (and route.json through a safe public path where the guide provides one) — the shared `contracts/reader.mjs` reader, no second parser.
- Button wiring: `Download` triggers the existing download flow (G04.02 services; fake ports in Node tests) and flips to `Start` on completion; `Start` hands over to the run controller (G05.05); with an active or paused session the single confirm dialog of 11 §4.1 opens and «Скасаваць» changes nothing (NAV8); `Start` for paid stays disabled with a stated reason until access exists (the purchase flow itself is G08).
- Tests, `docs/demos/<YYYY-MM-DD>-g0601b-guide-preview.md`, `docs/agent-tasks/results/G06.01.b.md`.

## Acceptance

1. [ ] Metadata is visible: languages per availability, the recommended route time (`estimated_duration` range or `duration_min`), open and locked stops distinguishable; locked stops show name, place, teaser and lock only (NAV5).
2. [ ] Tariff is not mixed into the rubric or the content: free/paid badge; the paid preview shows `free_stop_count` and does not start — the button is disabled with its reason shown, and no purchase is triggered from the preview (NAV6, D06, 11 §7).
3. [ ] The main button has exactly one meaning: `Download` while the package is not fully on disk, `Start` when ready (09 §6.5); the state follows the inventory, and after the download completes the same button becomes `Start`; `Start` with an active or paused session opens the single confirm dialog of §4.1 and cancelling changes nothing (NAV8).
4. [ ] Back returns to the source surface the preview was opened from (rubric or city card), leaving session, audio and progress untouched (NAV9, 11 §16.2); opening the preview records that source surface.
5. [ ] A package verify failure leaves `Start` unavailable with the reason shown (11 §7); `npm run typecheck`, `npm test`, `npm run arch:check`, `npx expo-doctor` green; layer rules intact.
