# G06.10.b — Font layer: Golos Text, Alegreya, Caveat

**Status:** not-started. **Model class:** medium. **Dependencies:** G06.10.a closed (the font tokens and their rights records live in the canon). Parent task: G06.10 ([16 design block](../../16_delivery_backlog.md)).

## Scope

Load the three approved font families and put them to work on a real surface, eyes of the user: interface text renders in Golos Text, guide and story titles in Alegreya, the dragon-voice token is registered for its first surface. System-ui stays the fallback everywhere until a family is loaded; the big-text multiplier (canon §9) keeps working.

Read: [visual-language.md](../../design/visual-language.md) §3 (fonts and rights) and §9 (big text), the parent [G06.10.md](G06.10.md), [implementation-rules](../../agent-rules/implementation-rules.md).

## Allowed outputs

- `package.json` + `package-lock.json` — font packages pinned exactly as `npx expo install --check` accepts for SDK 54 (official `@expo-google-fonts/*` packages; if the Alegreya package does not exist, self-host the OTF/TTF with the OFL file next to it and record that in the results)
- the font-loading module of the root composition (named per-weight exports — one family per weight, the Android workaround; the loading gate does not block rendering past the timeout)
- `components/design-tokens.ts` — the font-family mirror of the canon tokens (the guard pins this file to the canon)
- `components/screen-styles.ts` and the surfaces that consume it — UI family on interface text, display family on screen/guide titles
- render tests (`app/**/*.test.tsx`) proving the families on a real surface; `docs/demos/<YYYY-MM-DD>-g0610b-fonts.md`, `docs/agent-tasks/results/G06.10.b.md`

## Acceptance

1. [ ] On the guide preview surface the guide title renders with the display family and the metadata/body with the UI family; a render test asserts the font-family values through the token mirror, not through hardcoded strings.
2. [ ] Belarusian and English samples both render (ў/і and Latin glyphs present in the loaded weights) — checked in the demo screenshots.
3. [ ] The dragon-voice family is loaded and exported as a token; the render test asserts the token resolves to the Caveat family (its first interface surface is the dragon hint card, G07.04 — not this task).
4. [ ] With fonts still loading (and in tests without them), every surface falls back to system-ui and stays readable; the big-text multiplier applies to the new families (render test with the big-text factor).
5. [ ] Every new dependency pin and its source are recorded (ADR G00.04 §6 style note in the results file); `npx expo-doctor` passes.
6. [ ] `npm test`, `npm run typecheck`, `npm run arch:check` and the copy-paste gate are green.

## Out of scope

Any icon work (G06.10.c); button styles (d); backgrounds (e); animation (f); the dragon hint card surface; subsetting/compressing fonts; changing any color or contrast pair.

## Proof

Point the token mirror of the UI family back to system-ui → the render test that asserts Golos on the preview surface fails; restore → green. Showboat: required (user-visible runtime behaviour — screenshots of the preview in BY and EN).
