# G06.10.a — The approved style package in the visual canon

**Status:** not-started. **Model class:** medium. **Dependencies:** none — the first task of the row. Parent task: G06.10 ([16 design block](../../16_delivery_backlog.md)).

## Scope

Write the founder-approved style package (founder quiz 2026-09-29, two rounds) into the single design source, so every later task consumes the canon and not the demo. The canon gains: two derived shelf shades for buttons (darker tensions of the existing accent and line colors — not new brand colors), three font families (UI sans Golos Text, display serif Alegreya, dragon handwriting Caveat) with usage rights, and a paper-grain token with an explicit list of allowed and forbidden places. The token guard is extended to police all of it.

Read: [visual-language.md](../../design/visual-language.md) (whole file — §3 fonts and rights, §5 components, §9 street readability, §10 change rules), [06 §1, §5](../../06_brand_and_promotion.md), the parent [G06.10.md](G06.10.md), [implementation-rules](../../agent-rules/implementation-rules.md). The demo `spikes/2026-09-29-style-showcase.html` is the visual reference only — never a source of values.

## Allowed outputs

- `docs/design/visual-language.md` — new tokens in the machine JSON block with `use` rules; the license records of the three fonts (OFL, embeddable, official source/package, link to the license text); a §10-compatible note on why the shelf shades carry no contrast pair (decorative reinforcement; the text pair `accent-ink`/`accent` is unchanged); the grain token with allowed/forbidden places (never Run, never under dense body text)
- `test/design-tokens.test.mjs` — guard extensions: a token without `use` fails; a font token without a license record fails; existing contrast pairs and the draft-prototype consistency stay green
- `docs/demos/<YYYY-MM-DD>-g0610a-style-canon.md`, `docs/agent-tasks/results/G06.10.a.md`

## Acceptance

1. [ ] The machine JSON block of the canon contains the shelf shades, the three font tokens and the grain token; every new token has a non-empty `use` rule; no existing token, marker color or contrast pair changed a value (diff shows additions only).
2. [ ] Each of the three fonts has a rights record in the canon per §3: license (OFL 1.1), embedding allowed, official source, self-host/package note, link to the license text.
3. [ ] The guard fails when any new token's `use` is emptied and when any font token's license record is removed; it passes again after restoring them (shown in the demo, then restored).
4. [ ] `npm test` (including the extended guard), `npm run typecheck`, `npm run arch:check` and the copy-paste gate are green.

## Out of scope

## Proof
