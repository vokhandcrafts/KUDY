# G06.10.e — Paper grain background

**Status:** not-started. **Model class:** medium. **Dependencies:** G06.10.a closed (the grain token and its allowed-places rule live in the canon). Parent task: G06.10 ([16 design block](../../16_delivery_backlog.md)).

## Scope

The calm screens get the founder-approved paper feel: a very light grain (4–5% opacity) tiled over the paper background on Explore and My KUDY. The asset is generated in-repo (no third-party rights), the paper color value itself is unchanged, and the grain never appears on Run/map surfaces or under dense body text — the canon's allowed-places rule is the contract.

Read: [visual-language.md](../../design/visual-language.md) §2 (paper), §9 (contrast), the parent [G06.10.md](G06.10.md), the current screen-frame styles, [implementation-rules](../../agent-rules/implementation-rules.md).

## Allowed outputs

- a small generated tile asset (e.g. a PNG produced by a committed one-shot script in `tools/`; the script and the asset both live in the repo; no third-party assets)
- a shared paper-surface component or a screen-styles extension in `components/` that layers the grain over the paper color
- the two tab surfaces (Explore, My KUDY) consuming it; nothing else
- a component test (grain layer renders under content, opacity within the token rule, children unaffected) and a screen test that Run does not gain the grain; `docs/demos/<YYYY-MM-DD>-g0610e-grain.md`, `docs/agent-tasks/results/G06.10.e.md`

## Acceptance

1. [ ] Explore and My KUDY render the grain over the paper; the paper token value is unchanged (diff on the token mirror shows no color change), so every existing contrast pair stays measured-and-green.
2. [ ] Run/map surfaces do not consume the grain (test asserts the shared wrapper is absent there); the canon's allowed-places list matches the code.
3. [ ] The tile is generated by the committed script from a seed (regenerating produces the same asset — determinism recorded in the results); no third-party file entered the repo.
4. [ ] Demo screenshots of both surfaces in BY and EN show the grain is felt but the text stays crisp; the screen-reader tree of a surface is unchanged (the grain layer is hidden from accessibility).
5. [ ] `npm test`, `npm run typecheck`, `npm run arch:check` and the copy-paste gate are green.

## Out of scope

Warm band, dots, skyline backgrounds; any Run/map styling; web/; changing the paper color or adding contrast pairs; the dragon-line illustrations.

## Proof

Remove the grain layer from the shared wrapper → the surface test fails (and the demo screenshot pair changes); restore → green. Showboat: required (user-visible runtime behaviour — before/after screenshots).
