# G06.09.a — Expo Router and the navigation skeleton

**Status:** not-started. **Model class:** medium. **Dependencies:** G00.04 (#10) and G01.04 (#109) closed. Parent task: G06.09 ([16 row G06.09](../../16_delivery_backlog.md)).

## Scope

Replace the placeholder `App.tsx` with Expo Router and the route files that 19 §2.5 names, as empty placeholder screens. No product visuals: those are gated by G06.06–G06.08. This part gives later G05/G06/G07 tasks a real app to mount into.

Read: [09 §6, §6.5](../../architecture/09_technical_architecture.md), [11 §16](../../11_run_interaction.md) (navigation contract G01.04: sequence, Back, return to Run), [19 §2.5–§2.6, §4.2](../../architecture/19_class_and_module_map.md), [ADR G00.04](../../architecture/decisions/G00.04-stack-baseline.md) §1 and §6 (pins and how they were verified), [development_setup](../../development_setup.md), [implementation-rules](../../agent-rules/implementation-rules.md).

**Device decision (2026-09-23, founder):** this wave runs without a device or Android SDK. Proof runs on the host: component tests, `tsc`, `expo-doctor`, `expo prebuild --platform android --no-install`. A dev build on a phone is `not-run` and is listed in the results file.

## Allowed outputs

- `app/` — `_layout.tsx`, `(tabs)/explore.tsx`, `(tabs)/my.tsx`, `city/[id]/guides.tsx`, `route/[id].tsx`, `run/[id].tsx`, `map.tsx`, `+not-found.tsx`
- `index.ts`, `App.tsx` (removed or reduced to the router entry), `app.json` (`scheme`, router plugin), `package.json` + `package-lock.json` (router and its required peers only), `tsconfig.json` if the router needs it
- `.dependency-cruiser.cjs` — a rule that `app/` does not import `services/`
- a component test runner for `app/` (`jest-expo` with `expo-router/testing-library`, exact pins), its config, and an `npm test` entry that runs it after the existing `node --test` suites; `app/**/*.test.tsx`
- `docs/development_setup.md` — how to start the router app; ADR G00.04 §6 — the new pins with their source
- `docs/demos/<YYYY-MM-DD>-g0609a-router-skeleton.md`, `docs/agent-tasks/results/G06.09.a.md`

## Acceptance

1. [ ] Every route of 19 §2.5 exists and renders a placeholder that names the screen and its route params; an unknown path renders `+not-found`, not a crash. A `renderRouter` test renders each route by URL.
2. [ ] The navigation order matches 11 §16.1–§16.2: City → Guides → preview → Run; Back from Run returns to the previous screen without ending anything (there is no session yet — the screen says so). A `renderRouter` test walks this path by pressing the placeholder links and pressing Back.
3. [ ] New dependencies are pinned to exact versions that `npx expo install --check` accepts for SDK 54; `npx expo-doctor` passes; each pin and its source are recorded in ADR G00.04 §6.
4. [ ] `npm run typecheck`, `npm test` and `npm run arch:check` are green; the new `app/ ↛ services/` rule fails on a deliberate violating import (shown in the demo, then removed).
5. [ ] `npx expo prebuild --platform android --no-install` on a clean copy still produces the manifest with the five location permissions of ADR G00.04 §1; the output is recorded, the generated `android/` folder is not committed.
6. [ ] The dev build on a device is listed as `not-run` with the exact command to run it later (`eas build --profile development --platform android` or a local `expo run:android`).
