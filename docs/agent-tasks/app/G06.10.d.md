# G06.10.d — Clay buttons: the shelf and the dip

**Status:** not-started. **Model class:** medium. **Dependencies:** G06.10.a closed (the shelf shades are canon tokens). Parent task: G06.10 ([16 design block](../../16_delivery_backlog.md)).

## Scope

The primary button of a screen becomes "clay": a bottom shelf (a darker tension of the accent color, ~4px) and a visible dip on press — the button sinks into the shelf. The secondary button gets the same treatment with the line-color shade. The existing unified pressable behavior (the ≥10% dim, the Android ripple) is kept on top of it; focus outline, disabled state with the reason nearby, and "one primary action per screen" (canon §5) are unchanged.

Read: [visual-language.md](../../design/visual-language.md) §5 (buttons, focus), §9 (contrast), the parent [G06.10.md](G06.10.md), the current pressed wrapper and the walk button (their tests too), [implementation-rules](../../agent-rules/implementation-rules.md).

## Allowed outputs

- the shared pressable wrapper and the walk button — the shelf styles and the pressed dip (translate + shelf reduction) derived from the canon shelf tokens; the ripple and dim stay
- the surfaces that render the primary action (guide preview Download → Start) and the secondary actions they already own
- tests: the pressed-state test of the wrapper extended (dip applies on press, shelf color from tokens), the walk-button test (shelf on primary, disabled contract unchanged)
- `docs/demos/<YYYY-MM-DD>-g0610d-clay-buttons.md`, `docs/agent-tasks/results/G06.10.d.md`

## Acceptance

1. [ ] On the guide preview the primary action renders the accent shelf; pressing it visually dips (translate plus reduced shelf) while the dim/ripple still fire — asserted by the extended pressed test.
2. [ ] The shelf colors are read from the canon shelf tokens through the token mirror; overriding a token changes the rendered shelf (test), no hardcoded literals in components.
3. [ ] The disabled contract is untouched: opacity 0.5, no dip fires on a disabled press (test), the reason stays next to the button.
4. [ ] The focus outline rule (canon §5) still applies to the buttons; the text-on-accent contrast pair is unchanged and the guard stays green.
5. [ ] `npm test`, `npm run typecheck`, `npm run arch:check` and the copy-paste gate are green.

## Out of scope

Pill buttons, icon-round buttons, gradient/glass experiments; new colors beyond the two shelf shades; the Run panel's own buttons except the shared primary styling; web/.

## Proof

Point the shelf color back to a hardcoded literal (or remove the dip styles) → the pressed/walk-button tests fail; restore → green. Showboat: required (user-visible runtime behaviour — a recorded press or before/after screenshots).
