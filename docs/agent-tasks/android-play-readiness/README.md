# Задачы пасля аўдыту Android і Google Play

Крыніца: [жывая матрыца](../../audits/android-google-guidelines.md), праверка 2026-10-17. Гэты індэкс звязвае кожны адкрыты радок матрыцы з вынікам, які можна прыняць. Сцяжок у матрыцы мяняецца толькі пасля доказу, не пасля стварэння issue. Праца па выпраўленнях тут не пачыналася.

Публікацыя індэкса і матрыцы чакае merge [PR #803](https://github.com/vokhandcrafts/KUDY/pull/803). Кожнае GitHub issue мае самадастатковае заданне; да merge PR выканаўца не павінен лічыць гэты шлях даступным у `main`. Статусы `agent:ready` не ставяцца толькі таму, што задача апублікаваная. Бацькоўскі рэлізны трэк — існае [#299](https://github.com/vokhandcrafts/KUDY/issues/299); новы паралельны эпік не ствараецца.
