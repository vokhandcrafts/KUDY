## Межы паралельнасці

G01 ідзе паслядоўна: агульная мадэль і назвы палёў. G00-спайкі ізаляваныя ў сваіх папках; іх .b/.c не змяняюць код .a ціха. G00.04 інтэгруе root-канфіг толькі пасля доказаў спайкаў. Яго запіс агульных дакументаў не перасякаецца з G01.*.c. Праца ў цяперашнім checkout, без worktrees і reset.

Кантрактная частка вырабляе рашэнне, мадэльная — паводзіну з тэстамі, прыёмачная — доказ гатовай паводзіны. Parent complete толькі калі ўсе яго часткі complete; старыя бацькоўскія briefs не запускаць цалкам.
