# G21.10 — Add the complete German UI catalogue

## Epic

Epic: #532

## Goal

All shipped native and web interface message domains have reviewed German phrases; this does not promise German guide narration.

## Scope

contracts/ui-messages/translations/de.json (G21.24/G21.25 schema); generated native/web outputs, locale-specific semantic/rendering tests and review ledger only.

## Acceptance criteria

1. [ ] Implement the de message set with native name Deutsch, matching every typed domain and placeholder signature from G21.09. Translate complete contextual phrases, including accessibility/error/privacy/payment/permission words.
2. [ ] Cover plural/count/date/number examples, long labels and missing-content states; do not translate IDs, substitute access status or invent a voice/guide.
3. [ ] Run the key/parameter checks and a separate semantic review of all messages, with special attention to negation, purchase cancellation and delete/restore.
4. [ ] Leave registration/picker publication to G21.15/G21.17 after the whole required set is complete; guide content translation and voice production are outside this task.
5. [ ] Author de in canonical translation data; record reviewedSourceHash, semantic review and G21.27 provenance. Generate native/web files through G21.25 rather than editing them manually; run G21.26 and output freshness checks. New messages or changed originals include all shipped locales in the same commit under G21.19.

## Out of scope

Production guide writing/narration, unrelated refactors, new runtime translation services, automatic worker launch and unauthorized workflow changes.

## Dependencies

Blocked-by: #533, #542, #543

## Proof

Locale-specific message/rendering tests (planned), catalogue completeness check and semantic review ledger for de.
