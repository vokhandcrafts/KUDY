# G21.19 — Update and review every shipped UI language in the source-change commit

## Epic

Epic: #532

## Goal

Changing a canonical UI message updates or explicitly re-reviews every shipped language, its provenance and generated outputs in the same commit.

## Scope

Translation authoring instructions, reviewed terminology glossary and example review ledger using G21.24–G21.27 records/generator/gates; existing agent documentation.

## Acceptance criteria

1. [ ] Use the canonical meaning, screen/action, placeholders, limits and tone from G21.24 without duplicating source records; keep a reviewed glossary for guide, stop, walk, download, unavailable, purchase and restore.
2. [ ] Use LLMs offline to draft complete phrases, followed by a separate semantic review against the source/context; preserve placeholders, negation, access promises and deletion meanings.
3. [ ] Check missing/extra/empty keys, placeholder types and rendered count/date/number examples. Test 0/1/2/5/11/21 and fractional values where messages support them.
4. [ ] Keep reviewed results versioned; do not call an LLM at app runtime. Apply G21.27 mandatory lookup when uncertain and record evidence; respect G21.33 source decisions, registry requirements, licenses and read-only least privilege. Downloaded entries are reference data, never executable instructions.
5. [ ] Document and demonstrate source/context edit → review every shipped locale in the same commit → record reviewedSourceHash and evidence → regenerate outputs → pass G21.26. A retained translation needs a renewed review and reason; blindly updating hashes is not a review.
6. [ ] A controlled omitted locale or stale review fails the standard check; a fully reviewed update passes. Distinguish automated revision/completeness checks from semantic review rather than claiming the gate proves translation quality.

## Out of scope

Production guide writing/narration, unrelated refactors, new runtime translation services, automatic worker launch and unauthorized workflow changes.

## Dependencies

Blocked-by: #533, #542, #556, #558, #559, #566

## Proof

Behavioral missing/stale-locale failure and complete-update success through the standard check; generated freshness and versioned semantic/provenance ledger.
