# G21.04 — Prove playback using valid synthetic audio

## Epic

Epic: #532

## Goal

Browser audio acceptance uses a decodable licensed test asset and proves actual playback.

## Scope

Synthetic demo media and owning manifests/locks; web audio browser proof; native test-media reuse after #491.

## Acceptance criteria

1. [ ] Replace the 85-byte KUDY-DEMO-AUDIO placeholder in the relevant synthetic acceptance fixture with a short valid offline-generated M4A tone; record generation source, checksum and rights.
2. [ ] Update only the owning synthetic manifest/lock atomically; retain byte-integrity validation, public/free boundaries and absence of paid media in the web export.
3. [ ] After a user click, audio metadata has finite positive duration, play succeeds and currentTime advances before pause; a corrupt asset fails.
4. [ ] Keep text-only/no-audio guides valid and explicitly labelled; do not mark them playable or generate production narration.

## Out of scope

Production guide writing/narration, unrelated refactors, new runtime translation services, automatic worker launch and unauthorized workflow changes.

## Dependencies

Blocked-by: #533

## Proof

synthetic_audio_decodes and playback_advances (planned); web build/leak scan; real Chromium media playback.
