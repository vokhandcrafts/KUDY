# G21.18 — Accept all eight interfaces on native and web surfaces

## Epic

Epic: #532

## Goal

Every shipped language has functional, visual and semantic proof without relying on guide narration in that language.

## Scope

Locale acceptance matrix and semantic review records; synthetic packages; Android/iOS/web verification protocols and narrowly scoped regressions.

## Acceptance criteria

1. [ ] Cover all available native screens and web surfaces in eight languages, including privacy/payment/errors/hints, valid empty catalogue, selected-language filtering, text-only and explicitly selected foreign-language audio.
2. [ ] Test 320/390/1440px web, Android font 150%, long German/French labels, Czech/Swedish characters, accessibility names, focus/Back and saved selection after restart.
3. [ ] Record separately native emulator, physical Android and iOS results; unavailable hardware is not-run/blocked-external and cannot be labelled passed. Android and browser proof must exercise shipped code.
4. [ ] Review all translations for meaning and glossary consistency; prove be/en/uk regressions remain clean and the three web defects are fixed.
5. [ ] Report remaining defects by severity and exact evidence, rather than calling basic unavailable-state checks full walk or store acceptance.

## Out of scope

Production guide writing/narration, unrelated refactors, new runtime translation services, automatic worker launch and unauthorized workflow changes.

## Dependencies

## Proof

Eight-locale rendered/device/browser matrix, screenshots and semantic ledger; Showboat where runtime changes trigger it.
