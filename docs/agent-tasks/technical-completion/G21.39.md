# G21.39 — Compare Chinese language variants and verified terminology sources

## Epic

Epic: #532

## Goal

Recommend the first Chinese audience, writing variant and spoken narration variant from evidence, with usable modern dictionaries and contextual terminology sources rather than a guessed generic Chinese locale.

## Scope

Allowed outputs: `docs/reports/chinese/language-and-dictionaries.md`, its evidence JSON and synthetic benchmark records. Read the Chinese research specification, existing locale/content contracts, G21.20 identity decision and tool registry. Do not edit production locale enums, catalogues, schemas or the external registry.

## Acceptance criteria

1. [ ] Compare simplified/traditional writing, standard Mandarin and regional usage; evaluate whether Cantonese is needed as a distinct spoken option. Record target users, native labels, region, script and official locale-tag evidence. Recommend use/defer/reject by variant; no code is added to the shipped registry.
2. [ ] Assess at least one accessible primary source in each role: modern normative/bilingual dictionary, terminology/UI reference, and pronunciation/contemporary spoken-register reference. An unavailable role requires attempted locator/access evidence and an explicit unresolved result, not a fabricated source. Reuse relevant existing source research; examine Chinese coverage directly.
3. [ ] Run the shared ten-term contextual battery and two short synthetic tourism passages. Distinguish noun/action senses, ordinary contemporary wording, pronunciation, regional forms and Polish place names. Record source version/revision or dated URL, entry/sense, chosen candidate, reason, rights and access limits for each supported result; unsupported senses remain unresolved.
4. [ ] Compare read-only access, extractability, offline feasibility, data size, update cost and terms/attribution. Dictionary consultation is distinct from copied data; no corpus/download or compulsory MCP integration is inferred from source availability. Check the shared registry before proposing a tool.
5. [ ] Produce a recommendation and uncertainties for G21.42, including whether a native-speaking semantic/pronunciation reviewer is available. External access, account, paid review or unavailable evidence is named with its actual status. Do not assert linguistic quality from an LLM/vendor language list.

## Out of scope

Production translation or guide narration, source integration, bulk corpus import, new accounts, changes to egress controls and premature Chinese locale activation.

Published report plus evidence-linked benchmark: every claimed resolved sense has a real locator and dated observation; unresolved, inaccessible and wrong-sense cases remain visible. Apply the Showboat decision rule if a probe triggers it.
