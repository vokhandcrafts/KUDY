# G21.21 — Play explicitly selected audio beside translated guide text

## Epic

Epic: #532

## Goal

A free guide with fr text and en audio works offline through production composition, without silently switching content or bypassing paid access.

## Scope

Only the approved G21.20 session/readiness/audio/access boundaries and their integration/device tests.

## Acceptance criteria

1. [ ] Implement the approved separate language identity and explicit available-audio selection; bind both parts to the same route/version/stop mapping and preserve text-only reading.
2. [ ] Require verified full readiness of every selected layer before Start. Stop/reject unavailable or mismatched audio; do not fetch/play a fallback language silently.
3. [ ] Prove fr-text/en-audio Start/Pause/restart/End on Android using synthetic licensed content and the real #491 composition; progress/text/audio pins survive restart.
4. [ ] Test each language/tier grant independently, wrong-locale/wrong-version/expired/refunded access and corrupt audio; retain fail-closed paid behavior when live stores are unconfigured. Live paid evidence belongs to #492 and full acceptance #296.
5. [ ] Same-language existing sessions and text-only guides remain compatible; migrations preserve recovery/rollback safeguards and never lose progress.

## Out of scope

Production guide writing/narration, unrelated refactors, new runtime translation services, automatic worker launch and unauthorized workflow changes.

## Dependencies

Blocked-by: #533, #552, #550, #551, #491

## Proof

mixed_language_offline_restart, foreign_grant_denied and text_only_no_audio (planned); Android synthetic free path; runtime Showboat/reverted-fix tests.
