# G21.16 — Allow the eight content locales without inventing availability

## Epic

Epic: #532

## Goal

Published translated text can use the requested locale codes; text and audio availability remain independent verified facts.

## Scope

Owning JSON schemas in contracts/schemas; schema-generated contracts/wire/wire-types.ts; content publisher/validators; locale canon documentation.

## Acceptance criteria

1. [ ] Expand the schema-owned content allowlist to be/en/uk/de/es/fr/cs/sv and regenerate its wire projection; do not duplicate it in readers/services or broaden to arbitrary strings.
2. [ ] Update localized text, catalog/discovery, media/voice and feedback-target owners consistently; retain existing limits, unknown-locale rejection, path checks and raw-byte pins.
3. [ ] A valid fr-text/no-fr-audio package yields text_locales including fr while audio_locales stays limited to actual licensed media; no empty planned locale creates availability.
4. [ ] Backward-compatible be/en/uk fixtures still validate; malformed/unknown locale and a claimed audio locale without a published asset fail at the boundary.

## Out of scope

## Proof
