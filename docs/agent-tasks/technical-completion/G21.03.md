# G21.03 — Show a localized message when the web map fails

## Epic

Epic: #532

## Goal

A map-provider failure leaves a visible explanation and the guide links usable.

## Scope

web/components/city-map.tsx; web/lib/i18n/be.ts and en.ts; map browser tests.

## Acceptance criteria

1. [ ] Abort map requests with internetdisconnected and reproduce the empty map with only data-map-error.
2. [ ] Render a localized accessible failure message; clear it after successful initialization and clean up map resources on unmount.
3. [ ] Test provider rejection, successful load and recovery; no raw exception/URL is shown to visitors and guide links remain usable.
4. [ ] The visible-error assertion fails when the fix is reverted.
