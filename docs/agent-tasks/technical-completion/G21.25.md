# G21.25 — Generate typed native and web messages from the canonical data

## Epic

Epic: #532

## Goal

Runtime message catalogues are reproducible projections of source records and reviewed locale data, never parallel manually edited originals.

## Scope

tools/i18n/generate-messages.mjs; translation data under contracts/ui-messages/; generated controller/web catalogues and existing selector adapters.

## Acceptance criteria

1. [ ] Define a translation record with message value/forms, reviewedSourceHash and review/provenance metadata; preserve canonical message parameter types and the existing selector/function signatures from #542.
2. [ ] Generate native/controller and web catalogues from the same canonical source plus locale data. Mark outputs generated; do not duplicate base text/context in hand-maintained catalogue files.
3. [ ] Use supported message patterns and safely escaped static output. Dictionary text is data: no eval, executable template snippets, runtime LLM or remote translation calls.
4. [ ] Repeated generation is byte-identical; check mode fails for a removed/edited/stale generated output. Render existing messages, plural/count/date examples and quotes/newlines without code execution.
5. [ ] Test on Windows/Linux without altering media/hash-pinned content fixtures; keep layer boundaries and existing be/en/uk behavior.
