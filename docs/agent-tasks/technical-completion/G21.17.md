# G21.17 — Filter guides by UI text language and keep chrome independent

## Epic

Epic: #532

## Goal

Only guides with published text in the selected UI language appear in catalogues; interface controls use the UI language without replacing active content.

## Scope

Catalog/discovery/nearby projections; guide availability/start UI; Run display strings; controllers/createServices.ts and content selection boundaries.

## Acceptance criteria

1. [ ] For French UI and be/en-only guide text, the guide is absent from catalogues, discovery and nearby offers; a valid empty catalogue shows a localized explanation, never a service-failure message.
2. [ ] For French text with English audio, show French title/text and explicit audio availability; selecting an audio language must be explicit and use G21.21 once available.
3. [ ] Run chrome/errors/hints use the selected UI catalogue; changing UI language never changes the active session text/audio versions, progress, player or grants. An existing differently localized session remains resumable with its content languages labelled.
4. [ ] Direct links to a guide without selected-language text show a localized unavailable state; do not silently substitute be/en content. Mixed-language playback remains denied/unavailable until G21.21 proves the authorized path.
5. [ ] Test all eight UI locales, empty and malformed catalogues, and switch during an active pinned session; preserve Start full-readiness and paid denial.

## Out of scope

Production guide writing/narration, unrelated refactors, new runtime translation services, automatic worker launch and unauthorized workflow changes.

## Dependencies

Blocked-by: #533, #542, #550

## Proof

selected_text_locale_filter, empty_locale_catalogue and ui_switch_keeps_content_pin (planned); controller/Jest and device proof.
