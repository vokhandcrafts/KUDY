# G21.15 — Ship an accessible persistent eight-language selector

## Epic

Epic: #532

## Goal

All eight complete UI catalogues can be selected, and the choice survives an application restart.

## Scope

app/(tabs)/my.tsx; controllers/uiLocaleStore.ts; production locale persistence composition owned by #491; native locale registration.

## Acceptance criteria

1. [ ] Register all eight complete catalogues; derive native names from the registry and keep every choice reachable at phone width and font scale 150%.
2. [ ] Use the existing persistence port with the production storage owner from #491; write/read the UI setting safely and retain the approved default when there is no stored setting.
3. [ ] Switch each language without restart, force-stop/relaunch and verify the same choice; handle invalid stored codes and write failures without corrupting session/content state.
4. [ ] Keep selected/accessibility states and translated Back/Language/error labels consistent; the UI setting must never change pinned text/audio identity or entitlement.

## Out of scope

Production guide writing/narration, unrelated refactors, new runtime translation services, automatic worker launch and unauthorized workflow changes.

## Dependencies

Blocked-by: #533, #542, #544, #545, #546, #547, #548, #491

## Proof

Rendered selector tests and Android persisted_locale_restart/eight_locale_picker (planned); real storage proof after #491.
