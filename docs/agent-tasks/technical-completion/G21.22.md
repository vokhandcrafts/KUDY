# G21.22 — Publish web UI routes independently of guide narration

## Epic

Epic: #532

## Goal

The web has all eight interface languages and shows only selected-language text that is actually published.

## Scope

web/lib/i18n; locale routes/layouts; web/lib/content/site.ts/pages; language switch, sitemap/hreflang/canonical owners.

## Acceptance criteria

1. [ ] Publish be/en/uk/de/es/fr/cs/sv UI routes from the registry even when a locale has no guides or narration; override the former uk-first-guide release coupling through the approved G21.00 decision.
2. [ ] Filter before exact-localized text reads: fr UI with no fr text yields a valid localized empty catalogue; missing/corrupt declared content still fails distinctly.
3. [ ] A translated guide page has its actual text locale and separately labelled available audio; unavailable-language direct links return localized unavailable/404 behavior without content fallback.
4. [ ] Language switch, html lang, canonical/hreflang and sitemap follow actual published text; do not advertise untranslated guide variants or expose paid/private content.
5. [ ] Build with all eight UI languages and a synthetic mixed availability catalogue; test URLs, switch/Back, empty locales and public-layer leak scan.

## Out of scope

Production guide writing/narration, unrelated refactors, new runtime translation services, automatic worker launch and unauthorized workflow changes.

## Dependencies

Blocked-by: #533, #542, #544, #545, #546, #547, #548, #550, #534

## Proof

Eight-locale static build plus web_selected_text_locale and sitemap_actual_translations (planned).
