# G21.37 — Record source reuse boundaries before localization data import

## Epic

Epic: #532

## Goal

Record whether a measured KUDY need warrants copying data from the assessed sources and which source-specific permissions apply. An explicit defer/reject outcome completes this decision task; it does not authorize an importer.

## Scope

Allowed files: `docs/reports/localization-sources/reuse-decision.md`, decision fields in `docs/reports/localization-sources/decisions.json`, and the report index. Inputs: five published reports/evidence, their primary license/terms locators, and the G21.33 reference-only decisions. Output: dated owner decisions with evidence, approved data/channel boundaries and any remaining blockers.

## Acceptance criteria

1. [ ] Identify the actual message/authoring need for each proposed excerpt. Separate AOSP XML, Microsoft TBX, Wiktionary text, IATE Download and IATE website/API channels; do not presume copying is needed. CLDR notice requirements apply if a data subset is proposed.
2. [ ] Record use/defer/reject for each proposed reuse, decision owner/date, primary terms locator/version, attribution/notice obligations and redistribution boundaries. Unknown rights mean defer/reject; owner preference is not a substitute for permission from the rightholder.
3. [ ] Preserve Microsoft's missing detailed terms, Wiktionary's unreviewed full-license boundary, IATE's stale anonymous export and channel-specific permissions, and AOSP's per-file notice verification. Do not turn an inventory language into verified term coverage.
4. [ ] A requested EU Login, host allowlist change or external contact remains a named human prerequisite; create no account, request no token and send no messages in this task. A defer decision needs none of these actions.
5. [ ] If an import is approved, create a separate backlog implementation issue with exact fields, pins, tests, notice handling and `Blocked-by` on this issue. Otherwise create no connector/downloader issue. Do not set readiness labels or start workers.

## Out of scope

Corpus downloads, production code, copied glossary entries, MCP installation, security exceptions and automatic workers.

## Dependencies

Blocked-by: #565

## Proof

Review the completed decision against all five source rows and read back any newly created issue's prerequisites. A missing decision owner, permission evidence or explicit defer/reject for an unresolved boundary fails acceptance.

The new index/decision manifest and this brief become available on main only when #565 closes through its PR. Do not execute against unavailable blob/main documents.
