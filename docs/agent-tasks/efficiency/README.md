## Публікацыя і праверка

Перад стварэннем правераныя існыя Issues; дублікаты G22 не знойдзеныя. Створаныя восем задач, бацькоўскі эпік і перадумова публікацыі. Усе перачытаныя праз GitHub API: адкрытыя, без прызначаных выканаўцаў і пазнак; бацькоўскія спасылкі і залежнасці адпавядаюць індэксу, цыклаў няма. Карткі маюць мэту, абсяг, нумараваную прыёмку, доказ і спасылкі паводле [.github/ISSUE_TEMPLATE/agent-ready.md](../../../.github/ISSUE_TEMPLATE/agent-ready.md).

Бачнасць на дошцы dispatcher не правераная: `gh project list --owner vokhandcrafts --format json` вярнуў `missing required scopes [read:project]`. Дазволы акаўнта і налады dispatcher не змяняліся. Доказы: [здымак публікацыі](publication.json), [вынік G22.00](../results/G22.00.md).

Публікацыя не дазваляе дадаць `agent:ready`, пачаць выкананне або запусціць dispatcher. Перад асобна дазволеным пачаткам выканаўца правярае закрытасць перадумоў і наяўнасць дакументаў у сваім checkout. Пры новай задачы ў тых жа файлах спачатку ўзгадняе валоданне і паўторна правярае базу.
