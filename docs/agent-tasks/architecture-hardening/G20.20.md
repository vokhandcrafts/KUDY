# G20.20 — Compose real device services at the application root

## Goal

Installed application surfaces receive one production service graph with durable storage, verified content, location and audio without waiting for store accounts. Purchase/restore stays explicitly unavailable and denies paid access until G20.21 verifies the live path.

## Scope

## Acceptance criteria

1. [ ] Inventory each missing ServicePorts member and platform dependency; implement only required production adapters with one DB/audio/location owner and explicit teardown.
2. [ ] The root consumes controller composition; UI/core do not import OS/network/storage implementations. No fake success port or privileged key enters a build.
3. [ ] A free synthetic package exercises catalog -> download/hash/activation -> Start/Pause/restart/End through the production composition without store accounts. Purchase/restore returns the existing unavailable state with zero store/grant/paid-byte calls and no fabricated entitlement; G20.21 later enables the verified live path.
4. [ ] Missing configuration and adapter failures surface safe localized unavailable/error states; build/type/layer tests pass. Record device-ready prerequisites for #296 without claiming live acceptance.

No new features, engine rules, access bypasses, unrelated refactoring or production data.
