## Goal

## Scope

## Acceptance criteria

1. [ ] Exercise the production grant handler with stored malformed JSON, null, array and invalid paths/lock_url; each returns 403 manifest_not_found, with zero provider/sign calls.

3. [ ] Valid exact manifest membership still authorizes only requested safe paths and the matching environment; no broad catch may turn unknown authorization into permission.
4. [ ] Adapter tests run in the standard command and fail when malformed JSON/null escape again; evidence states fake Storage transport rather than a live deployment.
