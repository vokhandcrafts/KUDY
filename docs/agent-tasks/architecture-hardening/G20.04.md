# G20.04 — Assign subscriptions only to accepted walk owners

## Goal

A refused second walk cannot steal location from the first; disposed owners leave no audio/location/download listeners.

## Sources

- Specification: [runtime.md](../../specifications/architecture-hardening/runtime.md), section R3.
- [Publication index](README.md) contains the real issue IDs and dependencies.
- [Original audit](../../audits/2026-10-02-architecture-review.md) and [reproduction script](../../audits/2026-10-02-proof.mjs.txt).

## Evidence boundary

Audit A26-04: live-session-exists; first lastFix.at remains1000 after fix2000.

## Scope

controllers/run/runOrchestrator.ts; runSurfaceController.ts; resource subscription interfaces and implementations.

## Acceptance criteria

1. [ ] Start a real first walk, refuse a second via runSurfaceController, then deliver another fix: the first receives it and remains the owner.
2. [ ] Construction, refusal, End and disposal have balanced subscriptions; repeated open/close cycles do not grow live listeners.
3. [ ] An old owner cleanup cannot release the new owner; callbacks after disposal cannot mutate the session.
4. [ ] The ownership regression fails on reverting the fix; keep the accepted session-switch behavior and one physical player/GPS stream.
