# G20.02 — Start and release the physical Expo audio player

## Goal

A play request invokes the real adapter player.play and releases failed or replaced resources.

## Scope

services/audio/expo/expo-audio-port.ts and adapter behavioral tests.

## Acceptance criteria

1. [ ] Import the production adapter, mock only Expo APIs, and assert one physical play after identity/listener setup.
2. [ ] Replacing a player releases the old one; old completion/error callbacks cannot change the new owner.
3. [ ] Creation and play failures reach the existing error path and release listeners/player exactly once; pause/end remain valid.
4. [ ] The play-call test fails on reverting the fix and is wired into npm test; physical-device sound is explicitly not claimed by a mock test.
