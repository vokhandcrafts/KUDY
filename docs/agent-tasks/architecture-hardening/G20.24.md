# G20.24 — Diagnose malformed route stops without throwing readiness errors

## Goal

Untrusted route stop rows produce incomplete readiness diagnostics and never crash evaluatePackage or authorize damaged content.

## Sources

- Specification: [runtime.md](../../specifications/architecture-hardening/runtime.md), section R7.
- [Task index](README.md) and [review boundary proof](../../audits/2026-10-02-review-boundaries-proof.mjs.txt).

## Evidence boundary

## Scope

services/contentRepo/contentRepo.ts; schema-owned route validation and readiness tests.

## Acceptance criteria

1. [ ] Run evaluatePackage through the real PackageStore boundary with null, primitive, array and malformed object stop rows; each returns a named incomplete result without throwing.

3. [ ] Valid packages keep their readiness behavior; repair/retry retains durable user progress and existing verified files.
4. [ ] Behavioral corrupt-stop tests run in npm test and fail on restoring unchecked field access/casts.
