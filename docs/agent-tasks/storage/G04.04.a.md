## Acceptance

1. [ ] The inventory lists each `route_id@version × locale × tier` with bytes from `lock.json` and disk facts; the state is one of `not_downloaded` / `partial (N missing)` / `ready` / `stale`, with a test per state.
2. [ ] `stale` means the catalog advertises a newer version; a newer catalog next to a paused session leaves the pinned version's readiness unchanged and replaces no file.
3. [ ] Sizes are derived, never stored in zone B.
4. [ ] A corrupt `catalog_cache` or lock entry yields diagnostics, not a thrown error.
