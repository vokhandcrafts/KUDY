**Status:** not-started. **Model class:** medium. **Dependencies:** [G04.02.a](G04.02.a.md) (owner of package files) and [G04.04.a](G04.04.a.md) complete. Parent task: G04.04.

## Acceptance

1. [ ] Deleting a version pinned by a non-finished session is refused with a named reason; after End the same deletion succeeds.
2. [ ] Only the package directory and its zone A rows are deleted; zone B (sessions, settings, events, hints, feedback) is byte-identical before and after.
3. [ ] Nothing touches entitlement or the grant cache; re-downloading a purchased layer goes through grant without a repeat purchase (asserted on the grant-port fake).
4. [ ] Deleting during an in-flight download of the same package has a defined outcome: staging is cancelled and no half-deleted ready state remains.
5. [ ] The deletion path is built only from validated segments; ids with `..` or separators are refused.
