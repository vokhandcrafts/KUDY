## Acceptance

1. [ ] An interrupted transfer, lack of space, a corrupted hash and a repeated request each have their own test, and none of them yields ready; after a failed upgrade the old ready layer is byte-identical.
2. [ ] Resume does not re-fetch files already verified by hash (the test counts fetches).
3. [ ] Staging sits next to the final directory; an injected crash between verify and rename leaves either the old or the new complete layer, never a mix (ADR G01.03 §3.7).
4. [ ] Every path segment and every lock path is checked as a safe unit on input (`..`, separators, NUL, absolute paths) before any filesystem call, reusing the existing idiom (rule §3); a corrupt `lock.json` (null entries, missing fields, wrong types) yields diagnostics, not a thrown error.
5. [ ] `bundle_asset` reflects pending/partial/complete and can be rebuilt by re-hashing the disk; zone B is untouched (the test snapshots it).
6. [ ] Hashing is over raw bytes and the fixture paths are EOL-pinned (rule §4); the new suite is enumerated by `npm test`.
