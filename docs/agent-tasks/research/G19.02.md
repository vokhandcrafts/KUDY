# G19.02 — Safe offline HTML and image packages

## Context

Read [the canonical specification](../../25_content_research.md), especially sections 3–4, and [the implementation plan](../../superpowers/plans/2026-10-01-content-research.md). The source library/parser are external; repository collector files are implementation references, not a description of that live system.

## Goal

Immutable, deterministic per-article packages with structure, fragment locators, images, captions and private link provenance.

## Scope and files

- `tools/corpus/import.mjs`
- `tools/corpus/extract.mjs`
- `tools/corpus/import.test.mjs`
- `tools/corpus/extract.test.mjs`
- `tools/corpus/cli.mjs`

## Interfaces

importArticle(inputRecord, { inputRoot, libraryRoot, sourceNamespace, extractorVersion }) -> ArticlePackage; extractArticle(htmlBytes, { articleId, revisionId, extractorVersion, browserFactory }) -> ArticleDocument.

## Acceptance criteria

1. [ ] Same source identity and raw bytes give the same article/revision IDs; duplicate titles under different source keys stay separate; a new extractor version retains earlier extracted files.
2. [ ] Offline wiki-html/v1 parsing preserves all fixture body text, line breaks, headings and captions, excludes navigation/icons, and distinguishes family/person references without resolving identity automatically.
3. [ ] Static original-image references are read as inert data, never evaluated; provided local media are hashed and MIME/extension checked; unavailable remote originals remain missing without fetching.
4. [ ] Traversal, escaping symlink/junction, oversize input and declared missing local files yield named diagnostics before registration; raw files remain byte-identical.
5. [ ] Script traps and remote-image fixtures cause no script execution or network request; an interrupted write leaves old packages readable and retrying completes one revision.

## Checks

## Proof

Reverting the owned behavior must break the named behavior test. G19.08 is a human-input tracking task: its proof is actual validation and decisions, not a code-revert test.
