## Acceptance criteria

1. [ ] One actual private article passes package → level 1 → explicit Case → level 2 → review/export; then the varied 30-article set receives level 1 and only one selected topic receives level 2.
2. [ ] Private report measures text/caption preservation, entity collisions, missed mentions, time/place/type errors, accepted/rejected claims, manual-review minutes, tokens and actual/unknown cost; findings are itemized.
3. [ ] Every control text/caption is preserved, no incorrect auto-merge occurs, all evidence validates, no unaccepted claim leaks into script material and the accepted budget is respected; author signs usefulness/coverage verdict.
4. [ ] A crash/restart demonstrates reuse of completed work; rerun preserves author decisions; no live model call is masked by test injection in pilot evidence.
5. [ ] Public summary and Showboat use synthetic data only; private material and provider secrets stay outside Git. Corpus suites are wired into npm test; architecture, duplication and documentation checks run against final HEAD.
6. [ ] Author bulk-run decision is recorded; failure blocks bulk use; no command starts a thousands-article run as part of this task.
