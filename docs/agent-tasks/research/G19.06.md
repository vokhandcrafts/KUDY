# G19.06 — Selected facts and relationships with exact evidence

## Context

Read [the canonical specification](../../25_content_research.md), especially sections 2, 6, 8, and [the implementation plan](../../superpowers/plans/2026-10-01-content-research.md). The source library/parser are external; repository collector files are implementation references, not a description of that live system.

## Goal

Second-level candidate claims/relations limited to a saved author's Case, with exact quotes and explicit modality.

## Scope and files

- `tools/corpus/claims.mjs`
- `tools/corpus/claims.test.mjs`
- `tools/corpus/prompts/level2-v1.txt`
- `tools/corpus/cli.mjs`

## Interfaces

extractClaims(store, caseId, { runConfig, transport, dryRun }) -> RunReport; validateEvidence(claim, selectedFragments) -> { ok, errors }; uses runModelJob from G19.04.

## Acceptance criteria

1. [ ] Missing/empty/stale Case fails before spending tokens; only selected fragments and explicitly registered context enter the request.
2. [ ] Each claim quotes an existing input span exactly; wrong Unicode offsets, altered quotes, fabricated IDs and evidence from unselected material are rejected.
3. [ ] The extraction instruction requires planned/attributed modality; the runtime preserves it without promoting it to occurred. Relations require a claim; historical interpretation and causal support are checked by author review and the live pilot, not certified by a schema.
4. [ ] Output always remains unreviewed; level-1 classification and successful quote validation cannot supply an accepted decision.
5. [ ] Budget, caching, retries and run provenance reuse the first-level runner; failure preserves earlier valid outputs and all author decisions.
