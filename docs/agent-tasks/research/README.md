## Публікацыя і праверка

Дата: 2026-10-01. Спецыфікацыя, план і брыфы апублікаваныя ў [PR #467](https://github.com/vokhandcrafts/KUDY/pull/467), галіна `457-content-research-specification`; G19.00 закрываецца толькі пасля публікацыі ў асноўную галіну. Агенту-выканаўцу патрэбны гэтыя файлы ў яго checkout, а не толькі ў гэтым чаце або ў лакальнай тэчцы аўтара.

GitHub-задачы створаныя без `agent:ready`, `agent:running`, `epic` і `prio:*`; іх наяўнасць не дазваляе запуск. Усе issue перачытаныя праз GitHub API 2026-10-01: адкрытыя, без пазнак; бацькоўскія спасылкі і залежнасці адпавядаюць брыфам, граф не мае цыклаў. Доказ і абмежаванні — у [справаздачы публікацыі](../results/G19.00.md).

Бачнасць на асобнай дошцы dispatcher не правераная: яе інтэрфейс/доступ у сесіі не вызначаны. Спіс GitHub Projects таксама недаступны: `gh project list --owner vokhandcrafts --format json` вярнуў `missing required scopes [read:project]`. Дазволы акаўнта і налады dispatcher не змяняліся; адкрытасць задач правяраецца праз GitHub Issues API.
