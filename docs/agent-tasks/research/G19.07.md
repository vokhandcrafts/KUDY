# G19.07 — Author review and private research export

## Context

Read [the canonical specification](../../25_content_research.md), especially sections 8–9, and [the implementation plan](../../superpowers/plans/2026-10-01-content-research.md). The source library/parser are external; repository collector files are implementation references, not a description of that live system.

## Goal

Explicit version-bound decisions, preserved corrections and source-backed private dossiers containing accepted facts only.

## Scope and files

- `tools/corpus/review.mjs`
- `tools/corpus/export.mjs`
- `tools/corpus/review.test.mjs`
- `tools/corpus/export.test.mjs`
- `tools/corpus/cli.mjs`

## Interfaces

reviewClaim(store, { claimId, claimVersion, decision, actor, note }); correctClaim(store, claimId, { statement, evidence, actor }); exportResearch(store, caseId, { outDir, mode }); mode is private or public-status.

## Acceptance criteria

1. [ ] Author reviews claim, exact evidence and modality; acceptance records actor/time/version; correction creates a new unreviewed version.
2. [ ] Regeneration and source changes cannot inherit acceptance onto a different claim version; author decisions and rejected history remain available.
3. [ ] Private export includes accepted claims/relations with evidence, image rights and separately listed unresolved context needs; unreviewed/rejected/stale facts are excluded from the script-material list.
4. [ ] Public-status export contains no source addresses/titles/keys, filesystem paths, quotes or images; privacy tests include nested values and failed-export diagnostics.
5. [ ] Export is deterministic and atomic; failed writes do not overwrite a previous dossier; no Story/bundle publication or network call occurs.

## Proof

Reverting the owned behavior must break the named behavior test. G19.08 is a human-input tracking task: its proof is actual validation and decisions, not a code-revert test.
