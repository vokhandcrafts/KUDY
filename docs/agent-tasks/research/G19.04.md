# G19.04 — Budgeted first-level model annotation

## Context

Read [the canonical specification](../../25_content_research.md), especially sections 2, 5–6, and [the implementation plan](../../superpowers/plans/2026-10-01-content-research.md). ## Goal

Resumable first-level suggestions with controlled vocabulary, provenance, validated fragment references and persistent cost reservation.

## Acceptance criteria

1. [ ] Default dry-run makes no provider call; a missing/unaccepted private run decision cannot activate a live request; actual provider adapter follows the G19.08 decision.
2. [ ] Output contains people/mentions, places, time ranges, controlled themes, up to three hooks and context needs; no mass Claim extraction or automatic author approval is performed.
3. [ ] Every accepted response passes the real schema/reference validator; malformed JSON, unknown topics, invented fragment IDs and instructions embedded in article text cannot create trusted output.
4. [ ] Budget is reserved durably before each attempt, including retries; unknown price without an accepted request cap blocks live execution; at most three attempts and one in-flight request; timeout leaves uncertain spend reserved.
5. [ ] Repeated unchanged jobs reuse results; prompt/model/vocabulary/input changes cause a new run; one failed article leaves other completed runs and manual corrections intact.
6. [ ] Adapter enforces HTTPS, does not forward credentials on redirects, redacts errors/logs and receives only permitted clean text; tests exercise the same validation/budget path used by live transport.
