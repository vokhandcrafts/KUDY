# G17.05 — YouTube collector (yt-dlp transcripts)

## Context

- Specification: [`docs/24_web_collection.md`](../../24_web_collection.md) — sections «Калектары → YouTube» and «Фота» (thumbnail rule).
- `yt-dlp` is the external tool (checked 2026-09-21 via GitHub API: Unlicense, ~192k stars, actively developed — no license risk for an internal tool). Manual subtitles take priority over automatic ones (quality). Videos without any subtitles go to an `asr-backlog` list — speech recognition is not in the first version.

## Goal

Given campaign video ids, fetch subtitles with `yt-dlp`, store the transcript split into paragraphs with timecodes, the video metadata, and the thumbnail as a cover file; subtitle-less videos land in the backlog. Unit tests use bundled subtitle fixtures — no network; the live yt-dlp run is manual and, if the tool or network is unavailable, the outcome is recorded `blocked-external`, never a mock pretending success.

## Scope

- yt-dlp invocation (spawned, version pinned at install time in the results file).
- Subtitle selection: manual > automatic; store which kind was used.
- Transcript paragraphs split by timecode anchors (VTT fixtures in tests).
- Metadata: title, channel, upload date, duration, language.
- Thumbnail saved as the record's cover with the same slug naming as G17.03.
- `asr-backlog` entries for subtitle-less videos.

## Out of scope

- Punctuation/paragraph restoration of auto-captions (that is cleaning, G17.06), speech recognition, audio download.

## Acceptance criteria

1. VTT fixture → transcript paragraphs each anchored to a timecode; assertion checks paragraph count and first/last timecodes.
2. Fixture with both manual and automatic subtitles → manual is stored and the kind is recorded — reverting the preference fails the test.
3. Metadata row complete for the fixture video; thumbnail file named per the slug rule.
4. Fixture video id without subtitles → an `asr-backlog` entry and the run continues with a diagnostic.
5. Missing yt-dlp binary → explicit diagnostic at startup, no partial records; suites wired into `npm test`; jscpd clean.

## Proof

Revert the manual-over-automatic preference → criterion 2's test fails.
