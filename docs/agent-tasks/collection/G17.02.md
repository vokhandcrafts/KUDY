# G17.02 — Web crawler with a fence (Playwright)

## Context

- Specification: [`docs/24_web_collection.md`](../../24_web_collection.md) — section «Калектары → Паўзук па сайтах».
- Why a real browser: JavaScript-rendered pages and login sessions (the author logs in once in his own browser profile; the tool reuses that session and never stores passwords).
- The fence is the safety contract: without it the crawler "reads" the whole internet. The fence audit log is the evidence that it held.

## Goal

A crawler that walks campaign seeds inside the fence and hands every fetched article page to the G17.01.b snapshot writer. All tests run against local fixture servers — no external network in tests; live runs are manual.

## Scope

- Fence: same-domain only plus `fence.extra_domains`; depth ≤ `fence.depth` (default 3); article heuristic (title + minimum paragraph count) — nav/catalog/service pages are skipped and marked `skipped` in the persisted queue.
- Politeness: delay between requests to one host taken from `fence.delay_s` (default 2–5 s); stop after a series of consecutive errors with a diagnostic.
- Login: reuse an existing browser user-data dir (config in the campaign file); no credential storage.
- Fence audit log: one machine-readable JSON line per fetched URL with `"allowed": true|false` (host decision), written to `<run-dir>/fence-audit.jsonl` — the pilot criterion "0 pages outside allowed hosts" is then checkable with a grep over that file.
- Persisted crawl queue so a run resumes where it stopped.

## Out of scope

- Photo extraction (G17.03), wiki/YouTube sources (G17.04/05), cleaning (G17.06).

## Acceptance criteria

1. Fence test against a local fixture server with an "external" link: the audit log shows 0 fetches outside allowed hosts — fails if the domain check is reverted.
2. Depth test: a page 4 hops from the seed is not fetched.
3. Article heuristic: a nav-only fixture page is marked `skipped`, an article fixture is snapshotted.
4. Error-series test: N consecutive failures stop the run with a diagnostic; the queue state allows resume.
5. Politeness test: timestamps of two consecutive requests to the same fixture host differ by at least the configured minimum delay.
6. Every fetched article page produces a `raw_records` row through the G17.01.b path (end-to-end from crawler to snapshot, no test-only shortcut).

## Proof

Revert the same-domain check → criterion 1's audit-log assertion fails.
