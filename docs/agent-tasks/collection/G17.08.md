# G17.08 — Pilot campaign: Gdansk

## Context

- Specification: [`docs/24_web_collection.md`](../../24_web_collection.md) — section «Пілот» (acceptance criteria 1–7 live there; this brief does not restate them — read the spec section).
- The founder-decisions tracking issue (see the epic's README table) chooses the pilot news portal and answers the open questions; without it this task does not start.
- Live external sites are involved. Per `docs/agent-tasks/README.md`, an external blocker (portal unavailable, login impossible) is recorded `blocked-external` — never a mock pretending success.

## Goal

One complete campaign on real sources — the chosen news portal, a Wikipedia article set about Gdansk, 5–10 YouTube videos with manual subtitles — run locally end-to-end (collect → photos → clean → review export), with every acceptance criterion evidenced and the post-pilot questions answered for the founder.

## Scope

- Campaign file `campaigns/gdansk-2026-09.yaml` (or dated accordingly) with real seeds and video ids.
- Local run of the G17 pipeline; live runs manual, on the author's machine/profile.
- Results file with per-criterion evidence and the tool versions used (yt-dlp, Playwright, rule package versions).
- Showboat demo per `docs/agent-rules/showboat.md` (external integration + persisted data) for the local pipeline portions; live-site fetches appear as recorded outputs, not as secrets or personal data.

## Out of scope

- Publishing anything, a second city, ASR, changes to `07` or the app.

## Acceptance criteria

1. Spec `24` «Пілот» criteria 1–7: each verified in `docs/agent-tasks/results/G17.08.md` with a command, log line or file path as evidence — an unticked criterion is a finding (implementation rule 17).
2. The results file names the tool and rule-package versions actually used.
3. The results file answers the three post-pilot questions: does the rule package suffice for a second news family; is ASR needed soon (`asr-backlog` size); the final handoff format to `07`.

## Proof

The fence audit log of the pilot run shows 0 fetches outside allowed hosts (criterion 1 of the spec).
