# G17.01.b — Raw snapshot, passport, dedup, resume

## Context

- Specification: [`docs/24_web_collection.md`](../../24_web_collection.md) — sections «Пашпарт запісу (RawRecord)», «Кампанія».
- Builds on G17.01.a (schema + run loop). The raw snapshot is the archive: the site may vanish, re-collection may be impossible, so the snapshot is written generously and is never rewritten later (G17.06 cleans into new versions, never over raw).

## Goal

Given a fetched page (fixture HTML in tests — no network), the collector writes the raw snapshot per article to disk and registers a `raw_records` row with the full passport. Deduplication works on two levels: canonical URL (same page twice → one record) and content hash (same text under a new URL → a new record linked to the original, not a duplicate).

## Scope

- Snapshot layout per article: `snapshot.html`, `text.md` (extracted text with anchor links preserved as `[anchor](url)` plus the surrounding context paragraph), `metadata.json` (title, published date, author, language), empty `media/` directory.
- `raw_records` insert with all passport fields + `content_hash`.
- Dedup: `canonical_url` unique per campaign; `content_hash` marks same-text records.
- Resume: pages already snapshotted are skipped on re-run.

## Out of scope

- Fetching pages (G17.02/04/05 deliver fetchers; tests use fixtures).
- Photo download (only the empty `media/` dir here), cleaning, search.

## Acceptance criteria

1. Fixture page → snapshot files exist; an assertion checks that every anchor in `text.md` keeps its target URL.
2. Same fixture processed twice → exactly one `raw_records` row; same text under a different URL → a second row with equal `content_hash` linked to the first (no duplicated text).
3. A corrupt fixture (empty HTML, missing title) produces a diagnostic in the run log and no crash (corrupt-input rule).
4. `content_hash` is computed over bytes as stored; the test re-reads the file from disk and verifies the hash (byte-addressed content pins its environment — no silent EOL conversion).
5. All suites are wired into the default `npm test`; jscpd gate clean.

## Proof

Revert the `content_hash` dedup check → criterion 2's test fails.
