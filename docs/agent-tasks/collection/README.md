## Публікацыя ў GitHub

Целы issue — з [issues-draft.md](issues-draft.md); публікацыя адбываецца ў тым жа цыкле, што і PR са спецыфікацыяй, пасля чаго нумары з'яўляюцца ў табліцы вышэй. Пазнакі `agent:ready`/`epic`/`prio:*` ставіць толькі аператар; задачы чакаюць у backlog, пакуль іх не пазначаць. Перад публікацыяй GitHub правераны на дублікаты; усе створаныя issue перачытваюцца назад праз API, а бачнасць на дошцы dispatcher з сесіі не правяраецца (асобнай дошкі-праекту няма).
