# Пацвярджэнне брэнда і дызайн-каркас (хваля G26)

Эпік: [#764](https://github.com/vokhandcrafts/KUDY/issues/764). Падстава: [узгадненне патрабаванняў 17.10.2026](../../design/brand/2026-10-17-requirements-synthesis.md) і [візуальная прапанова 01](../../design/brand/outputs/2026-10-17-style-exploration/README.md).

Хваля [G25](../brand-design/README.md) зрабіла палітру, слоўнік, дракона, іконкі, кампаненты і экраны, але ўсе вынікі выконвалі агенты, і ўладальнік іх не пацвярджаў. G26 спачатку дае ўладальніку перагледзець кожны вынік (пацвердзіць, пацвердзіць са зменамі або адхіліць), а потым агенты пераносяць пацверджанае ў код. Атрымліваецца каркас: экраны і кампаненты, якія пазней напоўняцца маршрутамі. Рэальныя маршруты і гісторыі ў гэтую хвалю не ўваходзяць.

## Пазнака ⚠️

**⚠️ у назве задачы азначае, што задача патрабуе ўладальніка і глыбокага аналізу.** Агент бярэ яе толькі разам з уладальнікам у жывой сесіі: рыхтуе матэрыял, праводзіць уладальніка па ім і запісвае яго ўласнае рашэнне. Без уладальніка такая задача не выконваецца, нават калі ўсё астатняе гатовае. Задачы без ⚠️ агент можа выконваць сам, калі іх залежнасці закрытыя.
