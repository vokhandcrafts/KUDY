## 2. Метад і межы

- Класы ячэек: `direct-run` (не было), `official-demo` (не выяўлена даступнай без акаўнта), `documentation` (з URL+датай), `blocked` (акаўнт/ключ/аплата/кансоль недаступная).
- Крыніцы — толькі афіцыйная дакументацыя пастаўшчыкоў; маркетынгавыя сцвярджэнні пазначаныя як vendor claim і не лічацца доказам якасці.
- Незалежнага кітайкамоўнага рэцэнзента ў сесіі няма — ацэнкі прыроднасці/правільнасці не ставяцца наогул (гл. §4.6, §10).
- Недаступныя старонкі зафіксаваныя як акцэс-эвідэнцыя: міжнародны док Tencent TMT — HTTP 404; usage-арткул DeepL — bot-check; `help.aliyun.com` — SPA-абалонка без кантэнту; прайсы Qwen-MT і iFlytek — за кансоллю.
- Кітайскія ўзоры захаваныя ў JSON як `\uXXXX`-эскейпы (патэрн трэку, gitguard-праверка каммітаў); у гэтым файле — пін'ін і пераклады.

## 3. Аўдыё-кантракт KUDY — прачытана з кода main

Па правіле 2 implementation-rules: назвы капіяваныя даслоўна, крыніца заякарэнная ў тэксце; усе прапановы пазначаныя як прапановы.

| Факт | Значэнне | Крыніца |
|---|---|---|
| mime | enum `["audio/mp4", "image/webp"]` | `contracts/schemas/media.schema.json` |
| абавязковыя палі | `media_id, sha256, bytes, mime, locale, license, credit` | там жа |
| duration_s | `integer, minimum 1, maximum 86400` | там жа |
| locale enum | `["be","en","uk","de","es","fr","cs","sv"]` — **кітайскай няма** | там жа |
| шлях аўдыё | `` `${input.locale}/${tier}/audio/${story.story_id}.m4a` `` | `services/contentRepo/contentRepo.ts:201` |
| шлях у рухавіку | `` `${s.locale}/${storyTierOf(stop, storyId)}/audio/${storyId}.m4a` `` | `core/engine/reducer.ts:495` |
| індэкс | `text_locales`/`audio_locales`: `maxItems 8`, той жа enum | `contracts/schemas/discovery-index.schema.json:194-195` |
| прайгравальнік | адзіны модуль, што імпартуе `expo-audio` — адаптар порт-інтэрфейсу | `services/audio/expo/expo-audio-port.ts:1-4` |
| sha256 | па байтах файла ў LF/-text-рэжыме (`.gitattributes`, AR-1) | description media.schema.json |

Выснова для задачы: **кітайскі выпуск агучкі патрабуе папярэдняй змены кантрактаў** (locale enum, maxItems) — гэта рашэнне G21.42, не гэтай задачы. Рантайм-змен прайгравальніка задача не прапануе; playback `.m4a` expo-audio адчувае натыўна.

## 7. Валідацыя экспарту супраць кантракту KUDY

- **Выснова:** усе шэсць кандыдатаў — воблачныя і лакальныя — патрабуюць канвертацыі ў `audio/mp4`; натыўнага m4a не дае ніводзін.
- Ланцуг пілота (прапанова, не ўжыта): TTS-выхад (wav/mp3) → `ffmpeg -c:a aac -f mp4` (ffmpeg `n9.0.2` ёсць на хасце) → sha256 па байцах выніковага `.m4a` (LF/-text) → `duration_s` цэлымі секундамі → `license`/`credit` (пастаўшчык + голас + аснова правоў).
- `blocked`: сама канвертацыя і прымальнасць гуку не праганяліся — наратыву без акаўнта/аплаты няма. Дэмкі пастаўшчыкоў пацвярджаюць іх уласныя прыклады, **не** сумяшчальнасць з KUDY (паводле крытэрыя 3 брыфа).
- Для кітайскай лакаля спачатку патрэбная змена `media.schema.json` + `discovery-index.schema.json` — за межамі гэтай задачы (G21.42).
