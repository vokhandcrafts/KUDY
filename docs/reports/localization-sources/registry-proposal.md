## Стан прымянення: прыменена (2026-10-06, задача [#617](https://github.com/vokhandcrafts/KUDY/issues/617))

Задача #617 выканалася ў асяроддзі з даступным на запіс суседнім праектам Tool-Lib, таму вонкавы файл рэестра зменены. Фраза «pending» вышэй фіксуе стан на момант напісання прапановы (2026-10-05); гэты раздзел — яе датаванае абнаўленне, гісторыя захаваная без перапісвання.

- **Вонкавая змена:** `toolsLib/memory/registry/tools-registry.md` у суседнім праекце Tool-Lib (лакальны чэкаўт `/home/viktar/Projects/Tool-Lib`), каміт `a6df011823064f7ba340e11c746a6e42820526c3` ад 2026-10-06; push вонкавай рэпы гэтай задачай не рабіўся.
- **Рашэнні па радках:** AOSP — applied; Microsoft — applied; Unicode CLDR — applied; Вікіслоўнік — applied (новы радок + новы дэтальны файл `wiktionary-en-translations-2026-10-06.md`); IATE — applied.
- **Змест змены:** у чатырох існых радкоў чаканне рашэння G21.33 заменена канкрэтнымі вынікамі G21.33 (даведкавыя межы) і G21.37/#616 (імпарт адкладзены/адхілены, `import_approved=false`); да змены «рашэнне — за G21.33/#565» стаяла ў статус-ячэйцы AOSP/Microsoft/IATE, а ў CLDR той самы кантэкст быў у целе радка («прапанова FU-1 чакае рашэння G21.33»); у радку AOSP доступ апісаны праз удалае чытанне 25 XML з пінам blob-id і асобную мяжу +log→403. Ніякі інструмент не пазначаны ўсталяваным, корпус — прынятым.
- **Дэтальныя файлы:** AOSP, CLDR, Microsoft і IATE дапоўненыя датаваным блокам «Вынік G21.33 і G21.37»; копія ў `claude/` (рэестр + дэтальныя файлы) сінхранізаваная.
- **Зваротнае чытанне:** усе пяць радкоў прачытаны з файла рэестра пасля запісу; статусы засталіся «🟡 адкладзена» з канкрэтнай прычынай у кожным.
