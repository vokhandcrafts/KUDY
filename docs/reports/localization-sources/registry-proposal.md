# Прапанова зменаў агульнага рэестра крыніц

Дата: 2026-10-05. Задача прымянення: [#617](https://github.com/vokhandcrafts/KUDY/issues/617). Падстава: [параўнанне G21.33](README.md) і [рашэнні](decisions.json).

Рэестр `toolsLib/memory/registry/tools-registry.md` прачытаны; вонкавы файл не змяняўся. Дазволеныя для запісу каталогі гэтай задачы не ўключаюць toolsLib. Ніжэй — канкрэтныя радкі для ўзгаднення, а не паведамленне пра ўжо ўсталяваныя інструменты.

Перад прымяненнем зноў прачытаць рэестр: захаваць новыя незалежныя рашэнні і існыя спасылкі. Калі аднайменны радок ужо існуе, абнавіць яго, а не дадаваць другі. Справаздачы ў KUDY — першасныя ўваходы гэтай прапановы.
