Парадак звяркі вызначае сэнс паведамлення: агульная кнопка → AOSP; турыстычны тэрмін → Вікіслоўнік або IATE ў пацверджанай мове; моўная форма/лік/дата → CLDR. Адсутны або іншы сэнс не лічыцца доказам. Microsoft застаецца кандыдатам, а не абавязковым крокам пошуку.

Гэта ўваход для [G21.27/#566](https://github.com/vokhandcrafts/KUDY/issues/566): ідэнтыфікатар крыніцы, версія/URL, сэнс, дата, выбраная форма і прычына. Гэтая задача рэалізуе палітыку і яе праверкі; G21.33 не мяняе схему запісаў і не пазначае неперакладзеныя радкі праверанымі. Нявырашаная няпэўнасць блакуе публікацыю паведамлення паводле [прынятай спецыфікацыі](../../specifications/technical-completion/2026-10-03-single-source-translations.md).
