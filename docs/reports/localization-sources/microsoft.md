## 2. Што засталося ад Language Portal

Гістарычны доступ (партал www.microsoft.com/language + Terminology Service API на api.terminology.microsoft.com) больш не працуе — праверана жывымі запытамі 2026-10-04:

| Легасы-эндпойнт | Вынік |
|---|---|
| `https://www.microsoft.com/language` | HTTP 404 |
| `https://www.microsoft.com/Language/en-us/Default.aspx` | HTTP 404 |
| `https://api.terminology.microsoft.com/TerminologyService.svc` | DNS-фэйл (curl exit 6 — дамена не існуе) |

На жывых афіцыйных старонках спасылак на партал ці SOAP/REST API няма. Заява пацверджаная перш за ўсё прамой праверкай эндпойнтаў: няўдалы спосаб доступу — таксама доказ, не прабел.

### 3.2 Пошук тэрміналогіі — Power BI

Поўны токен убудовы апублікаваны вербатым на запінаванай hub-старонцы (§3) і ўстаўляецца ў спасылку аднаўльна адтуль; у рэпе ён скарочаны да `<embed-token>` — high-энтрапійны base64 у рэпасіторыі не трымаем (gitleaks зблытае яго з API-ключом).

## 4. Ліцэнзія і атрыбуцыя — прабел, які блакуе ўсынаўленне

- На ўсіх правераных жывых старонках (hub, microsoft-terminology, style-guides) **умовы выкарыстання тэрміналогіі не апублікаваныя**; архіў не змяшчае ні LICENSE, ні README, ні terms-файла (грэп па імёнах — 0 супадзенняў).
- Гістарычная ToU існавала на зачыненым партале (§2) і больш не даступная па афіцыйным адрасе.
- Ні адзін жывы афіцыйны дакумент не кажа: ці дазволена вытворнае выкарыстанне, ці патрэбная атрыбуцыя, ці ёсць абмежаванні на рэдыстрыбуцыю выразак.

Невядомасць запісана як невядомасць: перад любым уключэннем даных (нават выразкі) патрабуецца альбо знойдзеная афіцыйная ліцэнзія, альбо рашэнне ўладара. Гэта першы follow-up (§10, FU-1).

### 6.1 Станоўчыя прыклады з кантэкстам

- Кнопкавыя загалоўкі трапляюць як асобныя артыкулы з азначэннем кантэксту: Back → «Назад», Cancel → «Адмена», Settings → «Налады».
- Дзеяслоўныя пары выдатныя: download → «спампаваць», stop → «спыніць», restore → «аднавіць» — з азначэннямі, якія нясуць сэнс (у restore два артыкулы: вяртанне з рэзервовай копіі і вяртанне ў пачатковы стан).
- Сэнсавае размежаванне працуе: guide → «гід» толькі ў сэнсе экраннай панэлі (Xbox), «інструкцыя» — у сэнсе выраўноўвальнай лініі. Для KUDY-сэнсу «аўдыягід па горадзе» запісу няма; бліжэйшы — «гід».

### 6.2 Неаднароднасці і mismatches (ценнасць даных — і мяжа даверу)

- **unavailable**: адно і тое самае азначэнне («state of a control in which normal functionality is not available») суправаджаецца дзвюма рознымі перакладамі — «недаступны» і «адключаны». Аднолькавы сэнс — розныя словы.
- **download**: адзін назоўнік ідзе ў двох правапісных варыянтах — «спампоўванне» і «спампаванне» — у розных артыкулах з аднолькавым азначэннем.
- **Downloads Marketplace** → «Крама Office»: пераклад назвы прадукту, не літаральны — правіла «шукай літаральны адпаведнік» па гэтай калекцыі не працуе для назваў.
- **purchase**: дакладнага артыкула няма, а складанні даюць два розныя дзеясловы («купля», «аплаціць»); purchaseid → бяз перакладу.
- **walk**: толькі навігацыйны сэнс; турыстычнай прагулкі ў калекцыі няма.
- Яккасць дадзеных: у артыкуле `25472_1176798_2072187` (drawing guide) беларускі тэрмін захоўвае лацінскую літару ўнутры кірылічнага слова — змешаны скрыпт усярэдзіне саміх даных (айді зафіксаваны ў маніфесце, токен тут не узнаўляецца, каб не псуць скрыпт-сканы).

Абмежаванне метаду: батарэя прагнаная па беларускім файле; іншыя 110 моўных файлаў, акрамя структуравага прагляду пераліку, не агледжаныя; UI-радкі ў бэнчмарк не трапляюць, бо недаступныя як даныя (§7).

## 7. Разрозненне: тэрміналогія ≠ UI-радкі

Калекцыя — тэрмін-цэнтрычны глосарый: артыкула «тэрмін + азначэнне + граматыка», а не слот прадукту з гатовай фразай. Кнопкавыя словы трапляюць таму, што іх узялі ў глосарый як тэрміны, а не таму, што калекцыя імітуе набор радкоў. UI-радкі існуюць у Microsoft як асобны пласт, але іх канал — толькі інтэрактыўны Power BI (§3.3): не пінаваны, не рэпрадуцыраваны скрыптам, без хэшаў. Для генерацыі набораў паведамленняў KUDY гэты пласт непрыдатны; для чалавечага перавяркі тэрмінаў — прыдатны.

## 8. Кошт падтрымання

- Кожнае абнаўленне — 168 МБ; выразка адной мовы — 8,8 МБ; парсінг просты (плоскі XML TBX-Basic, стандартны парсер).
- **Версійнага механізму няма**: URL пастаянны, змесціва мяняецца на месцы; пін можа толькі sha256 + Last-Modified + ETag (як у маніфесце). Пры змене піна без перазапуску верыфікацыі змены нябачныя.
- Кадэнцыя невядомая: вонкавы Last-Modified (2025-02-06) і ўнутраныя даты файлаў (2024-11-06) фіксуе мінімум адзін рэліз, рэгулярнасць — невядомасць.
- Жыццёвы цыкл старонак рассінхранізаваны: hub абнаўлены 2023-06-29, старонка тэрміналогіі — 2024-05-02, стыль-гайды — 2025-05-02. Заява «nearly 100 languages» на hub ужо расходзіцца з фактам (111).

## 9. Назіранні і рэкамендацыі — асобна

**Назіранні (факты гэтага прагону):** усе пункты §3–§8 з лакатарамі і камандамі ў [microsoft-evidence.json](microsoft-evidence.json).

**Рэкамендацыі (прапановы, не рашэнні):**
- Тэрміналогію Microsoft варта разглядаць як **даведкавы глосарый для чалавека** — пераверка тэрмінаў пры напісанні гідаў, крыніца кандыдатаў тэрмінаў, а не як аўтаматычную крыніцу строк для набораў паведамленняў.
- **Ліцэнзійны статус — блокер любога ўсынаўлення**: да яго разавытку нават чытанне выразак у рэпу нельга лічыць усынаўленнем.
- Стыль-гайды (беларускі PDF ёсць) — асобны чалавечы рэсурс; іх прымяненне да мовы гідаў — рашэнне G21.33/уладара.
- Перад устаноўкай якога-небудзь інструмента — спачатку рэестр інструментаў (прагледжаны; запіс аб калекцыі дададзены асобна па-за гэтым рэпазіторыем).

## 10. Чарнавікі follow-up для G21.33

### FU-1. Запыт рашэння: прававы статус Microsoft Terminology Collection

- **Вынік:** дакументаванае рашэнне ўладара (або знойдзеная афіцыйная ліцэнзія) пра магчымасць выкарыстання даных калекцыі ў KUDY — як для чытання, так і для ўсялякіх выразак.
- **Падстава:** ні адна жывая афіцыйная старонка і ні адзін файл архіва не публікуе ўмоваў выкарыстання; гістарычная ToU згубленая разам з парталам (§4).
- **Вынік можа быць:** дазвол/адмова/адкладанне да знанняліцэнзійнага пытання — любы з іх завяршае follow-up, задачу-канектар ствараць не трэба.
- **Спасылка:** гэтая справаздача (§4) і маніфест.
- **Статус:** патрабуе рашэння ўладара праз G21.33.

### FU-2. Прапанова (умоўная): пінаваная be-тэрміналогія як даведкавы глосарый

- **Вынік:** выразанае падмноства беларускіх тэрмін-пар (пін sha256 + Last-Modified) даступнае для праверкі тэрмінаў пры напісанні гідаў; тэрміны-кандыдаты параўноўваюцца з глосарыем тэстам.
- **Абсяг:** скрыпт выразкі чытае пінаваны TBX і выдае толькі зацверджаныя палі (en → be + POS); у рэпу трапляе выразка, не 8,8 МБ крыніцы; бяз устаноўкі MCP, акаўнтаў, аплатаў.
- **Залежнасці:** Blocked-by FU-1 (ліцэнзія) і G21.24 (кананічныя запісы) — уключаць у ланцуг пасля іх.
- **Правяраемыя крытэрыі:** (1) пін зафіксаваны ў маніфесце; (2) скрыпт узнавіты: той жа пін → тая ж выразка; (3) тэст падае пры змене піна без абнаўлення маніфесту; (4) у рэпу не трапляе нічога па-за зацверджанымі палямі выразкі.
- **Доказ:** каманда прагону тэсту, якая падае пры адкату піна.
- **Спасылка:** гэтая справаздача (§5–§6) і маніфест.
- **Статус:** прапанова; стае FU-1 паміж прапановай і ўсялякай рэалізацыяй.

### FU-3. Зафіксаванае адмоўнае: UI-радкі Microsoft як крыніца набораў паведамленняў

- **Вынік:** не разглядаць UI-радкі Microsoft як крыніцу генерацыі натыўных/вэб-набораў KUDY; задача-канектар на «імпарт UI-радкоў» не ствараецца.
- **Падстава (з гэтага прагону):** масавай загрузкі UI-радкоў на жывых старонках няма; адзіны канал — інтэрактыўны Power BI без праграмнага доступу (§3.3, §7) — немагчыма запінаць і рэпрадуцыраваць.
- **Статус:** адмова з падставай — рашэнне за G21.33/уладаром; пры з'явы афіцыйнай загрузкі UI-радкоў патрабуецца новае даследаванне.

## 11. Нявырашанае і нязробленае

- Ліцэнзійны статус калекцыі — не вызначаны (гэта прадмет FU-1, не гэтай справаздачы).
