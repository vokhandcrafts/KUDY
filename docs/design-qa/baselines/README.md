# Узоры (baselines) visual:check

Піксельныя ўзоры матрыцы V1 (спец §8.1): светлая тэма × шрыфт 1 / 1.5 × мова
`be`. Адзін файл = адзін слот матрыцы: `<паверхня>@font<маштаб>-<мова>.png`.
Паверхні: чатыры гісторыі карткі гіда праз экран узораў
(`kudy:///dev-specimen?component=guide-card&story=<назва>`, DQ-02/DQ-03) і
экран Explore у дзвюх фазах (`explore-a` — без каталога, `explore-b` — з
фікстурным каталогам G23.01).

## Як яны знятыя

- Тул: `npm run visual:check -- --update` (DQ-03) — адзіны спосаб змены гэтай
  тэчкі. Ручная праўка або замена файлаў забароненая: узор без прыгоджанага
  запісу паходжання не ўзор.
- Асяроддзе: AVD `kudy-ci` (рэпліка дакладнай каманды
  `.github/workflows/android-e2e.yml`), API 36, swiftshader_indirect, адзін
  эмульятар у сістэме; анімацыі 0; статусбар выключаны ў параўнанні (crop
  верхніх 100 px, DQ-01); дэма-рэжым SystemUI не выкарыстоўваецца.
- Паходжанне першай здымкі: 2026-11-01, змена DQ-03 (issue #913), коміт
  чытання крыніц `9ec83904`, APK dev-кліента SHA-256
  `f7e30d0f8b56c571…` (поўны ў `manifest.json` прагону).

## Статус

Узоры знятыя рэплікай CI-профілю лакальна; эквівалентнасць «лакальны host ↔
CI runner» не вымераная (DQ-01), таму эталонам лічыцца CI: уручным запуску
workflow артэфакт PNG спампоўваецца і камітуецца праз
`visual:check --update --from <тэчка>`. Ухваляе ўладальнік (DQ-04, issue
#915) — да таго ўзоры маюць статус «пендынг».
