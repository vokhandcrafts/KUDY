## Галоўны прынцып

KUDY дапамагае адкрываць і разумець горад вачыма аўтара. Прагулкі — адзін спосаб; практычныя гарадскія рубрыкі могуць існаваць без маршруту. Іх платнасць не вырашаная.

## Галоўны сцэнар

Прыехаў у горад → хачу зразумець, што тут цікава → выбіраю, куды пайсці → выбіраю ўласны шлях, KUDY прапануе кантэкст → па дарозе адкрывае гісторыі → ем / гляджу / даведваюся → запамінаю дзень.
