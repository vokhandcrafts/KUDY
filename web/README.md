# Вэб-канал KUDY — каркас G10.01.a

Другі чытальнік тых самых версіяваных бандлаў, што і дадатак (`route × version × locale × tier`),
толькі бясплатны пласт. Асобнай крыніцы кантэнту ў вэба няма. План:
[2026-09-16-web-audio-version](../docs/plans/2026-09-16-web-audio-version.md).

## Рашэнне пра стэк

**Next.js + TypeScript** (App Router, статычная генерацыя праз `output: 'export'`), пацверджанае
заснавальнікам 2026-09-17 перад скафолдам — у плане стэк быў толькі прапановай. Хостынг на Vercel
ужо прыняты ў плане; сама публікацыя — G10.02.b.

## Што ўжо ёсць

- `lib/content/` — тыпізаваныя чытальнікі public-пласту: каталог, discovery-індэкс, route,
  base-гісторыі, previews, public-праекцыі. Кожны JSON правяраецца супраць сваёй схемы ў
  `contracts/schemas/` праз супольны `contracts/reader.mjs` (адна крыніца інтэрпрэтацыі схем —
  загаловак reader.mjs). Невядомая `schema_version` — вызначанае бяспечнае адхіленне, не частковы рэндэр.
- `lib/content/leak-guard.ts` — незалежная пераверка ўваходу вэб-зборкі: сегменты
  `private`/`extended`/`..` у шляхах, `*.map` у public, 8-слоўныя n-грамы прыватнага наратыву
  (`text`/`transcript`) у public-радках. Коды памылак — тыя ж класы, што ў зборшчыка:
  `private-path-in-public`, `source-map-in-public`, `private-text-leak`.
- `lib/app-links.ts` — адзіны канфіг пераходу ў дадатак; store-спасылкі — плейсхолдары, трапы
  трапляюць на `/app` (G10.02.a замяніць на рэальныя).
- `app/` — мінімальны скелет без прадуктовых старонак; каталог/гід/кропкі — G10.01.b/.c.

## Як запускаць

```sh
cd web && npm install
npm run build        # статычны export у web/out/
```

Тэсты — з кораня рэпазіторыя (`npm test`); suite `web/lib/content/*.test.ts` ідзе праз
`node --experimental-strip-types`. Згенераванае дрэва кантэнту кладзецца ў `web/content/`
(gitignored); тэсты збіраюць свой бандл у часоваю тэчку праз злітую зборшчыку `tools/build-bundle`.

## Межы

Толькі public-пласт, без акаўнтаў, аналітыкі, сервернага стану і web-checkout (09 §17).
Вэб не мутуе бандлы; версіяванне і pointer update — G02.04. Ніякай прыватнай байты ў зборцы:
прыватнае дрэва гард выкарыстоўвае толькі як эталон n-грам падчас зборкі, у публічны выхад яно
не трапляе.
