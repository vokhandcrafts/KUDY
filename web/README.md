# Вэб-канал KUDY — каркас і старонкі (G10.01.a/.b)

Другі чытальнік тых самых версіяваных бандлаў, што і дадатак (`route × version × locale × tier`),
толькі бясплатны пласт. Асобнай крыніцы кантэнту ў вэба няма. План:
[2026-09-16-web-audio-version](../docs/plans/2026-09-16-web-audio-version.md).

## Рашэнне пра стэк

**Next.js + TypeScript** (App Router, статычная генерацыя праз `output: 'export'`), пацверджанае
заснавальнікам 2026-09-17 перад скафолдам — у плане стэк быў толькі прапановай. Хостынг на Vercel
ужо прыняты ў плане; сама публікацыя — G10.02.b.

## Што ўжо ёсць

- `lib/content/` — тыпізаваныя чытальнікі public-пласту: каталог, discovery-індэкс, route,
  base-гісторыі, previews, public-праекцыі. Кожны JSON правяраецца супраць сваёй схемы ў
  `contracts/schemas/` праз супольны `contracts/reader.mjs` (адна крыніца інтэрпрэтацыі схем —
  загаловак reader.mjs). Невядомая `schema_version` — вызначанае бяспечнае адхіленне, не частковы рэндэр.
- `lib/content/leak-guard.ts` — незалежная пераверка ўваходу вэб-зборкі: сегменты
  `private`/`extended`/`..` у шляхах, `*.map` у public, 8-слоўныя n-грамы прыватнага наратыву
  (`text`/`transcript`) у public-радках. Коды памылак — тыя ж класы, што ў зборшчыка:
  `private-path-in-public`, `source-map-in-public`, `private-text-leak`.
- `lib/app-links.ts` — адзіны канфіг пераходу ў дадатак; store-спасылкі — плейсхолдары, трапы
  трапляюць на `/app` (G10.02.a замяніць на рэальныя).
- `lib/i18n/` — радкі інтэрфейсу `be` + `en` (09 §8: ніводнага зашытага радка; тэст парытэту
  ключоў трыма абодва файлы ў адным наборы).
- `lib/content/site.ts` — зборка дадзеных старонак з public-пласту; любое вызначанае адхіленне
  (разарваны паказальнік, невядомая версія) кідае `SiteDataError` і руйнуе зборку — пустыя
  старонкі немагчымыя. View-мадэлі паўтараюць палі кантракту даслоўна; вытворныя (href,
  languages, stop_count) аб'яўленыя як вытворныя.
- `components/` + `app/` — каталог горада (`/`, `/en`) і старонка гіда (`/guides/<route_id>`,
  `/en/guides/<route_id>`): рэальныя запісы з каталогу + discovery-індэкса, замочаныя кропкі як
  замочак + `name` + `announce` з `previews.json`, адзін спакойны блок цаны ўнізе праз
  `lib/app-links.ts`. `be` — дэфолтная локаль у корані, `en` — прэфіксам (план §4).
- `scripts/` — прэбілд кантэнту (`build-content.ts`: дэма-фікстура праз зборшчык + interim
  `catalog.json`, рэальную публікацыю рабіць будзе G02.04) і `scan-rendered.ts` — leak-scan
  адрэндэранага export-у пасля `next build` (крок 6 G10.01.b).
- Старонка статычнай мапы горада (крок 3 G10.01.b) яшчэ не зробленая: тайл-правайдар —
  рашэнне фаундара (план §3), пытанне зададзена; **запіс «Мапа горада» схаваны** да рашэння
  (TR-8 дак. 23, 2026-09-20: мёртвы лінк на будучы `/map` — найгоршы з варыянтаў; guard-тэст
  унутраных href-аў не дасць яму вярнуцца неўсвядомліва).
  *(2026-09-21, рэзалюцыя: фаундар зафіксаваў OpenFreeMap — `lib/map-config.ts`, адзінае месца
  тайл-URL-аў; карта зроблена — `/map`, `/en/map` на MapLibre GL JS, маркеры з `places.json`
  бандла, серверная ODbL-атрыбуцыя; запіс карты вернуты ў каталог. Гл.
  `docs/agent-tasks/results/G10.01.b.md` і дэму `2026-09-21-g1001b-web-city-map.md`.)*
- `app/` — каталог горада і старонка гіда (гатова з G10.01.b); кропкі і вэб-аўдыё — G10.01.c.
  *(2026-09-20, TR-9 дак. 23: папярэдні радок «мінімальны скелет без прадуктовых старонак»
  быў састарэлы — старонкі ідуць з G10.01.b.)*
- `components/{stop-page,manual-audio-player}.tsx` + `app/{,en/}guides/[route_id]/stops/[stop_id]/`
  + `app/not-found.tsx` — старонкі кропак (G10.01.c): серверны транскрыпт гісторыі, ручны
  плэер на стандартным `<audio controls preload="none">` без аўтастарту, аўдыё па факце —
  адзін элемент на кожную локаль бандла, у якой базавы аудыёфайл сапраўды існуе;
  адсутнасць аўдыё — пазначаны стан з даступным тэкстам, не цішыня. Замочаная кропка нясе
  толькі публічнае прэв'ю: аўдыё і транскрыпт у яе дадзеных адсутнічаюць на ўзроўні формы.
  Prev/next па
  `RouteStop.position` — толькі рэкамендаваны парадак паказу; схема URL стабільная для
  будучых deep links (09 §13 M7). Невядомы URL — статычная 404-старонка «Версія
  недаступная». Люстэрка аседаў для аўдыё: prebuild капіруе public-дрэва ў
  `web/public/content/` (gitignored; адзіны пункт мапінгу URL — `CONTENT_ASSET_BASE` у
  `lib/content/site.ts`). Без захавання стану: няма `'use client'`, localStorage,
  кукаў і аналітыкі (гард у `lib/content/stop-page.test.ts`).
  *(гл. `docs/agent-tasks/results/G10.01.c.md` і дэму `2026-09-21-g1001c-stop-pages.md`.)*
- `lib/map-config.ts` + `components/{map-page,city-map}.tsx` + `app/{,en/}map/` — статычная
  карта (крок 3): OpenFreeMap як запісаны правайдар (рашэнне фаундара 2026-09-21), пары
  `places.json` бандла, `[lng, lat]` GeoJSON з чытальніка, без узаемадзеяння маркераў;
  чытальнік геа-фактаў — `readBundlePlacesGeo` над `bundle/<route_id>/<version>/places.json`.

## Як запускаць

```sh
cd web && npm install
npm run build        # прэбілд кантэнту → статычны export у web/out/ → leak-scan рэндэру
```

Тэсты — з кораня рэпазіторыя (`npm test`); suite `web/lib/content/*.test.ts` ідзе праз
`node --experimental-strip-types`. Згенераванае дрэва кантэнту кладзецца ў `web/content/`
(gitignored); тэсты збіраюць свой бандл у часоваю тэчку праз злітую зборшчыку `tools/build-bundle`.

## Межы

Толькі public-пласт, без акаўнтаў, аналітыкі, сервернага стану і web-checkout (09 §17).
Вэб не мутуе бандлы; версіяванне і pointer update — G02.04. Ніякай прыватнай байты ў зборцы:
прыватнае дрэва гард выкарыстоўвае толькі як эталон n-грам падчас зборкі, у публічны выхад яно
не трапляе.
