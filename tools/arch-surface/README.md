# arch-surface — жывы зрэз паверхні модуля

`node tools/arch-surface/arch-surface.mjs <dir>` друкуе для заданай дырэкторыі
яе зыходныя файлы, іх экспарты і знешнія імпарты — як просты тэкст, які можна
уклеіць у промпт. Гэта **згенераваныя жывыя факты** з рэальнага кода; іх месца
— побач з [19](../../docs/architecture/19_class_and_module_map.md), **не**
замест яго: 19 — праектаваная мапа, гэты зрэз трымае рэв'ю сумленным наконт
дрэйфу паміж мапай і кодам.

## Вывад

```
# arch-surface: core/discovery

## selectDiscovery.ts
exports: DiscoveryCollection, …, selectDiscovery
imports: (none)
```

Файлы, экспарты і імпарты сартуюцца па кодавых кропках; часовых метак няма —
два запускі над тым самым кодам даюць байт-у-байт аднолькавы тэкст. Шляхі —
скосныя рысы, адносна сканаванай дырэкторыі. Скрыпт чытае толькі `node:fs` і
`node:path` і не мае залежнасцяў.

## Што лічыцца знешнім імпартам

| Спецыфікатар | Сэнс | У вывадзе |
|---|---|---|
| `node:fs`, `node:fs/promises` | убудаваныя модулі | так |
| голы пакет (`react`, `expo-location`) | npm-залежнасць | так |
| `../x` — адносны, што выходзіць з дырэкторыі | мяжа модуля ўверх | так |
| `./x` — адносны ўсярэдзіне дырэкторыі | унутраная структура (файл і так у спісе) | не |

Скануюцца пашырэнні `.ts .tsx .mts .cts .js .jsx .mjs .cjs`; тэчкі-ўваходы
(`.`-файлы) і `node_modules` прапускаюцца.

## Эўрыстыка: здабыванне парадковае, не парсінг

Здабыванне — **радковае і эўрыстычнае**: рэгэкспы па радках кода, без
TypeScript-парсера. Абвешчаныя мяжы эўрыстыкі:

- `export { … }` і `import type { … }` бачацца толькі ў межах аднаго радка;
  шматрадковы спіс у фігурных дужках экспартных імёнаў не сабярэцца (шматрадковы
  `import type { … } from '…'` працуе, бо спецыфікатар шукаецца ў радку `from`);
- `export` не з пачатку радка (усярэдзіне функцыі ці неймспэйсу) не здабываецца;
- радок-каментар з тэкстам `from '…'` дае хлушчавы імпарт;
- `./../x` лічыцца ўнутраным, хоць фактычна выходзіць з дырэкторыі.

Крытэр правільнасці — не паўната парсера, а **рукаверка**: параўнанне вываду з
кодам запісана ў
[results G18.03](../../docs/agent-tasks/results/G18.03.md) для
`core/discovery` і `services/contentRepo`. Калі патрэбныя гарантавана
поўныя факты — беры dependency-cruiser (`npm run arch:check`,
[tools/arch](../arch/README.md)); гэты скрыпт пра іншае: хуткі тэкставы зрэз
паверхні адной дырэкторыі.

## Тэст

`node --test tools/arch-surface/arch-surface.test.mjs` — фікстуры ў
`fixtures/` (фэйкавыя спецыфікатары `fake-*` наўмысна: скрыпт чытае тэкст і
ніколі не вырашае модулі), поўны snapshot вываду, праверка дэтэрмінаванасці і
дыягностыкі на псаваным уводзе. Suite падключаны ў glob `npm test`; пры згубе
запісу красіцца `tools/ci/check-required-checks.mjs`.
