# Фікстуры інструмента праверкі аўдыё (G03.03)

`be/base/` — мінімальны станоўчы пакет: два standard-стылі гісторыі з рэальнымі
запісамі, нармалізаванымі да мэты −16 LUFS (09 §6, радок `audio`: «Гучнасць начытанага
нармалізуецца (мэта −16 LUFS)»). Тулінг — `tools/validate/verify-audio.mjs`;
структурныя медыя-правілы (missing-media, orphan-media) гэты пакет не цікавяць —
імі валодае `validate-package`.

`cases/` — асобныя запісы для адмоўных сцэнараў тэстаў:

| Файл | Integrated loudness | Сцэнар |
|---|---|---|
| `loud.m4a` | ≈ −6.1 LUFS | адхіленне ад мэты > 2 LU → `loudness-target-deviation` |
| `spread-a.m4a` | ≈ −14.5 LUFS | пара з `spread-b`: розніца 3 LU → `loudness-spread` |
| `spread-b.m4a` | ≈ −17.5 LUFS | абодва ў межах толерансу ад −16, таму сцэнар ізаляваны |

Запісы згенераваныя аднойчы праз `ffmpeg … loudnorm=I=…` і закамічаныя як
сталыя байты (`fixtures/content/** -text` у `.gitattributes`), таму вымярэнні
ўспроізводзяцца на любым чэкаўце. Абодва запісы `be/base/audio` маюць
`duration_s` 2 і 3 — кароткія для тэсту, таму справаздача мае два
`duration-guideline` (інфармацыйныя, 13 §3: «Пачатковы арыенцір аднаго аўдыё —
60–120 секунд», дыягностыка, не забарона).
